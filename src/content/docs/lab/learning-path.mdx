목표로 삼은 백과 문서까지 필요한 선수 개념을 역방향으로 탐색해 중복 없는 읽기 순서를 만든다. 현재 수준, 최대 분량, 이론·실무 초점과 수학 문서 포함 여부를 조정할 수 있다.

## 계산 기준과 가정

입문은 확인된 선수 관계를 깊이 제한 없이 탐색한다. 중급은 목표에서 6단계, 전문은 3단계 이내의 선수 문서를 확인하며 그보다 기초적인 내용은 이미 익힌 것으로 가정한다. 최대 문서 수를 넘으면 목표와 가까운 선수 문서를 먼저 남기고, 이론·실무 초점은 같은 거리의 후보를 정렬할 때 사용한다.

선수 관계 충족률은 선택한 수준과 수학 포함 조건에서 확인된 선수 문서 가운데 실제 경로에 남은 문서의 비율이다. 이는 학습 성취도나 이해도를 측정하는 점수가 아니다.

## 데이터와 출처

경로는 AI Learning Wiki의 [전체 문서 관계 인덱스](/special/all-pages/)와 16개 [Wiki 학습 코스](/paths/)를 사용해 브라우저에서 계산한다. 문서 제목, 선수 문서, 관련 문서와 코스 연결이 바뀌면 다음 사이트 빌드에서 경로 데이터도 함께 갱신된다.

입력한 목표와 조건은 외부 서버로 전송하거나 저장하지 않는다. 공유 주소에는 문서 ID와 선택 조건만 포함되며 별도의 개인정보를 넣지 않는다.

## 사용 시 주의사항

자동 생성 경로는 위키에 등록된 선수 관계를 바탕으로 한 권장안이다. 특정 업무나 연구에 필요한 모든 지식을 보장하지 않으며, 생략된 기초나 최신 문서는 결과 아래의 가정과 알림을 확인해 보완해야 한다.
