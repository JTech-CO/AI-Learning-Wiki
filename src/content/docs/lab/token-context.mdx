모델 호출의 문맥 창은 사용자 질문만 차지하지 않는다. 시스템 지시, 도구 정의와 실행 결과, 검색 문맥, 메시지 래퍼와 생성할 출력이 같은 예산을 나눠 쓴다. 이 계산기는 각 계층을 분리해 입력 예산과 비용 상한을 검토한다.

## 계산 범위

토큰 수는 실제 모델 토크나이저를 내려받지 않고 문자 종류와 토크나이저 계열별 비율로 추정한다. 따라서 공급자의 정확한 사용량·청구값이 아니라 설계 단계의 비교값이다. 각 비어 있지 않은 메시지 계층에는 역할·구분자용 래퍼 4토큰을 더하고 요청 전체 래퍼 3토큰을 더한다.

입력 예산은 `문맥 창 - 출력 예약량 - 안전 여유분`이다. 예상 입력이 이 값을 넘으면 초과 토큰을 표시한다. 비용은 사용자가 입력한 백만 토큰당 단가에 예상 입력과 예약 출력 상한을 곱한 뒤 배치 크기와 반복 호출 수를 반영한다. 가격은 자동 조회하지 않는다.

문맥 프리셋은 특정 모델 지원을 보증하지 않는 비교용 크기다. 프리셋 버전과 확인일을 결과에 함께 표시하고 실제 적용 전에는 모델의 공식 문맥 한도와 토크나이저, 가격표를 다시 확인해야 한다. 계산 공식은 `token-context-budget-v1`, 프리셋 확인일은 2026-08-30이다.

## 개인정보와 한계

텍스트와 계산 결과는 브라우저 안에서만 처리하며 서버로 전송하거나 저장하지 않는다. 공유 주소에는 프리셋·문맥·단가 설정만 포함하고 입력 텍스트는 포함하지 않는다. 민감한 운영 프롬프트를 사용해야 한다면 오프라인 환경과 조직의 정보 처리 정책도 함께 확인해야 한다.
