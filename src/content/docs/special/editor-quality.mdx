편집 품질 대시보드는 AI Learning Wiki의 공개 콘텐츠와 품질 정책을 같은 기준일에 집계한 읽기 전용 화면이다. 문서의 정확성을 자동으로 단정하지 않고, 편집자가 먼저 살펴볼 항목과 출시를 막는 구조 오류를 구분한다.

<EditorQualityDashboard />

## 운영 원칙

대시보드 수치는 저장소의 문서, 출처 확인 기록, 코스, 자료실과 정적 빌드 결과에서 결정론적으로 생성한다. 검색과 필터는 브라우저 안에서만 처리하며 입력 내용을 전송하거나 저장하지 않는다.

재검토 기한이 가까운 문서는 아직 검토 기한을 넘긴 문서가 아니다. 빠르게 변하는 모델·API·운영 기술을 정해진 주기에 맞춰 다시 확인하기 위한 계획 대기열로 해석해야 한다. 자동 검사는 문서 구조와 연결 상태를 찾는 보조 수단이며, 주장과 출처가 실제 문맥에 맞는지는 편집자가 최종 판단한다.
