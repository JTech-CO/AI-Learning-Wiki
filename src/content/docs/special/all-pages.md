---

현재 검토 완료된 백과 문서는 **155개**입니다.

- [가드레일](/wiki/guardrail/) — 모델 입력·출력·도구 실행을 검사하고 위험 행동을 제한하는 정책과 기술이다.
- [가중치](/wiki/weight/) — 입력 신호가 출력에 미치는 상대적 크기를 조절하며 학습되는 파라미터다.
- [간접 프롬프트 인젝션](/wiki/indirect-prompt-injection/) — 모델이 읽는 웹·문서·메일·도구 결과 같은 외부 데이터에 악성 지시를 숨겨 애플리케이션의 행동을 바꾸려는 공격이다.
- [강화학습](/wiki/reinforcement-learning/) — 에이전트가 환경과 상호작용하며 누적 보상을 높이는 행동 정책을 학습하는 방식이다.
- [개인정보 보호](/wiki/privacy/) — AI 시스템이 개인 데이터를 수집·처리·저장·공개할 때 권리와 위험을 관리하는 원칙이다.
- [검색 증강 생성](/wiki/rag/) — 외부 자료를 검색해 그 결과를 생성 모델의 문맥으로 제공하는 구조다.
- [검색기](/wiki/retriever/) — 질의와 관련된 문서나 청크 후보를 저장소에서 찾는 구성 요소다.
- [경사하강법](/wiki/gradient-descent/) — 손실 함수의 기울기 반대 방향으로 파라미터를 반복 갱신하는 최적화 방법이다.
- [계획](/wiki/planning/) — 목표를 하위 단계와 실행 순서로 분해하고 필요에 따라 계획을 수정하는 과정이다.
- [관측성](/wiki/observability/) — 로그·메트릭·추적 정보로 시스템 내부 상태와 실패 원인을 이해할 수 있는 정도다.
- [광학 문자 인식](/wiki/ocr/) — 이미지 속 글자의 위치와 내용을 판독해 텍스트로 변환하는 기술이다.
- [구조화 출력](/wiki/structured-output/) — 모델 출력을 미리 정의한 JSON 스키마나 데이터 구조에 맞추는 기능이다.
- [그리디 디코딩](/wiki/greedy-decoding/) — 매 단계에서 확률이 가장 높은 토큰을 선택하는 결정적 생성 방식이다.
- [근거화](/wiki/grounding/) — 모델 출력을 제공된 자료나 검증 가능한 외부 사실에 연결하는 방법이다.
- [근사 최근접 이웃 검색](/wiki/approximate-nearest-neighbor/) — 정확도를 일부 양보하고 대규모 벡터 검색 속도를 높이는 알고리즘 계열이다.
- [기울기](/wiki/gradient/) — 여러 변수에 대한 함수 변화율을 모은 벡터로, 손실을 줄이는 방향을 알려준다.
- [다음 토큰 예측](/wiki/next-token-prediction/) — 이전 토큰들이 주어졌을 때 다음 토큰의 확률 분포를 예측하는 학습 목표다.
- [대규모 언어 모델](/wiki/large-language-model/) — 대규모 데이터와 많은 파라미터로 학습해 다양한 언어 과제를 수행하는 언어 모델이다.
- [데이터 증강](/wiki/data-augmentation/) — 기존 예시를 변형하거나 합성해 학습 데이터의 다양성을 높이는 방법이다.
- [데이터셋](/wiki/dataset/) — 특정 분석이나 학습 목적에 맞춰 구조화하고 관리하는 데이터의 모음이다.
- [도구 호출](/wiki/tool-calling/) — 모델이 정해진 함수 스키마를 선택하고 인수를 생성해 외부 기능 실행을 요청하는 방식이다.
- [디코더](/wiki/decoder/) — 이전 출력과 문맥을 이용해 다음 출력을 순차적으로 생성하는 구성 요소다.
- [디코더 전용 모델](/wiki/decoder-only-model/) — 인과적 어텐션을 사용하는 디코더 블록만으로 다음 토큰을 생성하는 모델이다.
- [딥러닝](/wiki/deep-learning/) — 여러 처리 층을 가진 신경망이 데이터에서 단계적인 표현을 학습하도록 훈련하는 머신러닝 접근이다.
- [레이어 정규화](/wiki/layer-normalization/) — 한 샘플 내부 특성의 분포를 정규화해 학습과 추론을 안정화하는 연산이다.
- [로짓](/wiki/logit/) — 확률로 정규화하기 전 모델이 각 클래스나 토큰 후보에 내놓는 실수 점수이며, 이항 문제에서는 로그 오즈로 해석된다.
- [리랭커](/wiki/reranker/) — 초기 검색 후보를 질의 관련성 기준으로 다시 정렬하는 모델이나 규칙이다.
- [머신러닝](/wiki/machine-learning/) — 명시적으로 모든 규칙을 작성하지 않고 데이터에서 패턴을 학습해 예측이나 결정을 수행하는 인공지능의 한 분야다.
- [멀티 에이전트 시스템](/wiki/multi-agent-system/) — 역할이 다른 여러 에이전트가 협력하거나 경쟁하며 문제를 해결하는 시스템이다.
- [멀티모달 모델](/wiki/multimodal-model/) — 텍스트·이미지·음성·영상 등 둘 이상의 데이터 양식을 함께 처리하는 모델이다.
- [멀티모달 임베딩](/wiki/multimodal-embedding/) — 서로 다른 데이터 양식을 비교 가능한 하나의 벡터 공간에 배치한 표현이다.
- [멀티헤드 어텐션](/wiki/multi-head-attention/) — 여러 어텐션 헤드가 서로 다른 관계를 병렬로 학습하도록 구성한 연산이다.
- [모델](/wiki/model/) — 입력을 출력으로 변환하도록 데이터에서 학습된 수학적 함수와 파라미터의 집합이다.
- [모델 라이선스](/wiki/model-license/) — 모델 가중치·코드 등 배포물의 사용·수정·재배포 조건을 정한 법적 약정이다. 일부 약정은 출력과 파생 모델의 이용 조건도 별도로 규정한다.
- [모델 레지스트리](/wiki/model-registry/) — 학습된 모델 버전과 메타데이터·검증 상태·배포 참조를 중앙에서 추적하고 관리하는 수명주기 시스템이다.
- [모델 컨텍스트 프로토콜](/wiki/mcp/) — AI 애플리케이션이 외부 도구와 데이터 소스를 표준 방식으로 연결하도록 정의한 프로토콜이다.
- [모델 평가](/wiki/evaluation/) — 정해진 데이터·기준·절차로 모델이나 시스템의 품질과 위험을 측정하는 과정이다.
- [모델 허브](/wiki/model-hub/) — 모델·데이터셋·데모·평가 정보를 검색하고 배포하는 공유 플랫폼이다.
- [미분](/wiki/derivative/) — 입력의 작은 변화에 따라 함수 값이 얼마나 변하는지를 나타내는 연산이다.
- [미세조정](/wiki/fine-tuning/) — 사전학습 모델을 특정 데이터와 목적에 맞게 추가 학습하는 과정이다.
- [바이트 페어 인코딩](/wiki/byte-pair-encoding/) — 자주 함께 나타나는 기호 쌍을 반복 병합해 서브워드 어휘를 만드는 방식이다.
- [배치](/wiki/batch/) — 한 번의 순전파와 역전파에서 함께 처리하는 데이터 예시의 묶음이다.
- [배칭](/wiki/batching/) — 여러 추론 요청을 묶어 하드웨어 사용률과 처리량을 높이는 기법이다.
- [벡터](/wiki/vector/) — 순서가 있는 수치 목록으로, 모델에서 데이터와 파라미터를 표현하는 기본 단위다. 유클리드 공간에서는 크기와 방향을 가진 대상으로 해석할 수 있다.
- [벡터 데이터베이스](/wiki/vector-database/) — 고차원 벡터와 메타데이터를 저장하고 유사도 검색을 제공하는 데이터 시스템이다.
- [벤치마크](/wiki/benchmark/) — 여러 모델이나 시스템을 비교하기 위해 고정한 과제·데이터·평가 지표의 묶음이다.
- [보상 모델](/wiki/reward-model/) — 여러 모델 출력 중 사람의 선호에 가까운 출력을 점수화하도록 학습된 모델이다.
- [비전-언어 모델](/wiki/vision-language-model/) — 이미지와 텍스트의 관계를 학습해 이해와 생성을 수행하는 멀티모달 모델이다.
- [비지도학습](/wiki/unsupervised-learning/) — 정답 표지 없이 데이터 내부의 구조·군집·표현을 찾는 학습 방식이다.
- [빔 탐색](/wiki/beam-search/) — 여러 후보 시퀀스를 동시에 유지하며 전체 점수가 높은 출력을 찾는 탐색 방법이다.
- [사전학습](/wiki/pretraining/) — 대규모 데이터로 일반적인 표현과 패턴을 먼저 학습하는 단계다.
- [상태 관리](/wiki/state-management/) — 여러 단계에 걸쳐 입력·중간 결과·진행 상황을 일관되게 유지하는 방법이다.
- [생성 온도](/wiki/temperature/) — 로짓의 크기를 조정해 생성 확률 분포의 평탄함과 무작위성을 제어하는 값이다.
- [생성형 인공지능](/wiki/generative-ai/) — 학습 데이터의 분포를 바탕으로 텍스트·이미지·음성·코드 같은 새로운 결과물을 생성하는 인공지능이다.
- [셀프 어텐션](/wiki/self-attention/) — 하나의 시퀀스 안에서 각 위치가 다른 위치의 정보를 참조하는 어텐션이다.
- [소규모 언어 모델](/wiki/small-language-model/) — 대규모 언어 모델보다 파라미터·메모리·연산 요구량을 줄여 제한된 환경에서 운용하도록 설계한 언어 모델이다.
- [소프트맥스](/wiki/softmax/) — 여러 실수 점수를 지수화하고 합으로 나눠 합이 1인 비율 벡터로 바꾸는 함수다.
- [손실 함수](/wiki/loss-function/) — 모델의 예측과 목표 사이 차이를 하나의 수치로 측정하는 함수다.
- [스칼라](/wiki/scalar/) — 벡터 공간의 벡터를 확대·축소하거나 계산의 단일 값을 나타내는 수학적 원소다.
- [스트리밍 응답](/wiki/streaming-response/) — 전체 결과가 완성되기 전에 생성된 일부 데이터를 순차적으로 전송하는 방식이다.
- [신경망](/wiki/neural-network/) — 연결된 계산 단위와 가중치를 층으로 쌓아 복잡한 함수를 학습하는 모델이다.
- [신경망 층](/wiki/layer/) — 입력 표현을 정해진 연산과 학습 파라미터로 변환해 다음 표현으로 전달하는 신경망의 구성 단위다.
- [알고리즘](/wiki/algorithm/) — 문제를 해결하기 위해 입력을 처리하는 유한하고 명확한 절차다.
- [양자화](/wiki/quantization/) — 가중치와 활성값을 낮은 정밀도로 표현해 메모리와 계산 비용을 줄이는 기법이다.
- [어텐션](/wiki/attention/) — 현재 표현을 만들 때 입력의 각 부분에 서로 다른 중요도를 부여해 정보를 결합하는 연산이다.
- [어휘 집합](/wiki/vocabulary/) — 토크나이저와 모델이 구분해 처리할 수 있는 토큰의 전체 목록이다.
- [언어 모델](/wiki/language-model/) — 토큰 시퀀스의 확률 분포를 학습해 다음 토큰이나 누락된 토큰을 예측하는 모델이다.
- [에이전트 루프](/wiki/agent-loop/) — 관찰·추론·행동·결과 반영을 목표 달성까지 반복하는 실행 구조다.
- [에이전트 메모리](/wiki/agent-memory/) — 에이전트가 이전 상호작용과 작업 상태를 저장하고 이후 판단에 사용하는 구조다.
- [에포크](/wiki/epoch/) — 학습 알고리즘이 전체 학습 데이터셋을 한 번 처리한 주기다.
- [역전파](/wiki/backpropagation/) — 출력의 손실에서 각 파라미터의 기여도를 연쇄 법칙으로 계산하는 알고리즘이다.
- [오픈소스 모델](/wiki/open-source-model/) — 사용·연구·수정·공유의 자유를 보장하고, 모델을 수정하는 데 필요한 코드·파라미터·데이터 정보를 제공하는 AI 모델 또는 시스템이다.
- [요청 한도](/wiki/rate-limit/) — 일정 시간 동안 허용하는 요청이나 토큰 사용량을 제한하는 정책이다.
- [워크플로 오케스트레이션](/wiki/workflow-orchestration/) — 여러 작업과 도구 호출의 의존 관계·상태·실패 처리를 정의하고 실행 순서를 조정하는 운영 방식이다.
- [웹훅](/wiki/webhook/) — 특정 이벤트가 발생했을 때 다른 시스템의 URL로 데이터를 보내는 자동 통지 방식이다.
- [위치 인코딩](/wiki/positional-encoding/) — 어텐션 모델에 토큰의 순서와 상대 위치 정보를 주입하는 표현이다.
- [음성 인식](/wiki/speech-recognition/) — 음성 신호를 텍스트나 언어 단위로 변환하는 기술이다.
- [음성 합성](/wiki/text-to-speech/) — 텍스트를 자연스러운 음성 파형으로 변환하는 기술이다.
- [의미 검색](/wiki/semantic-search/) — 문자열의 정확한 일치보다 질의와 문서의 의미 유사성을 이용하는 검색 방식이다.
- [이미지 생성](/wiki/image-generation/) — 텍스트나 다른 조건을 바탕으로 새로운 이미지를 합성하는 생성 과제다.
- [인간 참여형 제어](/wiki/human-in-the-loop/) — 중요한 판단이나 실행 단계에 사람의 검토·승인·교정을 포함하는 설계다.
- [인간 피드백 기반 강화학습](/wiki/rlhf/) — 사람의 선호 신호를 이용해 모델 응답 정책을 조정하는 사후학습 방법이다.
- [인공 뉴런](/wiki/neuron/) — 입력의 가중합에 활성화 함수를 적용해 출력을 만드는 신경망의 계산 단위다.
- [인공지능](/wiki/artificial-intelligence/) — 컴퓨터 시스템이 지각·추론·학습·행동과 같은 지능적 과제를 수행하도록 만드는 연구와 기술의 총칭이다.
- [인과 마스크](/wiki/causal-mask/) — 현재 위치가 미래 토큰을 참조하지 못하게 어텐션 점수를 제한하는 마스크다.
- [인용](/wiki/citation/) — 주장이나 생성 결과가 근거로 삼은 자료의 위치와 출처를 표시하는 정보다.
- [인코더](/wiki/encoder/) — 입력 시퀀스를 문맥이 반영된 내부 표현으로 변환하는 구성 요소다.
- [인코더-디코더](/wiki/encoder-decoder/) — 입력을 인코딩한 뒤 별도의 디코더가 출력을 생성하는 모델 구조다.
- [임베딩](/wiki/embedding/) — 문장·이미지·항목의 의미나 특성을 연속적인 벡터 공간에 표현한 값이다.
- [임베딩 모델](/wiki/embedding-model/) — 텍스트·이미지 같은 입력을 비교와 검색에 사용할 수 있는 고정 길이 벡터로 변환하도록 학습한 모델이다.
- [자기지도학습](/wiki/self-supervised-learning/) — 데이터 자체에서 학습 목표를 만들어 대규모 비표지 데이터로 표현을 익히는 방식이다.
- [잔차 연결](/wiki/residual-connection/) — 블록의 입력을 출력에 더해 깊은 신경망의 학습을 안정화하는 연결이다.
- [전문가 혼합](/wiki/mixture-of-experts/) — 입력마다 일부 전문가 네트워크만 선택해 계산량 대비 모델 용량을 늘리는 구조다.
- [정밀도와 재현율](/wiki/precision-recall/) — 정밀도는 양성으로 예측한 항목의 적중 비율이고 재현율은 실제 양성 가운데 찾아낸 비율이다.
- [정확도](/wiki/accuracy/) — 전체 평가 예시 중 모델이 정답을 맞힌 비율이다.
- [조건부확률](/wiki/conditional-probability/) — 어떤 사건이 주어졌을 때 다른 사건이 발생할 확률이다.
- [지도 미세조정](/wiki/supervised-fine-tuning/) — 지시와 모범 응답 쌍으로 모델이 원하는 응답 형식을 따르도록 학습하는 단계다.
- [지도학습](/wiki/supervised-learning/) — 입력과 정답이 함께 있는 데이터로 입력에서 정답으로의 관계를 학습하는 방식이다.
- [지시 튜닝](/wiki/instruction-tuning/) — 다양한 자연어 지시 데이터로 여러 과제를 지시 형식에 맞게 수행하도록 만드는 학습이다.
- [지식 증류](/wiki/knowledge-distillation/) — 큰 교사 모델의 출력이나 표현을 작은 학생 모델이 모방하도록 학습하는 방법이다.
- [지연 시간](/wiki/latency/) — 요청을 보낸 뒤 첫 토큰 또는 전체 응답을 받을 때까지 걸리는 시간이다.
- [직접 선호 최적화](/wiki/dpo/) — 별도 강화학습 루프 없이 선호 응답과 비선호 응답으로 정책을 직접 최적화하는 방법이다.
- [처리량](/wiki/throughput/) — 단위 시간에 시스템이 처리하거나 생성할 수 있는 요청 또는 토큰 수다.
- [청킹](/wiki/chunking/) — 긴 문서를 검색과 문맥 구성에 적합한 작은 단위로 나누는 과정이다.
- [체크포인트](/wiki/checkpoint/) — 특정 학습 시점의 모델 가중치와 최적화 상태를 저장한 파일 집합이다.
- [최근접 이웃 검색](/wiki/nearest-neighbor-search/) — 벡터 공간에서 질의 벡터와 가장 가까운 항목을 찾는 문제다.
- [최적화](/wiki/optimization/) — 목적 함수를 최소화하거나 최대화하는 파라미터를 찾는 과정이다.
- [추론](/wiki/inference/) — 학습된 모델이 새 입력을 받아 예측이나 생성을 수행하는 과정이다.
- [추적](/wiki/tracing/) — 한 요청이 여러 모델·도구·단계를 거치는 실행 흐름과 시간을 기록하는 방법이다.
- [컨텍스트 윈도우](/wiki/context-window/) — 모델이 한 번의 요청에서 참조할 수 있는 토큰 범위다.
- [컴퓨터 비전](/wiki/computer-vision/) — 이미지와 영상에서 대상·장면·공간 구조를 추정하고 유용한 정보를 계산하는 인공지능 분야다.
- [컴플리션](/wiki/completion/) — 프롬프트와 이전 토큰을 조건으로 모델이 생성한 후속 토큰 시퀀스다.
- [코사인 유사도](/wiki/cosine-similarity/) — 두 벡터 사이 각도의 코사인으로 방향의 유사성을 측정하는 값이다.
- [콘텐츠 조정](/wiki/content-moderation/) — 유해하거나 정책을 위반하는 콘텐츠를 탐지·분류·처리하는 과정이다.
- [쿼리·키·값](/wiki/query-key-value/) — 어텐션에서 참조할 정보의 관련도를 계산하고 내용을 모으는 세 표현이다.
- [크로스 어텐션](/wiki/cross-attention/) — 한 표현의 질의가 다른 표현에서 만든 키와 값을 조회해 두 입력 사이의 관련 정보를 결합하는 어텐션이다.
- [탈옥 공격](/wiki/jailbreak/) — 모델의 안전 정책과 행동 제한을 우회하도록 입력을 구성하는 공격 기법이다.
- [텐서](/wiki/tensor/) — 머신러닝 프레임워크에서 스칼라·벡터·행렬과 그 이상의 차원을 일관된 방식으로 다루는 다차원 수치 배열이다.
- [토크나이저](/wiki/tokenizer/) — 텍스트와 토큰 ID 사이의 분할·변환 규칙을 구현한 구성 요소다.
- [토큰](/wiki/token/) — 언어 모델이 텍스트를 처리하기 위해 나눈 기본 기호 단위다.
- [토큰화](/wiki/tokenization/) — 문자열을 모델의 어휘 집합에 있는 토큰 ID 시퀀스로 변환하는 과정이다.
- [트랜스포머](/wiki/transformer/) — 어텐션을 중심으로 시퀀스의 관계를 병렬 계산하는 신경망 아키텍처다.
- [파라미터](/wiki/parameter/) — 학습 과정에서 조정되어 모델의 입력-출력 변환을 결정하는 수치다.
- [파라미터 효율적 미세조정](/wiki/peft/) — 전체 가중치 대신 일부 작은 파라미터만 학습해 비용을 줄이는 기법들의 총칭이다.
- [편향 항](/wiki/bias/) — 선형 변환의 기준점을 이동시키기 위해 더하는 학습 가능한 값이다.
- [편향과 공정성](/wiki/bias-fairness/) — 모델의 결과가 집단이나 특성에 따라 체계적으로 불리하게 달라지는지를 다루는 개념이다.
- [평가 지표](/wiki/metric/) — 성능이나 품질의 특정 측면을 수치로 요약하는 측정 기준이다.
- [프롬프트](/wiki/prompt/) — 모델에 과제·문맥·제약·출력 형식을 전달하는 입력이다.
- [프롬프트 인젝션](/wiki/prompt-injection/) — 악의적 입력이 기존 지시를 무시하거나 비밀을 노출하도록 모델 행동을 조작하는 공격이다.
- [피드포워드 네트워크](/wiki/feed-forward-network/) — 각 토큰 위치에 독립적으로 적용되는 비선형 완전연결 변환 블록이다.
- [하이퍼파라미터](/wiki/hyperparameter/) — 학습 전에 사람이 정하거나 탐색하며 학습 과정과 모델 구조를 제어하는 값이다.
- [학습 데이터](/wiki/training-data/) — 모델이 파라미터를 조정하며 패턴을 배우는 데 사용하는 예시와 기록의 집합이다.
- [학습률](/wiki/learning-rate/) — 한 번의 최적화 단계에서 파라미터를 얼마나 크게 변경할지 정하는 값이다.
- [합성 데이터](/wiki/synthetic-data/) — 실제 관측값을 그대로 복제하지 않고 규칙·시뮬레이션·통계 또는 생성 모델로 만든 데이터다.
- [행렬](/wiki/matrix/) — 수치를 행과 열로 배열한 구조로, 신경망의 선형 변환과 배치 계산에 사용된다.
- [확률](/wiki/probability/) — 불확실한 사건이 일어날 가능성을 수치로 표현하는 체계다.
- [확률분포](/wiki/probability-distribution/) — 가능한 값마다 확률을 대응시켜 불확실성을 나타내는 함수다.
- [확산 모델](/wiki/diffusion-model/) — 데이터에 노이즈를 더하고 제거하는 역과정을 학습해 샘플을 생성하는 모델이다.
- [환각](/wiki/hallucination/) — 모델이 근거가 없거나 사실과 다른 내용을 그럴듯하게 생성하는 현상이다.
- [활성화 함수](/wiki/activation-function/) — 신경망에 비선형성을 부여해 복잡한 관계를 표현하게 하는 함수다.
- [AI 거버넌스](/wiki/ai-governance/) — AI의 개발과 사용을 조직의 정책·책임·통제·감사 체계로 관리하는 활동이다.
- [AI 에이전트](/wiki/ai-agent/) — 목표를 바탕으로 상태를 관찰하고 도구를 선택해 여러 단계의 작업을 수행하는 시스템이다.
- [AI 정렬](/wiki/alignment/) — 모델의 행동이 사람의 의도·가치·안전 제약과 일치하도록 만드는 연구와 과정이다.
- [API](/wiki/api/) — 소프트웨어 구성 요소가 정해진 규약으로 기능과 데이터를 요청·교환하는 인터페이스다.
- [API 키](/wiki/api-key/) — API 요청의 프로젝트나 사용자를 식별하고 권한을 확인하는 비밀 문자열이다.
- [HTTP 요청](/wiki/http-request/) — 클라이언트가 서버에 메서드·주소·헤더·본문을 보내는 메시지다.
- [HTTP 응답](/wiki/http-response/) — 서버가 HTTP 요청의 처리 결과를 상태 코드·필드·선택적 콘텐츠로 전달하는 메시지다.
- [JSON](/wiki/json/) — 키-값과 배열 구조로 데이터를 표현하는 경량 텍스트 형식이다.
- [KV 캐시](/wiki/kv-cache/) — 이전 토큰의 어텐션 키와 값을 저장해 자동회귀 생성의 중복 계산을 줄이는 캐시다.
- [LLM 심사자](/wiki/llm-as-a-judge/) — 언어 모델을 사용해 다른 모델 출력의 품질을 판정하거나 비교하는 평가 방식이다.
- [LoRA](/wiki/lora/) — 기존 가중치를 고정하고 저랭크 행렬만 학습하는 파라미터 효율적 미세조정 기법이다.
- [REST API](/wiki/rest-api/) — REST의 제약과 균일한 인터페이스를 적용해 자원의 표현을 주고받도록 설계한 웹 API 방식이다.
- [SDK](/wiki/sdk/) — 특정 플랫폼이나 API를 쉽게 사용하도록 제공하는 라이브러리·도구·문서의 묶음이다.
- [Top-k 샘플링](/wiki/top-k-sampling/) — 확률이 높은 상위 k개 후보만 남겨 다음 토큰을 선택하는 방법이다.
- [Top-p 샘플링](/wiki/top-p-sampling/) — 누적 확률이 p에 도달하는 최소 후보 집합에서 다음 토큰을 선택하는 방법이다.
