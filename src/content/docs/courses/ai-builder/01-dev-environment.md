_코딩을 한 줄 몰라도 Cursor·Replit·Claude 같은 AI 코딩 툴에 계정을 만들고 프로젝트 폴더를 연 뒤, AI에게 첫 명령을 내려 화면에 'Hello EduVerse'를 띄우는 것까지 20분 만에 준비한다._

:::note[학습 목표]
- Cursor(또는 Replit)에 계정을 만들어 로그인하고 내 프로젝트 폴더를 연다
- AI 채팅 패널에 한국어로 첫 명령을 내려 index.html을 만든다
- 제안된 코드를 Apply/Accept로 저장하고 브라우저로 열어 'Hello EduVerse'를 화면에 띄운다
:::

## 핵심 개념

AI 코딩 툴은 **똑똑한 메모장**이에요. 내가 한국어로 "이렇게 만들어줘"라고 적으면 AI가 그 자리에서 코드를 써주고 실행까지 도와줍니다. 대표 툴은 세 가지 — 설치형인 **Cursor**(내 컴퓨터에 깔아 씀), 브라우저만 있으면 되는 **Replit**(설치 불필요), 채팅으로 코드를 물어보는 **Claude**. 이 셋의 공통 준비물은 딱 두 가지, **'계정'과 '프로젝트 폴더'**예요. 오늘은 이 둘을 만들고 AI에게 첫 지시를 내려 화면에 'Hello EduVerse'를 띄우는 것까지가 목표예요.

### 왜 이게 될까?

AI 코딩 툴은 이미 수억 줄의 코드를 학습해서 "이렇게 만들어줘"라는 한국어 문장만 봐도 어떤 코드를 써야 할지 패턴을 압니다. 원하는 결과를 말로 설명하기만 하면 되고, 실제 타이핑과 문법은 AI가 대신해요. 처음에 계정과 폴더만 제대로 마련해두면 그 다음부터 이 **"말하면 만들어주는"** 흐름이 쭉 이어집니다.

## 👀 따라하기 예시 — Cursor로 'Hello EduVerse' 띄우기

(Cursor 설치·구글 로그인을 마치고, 바탕화면에 my-first-app 폴더를 연 상황)

**① AI 채팅창 열기** Ctrl+L(Mac Cmd+L)로 AI 채팅창을 엶 → 오른쪽에 빈 채팅 패널("Ask anything...")이 뜬다.
> 💡 폴더를 열어둔 상태에서 채팅을 열어야 AI가 이 프로젝트 안에 파일을 만들어줘요.

**② 한국어로 명령** "초보자용 index.html 파일을 만들고 화면 가운데에 큰 글씨로 Hello EduVerse를 띄워줘" 입력 → AI가 `<!DOCTYPE html>`… flex 중앙정렬 `<h1>Hello EduVerse</h1>` 코드 생성.
> 💡 한 문장짜리 요청에도 AI는 파일 생성부터 스타일까지 한 번에 — "말하면 만들어주는" 첫 순간이에요.

**③ Apply 클릭** 코드 옆 "Apply" 버튼 클릭 → 왼쪽 파일 목록에 index.html 생성.
> 💡 제안은 클릭해야 실제 파일로 저장돼요. 여기서 안 누르면 아무 일도 안 일어난 것처럼 보이는 게 가장 흔한 함정.

**④ 브라우저로 열기** index.html 더블클릭해서 브라우저로 열기 → 흰 화면 가운데에 검은 큰 글씨 Hello EduVerse.
> 💡 내가 쓴 말이 실제 화면 결과로 바뀌는 순간을 눈으로 확인해야 다음 레슨에서도 이 흐름을 믿고 갈 수 있어요.

좋은 결과의 기준: (1) 더블클릭하면 브라우저가 바로 열린다 (2) 화면 가운데에 Hello EduVerse 글씨가 보인다 (3) 파일이 my-first-app 폴더 안에 저장되어 있다.

## 단계별 따라하기

1. **내 상황에 맞는 툴 고르기** — 컴퓨터에 프로그램 설치가 가능하면 Cursor 추천. 회사/학교 컴퓨터라 설치가 막혀 있거나 태블릿뿐이면 브라우저만으로 되는 Replit. 이 레슨은 Cursor 기준, Replit 사용자는 각 단계의 괄호 안내를 따라감.
2. **계정 만들기** — Cursor는 cursor.com → 우측 상단 Download로 설치파일 받고 실행 → 앱을 열면 로그인 화면 → 'Sign up' → 'Continue with Google'. (Replit은 replit.com → Sign up → Continue with Google.) 이메일 인증 메일이 오면 링크 눌러 인증.
3. **프로젝트 폴더 만들기** — 바탕화면에 새 폴더를 만들고 이름을 영문으로(한글·띄어쓰기 금지). Cursor에서 File → Open Folder → 방금 만든 폴더 선택. 왼쪽에 폴더 이름이 보이면 '작업실'이 열린 것. (Replit은 Create Repl → 언어 HTML/CSS/JS → 이름 → Create.)
4. **AI 채팅 패널 열고 인사하기** — Cursor에서 Ctrl+L(Mac Cmd+L) → 오른쪽 AI 채팅창. 한국어로 명령 입력 후 Enter. AI가 index.html을 만들어 코드를 채우면 'Accept' 또는 'Apply' 클릭.
5. **첫 실행으로 결과 확인하기** — 만들어진 index.html을 웹브라우저로 열기(폴더에서 더블클릭 → 크롬/사파리). 화면 가운데 'Hello EduVerse'가 보이면 성공. (Replit은 상단 초록색 Run 버튼 → 오른쪽 미리보기.) 안 보이면 AI에게 고쳐달라고.
6. **오늘 세팅 저장·정리하기** — 폴더 위치, 로그인한 계정, 실행 방법 세 가지를 메모장에. AI 채팅창은 대화가 저장되니 오늘 쓴 명령을 다시 읽어보며 어떤 말이 잘 통했는지 눈에 익혀둠.

## 흔한 실수 → 교정

- ✗ 폴더 이름이나 파일 이름을 한글·띄어쓰기로 지음(예: '내 첫 앱') → **영문 소문자와 하이픈만(예: my-first-app).** 한글·공백은 나중에 실행 오류의 흔한 원인.
- ✗ AI가 코드를 제안했는데 'Apply/Accept'를 안 눌러서 실제 파일에는 아무 변화가 없음 → **채팅에 뜬 코드는 '제안'일 뿐. 반드시 Apply(또는 Accept)를 눌러야 파일에 저장.** 저장 후 파일이 실제로 생겼는지 왼쪽 목록에서 확인.
- ✗ 한 번에 완벽하게 만들려고 긴 명령을 잔뜩 적고, 안 되면 포기 → **작게 시키고 바로 확인하는 게 정석.** 'Hello EduVerse 띄우기'처럼 한 가지씩 시키고, 안 되면 현재 코드를 통째로 붙여 고쳐달라.

## 도구

- 🛠 **Cursor** (cursor.com) — 내 컴퓨터에 설치해 쓰는 AI 코드 에디터.
- 🛠 **Replit** (replit.com) — 설치 없이 브라우저에서 코딩·실행.
- 🛠 **Claude** (claude.ai) — 채팅으로 코드를 물어보고 설명받는 AI.
- 🛠 **Google 계정** (accounts.google.com) — 위 툴들에 원클릭 로그인용.

## 실전 프롬프트

### 첫 실행 파일 만들기(가장 먼저)

```text
나는 코딩을 처음 배우는 사람이야. [내 폴더]에 index.html 파일을 새로 만들어줘. 화면 한가운데에 아주 큰 글씨로 'Hello EduVerse'라는 문구가 보이게 하고, 배경은 흰색, 글씨는 검은색으로. 파일을 브라우저로 열면 바로 보이도록 완성된 전체 코드로.
```

`프롬프트` `첫실행` `html`

### 세팅이 맞았는지 점검받기

```text
나는 AI 코딩 툴을 방금 처음 설치한 초보자야. 지금 [Cursor 또는 Replit]에 로그인했고 [폴더 이름] 폴더를 열었어. 첫 프로젝트를 실행하기 전에 준비가 제대로 됐는지 확인하고 싶어. 지금 상태에서 내가 빠뜨린 게 있는지, 다음에 뭘 하면 되는지 초보자도 알아듣게 3단계로.
```

`프롬프트` `점검` `세팅`

### 화면에 아무것도 안 뜰 때 고치기

```text
index.html을 브라우저로 열었는데 [흰 화면만 나오고 / 아무것도 안 보이고 / 에러가 뜨고] 있어. 아래가 지금 내 코드 전체야. 초보자도 알 수 있게 무엇이 문제인지 한 줄로 설명하고, 그대로 복사해 붙여넣을 수 있는 고친 전체 코드를 다시 줘. [내 코드 붙여넣기]
```

`프롬프트` `디버깅`

### 용어가 어려울 때 쉬운 말로 풀기

```text
AI 코딩 툴을 쓰다 보니 '[모르는 단어: 터미널 / 커밋 / 확장자]'라는 말이 나왔어. 나는 완전 초보라서 어려운 설명은 이해가 안 돼. 초등학생도 이해할 수 있는 비유를 하나 들어서 이 단어가 무슨 뜻인지 두세 문장으로만.
```

`프롬프트` `용어`
