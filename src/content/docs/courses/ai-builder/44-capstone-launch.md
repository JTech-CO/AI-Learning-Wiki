_전 역량을 통합하는 최종 캡스톤. 실제 사용자가 있는 작은 산출물을 문제정의→제작→출시→피드백→재배포→포트폴리오의 한 바퀴로 자율 완성해, 빈 화면에서 시작해 7일 안에 인터넷 주소가 있는 '내 작품'을 출시하고 누군가 실제로 클릭하게 만든다._

:::note[학습 목표]
- AI 도구(v0)로 만든 진짜 웹앱을 인터넷 주소(URL)가 있는 상태로 출시한다
- 친구 3명에게 링크를 보내 피드백을 받고, 그중 가장 많이 나온 1개를 반영해 같은 주소로 재배포한다
- 문제 한 문장·AI가 한 일·내가 판단한 일·피드백·윤리 표기를 담은 포트폴리오 1장을 완성한다
:::

## 핵심 개념

**캡스톤(capstone)**은 건물 꼭대기에 마지막으로 얹는 돌이에요. 지금까지 배운 모든 걸 하나로 합쳐 '완성'을 증명하는 졸업작품이죠. 핵심은 **'출시(배포)'** — 내 컴퓨터에만 있던 걸 인터넷에 올려 '누구나 주소로 접속'하게 만드는 일이에요. 요리에 비유하면 맛있게 만드는 것(제작)과 손님 식탁에 내놓는 것(출시)은 다른 일이에요. 많은 사람이 만들기만 하고 '내놓기'를 안 해서 멈춰요. 만든 뒤에는 진짜 사용자에게 보여주고(피드백) 한 번 더 고쳐요. 이 **'만들기→내놓기→고치기'의 한 바퀴**를 끝까지 도는 게 이 레슨의 전부예요.

### 흐름 — 캡스톤 출시 한 바퀴

> 🎯 문제 정하기 → 🤖 AI로 제작 → 🚀 출시(배포) → 💬 사용자 피드백 → 🔧 고쳐서 재배포 → 📒 회고·포트폴리오 ↻

### 왜 이게 될까?

v0 같은 AI 도구는 수억 줄의 실제 코드를 미리 학습해서, 당신이 화면을 말로 설명하기만 하면 그걸 바로 작동하는 웹페이지 코드로 바꿔줘요. 그래서 당신은 '누구의 어떤 불편을 풀지'와 '무엇을 고칠지'만 판단하면 되고, 화면을 짜는 노가다는 AI가 대신해요. **Vercel**은 그 코드를 인터넷 서버에 자동으로 올려주는 배달원이라 당신은 버튼만 누르면 돼요.

## 👀 따라하기 예시 — 분리수거 요일을 헷갈려하는 아파트 주민용 웹앱을 7일 안에 출시

**① v0.app에 화면을 한국어로 구체적으로 설명** — '분리수거 안내 웹앱을 만들어줘. 요일 버튼 7개(월~일)가 있고, 누르면 그날 버릴 쓰레기 종류를 큰 글씨로 보여줘.' → 30초 뒤 요일 버튼 7개와 미리보기 화면이 나옴.
> 💡 막연히 '분리수거 앱 만들어줘'가 아니라 버튼 개수·동작·스타일까지 구체적으로 적어야 AI가 정확한 화면을 한 번에 만들어요.

**② Deploy 버튼으로 GitHub 저장소 만들기** — 'Connect GitHub' → 'Create repository' 클릭 후 github.com/내아이디/recycle-helper 저장소 주소 생성.
> 💡 GitHub은 내 코드를 잃어버리지 않게 보관하는 창고예요. 이 단계가 있어야 Vercel이 그 코드를 가져다 출시할 수 있어요.

**③ Vercel에서 Import → Deploy로 진짜 인터넷 주소 받기** — 1~2분 뒤 색종이 효과와 함께 recycle-helper.vercel.app 공개 주소 발급.
> 💡 내 컴퓨터 화면과 '전 세계 누구나 열 수 있는 주소'는 달라요. 이 순간이 바로 '출시'예요.

**④ 친구 3명에게 링크를 보내 피드백 3가지 받기** — 친구A '요일이 영어라 헷갈려', 엄마 '글씨가 작아', 동생 '오늘 날짜가 자동으로 떴으면' → 공통점: 한국어 요일 표기 + 큰 글씨.
> 💡 내 눈엔 안 보이던 문제가 남이 써보면 1분 만에 드러나요. 그래서 반드시 진짜 사용자에게 보여줘야 해요.

좋은 결과의 기준: (1) 친구 폰에서 실제로 열린다 (2) 피드백 중 가장 많이 나온 1개가 반영돼 있다 (3) 포트폴리오에 AI가 한 일과 내가 판단한 일이 구분돼 적혀 있다.

## 단계별 따라하기

1. **'누구의 어떤 불편'을 풀지 한 문장으로 정한다** — 거창하게 시작하지 말고 주변에서 진짜 불편을 찾아요. `OO한 사람이 OO 때문에 불편하다. 그래서 나는 OO를 만든다` 형식의 한 문장으로. 너무 크면(예: '교육을 바꾼다') 7일에 못 끝나니 '화면 하나로 끝나는 작은 도구'로 좁혀요. (정한 문장: '우리 아파트 주민이 분리수거 요일을 자꾸 헷갈린다. 그래서 나는 요일을 입력하면 오늘 뭘 버리는지 알려주는 웹페이지를 만든다.')
2. **v0.app 계정을 만들고 AI에게 화면을 만들게 한다** — v0.app 접속(구 v0.dev에서 자동 리다이렉트) → 'Sign Up' → 구글 계정 로그인. v0는 글로 설명하면 진짜 작동하는 웹화면을 만들어주는 AI예요. 무료 플랜은 매월 $5 상당 크레딧 리셋 + 하루 최대 7메시지. 하루 7번 다 쓰면 다음 날 자정(태평양 시간) 초기화되니, 한 번에 구체적으로 적어 메시지 횟수를 아껴요. (입력: '분리수거 안내 웹앱. 요일 버튼 7개(월~일), 버튼을 누르면 그 요일에 버리는 쓰레기 종류(월=플라스틱, 화=종이)를 큰 글씨로. 모바일에서 보기 좋게, 따뜻한 색으로.')
3. **만든 화면을 GitHub에 저장(코드 보관함 만들기)** — v0 화면 오른쪽 위 'Deploy'(또는 'Add to Codebase'/'Push') → GitHub 연결. github.com 무료 가입 후 'Connect GitHub' → 'Create repository'. 저장소 이름은 영어 소문자로(예: recycle-helper). 이 단계가 끝나면 내 코드가 GitHub에 한 묶음으로 올라가요. (저장소 주소 예: github.com/내아이디/recycle-helper)
4. **Vercel로 인터넷에 '출시'한다(진짜 주소 받기)** — vercel.com → 'Sign Up' → 'Continue with GitHub'(3단계와 같은 계정) → 'Add New... → Project' → 방금 만든 저장소 옆 'Import' → 아무것도 안 바꾸고 파란 'Deploy'. 1~2분 뒤 색종이와 함께 공개 주소(URL)가 나와요. v0에서 'Deploy'로 바로 왔다면 이 과정이 자동으로 끝나 있을 수도 있어요. (출시 주소 예: recycle-helper.vercel.app — 카톡에 링크를 붙여 나에게 보내보고 폰에서 열리는지 확인)
5. **진짜 사용자 3명에게 보여주고 피드백을 모은다** — 혼자 보면 안 돼요. 출시 주소를 가족·친구 3명에게 카톡으로 보내고 딱 3가지만 물어요: ① 뭐 하는 건지 한눈에 알겠어? ② 쓰다가 막힌 곳? ③ 하나만 고친다면? 답을 메모장에 그대로 적어요. 내 생각과 진짜 사용자의 반응은 거의 항상 달라요. (피드백 예: 친구A '요일이 영어라 헷갈려', 엄마 '글씨가 작아', 동생 '오늘 날짜 자동으로 떴으면' → 공통점: 한국어 요일 + 글씨 크게)
6. **피드백 중 '딱 1개'만 고쳐서 다시 출시한다** — 전부 고치려 하지 말고 가장 많이 나온 1개만. v0.app 그 프로젝트로 돌아가 입력칸에 고칠 내용을 한국어로 적어요. 고친 뒤 다시 'Deploy'(또는 GitHub에 자동 반영)하면 Vercel이 같은 주소(URL)를 자동으로 새 버전으로 바꿔줘요. 주소는 그대로, 내용만 좋아지는 이게 '재배포'예요. v0 하루 메시지 한도(7회)를 이미 소진했다면 다음 날에. (추가 입력: '요일 버튼 글씨를 월·화·수처럼 한국어로 바꾸고, 글씨 크기를 1.5배 키워줘.' → Deploy → 새로고침하니 한국어로 바뀜)
7. **회고 1장 + 포트폴리오로 '졸업 증거'를 남긴다** — 마지막은 기록. Gamma(gamma.app) 또는 구글 문서에 한 장으로. Gamma는 '만들 내용을 한국어로 적으면' 발표자료를 자동 디자인해줘요. 단 Gamma 신규 가입 시 400 크레딧 지급, 발표자료 1장 생성에 약 40크레딧(전체 약 10회 생성 가능). 크레딧 소진 후에는 유료 전환이 필요하니, 걱정되면 구글 문서나 Canva(무제한 무료)로 대신해요. 담을 것: ① 출시 주소 ② 만든 화면 사진 ③ 문제 한 문장 ④ AI가 한 일 vs 내가 판단한 일 ⑤ 받은 피드백과 고친 점 ⑥ 출처·윤리(AI로 만들었음을 표기). 이 한 장이 '나는 AI로 진짜 출시를 해봤다'는 평생 증거예요.

## 흔한 실수 → 교정

- ✗ 범위를 너무 크게 잡음(예: '교육 플랫폼을 만든다') → **'화면 하나, 기능 하나'로 줄여라.** 7일 안에 출시 못 하면 영원히 안 끝나요. 크게는 다음 작품에서.
- ✗ 내 컴퓨터에서 잘 되니 '완성'이라 착각 → **출시는 인터넷 주소(URL)가 생겨 '남이 폰으로 여는' 순간.** 친구 폰에서 실제로 열리는지 꼭 확인.
- ✗ 혼자 만들고 아무에게도 안 보여줌 → **사용자 3명 피드백이 졸업 조건.** 내 눈엔 안 보이던 문제가 1분 만에 드러나요. 부끄러워도 보내라.
- ✗ 피드백을 받자마자 전부 다 고치려다 무너짐 → **가장 많이 나온 '딱 1개'만 고쳐 재배포.** 한 바퀴를 끝까지 도는 게 핵심이지 완벽이 목표가 아니에요.
- ✗ AI로 만들었다는 걸 숨김 → **포트폴리오에 'AI(v0/ChatGPT)로 제작, 내 판단이 들어간 부분은 OO'라고 정직하게 표기.** 이게 윤리이자 실력 증명.

## 도구

- 🛠 **v0.app** — 글로 설명하면 작동하는 웹화면을 만들어주는 AI. 무료: 매월 $5 크레딧 리셋 + 하루 최대 7메시지 제한(공식 주소 v0.app, 구 v0.dev에서 이전).
- 🛠 **GitHub** (github.com) — 코드를 인터넷에 보관하는 무료 창고.
- 🛠 **Vercel** (vercel.com) — 코드를 인터넷에 '출시'해 공개 주소를 주는 무료 도구.
- 🛠 **Gamma** (gamma.app) — 내용만 적으면 발표자료·포트폴리오를 자동 디자인. 신규 가입 시 400 크레딧 1회 제공(소진 후 유료 전환 필요).
- 🛠 **대안** — 구글 문서, Canva(무제한 무료).

## 실전 프롬프트

### 문제 좁히기 — 작은 아이디어 10개 받기

```text
나는 7일 안에 화면 하나짜리 작은 웹앱을 만들어 출시하고 싶어. 내 주변 사람들의 사소한 불편을 웹페이지 하나로 풀 수 있는 아이디어 10개를 예시로. 각각 '누가-무엇이불편-무엇을만든다' 한 문장으로. 너무 크거나 로그인·결제가 필요한 건 빼줘. 내 관심사는 [관심사]야.
```

> 확인된 작성 예시 없음

`프롬프트` `문제정의` `아이디어`

### v0로 화면 만들기

```text
[앱 이름] 웹앱을 만들어줘. 핵심 기능: [한 문장]. 화면에 [필요한 버튼·입력칸]이 있고, 누르면 [무슨 일이 일어나는지]. 모바일에서 보기 좋게, [원하는 색·분위기]으로. 글씨는 크게.
```

> 확인된 작성 예시 없음

`프롬프트` `v0` `제작`

### 피드백 요청 — 친구에게 카톡

```text
내가 AI로 만든 [앱 이름]이야: [출시 URL]. 1분만 써보고 3가지만 답해줘 🙏 ① 뭐 하는 건지 바로 알겠어? ② 쓰다가 막힌 곳 있어? ③ 딱 하나만 고친다면 뭐?
```

> 확인된 작성 예시 없음

`프롬프트` `피드백` `사용자테스트`

### 회고·포트폴리오 자동작성 — Gamma

```text
내 캡스톤 프로젝트 포트폴리오를 한 장으로. 제목: [앱 이름]. 문제: [누구의 어떤 불편]. 해결: [내 앱이 하는 일]. 출시 주소: [URL]. AI가 한 일: [v0가 화면 제작]. 내가 판단한 일: [문제 선정·피드백 반영]. 결과: [친구 N명 테스트 후 OO 개선]. 윤리: AI 도구로 제작했음을 표기. 깔끔하고 따뜻한 디자인으로.
```

> 확인된 작성 예시 없음

`프롬프트` `포트폴리오` `회고`
