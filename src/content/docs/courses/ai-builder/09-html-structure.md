_제목·문단·버튼·입력창 같은 기본 HTML 태그로 웹페이지 구조를 짜고, AI가 만들어 준 HTML의 글자·버튼을 직접 손봐 내 것으로 만든다. 태그 몇 개만 알면 남의 코드도 내 손으로 뜯어고칠 수 있다._

:::note[학습 목표]
- 제목·문단·버튼·입력창이 들어간 간단한 웹페이지를 직접 만든다
- AI가 준 HTML의 글자·버튼을 원하는 대로 수정한다
- 여는 태그·닫는 태그 규칙을 익혀 '태그 읽는 눈'을 기른다
:::

## 핵심 개념

HTML은 웹페이지의 **'뼈대'**예요. 집을 지을 때 기둥·벽·문의 위치를 먼저 정하듯, HTML 태그로 **제목은 어디, 문단은 어디, 버튼은 어디**에 둘지 구조를 짭니다. 태그는 `<h1>제목</h1>`처럼 **여는 태그와 닫는 태그로 내용을 감싸는** 방식이라 규칙이 아주 단순해요. ChatGPT·Claude 같은 AI는 HTML을 순식간에 써 주지만, 글자를 바꾸거나 버튼을 하나 더 넣는 자잘한 수정은 내가 직접 하는 게 훨씬 빠릅니다. **'태그 읽는 눈'** 하나만 있으면 AI를 조수처럼 부리면서 결과물을 내 것으로 만들 수 있어요.

### 왜 이게 될까?

AI는 이미 수억 줄의 HTML 코드를 학습해서 "이벤트 신청 페이지 만들어줘" 한 마디에 제목·입력창·버튼이 갖춰진 뼈대를 몇 초 만에 뽑아냅니다. 그러니 처음부터 태그를 다 외워 짤 필요가 없어요. AI가 만든 뼈대에서 **글자와 태그 몇 개만 알아보고 직접 고치면** 됩니다. 한마디로 **"생성은 AI, 손질은 나"**예요.

## 👀 따라하기 예시 — 동네 베이킹 클래스 신청 페이지

**① CodePen을 열고 AI에게 뼈대 부탁** — "베이킹 클래스 신청 페이지 HTML 만들어줘" → `<h1>주말 베이킹 클래스 신청</h1>`, 이름·이메일 `<input>` 두 줄, `<button>신청하기</button>`가 나옴.
> 💡 AI는 '뼈대 구조'를 통째로 만드는 걸 제일 잘해요. 처음부터 태그를 하나하나 안 쳐도 되니 여기서 시간을 아낍니다.

**② 받은 코드를 CodePen HTML 칸에 통째로 붙여넣기** — 미리보기에 제목·입력창 2개·버튼 1개가 바로 뜸.
> 💡 붙여넣자마자 눈으로 결과가 보이니, 코드를 읽기 전에 "이게 맞나"부터 확인할 수 있어요.

**③ `<h1>` 안의 글자를 내 클래스 이름으로 직접 고치기** — `<h1>주말 베이킹 클래스 신청</h1>` → `<h1>7월 딸기 케이크 클래스</h1>` → 미리보기 제목이 즉시 바뀜.
> 💡 태그 사이 글자만 바꾸는 건 AI를 다시 부르는 것보다 내가 타이핑하는 게 훨씬 빨라요 — "AI 결과물을 내 것으로 만드는" 첫 순간.

**④ 전화번호 입력칸을 직접 추가** — 이메일 `<input>` 아래에 `<input placeholder="전화번호">` 한 줄을 복사해 붙이니 입력창이 3개로.
> 💡 새 태그를 처음부터 외워 쓰는 게 아니라 "이미 있는 태그를 복사해서 살짝 바꾸는" 방식이 실전에서 제일 빨라요.

좋은 결과의 기준: (1) 여는 태그마다 닫는 태그가 짝을 이룬다 (2) 미리보기에서 태그 글자(`<`, `>`)가 그대로 안 보이고 제대로 화면으로 렌더링된다 (3) 내가 손댄 부분(제목·버튼 글자·추가 입력창)이 원하는 대로 반영돼 있다.

## 단계별 따라하기

1. **코드 없이 웹페이지 미리보기 열기** — codepen.io 접속 후 오른쪽 위 'Start Coding'(또는 Pen). 화면이 HTML/CSS/JS 3칸으로 나뉘는데, 왼쪽 위 HTML 칸에만 입력하면 아래 결과가 실시간으로 보여요. 설치·회원가입 없이 `<h1>안녕하세요</h1>` 한 줄만 쳐도 미리보기에 큰 글씨가 뜹니다.
2. **뼈대 태그 4개 직접 쳐 보기** — HTML 칸에 5줄을 손으로 직접 타이핑하세요(복붙 말고 손으로 쳐야 태그가 눈에 익어요). `h1`=제목, `p`=문단, `button`=버튼, `input`=입력창. 각 태그가 미리보기에서 어떻게 보이는지 눈으로 확인.
3. **여는 태그·닫는 태그 규칙 익히기** — 대부분 태그는 `<p>내용</p>`처럼 여는 `<p>`와 닫는 `</p>`로 감쌉니다. 닫는 태그의 슬래시(`/`)를 일부러 지워 보고 미리보기가 어떻게 깨지는지 확인한 뒤 다시 복구하세요. `input`처럼 감쌀 내용이 없는 태그는 닫는 태그가 없어요.
4. **AI에게 페이지 뼈대 시키기** — '이벤트 신청 페이지' HTML을 받습니다. 받은 코드 전체를 복사해 CodePen HTML 칸에 붙여넣어 미리보기로 확인.
5. **AI 결과물을 내 손으로 수정하기** — `<h1>` 안의 제목을 내 이벤트 이름으로, `<button>` 안의 글자를 '지금 신청'으로 고치고, 전화번호 `<input>` 한 줄을 이메일 input 아래에 복사해 추가. AI를 다시 부르지 말고 내가 직접 타이핑하는 게 핵심.
6. **안 되는 부분만 AI에게 콕 집어 묻기** — 수정하다 화면이 깨지면 내 코드 전체와 '무엇이 문제인지'를 붙여 물어보세요. 통째로 다시 만들라고 하지 말고 '이 부분만 고쳐 줘'라고 범위를 좁히는 게 요령.

## 흔한 실수 → 교정

- ✗ 닫는 태그(`</p>`, `</h1>`)를 빼먹어서 그 아래 글자까지 이상하게 뭉쳐 나옴 → **여는 태그를 쳤으면 곧바로 닫는 태그를 함께 치는 습관.** `<p></p>`를 먼저 만들고 그 사이에 내용을 넣으면 빼먹지 않아요.
- ✗ AI가 준 코드를 글자 하나 못 고치고, 마음에 안 들면 '다시 만들어 줘'만 반복 → **제목·버튼 글자 같은 텍스트 수정은 태그 사이의 글자만 직접 바꾸면 끝.** AI를 다시 부르는 것보다 내가 타이핑하는 게 10배 빠릅니다.
- ✗ 꺾쇠괄호를 한글 모드로 쳐서 `＜＞`(전각) 문자가 들어가 태그가 작동하지 않음 → **태그의 `<` `>`는 반드시 영문 입력 상태에서.** 미리보기에 태그 글자가 그대로 보이면 전각 괄호를 의심하고 영문으로 다시 치세요.

## 도구

- 🛠 **CodePen** (codepen.io) — 설치 없이 HTML을 치면 결과가 바로 보이는 온라인 편집기.
- 🛠 **ChatGPT** (chat.openai.com) — 페이지 뼈대 HTML 생성과 수정 질문.
- 🛠 **Claude** (claude.ai) — 긴 코드 설명·부분 수정에 강한 AI 조수.
- 🛠 **MDN HTML 요소 사전** (developer.mozilla.org/ko/docs/Web/HTML/Element) — 태그 뜻이 궁금할 때 찾아보는 한국어 공식 문서.

## 실전 프롬프트

### 이벤트 신청 페이지 뼈대 만들기

```text
HTML 기본 태그만 써서 간단한 '[이벤트 이름]' 신청 페이지를 만들어 줘. 조건: (1)CSS·자바스크립트 없이 순수 HTML 태그만 (2)제목은 <h1>, 안내 문단은 <p>, 이름·이메일 입력은 <input>에 placeholder 넣기, 신청 버튼은 <button> (3)초보자가 읽기 쉽게 태그마다 한 줄씩 줄바꿈 (4)20줄 이내. 코드만 출력.
```

`HTML` `뼈대` `생성`

### 내 HTML 깨진 곳 콕 집어 고치기

```text
아래는 내가 만든 HTML이야. [무엇이 문제인지 한 줄로: 버튼을 맨 아래로 옮기고 싶어]. 전체를 다시 만들지 말고 바꿔야 할 줄만 알려주고, 왜 그렇게 되는지 초보자 눈높이로 한 문장으로 설명해 줘. [내 HTML 코드 전체 붙여넣기]
```

`HTML` `부분 수정` `디버깅`

### 태그 뜻 쉬운 말로 풀어보기

```text
아래 HTML 코드를 한 줄씩 짚어가며 각 태그가 화면에서 무슨 역할을 하는지 초등학생도 알 수 있는 쉬운 말로 설명해 줘. 전문 용어는 쓰지 말고, 각 줄 옆에 '이건 ~하는 부분' 형식으로. [코드 붙여넣기]
```

`HTML` `태그` `설명`

### 입력칸·버튼 하나 더 추가하기

```text
아래 HTML에 '[추가하고 싶은 것: 전화번호 입력칸]'을 하나 더 넣어 줘. 기존 코드는 그대로 두고 추가되는 줄만 어디에 넣으면 되는지 위치와 함께 알려줘. [코드 붙여넣기]
```

`HTML` `입력창` `추가`
