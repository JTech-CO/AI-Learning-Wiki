_코드 0줄로 Replit Agent에게 말로만 주문해 DB·입력폼·목록·삭제까지 갖춘 미니 CRM 웹앱을 오늘 밤 안에 미리보기까지 완성한다. AI가 화면과 데이터베이스를 알아서 짓고, 새로고침해도 데이터가 남는 진짜 앱을 무료 한도 안에서 만든다._

:::note[학습 목표]
- 말(자연어)만으로 Replit Agent에게 미니 CRM 웹앱을 짓게 해 미리보기에서 완성한다
- 'Replit PostgreSQL'을 명시해 새로고침해도 사라지지 않는 영구 저장을 구현한다
- 코드를 한 줄도 안 건드리고 채팅으로 기능 추가·오류 수정을 반복한다
:::

## 핵심 개념

지금까지 AI에게 '글 써줘'를 시켰다면, 이번엔 **AI에게 앱을 짓게** 합니다. AI가 똑똑한 시공팀이고 당신은 건물주예요. '손님 이름·전화·메모를 적는 작은 관리 프로그램을 만들어줘'라고 **말로 주문만** 하면, AI가 화면(눈에 보이는 부분)과 데이터베이스(정보가 영구 저장되는 창고)를 알아서 만듭니다. 핵심 도구는 **Replit** — 브라우저 안에서 AI(Replit Agent)가 코드를 짓고 바로 실행해 보여주는 작업실이라 **코드를 몰라도 됩니다.**

꼭 알아야 할 세 가지:

1. **데이터를 영구 저장하려면 'Replit의 PostgreSQL 데이터베이스를 써줘'라고 명시**해야 합니다. 요청하면 Replit이 자체 관리형 PostgreSQL을 자동 연결해요. Supabase 같은 외부 DB가 저절로 붙는 게 아닙니다.
2. **미리보기(Preview)는 나만 보는 연습 화면**이고, '배포(Deploy)'로 공개 주소를 만드는 건 유료라 목표는 '미리보기에서 완성'까지입니다.
3. **무료(Starter) 플랜은 매일 소량의 Agent 크레딧을 충전**(매일 리셋·월 상한)하되 '라이트 빌드(Lite build)'만 가능합니다. 미니 CRM 정도는 라이트 빌드로 충분해요. 더 복잡한 풀빌드나 공개 배포는 유료(Core 등)가 필요하고, 무료 한도를 넘으면 'Core로 업그레이드' 안내가 뜰 수 있습니다 — 고장이 아니라 정상 경계예요.

### 흐름

🗣️ 내가 말로 주문(미니 CRM 만들어줘) → 🤖 AI가 라이트 빌드 계획(화면은 나올 때만) → ⌨️ AI가 코드 작성(화면+저장 로직) → 🗄️ DB 자동 연결(Replit PostgreSQL) → ✅ 미리보기 완성(무료 한도 안에서)

### 왜 이게 될까?

Replit Agent는 수많은 실제 코드베이스를 학습해서 '화면 만들기·데이터베이스 연결하기·에러 고치기'를 사람 대신 실행할 줄 압니다. 그래서 **'무엇을 만들고 싶은지'만 말로 정확히 주문**하면 나머지 화면·저장소·연결 작업은 AI가 대신 다 짜요. 설계도만 그려주면 시공은 통째로 맡기는 겁니다.

## 👀 따라하기 예시 — 단골손님 이름·전화·메모를 저장하는 미니 CRM

**① 채팅창에 정확한 주문**

> 이름·전화번호·메모를 입력해 저장하는 간단한 고객관리(CRM) 웹앱을 만들어줘. 저장된 고객은 목록 카드로 보여주고 카드마다 삭제 버튼을 넣어줘. Replit의 PostgreSQL 데이터베이스를 연결해서 새로고침해도 안 사라지게 해줘.

> 💡 막연히 "CRM 만들어줘"가 아니라 저장 방식(DB)·화면 구성(카드)·기능(삭제)까지 콕 집어야 AI가 헤매지 않아요.

**② Agent가 라이트 빌드로 즉시 작업 시작** — "PostgreSQL 데이터베이스를 생성하고 customers 테이블을 만들었습니다 → 입력 폼과 카드 목록 UI를 작성 중 → 저장/삭제 라우트를 연결합니다..." 로그가 순서대로 올라오고 오른쪽 Preview에 입력창과 저장 버튼이 뜹니다.

> 💡 무료 Starter는 Lite 빌드라 계획 승인 없이 바로 짓기 시작하는 게 정상 — 멈춘 게 아니라 일하는 중이에요.

**③ 직접 테스트로 진짜 저장되는지 확인** — "홍길동/010-1234-5678/단골손님"을 넣고 저장하면 카드가 생깁니다. 미리보기를 새로고침해도 카드가 그대로 남아요.

> 💡 새로고침 후에도 남아있어야 "진짜 데이터베이스에 저장"된 것 — 아하 포인트예요.

**④ 말로 기능 하나 더 추가** — "고객 목록 맨 위에 총 고객 수: N명을 큰 글씨로 보여줘" → Preview 상단에 "총 고객 수: 1명"이 즉시 반영됩니다.

> 💡 한 번에 하나씩 확인하고 다음 걸 시키면 AI가 헷갈리지 않고 정확히 반영해요.

좋은 결과의 기준: (1) 새로고침 후에도 저장한 고객이 남아있다 (2) 카드 목록과 삭제 버튼이 정상 작동한다 (3) 코드를 한 줄도 안 건드리고 전부 말로만 완성했다.

## 단계별 따라하기

1. **Replit 가입(무료 Starter, 2분)** — replit.com → 'Sign up' → 'Continue with Google'로 구글 계정 가입(비번 안 만들어도 됨). 용도 설문은 'Skip'. 신용카드 없이 무료 Starter로 시작 — Agent에게 매일 무료 크레딧이 조금씩 충전(매일 리셋·월 상한). '무엇을 만들까요?' 큰 입력창이 보이면 성공.
2. **AI에게 앱을 통째로 주문하기(Replit Agent)** — 큰 입력창에 만들고 싶은 앱을 한국어로 적습니다. 'Improve prompt'(주문 다듬기) 버튼이 있으면 눌러도 좋아요(선택). 보내기(↑/Send). (예: "이름·전화번호·메모를 입력해 저장하는 간단한 CRM 웹앱. 목록 카드로 보여주고 각 카드에 삭제 버튼. Replit의 PostgreSQL로 영구 저장. 화면은 한국어, 모바일에서도 잘 보이게.")
3. **빌드 모드 확인 및 빌드 시작** — Agent 4에는 세 빌드 모드가 있어요: ① Lite(무료 포함 모든 플랜, 빠른 경량 모델 10~60초, 미니 CRM은 이 모드로 완성 가능) ② Economy(Core 이상 유료, 비용 최적화 모델, 일반 빌드 기본값) ③ Power(Core 이상 유료, 가장 강력, 복잡·대형용). 무료 Starter는 Lite가 자동 적용. 빌드는 ⓐ 곧바로 시작(간단한 주문이면 계획 화면 없이 바로 — 4단계로) 또는 ⓑ 계획(Plan)·질문이 먼저 뜸('Approve/Start/Build' 누르고 질문엔 한국어로 답). Economy/Power 안내가 뜨면 유료 필요 → 채팅에서 '라이트 빌드로 간단히 만들어줘' 재요청.
4. **AI가 짓는 동안 기다리고 화면 확인** — 몇 분간 AI가 파일을 만들고 DB를 연결(글자가 주르륵 올라가도 정상). 끝나면 화면이 둘로 나뉘어 왼쪽 채팅, 오른쪽 미리보기(Preview). 입력칸과 '저장' 버튼이 보이면 성공. 오른쪽이 비어 있으면 초록 'Run' 버튼이나 미리보기 새로고침. 안 뜨면 '미리보기가 안 떠. 다시 실행해줘'.
5. **직접 테스트 — 진짜 저장되나** — '홍길동/010-1234-5678/단골손님' 저장 → 카드 생김 → 새로고침해도 남으면 DB에 진짜 저장. 사라지면 '저장한 고객이 새로고침하면 사라져. Replit PostgreSQL에 영구 저장되도록 고쳐줘.'
6. **말로 기능 추가·수정하기(코딩 없이)** — 왼쪽 채팅창에 원하는 변화를 한국어로. 한 번에 하나씩 주문하는 게 안전. 무료 Starter는 하루 Agent 크레딧이 제한돼 많이 고치면 '크레딧 소진'/'Core로 업그레이드' 안내가 뜰 수 있음 — 다음 날 충전되니 그날은 거기까지. (예: '고객 목록 맨 위에 "총 고객 수: N명"을 큰 글씨로' 또는 '전화번호가 비어 있으면 저장이 안 되게 하고 경고를 띄워줘')
7. **결과물 보관 + (선택) 공개 배포 안내** — 프로젝트는 내 Replit 계정에 자동 저장. 다시 로그인해 열고 'Run'만 누르면 그대로 돎. 'README.md에 이 앱이 뭐고 어떻게 다시 켜는지 정리해줘'로 설명서도 생성. (선택) 공개 주소가 필요하면 'Deploy'(유료, 결제 안내). 무료 Starter는 30일 유지 시험용 배포 1개 가능하나 꾸준히 운영하려면 유료 필요. 배포는 사용량 기반 과금이라 소규모라도 월 몇 달러. 정기 배포는 Replit Core(2026-02-25 기준 월 $20, 매월 $20 사용 크레딧 포함, 미사용 시 소멸)가 현실적 진입점.

## 흔한 실수 → 교정

- ✗ 한 번에 기능 10개를 몰아서 주문 → AI가 헷갈려 절반만 만듦 → **'저장→목록→삭제→검색' 순서로 하나씩, 잘 되는지 확인 후 다음을.**
- ✗ 데이터베이스를 안 적어서 정보가 임시로만 저장 → **'Replit PostgreSQL에 영구 저장'을 꼭 명시.** Replit이 알아서 외부 Supabase를 붙여주는 게 아니라 요청해야 자체 DB를 연결. 새로고침해도 남는지로 확인.
- ✗ 오류가 나면 직접 코드를 건드리려 함 → **코드 화면은 손대지 말고 에러 메시지를 그대로 복사해 채팅창에 '이 에러 고쳐줘'.** AI가 고치는 게 더 빠르고 안전.
- ✗ 무료로 '공개 URL 배포'까지 될 거라 기대 → **미리보기(나만 보는 연습)는 무료지만 공개 배포(Deploy)는 유료 크레딧 필요.** 연습은 미리보기 완성까지, 정말 공유가 필요할 때만 유료 Deploy.
- ✗ Agent가 갑자기 멈추거나 '크레딧 소진/Core로 업그레이드' 안내 → **무료 Starter는 라이트 빌드만·하루 크레딧 제한.** 풀빌드 요구나 크레딧 소진 시 업그레이드 안내가 뜨는 건 정상 경계. '라이트 빌드로 간단히' 재요청하거나 다음 날 충전 크레딧으로 이어감.
- ✗ 계획(Plan) 화면이 안 떠서 '실패한 줄' 알고 멈춤 → **라이트 빌드에서 간단한 주문이면 Plan 승인 화면 없이 바로 빌드 시작이 정상.** Approve 버튼이 없어도 이미 일하는 중이니 미리보기가 채워질 때까지 기다림. 계획을 꼭 보려면 채팅의 'Plan' 옵션을 직접 눌러야.

## 도구

- 🛠 **Replit** (replit.com) — 브라우저에서 AI에게 말로 앱을 짓게 하고 바로 실행해 보여주는 작업실. 무료 Starter로 가입, Agent에게 매일 무료 크레딧 충전(매일 리셋·월 상한), 무료는 '라이트 빌드'만.
- 🛠 **Replit Agent** (2026 현재 Agent 4) — 자연어 주문을 받아 화면·DB·코드를 자동 생성하는 내장 AI. Agent 4 기준 3가지 빌드 모드(Lite/Economy/Power), 라이트 빌드는 간단한 주문이면 Plan 화면 없이 바로 빌드.
- 🛠 **Replit 내장 데이터베이스(관리형 PostgreSQL)** — 요청하면 Agent가 자동 연결해 영구 저장(외부 Supabase는 직접 설정해야).
- 🛠 **공개 배포(Deploy)** — 공개 URL을 만드는 유료 단계, 사용량 기반 과금. 정기 운영은 Replit Core(월 $20, 매월 $20 사용 크레딧 포함).
- 🛠 **Claude·ChatGPT** — 주문 문장이 막힐 때 다듬어주는 보조.

```text
고객 메모에 'VIP'가 들어가면 그 카드를 노란색으로 강조하고 위에 '⭐VIP' 배지를. VIP 고객만 따로 모아 보는 버튼도.
```

`프롬프트` `심화`

## 직접 만들기 (미션)

:::tip
'고객관리(CRM)'가 아니라 '할 일 목록(To-Do)' 앱을 같은 방식으로 만들어보세요. Replit Agent 채팅창에 할 일 제목·완료 체크·삭제 기능이 있고 Replit PostgreSQL로 영구 저장되는 앱을 주문하고, 새로고침해도 남는지 직접 테스트해보세요.
:::
