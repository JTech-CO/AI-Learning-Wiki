_색·여백·글꼴·정렬과 flex 레이아웃 같은 기본 CSS로 밋밋한 흰 화면을 바꾼다. 같은 HTML도 CSS 몇 줄이면 카드가 나란히 놓인 깔끔한 디자인으로 변신함을 직접 실습으로 확인한다._

:::note[학습 목표]
- '선택자 { 속성: 값; }' 규칙으로 body와 카드에 색·글꼴·여백을 직접 지정한다
- padding·margin·border-radius·box-shadow로 밋밋한 사각형을 입체적인 카드로 만든다
- 카드들을 감싼 부모에 display:flex를 줘서 카드를 가로로 나란히 정렬한다
:::

## 핵심 개념

CSS는 HTML이라는 '뼈대'에 **색과 옷을 입히는 규칙**이에요. 규칙은 항상 `무엇을(선택자) { 어떻게(속성: 값;) }` 형태를 띱니다. 예를 들어 `body { background: #f5f5f5; }` 는 "몸통 전체 배경을 연회색으로"라는 뜻이에요. 여백은 **안쪽 여백(padding)** 과 **바깥쪽 여백(margin)** 으로 나뉘고, 여러 요소를 가로/세로로 나란히 배치할 때는 **부모에 `display: flex` 를 주는 것**이 오늘의 핵심 무기예요. 색·글꼴처럼 취향이 필요한 값은 AI에게 팔레트를 물어보고, 배치 감각은 직접 숫자를 바꿔보며 익히는 게 가장 빠릅니다.

### 왜 이게 될까?

브라우저는 CSS 규칙을 `선택자 { 속성: 값; }` 순서 그대로 읽어 화면에 바로 반영해요. 색이나 여백 숫자 하나만 바꿔도 결과가 즉시 눈에 보입니다. 색 조합처럼 '감각'이 필요한 부분은 AI가 이미 수천 개의 예쁜 웹사이트 팔레트를 학습해뒀기 때문에, "어떤 느낌"인지만 말하면 HEX 코드는 AI가 채워줘요.

## 👀 따라하기 예시 — 카페 메뉴 카드 2개를 "따뜻하고 아늑한 느낌"으로

**① 팔레트부터 물어보기** — AI에게 "카페 메뉴 카드, 따뜻하고 아늑한 느낌의 색 팔레트 4개(HEX)와 어울리는 글꼴 추천해줘" → 배경 `#FFF8F0` / 카드 `#FFFFFF` / 강조 `#E07A5F` / 글자 `#3D405B`, 글꼴은 부드러운 고딕 계열.
> 💡 색 감각은 AI가 대신 고민하고, 나는 "따뜻하고 아늑한"처럼 느낌만 말로 전달하면 되니 훨씬 빠릅니다.

**② 받은 HEX를 붙여넣기** — style 태그 안 body와 .card에 그대로 붙여넣어요.
```css
body { background:#FFF8F0; font-family:sans-serif; }
.card { background:#FFFFFF; color:#3D405B; }
```
> 💡 AI가 준 값을 통째로 복붙하면 되니 색상표를 뒤져가며 고민할 시간이 사라져요.

**③ 여백·그림자로 입체감** — 카드에 padding·border-radius·box-shadow를 더해요.
```css
.card { padding:20px; margin:12px; border-radius:12px; box-shadow:0 2px 8px rgba(0,0,0,0.1); }
```
> 💡 평평하던 사각형이 "떠 있는 카드"처럼 보이는 순간, 왜 여백과 그림자가 디자인의 8할인지 몸으로 알게 돼요.

**④ flex로 가로 정렬** — 두 카드를 `.row`로 감싸고 flex를 줘요.
```css
.row { display:flex; gap:16px; justify-content:center; }
```
> 💡 flex는 반드시 "카드들을 감싼 부모"에 줘야 자식들이 나란히 서요. 카드 자신에게 주면 아무 일도 안 일어납니다 — 오늘의 아하 포인트.

좋은 결과의 기준: (1) 카드가 세로로 안 쌓이고 가로로 나란히 섰는가 (2) 배경·글자색이 서로 부딪히지 않고 통일감 있는가 (3) 여백이 답답하지 않게 숨 쉬는가.

## 단계별 따라하기

1. **실습용 HTML 한 장 준비** — 메모장(윈도우)/텍스트편집기(맥)를 열고 뼈대를 붙여넣은 뒤 `index.html` 로 저장. 저장할 때 파일 형식을 '모든 파일'로 하고 확장자를 `.html` 로. 더블클릭하면 브라우저에서 열려요. (`.card` div 2개: 커피 4000원, 케이크 6000원)
2. **style 태그 넣고 색부터 입히기** — `</title>` 바로 아래에 `<style></style>`를 추가하고 그 안에 body와 .card 규칙을 써요. 저장 후 새로고침(F5)하면 바로 보임. 색은 `#` 뒤 6자리 16진수(HEX).
3. **여백과 모서리로 카드답게** — .card 규칙에 padding(안쪽 여백), margin(바깥 여백), border-radius(둥근 모서리), box-shadow(그림자)를 추가. 숫자를 `20px`→`40px`로 바꿔보며 여백이 커지는 걸 눈으로 확인.
4. **flex로 카드를 가로로 나란히** — 두 카드를 감싸는 부모가 필요해요. 카드들을 `<div class="row">...</div>`로 감싼 뒤 `.row { display:flex; gap:16px; }`. 세로로 쌓여 있던 카드가 가로로 섭니다. gap은 카드 사이 간격.
5. **AI에게 색 팔레트와 글꼴 추천받기** — 어울리는 색 3~4개(HEX)와 글꼴을 받아요. 받은 HEX 값을 background·color·box-shadow 자리에 갈아끼우고 새로고침해 비교.
6. **정렬 다듬고 완성 확인** — 글자 정렬은 `text-align:center`, 가격을 굵게는 `font-weight:bold`, 제목 크기는 `font-size`. 마지막으로 브라우저 창 폭을 줄였다 늘였다 하며 깨지지 않는지 확인.

## 흔한 실수 → 교정

- ✗ 세미콜론(;)이나 중괄호(})를 빠뜨려서 그 아래 규칙이 통째로 안 먹힘 → **속성은 `값;` 처럼 항상 세미콜론으로 끝내고, 각 선택자 블록은 `{` 로 열고 `}` 로 닫혔는지 확인.** 갑자기 스타일이 안 먹으면 바로 윗줄의 세미콜론부터 의심.
- ✗ `display:flex` 를 카드(.card)에 줘서 아무 변화가 없음 → **flex는 '나란히 놓을 자식들의 부모'에 준다.** 카드들을 감싼 .row 같은 부모 요소에 `display:flex`.
- ✗ 저장을 .txt로 하거나 새로고침을 안 해서 변경이 화면에 안 보임 → **파일은 반드시 `.html` 확장자로 저장하고, 코드를 고칠 때마다 브라우저에서 F5(새로고침).**

### 색 팔레트+글꼴 추천 (가장 먼저)

```text
나는 [카페 메뉴 카드]를 만드는 초보야. 따뜻하고 깔끔한 느낌의 웹 색 팔레트를 추천해줘. 배경색, 카드색, 강조색, 글자색 4개를 각각 HEX 코드로 주고, 각 색을 CSS의 어떤 속성(background/color 등)에 쓰면 되는지 한 줄로. 한글 웹에 잘 어울리는 무료 글꼴도 1개.
```

> 확인된 작성 예시 없음

`프롬프트` `색 팔레트` `글꼴`

### 내 CSS 코드 리뷰받기

```text
아래는 내가 쓴 CSS야. 초보 눈높이로 (1)이상하거나 안 먹힐 부분 (2)더 깔끔해 보이게 할 수정 2가지를. 코드를 통째로 다시 쓰지 말고 바뀔 줄만 before/after로. [내 <style> 안 코드 붙여넣기]
```

> 확인된 작성 예시 없음

`프롬프트` `코드 리뷰` `CSS`

### flex 정렬이 원하는 대로 안 될 때

```text
CSS flex를 쓰는데 [카드들이 가로로 안 서고 세로로 쌓여] 있어. 내 HTML과 CSS는 아래와 같아. 무엇이 문제인지 초보도 알게 짚어주고, 고친 코드를. HTML: [붙여넣기] CSS: [붙여넣기]
```

> 확인된 작성 예시 없음

`프롬프트` `flex` `디버깅`

### 모바일에서도 안 깨지게

```text
내 카드 레이아웃이 휴대폰 좁은 화면에서 옆으로 삐져나와. flex-wrap이나 반응형으로 좁은 화면에선 세로로 쌓이게 하고 싶어. 아래 CSS에 추가할 최소한의 코드만. [CSS 붙여넣기]
```

> 확인된 작성 예시 없음

`프롬프트` `반응형` `모바일`
