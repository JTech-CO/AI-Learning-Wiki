_원하는 미니 도구를 자연어로 설명하면 AI가 코딩·디버그·수정까지 대신해, 코딩을 한 줄도 몰라도 브라우저에서 바로 쓰는 단일 페이지 웹 도구 1개를 무료 한도 안에서 완성한다._

:::note[학습 목표]
- 코딩을 한 줄도 몰라도 브라우저에서 바로 쓰는 단일 페이지 웹 도구(예: 견적 계산기·습관 트래커) 1개를 직접 완성한다
- '버튼 색 바꿔줘'처럼 말로 수정하고, 무료 한도를 아끼며 한 세션에 끝낸다
- 완성한 도구를 게시(Deploy)해 링크로 다른 사람과 공유한다
:::

## 핵심 개념

**바이브 코딩(vibe coding)**은 코드를 직접 타이핑하는 대신, 원하는 걸 그냥 **말(자연어)로 설명하면 AI가 코드를 대신 짜 주는 방식**이에요. 식당에서 요리법을 몰라도 "매운 거 빼고 새우 많이요"라고 주문하면 요리가 나오는 것과 똑같아요. 여기서 '코드'란 컴퓨터에게 주는 명령어 글자들이고, **'단일 페이지 웹 도구'는 링크 하나만 열면 바로 쓰는 작은 프로그램**이에요.

핵심 비결 세 가지:

- **① 처음엔 한 덩어리로** — '무엇을 만들고 싶은지'를 한 번에 또렷이 설명한다.
- **② 수정은 한 번에 하나씩** — 마음에 안 들면 한 가지만 고쳐 달라고 한다. 한꺼번에 열 개를 고치라고 하면 AI가 헷갈린다.
- **③ 무료 한도를 아낀다** — 이 도구들은 무료로 시작할 수 있지만 무료 사용량에 '하루 한도'가 있다. 그래서 수정 횟수가 가장 넉넉한 도구를 골라 한 세션에 끝내는 게 중요하다.

### 흐름

🗣 원하는 걸 말로 또렷이 설명 → 🤖 AI가 도구 생성 → 👀 미리보기로 눈으로 확인 → ✏️ 수정 한 가지씩(한도 아끼며) → 🔗 게시(Deploy)·공유.

### 왜 이게 될까?

AI가 이미 수억 줄의 코드와 설명을 통째로 학습해서 '말 → 코드' 번역을 대신 해주기 때문이에요. 통역사가 옆에 있어서 한국어로 원하는 걸 말만 하면 컴퓨터 언어로 바꿔주는 셈이죠. **'무엇을 원하는지'만 또렷하게 말하면 실제 코드를 짜는 건 AI가 합니다.**

## 👀 따라하기 예시 — 오늘 습관 체크리스트 웹 도구

**① 한 덩어리로 설명** 입력창에 '무엇을·누구를 위해·기능 2~3개'를 한 번에 적어요.

> 하루 습관 체크리스트 웹앱을 만들어줘. 운동/물 마시기/독서 3개 항목, 동그라미 누르면 체크, 맨 아래에 "3개 중 2개 완료" 표시. 한국어, 큰 글씨, 휴대폰 화면.

→ 20~40초 뒤 오른쪽에 진짜 작동하는 체크리스트 화면이 뜬다.
> 💡 처음부터 구체적으로 적을수록 나중에 고칠 횟수가 줄어들어요 — 무료 한도를 아끼는 핵심.

**② 미리보기에서 직접 눌러 테스트** '운동' 옆 동그라미 클릭 → 초록 체크, 아래 글자가 '3개 중 1개 완료'로 바뀐다.
> 💡 눈으로 먼저 확인해야 '진짜 고칠 부분'만 골라 요청해요 — 안 그러면 필요 없는 수정까지 요청해 한도만 낭비.

**③ 마음에 안 드는 점 '한 가지만' 수정** "완료한 항목 글자는 회색으로 흐리게 보여줘" → 완료된 항목만 회색으로.
> 💡 한 번에 여러 개를 요청하면 AI가 헷갈려 엉뚱하게 고쳐요. 하나씩 고치고 확인하는 리듬이 가장 빠른 길.

**④ 게시(Deploy)해서 링크 만들기** 'Deploy' 버튼 → `https://my-habit-app.bolt.host` 같은 링크 생성 → 복사해서 카톡으로.
> 💡 링크 하나만 있으면 코딩을 모르는 사람도 브라우저에서 바로 눌러 써요 — 이게 '완성'의 의미.

좋은 결과의 기준: (1) 미리보기에서 버튼을 눌렀을 때 실제로 반응한다 (2) 원했던 문구/색/한국어가 정확히 반영됐다 (3) 링크를 다른 사람 폰으로 열어도 똑같이 작동한다.

## 단계별 따라하기

1. **도구 고르고 무료 가입(무료 한도 먼저 알기)** — 말로 웹 도구를 만들어 주는 사이트는 여러 개고 방식은 모두 같지만, '무료로 얼마나 여러 번 만들고 고칠 수 있는지'가 다르다. 반복 수정 연습에는 무료 한도가 가장 넉넉한 **Bolt.new**(무료 월 100만 토큰, 하루 30만 토큰) 추천. bolt.new → 'Sign in' → 구글 계정 → 가운데 큰 입력창.
2. **만들고 싶은 걸 '한 덩어리'로 설명** — 가운데 입력창에 '무엇을·누구를 위해·어떤 기능'을 한 번에. 평소 말투로 적어도 AI가 알아듣는다. Enter 후 20초~1분 로딩 뒤 오른쪽에 미리보기가 뜬다. 무료 토큰을 아끼려면 처음 한 번에 원하는 모습을 최대한 또렷이, 기능은 2~3개로 시작.
3. **미리보기에서 직접 눌러 보기** — 버튼·동그라미를 실제로 눌러 반응을 확인한다. 동그라미를 누르면 체크가 되는지, 아래 숫자가 바뀌는지. 미리보기가 안 보이면 화면 위쪽 'Preview' 탭. 'Code' 탭은 안 눌러도 된다.
4. **'한 번에 하나씩' 고치기** — 처음 적었던 그 입력창(보통 왼쪽/아래 채팅창)에 한국어로 부탁. 규칙 두 가지: (1) 한 번에 한 가지만 (2) 무료 도구는 '수정 한 번'도 한도를 쓰므로 정말 바꿀 것만. 고치고 → 미리보기 확인 → 또 한 번. 잘못 고쳐졌으면 "방금 거 되돌려줘(undo)".
5. **막혔을 때 / 무료 한도에 닿았을 때** — (가) 빨간 에러·미리보기 깨짐 → "에러가 났어. 고쳐줘"만 적어도 AI가 스스로 원인을 찾아 고친다(디버그). (나) 영어로 나오면 "전부 한국어로 바꿔줘". (다) 엉뚱하게 알아들으면 더 구체적으로: "체크가 아니라 토글 스위치로". (라) '오늘 무료 한도(토큰)를 다 썼다' → 결제하지 말고 Bolt는 보통 다음 날 다시 채워지니 내일 이어서 하거나, 다른 도구(v0.dev 무료 월 $5 크레딧)로 이어감(작업물은 사이트에 저장). (마) 두세 번 고쳐도 더 나빠지면 새 채팅(New)으로 처음부터 다시 설명하는 게 빠를 때도 있다.
6. **완성본 저장·공유** — 화면 오른쪽 위 게시 버튼(Bolt·v0 모두 'Deploy') → 인터넷 주소(링크) 생성. 링크 형식은 도구마다 다르다 — Bolt는 `...bolt.host`, v0는 Vercel 위라 `https://v0-(프로젝트이름).vercel.app`('v0.app'은 홈페이지 주소일 뿐, 배포된 내 앱 링크는 'vercel.app'으로 끝난다). 링크를 복사해 카톡으로. 무료 게시 링크에는 도구 로고 배지가 붙고 나만의 도메인은 유료. 단순 보관만 원하면 'Code' 탭에서 코드 전체를 복사해 메모장에 'index.html'로 저장. 작업물은 사이트 목록에 자동 저장된다.

## 흔한 실수 → 교정

- ✗ 한 번에 여러 개를 고쳐 달라고 함('색 바꾸고, 항목 추가하고, 표로 만들어줘') → **수정은 무조건 한 번에 한 가지.** 하나 고치고 미리보기로 확인한 뒤 다음. 느려 보여도 이게 가장 빠르고 무료 한도도 아낀다.
- ✗ 처음 설명이 너무 막연('계산기 만들어줘'만) → **무엇을·누구를 위해·기능 2~3개를 구체적으로.** 첫 설명이 좋을수록 나중에 고칠 횟수(=무료 한도 소모)가 준다.
- ✗ 에러가 뜨면 내가 코드를 고쳐야 하는 줄 알고 포기 → **코드는 손대지 않는다.** "에러 났어, 고쳐줘"라고 입력창에 적으면 AI가 알아서 디버그.
- ✗ 처음부터 기능 10개짜리 거대한 앱을 요청 → **기능 2~3개짜리 작은 도구로 시작**해 완성한 뒤 하나씩 더. 작게 시작해야 끝까지 간다.
- ✗ 무료인 줄만 알고 수정 한도 없이 막 고치다 세션 중간에 '한도 초과'로 막혀 '안 된다'고 느낌 → **한도 방식이 도구마다 다르다**(Bolt=하루 30만 토큰으로 가장 넉넉, v0=월 $5 크레딧을 복잡도만큼 차감, Lovable=무료 크레딧이 더 적음). 넉넉한 Bolt로 한 세션에 끝내고, 막히면 결제 대신 다음 날·다른 도구로.

## 도구

- 🛠 **Bolt.new** (bolt.new) — 말로 웹 도구를 만들어 주는 사이트. 무료가 하루 30만 토큰(월 100만)으로 가장 넉넉해 반복 수정 연습에 적합. 무료 게시는 `...bolt.host` 링크 + 로고 배지.
- 🛠 **v0.dev** (홈페이지 v0.app) — Vercel이 만든 동일 방식. 무료는 횟수가 아니라 '월 $5 크레딧'제로 복잡도만큼 차감·다 쓰면 멈춤. 배포 링크는 `...vercel.app`(예: v0-my-app.vercel.app).
- 🛠 **Lovable** (lovable.dev) — 같은 방식. 무료는 하루 5크레딧(월 30) 정도로 한도가 가장 빡빡.
- 🛠 **Claude** — 만들 기능을 먼저 정리하거나 프롬프트를 다듬을 때 보조.

## 실전 프롬프트

### 새 도구 처음 만들 때

```text
[무엇]을(를) 만들어줘. 사용자는 [누구]이고, 다음 기능이 필요해: 1)[기능1], 2)[기능2], 3)[기능3]. 화면은 한국어로, 글씨 크게, 깔끔하게. 휴대폰에서도 잘 보이게. 단일 페이지 웹 도구로. 한 번에 완성도 높게(나중에 고칠 횟수를 줄이고 싶어).
```

`프롬프트` `바이브코딩` `생성`

### 한 번에 하나씩 수정

```text
[바꾸고 싶은 부분 한 가지]만 이렇게 바꿔줘: [원하는 모습]. 다른 부분은 건드리지 말고.
```

`프롬프트` `수정` `반복`

### 에러·오류 자동 수정

```text
지금 화면에 에러가 나거나 동작이 이상해. 원인을 찾아서 고쳐줘. 그리고 무엇이 문제였는지 한 줄로 쉽게 설명해줘.
```

`프롬프트` `디버그` `에러`

### 예시: 간단 견적 계산기

```text
간단한 견적 계산기 단일 페이지 웹앱을 만들어줘. 입력칸 3개(수량, 단가, 할인율%)가 있고, 입력하면 자동으로 '합계 = 수량 × 단가 × (1 − 할인율/100)'을 계산해 큰 글씨로. 결과는 천 단위 콤마와 '원'. 한국어, 휴대폰에서도 잘 보이게, 깔끔한 디자인.
```

`프롬프트` `예시` `견적 계산기`

### 예시: 하루 습관 체크리스트

```text
하루 습관 체크리스트 단일 페이지 웹앱을 만들어줘. 운동/물 마시기/독서 3개 항목, 각 항목 옆 동그라미를 누르면 완료 체크, 맨 아래에 '3개 중 2개 완료'처럼 오늘 진행도. 맨 위에 오늘 날짜도. 한국어, 큰 글씨, 휴대폰에서도.
```

`프롬프트` `예시` `습관 체크리스트`

## 채점 기준

| 기준 | 배점 |
| --- | --- |
| 내가 적은 설명에 '무엇을·누구를 위해·기능'이 다 들어있었나 | 5 |
