_트리거-액션 개념으로 반복 업무(리드 저장·알림·콘텐츠 발행)를 노코드 자동화하는 첫 시나리오를 직접 만들고 디버깅하는 법을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, 구글 폼(또는 이메일)으로 리드가 들어오면 스프레드시트에 자동 저장되고 슬랙/이메일로 알림이 오는 나만의 첫 자동화 시나리오를 직접 만들고 디버깅할 수 있습니다.
:::

> "이거 매번 손으로 복붙하는 거 지겹지 않아?" 새 문의가 들어올 때마다 스프레드시트에 옮겨 적고, 슬랙에 알리고, 답장하고... 이 반복을 오늘 로봇에게 넘깁니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 구글 폼(또는 이메일)으로 리드가 들어오면 스프레드시트에 자동 저장되고 슬랙/이메일로 알림이 오는 나만의 첫 자동화 시나리오를 직접 만들고 디버깅할 수 있습니다.

## 핵심 개념

자동화 도구의 핵심은 딱 두 단어입니다. 트리거(Trigger, "이런 일이 생기면")와 액션(Action, "이걸 해라"). 예를 들어 "구글 폼에 새 응답이 오면(트리거) → 스프레드시트 행을 추가하고(액션1) → 슬랙에 메시지를 보낸다(액션2)"처럼 레고 블록을 잇듯 연결합니다. 코드를 한 줄도 쓰지 않고, Zapier·Make·n8n 같은 도구가 앱들 사이의 배관공 역할을 대신해 줍니다. Zapier는 가장 쉽고, Make는 시각적이고 저렴하며, n8n은 무료로 직접 설치해 무제한으로 쓸 수 있다는 차이가 있습니다. 중요한 건 도구가 아니라 "트리거→액션" 사고방식이며, 이 하나만 익히면 리드 저장·알림·콘텐츠 발행 등 무엇이든 자동화할 수 있습니다.

### 왜 작동하는가

자동화 도구는 "트리거→액션" 규칙을 24시간 대신 지켜보는 로봇 조수예요. 사람이 폼을 확인하고, 옮겨 적고, 알리는 3단계를 매번 반복하는 대신, 로봇에게 "이런 일이 생기면 이걸 해줘"라고 딱 한 번만 알려두면 됩니다. 그래서 당신은 규칙만 한 번 세팅하면, 그 다음부터 반복 작업은 영원히 AI가 대신해줍니다.

## 👀 따라하기 예시

"상담신청서" 구글 폼으로 신청이 들어올 때마다 슬랙 #리드 채널에 자동으로 알림이 뜨게 만드는 상황이에요. 제가 먼저 처음부터 끝까지 만들어볼게요, 눈으로 따라오세요.

### 1. ① 반복 업무를 "트리거 + 액션" 한 문장으로 쪼갠다

**실제 결과**

```text
'구글 폼으로 상담 신청이 들어오면 → 슬랙 #리드 채널에 이름·연락처를 알림으로 보낸다'
```

> 자동화는 도구 선택보다 이 한 문장을 정확히 쓰는 게 8할입니다. 문장이 애매하면 다음 단계가 다 꼬여요.

### 2. ② Zapier에서 Trigger를 Google Forms로 연결하고 테스트

**실제 결과**

```text
Test trigger 실행 결과: 샘플 데이터 '홍길동, 010-1234-5678, 관심상품: 영어'가 화면에 표시됨 → 초록색 체크 표시로 연결 성공 확인
```

> 테스트에서 실제 데이터가 보여야 다음 단계에서 그 필드를 매핑할 수 있어요. 여기서 확인 안 하면 뒤에서 다 헤맵니다.

### 3. ③ Action을 Slack으로 연결하고 필드를 매핑(끼워넣기)

**실제 결과**

```text
Message Text 칸에 '🔔 새 상담: {{이름}} / {{연락처}} / 관심: {{관심상품}}'처럼 중괄호 필드를 드롭다운으로 삽입 완료
```

> 직접 타이핑하면 모든 응답에 똑같은 문구만 나가요. 필드로 매핑해야 신청자마다 다른 내용이 자동으로 채워집니다 — 이게 바로 아하 포인트예요.

### 4. ④ Test step 실행 후 토글을 On으로 켜기

**실제 결과**

```text
슬랙 #리드 채널에 '🔔 새 상담: 홍길동 / 010-1234-5678 / 관심: 영어' 메시지 도착 확인 → 오른쪽 상단 토글 초록색 On으로 전환
```

> 테스트 성공과 실제 작동은 달라요. 토글을 켜야 이 순간부터 사람 손 없이 진짜로 돌아갑니다.

### 완성 결과

완성물은 "구글 폼 응답 → 슬랙 알림"이 사람 개입 없이 자동으로 도는 살아있는 Zap입니다. 좋은 결과의 기준: (1) 토글이 On 상태다 (2) 알림 메시지에 매번 다른 신청자 정보가 정확히 채워진다 (3) 실패 시 Zap History에서 원인을 바로 확인할 수 있다.

## 단계별 따라하기

### 1단계 — 자동화할 반복 업무 1개 고르기 (5분) 🙋나

지금 손으로 매번 반복하는 일 중 '트리거 하나 → 액션 하나'로 쪼갤 수 있는 것을 딱 하나만 종이에 적으세요. '언제(트리거)' + '무엇을 한다(액션)' 형식으로 문장 하나를 만듭니다.

**복사·실행 예시**

```text
'구글 폼으로 상담 신청이 들어오면 → 슬랙 #리드 채널에 이름·연락처를 알림으로 보낸다'
```

### 2단계 — Zapier 무료 계정 만들고 Zap 새로 만들기 (5분) 🙋나

zapier.com에 구글 계정으로 가입한 뒤 왼쪽 상단 'Create' → 'Zaps'를 누릅니다. 빈 캔버스에 회색 'Trigger' 블록과 'Action' 블록이 보이면 준비 완료입니다.

**복사·실행 예시**

```text
가입 직후 'Create Zap' 버튼 클릭 → 'Trigger'라고 적힌 첫 블록을 클릭
```

### 3단계 — 트리거 앱 연결하기 (7분) 🤝함께

Trigger 블록에서 앱은 'Google Forms', 이벤트는 'New Form Response'를 고릅니다. 'Sign in'으로 구글 계정을 연결하고, 자동화할 폼을 선택한 뒤 'Test trigger'를 눌러 최근 응답 1건이 불러와지는지 확인합니다.

**복사·실행 예시**

```text
App: Google Forms / Event: New Form Response / Form: '상담신청서' → Test 성공 시 '홍길동, 010-1234-5678' 샘플이 표시됨
```

### 4단계 — 액션 앱 연결하고 필드 매핑하기 (10분) 🤝함께

Action 블록에서 앱은 'Slack', 이벤트는 'Send Channel Message'를 고릅니다. 채널을 #리드로 정하고 Message Text 칸에 고정 텍스트를 쓰다가, 이름·연락처 자리에는 3단계에서 불러온 폼 필드를 드롭다운으로 '끼워 넣습니다'(이게 매핑입니다).

**복사·실행 예시**

```text
Message Text: '🔔 새 상담: {{이름}} / {{연락처}} / 관심: {{관심상품}}' — 중괄호 부분은 직접 타이핑이 아니라 필드 선택으로 삽입
```

### 5단계 — 테스트하고 켜기 (5분) 🙋나

'Test step'을 눌러 슬랙에 실제 메시지가 도착하는지 눈으로 확인합니다. 도착했으면 오른쪽 상단 토글을 'On'으로 올려 Zap을 활성화합니다. 활성화해야 실제로 돌아갑니다.

**복사·실행 예시**

```text
슬랙 #리드에 '🔔 새 상담: 홍길동 / 010-1234-5678 / 관심: 영어' 메시지가 뜨면 성공 → 토글 On
```

### 6단계 — 고장 났을 때 디버깅하기 (8분) 🤖A

Zapier 왼쪽 메뉴 'Zap History'(또는 'Runs')에서 각 실행의 초록(성공)·빨강(실패)을 확인합니다. 빨간 실행을 클릭하면 어느 단계에서 어떤 에러가 났는지 나오는데, 그 에러 메시지를 통째로 복사해 AI에게 붙여넣고 원인과 해결책을 물어봅니다.

**복사·실행 예시**

```text
에러 'The channel #리드 was not found' → AI에게 물으니 '슬랙 채널명 앞의 # 제거 또는 봇을 채널에 초대하라'는 답을 받아 수정
```

## 흔한 실수와 교정
- **실수:** Zap을 만들고 'On'으로 켜지 않아 실제로는 아무것도 안 돌아간다.
  - **교정:** 만든 직후 오른쪽 상단 토글이 'On(초록)'인지 반드시 확인하세요. 테스트 성공 ≠ 활성화입니다. 켜야 실전에서 작동합니다.
- **실수:** 메시지에 이름·연락처를 직접 타이핑해서, 누가 신청해도 똑같은 고정 문구만 나간다.
  - **교정:** 이름·연락처 자리는 타이핑하지 말고 필드 드롭다운에서 트리거 데이터를 '매핑'해 삽입하세요. 그래야 응답마다 값이 바뀝니다.
- **실수:** 에러가 나면 도구를 탓하며 처음부터 다시 만든다.
  - **교정:** Zap History(실행 기록)에서 빨간 실패 단계의 에러 메시지를 읽으세요. 90%는 '권한 없음·채널명 오타·빈 필드' 같은 사소한 문제라 그 한 줄만 고치면 됩니다.

## 완료 체크리스트

- 반복 업무 1개를 '트리거 → 액션' 한 문장으로 적었다
- Zapier(또는 Make/n8n) 계정을 만들고 새 Zap을 생성했다
- 트리거 앱을 연결하고 Test에서 샘플 데이터를 받아봤다
- 액션 메시지에 고정 텍스트가 아니라 필드를 매핑해 넣었다
- 테스트로 실제 알림 도착을 확인하고 Zap을 'On'으로 켰다

## 도구

- Zapier (zapier.com) — 가장 쉬운 노코드 자동화, 무료 100건/월
- Make (make.com) — 시각적 시나리오 편집, 저렴하고 무료 1000건/월
- n8n (n8n.io) — 오픈소스 셀프호스팅, 직접 설치 시 무제한 무료
- ChatGPT/Claude (chatgpt.com / claude.ai) — 에러 디버깅과 시나리오 설계 도우미

## 참고 답안

1) 문장 정리: '이메일로 문의가 오면 → 구글 시트에 발신자·제목·내용을 한 줄 추가한다' 2) Trigger 앱: Gmail(또는 Outlook), Event: New Email 3) Action 앱: Google Sheets, Event: Create Spreadsheet Row 4) 발신자·제목·본문 필드를 드롭다운으로 매핑 5) Test step으로 실제 행이 추가되는지 확인 후 토글 On
