_제품을 만들기 전에 랜딩페이지·설문·사전주문·DM 등으로 실제 지불 의사를 확인하는 저비용 수요 검증 실험 설계법을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, 제품을 만들기 전에 랜딩페이지·설문·사전주문·DM으로 실제 '지불 의사'를 확인하는 검증 실험 1개를 직접 설계하고 돌릴 수 있습니다.
:::

> "좋은 아이디어 같아서 3개월 밤새 만들었는데, 막상 팔려니 아무도 안 산다." 이 비극은 만들기 전에 30분만 팔아보면 대부분 피할 수 있습니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 제품을 만들기 전에 랜딩페이지·설문·사전주문·DM으로 실제 '지불 의사'를 확인하는 검증 실험 1개를 직접 설계하고 돌릴 수 있습니다.

## 핵심 개념

수요 검증의 핵심은 "사람들이 좋다고 말하는가"가 아니라 "돈이나 그에 준하는 행동(사전주문 클릭, 이메일 입력, 계좌이체)을 실제로 하는가"입니다. 말은 공짜라서 다들 "좋아요"라고 하지만, 지갑을 여는 순간부터 진실이 드러납니다. 그래서 우리는 제품 없이도 '팔아보는' 저비용 실험을 먼저 합니다 — 랜딩페이지에 결제 버튼을 달아 클릭률을 재거나, 계좌번호를 주고 선입금을 받는 식입니다. 스타트업에서 이걸 '스모크 테스트' 또는 '가짜 문(fake door)' 실험이라 부릅니다. 목표는 완벽한 제품이 아니라, 만들 가치가 있는지 알려주는 '숫자 한 줄'을 얻는 것입니다.

### 왜 작동하는가

AI는 수억 개의 카피·랜딩페이지·마케팅 문구를 학습해서, "어떤 문장이 클릭을 부르는지" 패턴을 이미 알고 있습니다. 그래서 당신은 가설(누가·왜·얼마)만 던지면, 헤드라인부터 DM 초안까지는 AI가 30초 만에 초안을 뽑아줍니다. 당신은 그 위에 진짜 지불 신호(선입금·이메일)를 심고 사람들에게 노출시키는, AI가 절대 대신할 수 없는 일만 하면 됩니다.

## 👀 따라하기 예시

헬스 트레이너 지수님은 "집에서 15분, 장비 없이 하는 무릎 안 아픈 홈트 루틴 PDF(9,900원)"를 팔고 싶어합니다. 만들기 전에, 제가 먼저 검증 실험을 처음부터 끝까지 돌려볼게요. 눈으로 따라오세요.

### 1. ① 가설을 AI에게 던지고 헤드라인 3개 받기

**실제 결과**

```text
"무릎 아파서 운동 포기하셨나요? 15분, 장비 없이, 관절 안 아픈 홈트 루틴" / "헬스장 안 가도 됩니다 — 무릎 통증 걱정 없는 15분 루틴" / "운동 다시 시작하고 싶은데 무릎이 겁나시죠? 여기서 시작하세요"
```

> 말은 AI가 빠르게 초안을 뽑고, 어떤 문구가 통증·시간·장비 문제를 정확히 찌르는지는 사람이 골라야 합니다.

### 2. ② 진짜 지불 신호 설계 요청

**실제 결과**

```text
"버튼: [3,000원 예약금 걸고 1번으로 받기] → 클릭 시 \"오픈 준비중! 지금 예약하시면 전액 환불 가능 + 20% 할인\" 문구 + 토스 송금 링크 연결"
```

> 이메일보다 소액이라도 실제 돈이 움직이는 신호가 진짜 수요를 보여주는 아하 포인트입니다.

### 3. ③ DM 개인화 초안 요청

**실제 결과**

```text
"안녕하세요 OO님! 무릎 때문에 운동 망설이셨다는 얘기 들었어요. 제가 준비 중인 15분 홈트 루틴이 있는데, 3분만 봐주시고 솔직한 의견 주실 수 있을까요? (판매 아니에요) → 링크"
```

> AI가 스팸처럼 안 보이게 대화체로 다듬어주면, 실제 발송·응대는 사람 몫입니다.

### 4. ④ 결과 데이터 해석 요청

**실제 결과**

```text
"방문 90, 클릭 3(3.3%), 예약금 1건. 합격선(5%) 미달이지만 무릎 통증 키워드에 반응은 있음 → 가격을 6,900원으로 낮추거나 \"무릎\" 대신 \"허리\" 타깃으로 2차 실험 추천"
```

> 숫자만 던지면 AI가 원인 가설을 여러 개 제시해, 다음 실험 방향을 빠르게 좁혀줍니다.

### 완성 결과

완성물은 (1) 랜딩페이지 1장 + (2) 예약금/이메일 신호가 찍힌 결과표입니다. 좋은 결과의 기준: 실험 전에 정한 합격선이 있는가, 말뿐 아니라 비용 드는 행동(클릭·예약금)이 찍혔는가, 미달이어도 다음 실험 방향이 숫자로 나왔는가.

## 단계별 따라하기

### 1단계 — 검증할 가설을 한 문장으로 못 박기 (10분)

'누가 / 어떤 문제 때문에 / 얼마를 낼 것이다'를 한 문장으로 적으세요. 막연한 아이디어를 검증 가능한 명제로 바꾸는 단계입니다. 🙋나

**복사·실행 예시**

```text
가설: '자취하는 20대 직장인은 매일 저녁 메뉴 고민이 싫어서, 7일치 저칼로리 저녁 식단+장보기 리스트를 9,900원에 살 것이다.'
```

### 2단계 — 검증 지표와 합격선 정하기 (5분)

실험 시작 전에 '몇 명 중 몇 명이 무엇을 하면 통과인지' 숫자로 미리 정하세요. 이걸 안 정하면 결과가 나온 뒤 자기 합리화를 하게 됩니다. 🙋나

**복사·실행 예시**

```text
합격선: '랜딩 방문 100명 중 결제하기 버튼 클릭 5명(5%) 이상 + 사전주문 대기명단 이메일 10명 이상이면 만든다. 미만이면 가설 수정.'
```

### 3단계 — 30분짜리 랜딩페이지 만들기 (30분)

Carrd나 노션으로 한 페이지를 만듭니다. 구성: 헤드라인(문제)→해결약속→가격→[사전주문/신청] 버튼→이메일 입력칸. 제품은 아직 없어도 됩니다. AI에게 카피 초안을 받아 다듬으세요. 🤝함께

**복사·실행 예시**

```text
헤드라인: '저녁 뭐 먹지 고민, 이번 주부터 끝.' 버튼: '9,900원 사전주문하기'. 클릭 시 '초기 30명 한정, 이메일 남기면 오픈 시 알림+20% 할인' 폼으로 연결.
```

### 4단계 — 진짜 지불 신호 심기 (10분)

단순 이메일 수집보다 강한 신호를 하나 넣으세요. (a)토스/카카오 송금 링크로 선입금 받기, (b)결제 버튼을 누르면 '곧 오픈' 안내가 뜨는 가짜 문, (c)계좌번호 공개 후 선입금자에게 평생 반값. 실제 돈이 움직이는 신호가 가장 정확합니다. 🙋나

**복사·실행 예시**

```text
버튼 클릭 → '준비 중입니다! 지금 대기명단에 3,000원 예약금(전액 환불 가능)을 걸면 1번으로 받아보세요' → 토스 송금 링크. 예약금 건 사람 수가 진짜 수요.
```

### 5단계 — 100명에게 노출시키기 (30분)

타깃이 모인 곳 3군데에 링크를 뿌립니다. 관련 오픈채팅/커뮤니티/당근 동네생활, 그리고 잠재고객 10명에게 개인 DM. 광고비 0원으로 시작하세요. DM은 AI로 개인화 초안을 만들되 스팸처럼 보내지 마세요. 🤝함께

**복사·실행 예시**

```text
DM: '안녕하세요 OO님, 자취 저녁 식단 관련 작은 걸 준비 중인데 3분만 의견 주실 수 있을까요? (판매 아님) 링크: ...' 대화 후 자연스럽게 랜딩 공유.
```

### 6단계 — 숫자로 결론 내고 다음 행동 정하기 (15분)

방문수·클릭수·이메일수·선입금수를 표로 정리하고 2단계 합격선과 비교하세요. 통과=만들기 시작 / 애매=가설(대상·가격·문제) 하나만 바꿔 재실험 / 미달=폐기 또는 피벗. AI에게 데이터를 주고 원인 해석을 요청하세요. 🤖A

**복사·실행 예시**

```text
결과: 방문 120, 클릭 4(3.3%), 이메일 6, 선입금 1. 합격선 미달 → '가격이 문제인가 대상이 문제인가' 판단 위해 가격 6,900원으로 낮춰 2차 실험.
```

## 흔한 실수와 교정
- **실수:** '좋아요' '필요할 것 같아요' 같은 말뿐인 반응을 검증 성공으로 착각한다.
  - **교정:** 말은 공짜다. 이메일 입력·버튼 클릭·선입금처럼 '비용이 드는 행동'만 신호로 인정하라. 최소한 이메일, 가능하면 소액 선입금을 받아라.
- **실수:** 실험 전에 합격선을 안 정하고, 결과가 나온 뒤 '이 정도면 됐지'라며 자기 합리화한다.
  - **교정:** 2단계에서 숫자 기준을 먼저 못 박고 스크린샷을 찍어둬라. 판정은 실험 시작 전의 나에게 맡겨라.
- **실수:** 완벽한 랜딩페이지·로고·디자인에 며칠을 쓰며 정작 사람들에게 노출은 안 한다.
  - **교정:** 페이지는 30분, 노출은 그날 바로. 못생겨도 100명에게 보여주는 게 예쁜 페이지를 0명에게 보여주는 것보다 100배 낫다.

## 완료 체크리스트

- 검증 가설을 '누가/어떤 문제로/얼마 낼 것이다' 한 문장으로 적었다
- 실험 전에 합격선을 숫자로 정하고 기록했다
- 제품 없이 30분 안에 랜딩페이지+버튼을 만들었다
- 이메일보다 강한 지불 신호(선입금·결제버튼)를 하나 넣었다
- 실제 타깃 100명 규모에 노출하고 개인 DM 10건을 보냈다

## 도구

- Carrd (carrd.co) — 무료 1페이지 랜딩페이지 30분 제작
- 노션 (notion.so) — 랜딩·설문·대기명단을 무료로 빠르게
- 구글폼 (forms.google.com) — 이메일 대기명단·사전주문 수집
- 토스/카카오페이 송금 (toss.im) — 소액 선입금으로 진짜 지불 신호 받기
