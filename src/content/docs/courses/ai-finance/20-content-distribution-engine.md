_하나의 코어 콘텐츠를 숏폼·글·이미지로 분할해 여러 플랫폼에 배포하는 반복 가능한 워크플로를 AI로 세팅하는 법을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, 코어 콘텐츠 1개를 AI로 숏폼 대본·블로그 글·이미지 캡션으로 자동 분할해 여러 플랫폼에 배포하는 반복 워크플로를 세팅할 수 있습니다.
:::

> 매번 새 콘텐츠를 짜내느라 지치셨나요? 잘 만든 콘텐츠 하나면 일주일치 게시물을 뽑아낼 수 있습니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 코어 콘텐츠 1개를 AI로 숏폼 대본·블로그 글·이미지 캡션으로 자동 분할해 여러 플랫폼에 배포하는 반복 워크플로를 세팅할 수 있습니다.

## 핵심 개념

콘텐츠 재활용(리퍼포징)은 하나의 '코어 콘텐츠'(긴 영상, 글, 강의 하나)를 잘게 쪼개 여러 형태·플랫폼용으로 재가공하는 전략입니다. 유튜버나 크리에이터가 매일 새 아이디어를 짜내는 대신, 잘 만든 한 편을 15개 게시물로 늘리는 방식이죠. 핵심은 '한 번 만들고 열 번 배포한다(Create once, distribute many)'는 원칙입니다. AI는 이 분할·재작성 작업을 몇 분 만에 해주기 때문에, 사람은 코어 콘텐츠 하나에만 집중하면 됩니다. 반복 가능한 템플릿과 체크리스트만 갖추면 이 과정을 매주 기계처럼 돌릴 수 있습니다.

### 왜 작동하는가

AI는 이미 수억 개의 글·영상 스크립트 패턴을 학습해서, 같은 메시지를 플랫폼별 문체·길이·구조로 순식간에 바꿔 씁니다. 그래서 당신은 코어 콘텐츠 하나만 잘 만들면, 나머지 숏폼 대본·블로그·카드뉴스 문구는 AI가 몇 분 만에 대신 뽑아줍니다. 사람은 '무엇을 말할지'만 고민하고, '어떻게 각색할지'는 AI에게 넘기는 구조입니다.

## 👀 따라하기 예시

코어 콘텐츠로 '퇴근 후 30분으로 사이드 수입 만드는 3가지 방법'(블로그 글 700자)이 있다고 해봅시다. 제가 먼저 처음부터 끝까지 재활용해볼게요, 눈으로 따라오세요.

### 1. ① 코어 글 전문을 AI에 붙여넣고 '핵심 메시지 5개를 한 줄씩 뽑아줘' 요청

**실제 결과**

```text
1) 시간이 없다는 건 핑계다 2) 스킬 판매가 가장 빠르다 3) 첫 수익은 작아도 괜찮다 4) 하루 30분이면 충분하다 5) 완벽한 준비보다 시작이 먼저다
```

> 포인트를 먼저 뽑아두면 이후 모든 게시물이 이 5줄에서 파생돼요 — 씨앗을 한 번만 심으면 됩니다

### 2. ② '이 포인트로 30초 쇼츠 대본 만들어줘, 훅-본론-CTA 구조로'라고 요청

**실제 결과**

```text
훅: '퇴근하고 넷플릭스만 봤다면 이 영상 보세요' → 본론: '시간이 없다는 건 핑계예요. 당신에게 있는 스킬 하나만 팔아도 첫 수익은 시작됩니다' → CTA: '방법 저장하려면 팔로우'
```

> AI에게 '훅-본론-CTA'라는 구조 이름만 알려주면 형식을 알아서 채워줘요 — 이게 바로 아하 포인트

### 3. ③ 같은 포인트로 '이번엔 블로그 제목과 X 스레드 6개로 재작성해줘'라고 요청

**실제 결과**

```text
블로그 제목: '퇴근 후 30분, 사이드 수입 3가지 (직장인 실전 가이드)' / 스레드1: '9-6 직장인인 내가 부업으로 첫 수익 낸 방법 (스레드) 👇'
```

> 같은 재료인데 플랫폼 이름만 바꿔 말했을 뿐인데 문체가 완전히 달라져요 — 이게 리퍼포징의 핵심

### 4. ④ '인스타 카드뉴스 4장 문구(표지+본문3) 만들어줘'라고 요청 후 Canva에 옮겨 담기

**실제 결과**

```text
표지: '퇴근 후 30분의 기적' / 카드2: '핑계 1위: 시간이 없다 → 사실은 우선순위 문제'
```

> 텍스트만 나오면 무료 템플릿에 붙이기만 하면 되니 디자인 실력이 필요 없어요

### 완성 결과

코어 글 1개 → 쇼츠 대본 1개 + 블로그 제목 1개 + 스레드 6개 + 카드뉴스 문구 4장, 총 5가지 게시물 세트. 좋은 결과의 기준: (1) 플랫폼마다 문체·길이가 실제로 다른가 (2) 훅-본론-CTA 구조가 다 들어갔는가 (3) 요일별 배포 캘린더에 바로 넣을 수 있는 상태인가.

## 단계별 따라하기

### 1단계 — 코어 콘텐츠 1개 정하기 (5분)

🙋나: 이미 만든 것 중 가장 반응 좋았던 콘텐츠 하나를 코어로 정합니다. 영상이면 자막/대본 텍스트를, 글이면 본문 전체를 복사해 메모장에 붙여넣으세요. 아직 없다면 '내가 가장 잘 아는 주제 하나'를 500~800자로 씁니다.

**복사·실행 예시**

```text
코어 콘텐츠: '직장인이 퇴근 후 30분으로 사이드 수입 만드는 3가지 방법' (블로그 글 700자)
```

### 2단계 — 코어를 AI에 넣고 핵심 포인트 추출 (5분)

🤖A: ChatGPT나 Claude에 코어 콘텐츠 전문을 붙여넣고 '핵심 메시지 5개를 한 줄씩 뽑아줘'라고 요청합니다. 이 5개가 앞으로 만들 게시물의 씨앗이 됩니다.

**복사·실행 예시**

```text
추출된 포인트: 1) 시간이 없다는 건 핑계다 2) 스킬 판매가 가장 빠르다 3) 첫 수익은 작아도 괜찮다 ...
```

### 3단계 — 숏폼 대본 3개 생성 (7분)

🤖A: 아래 '숏폼 대본 배치' 템플릿을 붙여넣어 30~45초짜리 릴스/쇼츠 대본 3개를 한 번에 뽑습니다. 훅(첫 3초)·본론·CTA 구조가 나오는지 확인하세요.

**복사·실행 예시**

```text
쇼츠1 훅: '퇴근하고 넷플릭스만 봤다면 이 영상 보세요' → 본론 3문장 → CTA: '방법 저장하려면 팔로우'
```

### 4단계 — 블로그/스레드용 글로 재작성 (5분)

🤖A: 같은 코어를 '검색에 잘 걸리는 블로그 글'과 'X(트위터) 스레드 6개'로 각각 재작성 요청합니다. 플랫폼마다 문체·길이가 다르게 나오는지 봅니다.

**복사·실행 예시**

```text
블로그 제목: '퇴근 후 30분, 사이드 수입 3가지 (직장인 실전 가이드)' / 스레드1: '9-6 직장인인 내가 부업으로 월 X원 번 방법 (스레드) 👇'
```

### 5단계 — 이미지 캡션·카드뉴스 문구 만들기 (5분)

🤝함께: AI에 인스타 카드뉴스 4장 문구(표지+본문3)를 요청하고, 🙋나: Canva에서 무료 템플릿에 그 문구를 넣어 이미지 4장을 만듭니다.

**복사·실행 예시**

```text
표지: '퇴근 후 30분의 기적' / 카드2: '핑계 1위: 시간이 없다 → 사실은 우선순위 문제'
```

### 6단계 — 배포 캘린더에 배치하고 예약 (8분)

🙋나: 구글 시트나 노션에 요일×플랫폼 표를 만들고, 만든 게시물을 월~금에 하나씩 배치합니다. Buffer 무료 플랜이나 각 앱의 예약 기능으로 발행 시간을 예약하세요.

**복사·실행 예시**

```text
월-쇼츠1(틱톡) / 화-블로그(네이버) / 수-카드뉴스(인스타) / 목-쇼츠2(릴스) / 금-스레드(X)
```

## 흔한 실수와 교정
- **실수:** 플랫폼마다 똑같은 글을 그대로 복붙한다
  - **교정:** 플랫폼별로 문체·길이·해시태그를 다르게 재작성한다. AI에게 '이 플랫폼 특성에 맞게'라고 명시하면 자동으로 조정해준다.
- **실수:** 코어 콘텐츠 없이 매일 새 아이디어를 짜내려 한다
  - **교정:** 먼저 잘 만든 코어 1개에 집중하고, 그걸 10개로 쪼갠다. 새 아이디어는 다음 코어를 만들 때만 필요하다.
- **실수:** 만들기만 하고 배포 일정을 안 정해 흐지부지된다
  - **교정:** 요일×플랫폼 캘린더를 먼저 만들고 예약 발행까지 걸어둔다. 예약이 곧 실행이다.

## 완료 체크리스트

- 반응 좋았던 코어 콘텐츠 1개를 정해 텍스트로 확보했다
- AI로 핵심 포인트 5개를 뽑았다
- 숏폼 대본 3개와 블로그/스레드 글을 생성했다
- 카드뉴스 이미지 문구를 만들고 Canva로 이미지화했다
- 요일×플랫폼 배포 캘린더에 배치하고 예약을 걸었다

## 도구

- ChatGPT (chat.openai.com) — 코어 분할·플랫폼별 재작성
- Claude (claude.ai) — 긴 코어 콘텐츠 요약·대본 생성
- Canva (canva.com) — 카드뉴스·이미지 무료 제작
- Buffer (buffer.com) — 여러 플랫폼 예약 발행 (무료 플랜)

## 참고 답안

1) 핵심 메시지 5줄 확보 → 2) 훅-본론-CTA 쇼츠 대본 1개 → 3) 블로그 제목 1개 + 스레드 3개 → 4) 완성된 세트를 요일×플랫폼 표에 배치

### 숏폼 대본 배치 생성 (가장 유용)

```text

[코어 콘텐츠 전문 붙여넣기]
"""
이걸 바탕으로 30~45초짜리 숏폼(릴스/쇼츠/틱톡) 대본 3개를 만들어줘. 각 대본은 (1)첫 3초 훅 (2)본론 3문장 (3)마지막 행동유도(CTA) 구조로 써줘. 말투는 친근한 반말체, 한국어. 화면에 넣을 자막 텍스트 형태로.
```
