_좋은 프롬프트 자체와 그 프롬프트로 뽑은 결과물(이미지·카피·코드)을 상품화하는 두 가지 길을 구분하고, 재사용 가능한 프롬프트 팩 또는 결과물 묶음 1개를 설계해 판매 채널과 가격을 정한다. 프롬프트 판매의 한계(쉽게 복제됨)와 결과물 판매의 강점을 이해한다._

:::note[학습 목표]
- 프롬프트 판매와 결과물 판매의 차이를 이해하고, 재사용 가능한 '프롬프트 팩' 또는 '결과물 묶음' 중 나에게 맞는 1개를 설계해 판매 채널과 가격을 정한다.
:::

> 프롬프트 자체를 파는 사람과, 그 프롬프트로 만든 결과물을 파는 사람 — 누가 더 벌까? 답은 '대부분 결과물'이다. 그 이유와 둘 다 활용하는 법을 익힌다.

## 이 레슨에서 만드는 것

프롬프트 판매와 결과물 판매의 차이를 이해하고, 재사용 가능한 '프롬프트 팩' 또는 '결과물 묶음' 중 나에게 맞는 1개를 설계해 판매 채널과 가격을 정한다.

## 핵심 개념

AI로 돈 버는 두 갈래가 있다. (A)프롬프트 자체를 판다 — '이 프롬프트만 넣으면 멋진 로고가 나온다' 식의 잘 만든 명령어. (B)그 프롬프트로 '뽑은 결과물'을 판다 — 실제 로고 이미지, 광고 카피, 코드. 둘의 운명을 가르는 건 '복제 가능성'이다. 프롬프트는 텍스트라 한 번 팔리면 캡처·공유로 새어나가기 쉽다. 그래서 프롬프트 단독 판매는 가격이 낮고 수명이 짧다. 반면 결과물(완성된 이미지·문서·코드)은 고객이 '바로 쓸 수 있는 가치'라 더 비싸고 안정적이다. 그래서 현실적 전략은: 좋은 프롬프트는 '내 생산성 무기'로 쥐고, 그걸로 빠르게 뽑은 '결과물'을 판다. 프롬프트 팩을 팔더라도 '단순 명령어 한 줄'이 아니라 '상황별 30종 + 사용법 가이드'처럼 묶음·맥락을 더해야 베껴지기 어렵고 값을 받는다.

### 왜 작동하는가

AI는 프롬프트 하나로 몇 초 만에 수십 개의 결과물을 뽑아냅니다. 그런데 "명령어 한 줄"은 캡처 한 번이면 그대로 복제돼서 값을 못 받아요. 반면 "완성된 결과물 묶음"은 고객이 바로 쓸 수 있는 물건이라, 만드는 수고를 대신 덜어준 값을 쳐줍니다. 그래서 핵심은 프롬프트는 내가 쥐고, 그걸로 뽑은 결과물을 파는 것이에요.

## 👀 따라하기 예시

카페 사장님이 "인스타 홍보 이미지가 필요한데 디자이너 쓸 돈은 없다"고 합니다. 저라면 이렇게 팔 상품을 만들어볼게요, 눈으로 따라오세요.

### 1. ① 방향부터 정하기

**실제 결과**

```text
"프롬프트 자체"를 팔지, "그걸로 뽑은 이미지"를 팔지 고민 → 결정: 카페·식당용 인스타 이미지 20종 팩을 판다
```

> 결과물 판매가 초보에게 더 쉽고 안정적이라, 방향을 먼저 못 박아야 다음 단계가 흔들리지 않아요.

### 2. ② 대량 생성 프롬프트 넣기

**실제 결과**

```text
"따뜻한 조명의 아늑한 카페 내부, 라떼 아트 클로즈업, 인스타 정사각 비율, 파스텔톤" 같은 프롬프트를 조금씩 바꿔가며 30장 생성
```

> 한 번에 다 뽑으려 하지 말고 "넉넉히 뽑고 나중에 거른다"는 태도가 품질을 지켜줍니다.

### 3. ③ 매서운 눈으로 선별하기

**실제 결과**

```text
30장 중 손가락이 이상하거나 어색한 10장은 과감히 삭제 → 20장만 남김
```

> 고객은 "고르는 수고"를 덜기 위해 돈을 냅니다. 아쉬워도 버려야 진짜 값이 생겨요.

### 4. ④ 세트로 포장해서 값 매기기

**실제 결과**

```text
이미지 20장 + "요일별 추천 문구·해시태그 가이드" 1장을 묶어 "인스타 홍보 이미지 20종 팩 19,000원"으로 등록
```

> 낱장이 아니라 묶음+사용법을 더해야 캡처 한 번으로 안 베껴지고, 절약해준 시간만큼 값을 받을 수 있어요.

### 완성 결과

판매 등록 가능한 "인스타 이미지 20종 + 사용 가이드" 패키지. 좋은 결과의 기준: (1) 손가락·글자 깨짐 같은 AI 특유의 어색함이 없을 것 (2) 20장의 톤·스타일이 하나의 세트처럼 통일될 것 (3) 가이드가 붙어 있어 고객이 받자마자 바로 쓸 수 있을 것.

## 단계별 따라하기

### 1. 두 길 중 내 상품의 방향을 정한다

빠른 결과물(이미지·카피·코드)을 잘 뽑는다면 '결과물 판매'가, 특정 분야의 명령 노하우가 쌓였다면 '프롬프트 팩 판매'가 맞다. 초보는 보통 '결과물 묶음'이 진입이 쉽다(예: SNS용 이미지 20장 팩). 하나를 고른다.

**복사·실행 예시**

```text
결정: '카페·식당용 인스타그램 홍보 이미지 20종 팩'(결과물 판매)
```

### 2. '복제 어렵게' 묶음과 맥락을 더한다

명령어 한 줄, 이미지 한 장은 쉽게 베껴진다. 가치를 지키려면 ①개수를 늘리고(30종) ②상황·사용법 가이드를 붙이고 ③일관된 톤·스타일로 '세트'처럼 만든다. 프롬프트 팩이라면 '각 프롬프트가 언제·왜 작동하는지' 설명을 함께 넣어라.

**복사·실행 예시**

```text
추가: 이미지 20종 + '업로드 시 추천 문구·해시태그 가이드' 1장
```

### 3. AI로 결과물(또는 프롬프트)을 대량 생성하고 선별한다

아래 templates의 프롬프트로 후보를 넉넉히 뽑은 뒤, 품질 낮은 것을 걸러 '좋은 것만' 남긴다. 양산하되 선별이 핵심 — 고객은 '고르는 수고'를 덜어주는 데 돈을 낸다. 저작권: AI 생성물 이용 약관과 상업적 사용 가능 여부를 도구별로 확인한다.

**복사·실행 예시**

```text
30장 생성 → 어색한 10장 버리고 20장만 팩에 포함
```

### 4. 채널과 가격을 정해 등록한다

결과물 팩은 크몽·스마트스토어·Etsy(해외)에, 프롬프트 팩은 PromptBase 같은 전용 마켓이나 크몽에 올린다. 가격은 '묶음의 절약 가치'로 정한다 — 20장을 직접 만들 시간을 아껴주니 단품보다 비싸도 된다. 첫 가격은 9,900~29,000원 선에서 시작.

**복사·실행 예시**

```text
가격: 인스타 이미지 20종 팩 19,000원 / 사용 가이드 포함
```

## 흔한 실수와 교정
- **실수:** 명령어 한 줄을 그대로 '프롬프트 상품'이라며 비싸게 판다
  - **교정:** 한 줄은 캡처 한 번에 복제된다. 개수·맥락·사용법 가이드를 묶어 '쉽게 못 베끼는 세트'로 만들어야 값을 받는다.
- **실수:** AI가 뽑은 결과물을 선별 없이 전부 묶어 판다
  - **교정:** 고객이 돈을 내는 이유는 '고르는 수고'를 덜기 위해서다. 품질 낮은 건 과감히 버리고 '좋은 것만' 남겨라.
- **실수:** AI 생성물의 상업적 사용·저작권 약관을 확인 안 한다
  - **교정:** 도구마다 상업적 이용 가능 여부·표기 의무가 다르다. 판매 전 해당 AI 도구의 이용 약관을 반드시 확인하라.
- **실수:** 단품(이미지 1장) 단위로 팔아 가격이 바닥을 친다
  - **교정:** 묶음(팩)으로 팔아 '절약 가치'를 키워라. 20장 세트는 1장×20보다 훨씬 비싸게, 더 쉽게 팔린다.

## 완료 체크리스트

- 프롬프트 판매와 결과물 판매의 차이를 이해했다
- 결과물 묶음 또는 프롬프트 팩 중 1개 방향을 정했다
- 개수·맥락·가이드를 더해 '쉽게 못 베끼는 세트'로 설계했다
- AI로 대량 생성 후 선별하고, 저작권/상업 이용을 확인했다
- 채널과 가격을 정해 등록(또는 등록 준비)을 마쳤다

## 도구

- ChatGPT / Claude / 이미지 생성 AI — 결과물·프롬프트를 대량 생성. 상업적 사용 약관을 도구별로 확인.
- Canva (canva.com) — 결과물 묶음을 보기 좋게 정리해 PDF·이미지 세트로 포장.
- PromptBase (promptbase.com) — 프롬프트 전용 해외 마켓(프롬프트 팩 판매 시).
- 크몽 / 스마트스토어 / Etsy — 결과물 팩 판매 채널(국내·해외).

예: 네일샵 대상 → SNS 업로드용 네일아트 디자인 이미지 15종 + "시즌별 추천 컬러 가이드" → 프롬프트: "파스텔 핑크 톤의 미니멀 네일아트, 클로즈업, 정사각 비율" → 크몽에 15,000원으로 등록, 3일마다 5종씩 리뉴얼해서 재구매 유도.

## 실전 프롬프트

### 결과물 묶음 대량 생성

```text
나는 [카페·식당용 인스타그램 홍보] 콘텐츠 팩을 만들어 팔려고 해. 일관된 톤의 결과물을 묶음으로 만들고 싶어.
- 묶음 종류: [홍보용 짧은 캡션 + 해시태그 세트] 30종
- 톤: [친근하고 군침 도는, 자영업자가 바로 복붙 가능]
- 각 항목: ①상황(신메뉴/이벤트/재오픈 등) ②캡션 본문([가게명],[메뉴] 빈칸 포함) ③추천 해시태그 8개
30종을 상황이 겹치지 않게 골고루 만들어줘. 표 말고 읽기 좋은 목록으로.
```

```text
주제: [SNS용 깔끔한 제품 사진 스타일 이미지]

서로 다른 스타일 12종을 만들어줘.
```
