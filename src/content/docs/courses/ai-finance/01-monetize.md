_AI로 콘텐츠·서비스·자동화를 만들어 수익화하는 현실적 경로(프리랜싱·디지털제품·SaaS·교육)와 가격·시작법._

:::note[학습 목표]
- ChatGPT로 만든 '디지털 상품(예: 이메일 템플릿 모음 PDF)' 1개를, Canva로 표지까지 입혀 PDF로 뽑고, 가격을 정해 크몽/탈잉에 올릴 '판매 글 초안'까지 완성한다. 즉, 빈손 → 진짜 파는 물건 1개.
:::

> AI는 잘 다루는데 정작 '돈'은 못 버는 사람이 90%다. 이 레슨 하나면 오늘 안에 '팔 수 있는 결과물 1개'를 손에 넣고 가격표까지 붙인다.

## 이 레슨에서 만드는 것

ChatGPT로 만든 '디지털 상품(예: 이메일 템플릿 모음 PDF)' 1개를, Canva로 표지까지 입혀 PDF로 뽑고, 가격을 정해 크몽/탈잉에 올릴 '판매 글 초안'까지 완성한다. 즉, 빈손 → 진짜 파는 물건 1개.

## 핵심 개념

AI로 돈 버는 건 마법이 아니라 '대신 만들어 주기'다. 예전엔 디자이너·작가를 고용해야 만들던 걸, 이제 내가 AI에게 시켜서 빠르게 만든 뒤 그걸 파는 것이다. 핵심 공식은 딱 하나: '남이 귀찮아하거나 못 하는 일'을 AI로 빠르게 만들어 → 보기 좋게 포장해 → 값을 매겨 판다. 비유하면, AI는 24시간 일하는 알바생이고 나는 사장이다. 알바생(AI)에게 시켜 물건을 찍어내고, 사장(나)은 그걸 가게(크몽 같은 플랫폼)에 진열해 돈을 받는다. '수익화(monetize)'란 그냥 '내 결과물에 돈이 붙게 만들기'라는 뜻이다. 처음부터 큰 사업 말고, 5,000원짜리 작은 디지털 상품 1개부터 파는 게 정답이다.

### 왜 작동하는가

사람은 "이메일 30개 써줘" 하면 몇 시간이 걸리지만, AI는 수억 개의 글을 미리 학습해서 문장 패턴을 바로 꺼내 씁니다. 그래서 당신은 "어떤 상품을 만들지"만 정하면, 실제로 글을 쓰고 다듬는 건 AI가 대신 해줍니다. 이게 바로 "혼자서도 상품 하나를 뚝딱 만드는" 수익화의 비밀입니다.

## 👀 따라하기 예시

"바쁜 회사원이 매번 새로 쓰기 귀찮아하는 비즈니스 이메일"을 상품으로 만들어 파는 상황이에요. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① ChatGPT에게 "상황별 비즈니스 이메일 템플릿 30종을 만들어줘. 각 템플릿은 [제목], [상황 설명], [복붙용 본문]으로 구성해줘"라고 요청

**실제 결과**

```text
"1. 납기 지연 사과 / 상황: 약속한 날짜를 못 지킬 때 / 본문: 안녕하세요 [고객명]님, 예정보다 일정이 지연되어 죄송합니다..." 식으로 30개가 쭉 나옴
```

> 내가 하나하나 문장을 고민할 필요 없이, AI에게 "형식"만 정확히 알려주면 나머지는 AI가 채워줍니다 — 이게 아하 포인트예요.

### 2. ② 결과가 부실하면 "더 자세히, 각 템플릿에 [회사명] 같은 빈칸 변수도 넣어줘"라고 한 번 더 요청

**실제 결과**

```text
기존 30개 템플릿에 [고객명], [회사명], [날짜] 같은 빈칸이 추가되어 더 실용적으로 바뀜
```

> AI는 한 번에 완벽하지 않아요. "구체적으로 다시 요청"하면 품질이 확 올라간다는 걸 몸으로 느끼는 순간이에요.

### 3. ③ Canva에서 "ebook" 템플릿을 골라 표지 제목을 "바로 쓰는 비즈니스 이메일 30종"으로 바꾸고, 본문 페이지에 2단계 결과를 붙여넣은 뒤 PDF로 다운로드

**실제 결과**

```text
표지가 있는 깔끔한 PDF 파일(business_email_templates.pdf) 완성
```

> 같은 글이라도 "표지 + 정리된 디자인"이 입혀지면 사람들은 그걸 더 가치 있게 봅니다 — 포장이 값을 만든다는 원리예요.

### 4. ④ 가격을 정가 9,900원, 출시 할인가 6,900원으로 정하고, ChatGPT로 "메일 쓰느라 30분씩 버리셨나요?" 같은 판매 글을 뽑아 크몽에 등록

**실제 결과**

```text
크몽 등록 화면에 "서비스가 검토 요청되었습니다" 문구가 뜨고 1~2일 내 판매 시작
```

> 할인가는 "지금 사야 할 이유"를 만들어주고, 판매 글은 손님을 설득하는 간판 역할을 한다는 걸 확인하는 단계예요.

### 완성 결과

완성물은 "표지가 있는 PDF 디지털 상품 + 크몽에 등록된 판매 페이지"예요. 좋은 결과의 기준: (1) 처음부터 끝까지 내가 직접 읽고 어색한 곳을 고쳤는가, (2) 가격이 최소 5,000원 이상인가(공짜 아님), (3) 클릭하면 바로 살 수 있는 링크가 실제로 존재하는가.

## 단계별 따라하기

### 1. 팔 거리(아이템) 정하기 — '남이 귀찮아하는 일'을 고른다

거창한 아이디어 필요 없다. '사람들이 매번 새로 쓰기 귀찮아하는 글'을 떠올리면 된다. 예: 회사 사과 메일, 부동산 문의 답장, 인스타 캡션, 자기소개서 문구. 이런 걸 '바로 복붙해 쓰는 모음집'으로 만들면 팔린다. 종이에 후보 3개를 적고, 그중 '내가 조금이라도 아는 분야' 1개를 동그라미 친다. 잘 모르겠으면 그냥 '상황별 비즈니스 이메일 30종 템플릿'으로 정하라 — 가장 잘 팔리는 안전한 첫 상품이다.

**복사·실행 예시**

```text
동그라미 친 아이템: '상황별 비즈니스 이메일 템플릿 30종 (사과·요청·거절·독촉·감사 등)'
```

### 2. ChatGPT 계정 만들고 들어가기 (무료로 시작 가능)

크롬 브라우저 주소창에 chatgpt.com 입력 → 엔터. 화면 오른쪽 위 'Sign up(가입)' 버튼 클릭 → 구글 계정으로 'Continue with Google' 누르면 1분 만에 가입된다(따로 비밀번호 안 만들어도 됨). 로그인되면 화면 맨 아래 긴 입력칸(메시지 보내기)이 보인다. 거기에 글을 쓰면 된다.

【무료 티어 메시지 한도 안내】 2026년 현재 ChatGPT 무료 계정의 기본 모델은 GPT-5.5 Instant다. 무료 계정은 5시간 단위 슬라이딩 윈도우 기준으로 고성능 모델 메시지를 일정 횟수(OpenAI가 정확한 수치를 공식 공표하지 않으며, 서버 상황·개인 계정 조건에 따라 동적으로 달라짐) 사용할 수 있다. 한도에 도달하면 ChatGPT가 자동으로 경량 모델로 전환되어 대화 자체는 이어지나 응답 품질이 낮아질 수 있다. 템플릿 30개를 여러 차례 주고받다 보면 한도에 근접할 수 있으므로, 프롬프트는 한 번에 최대한 상세하게 보내는 것이 유리하다. 하루에 걸쳐 나눠 진행해도 되고, 더 빠르게 진행하고 싶다면 월 구독 유료 플랜(Plus)을 고려할 수 있다. ※막히면: 'Sign up' 대신 'Log in'이 보이면 이미 계정 있는 것 — 그냥 Log in 누르면 됨.

**복사·실행 예시**

```text
입력칸 안내 문구는 '무엇이든 물어보세요' 또는 'Message ChatGPT' 등 접속 시점에 따라 다를 수 있다.
```

### 3. ChatGPT에게 상품 내용물 만들게 시키기 (아래 템플릿 복붙)

입력칸에 아래 templates의 '상품 내용 생성' 프롬프트를 통째로 복사해 붙여넣고, [대괄호] 부분만 내 아이템으로 바꾼 뒤 엔터(전송 화살표↑ 클릭). AI가 30개 템플릿을 쭉 만들어 준다. 양이 적으면 입력칸에 '더 자세히, 각 템플릿에 빈칸 [회사명] 같은 변수도 넣어줘'라고 한 번 더 보내라. 결과가 마음에 들 때까지 '다시 써줘'를 눌러도 된다. 완성되면 답변 위 '복사' 아이콘을 눌러 전부 복사한다.

**복사·실행 예시**

```text
입력: '상황별 비즈니스 이메일 템플릿 30종을 만들어줘. 각 템플릿은 [제목], [상황 설명 한 줄], [복붙용 본문]으로 구성하고...' → 출력: '1. 납기 지연 사과 / 상황: 약속한 날짜를 못 지킬 때 / 본문: 안녕하세요 [고객명]님, ...'
```

### 4. Canva로 표지+PDF 만들기 (보기 좋게 포장하면 값이 3배)

주소창에 canva.com 입력 → 'Continue with Google'로 가입(무료). 들어가면 위쪽 검색창에 'ebook(이북)' 또는 '전자책' 입력 → 마음에 드는 무료 템플릿 클릭. 표지 글자를 더블클릭해 내 상품 제목으로 바꾼다. 내용 페이지에는 3단계에서 복사한 템플릿 글을 붙여넣는다. 다 됐으면 오른쪽 위 'Share(공유)' → 'Download(다운로드)' → 파일 형식을 'PDF Standard'로 골라 'Download' 클릭. PDF 파일이 컴퓨터에 저장된다. ※막히면: 무료 템플릿엔 왕관👑 표시가 없는 것만 고르면 추가 결제 안 뜸.

**복사·실행 예시**

```text
표지 제목: '바로 쓰는 비즈니스 이메일 30종 — 복붙만 하면 끝' / 파일명: business_email_templates.pdf
```

### 5. 가격 정하기 — '싸게, 그러나 공짜는 절대 금지'

첫 상품은 5,000원~9,900원이 정석이다. 너무 비싸면 안 사고, 공짜로 주면 가치가 없어 보인다. 가격 정하는 쉬운 기준: '이걸 사면 사는 사람이 아낄 시간 × 그 사람 1시간 가치'. 이메일 30종이면 직접 쓸 때 3시간은 아껴주니 충분히 9,900원 값어치다. 고민되면 그냥 7,700원으로 시작하고, 잘 팔리면 나중에 올려라.

【수수료 미리 알기】 크몽 같은 플랫폼은 판매 금액에서 수수료를 제한 뒤 정산한다. 9,900원짜리 상품을 팔면 실수령액은 약 7,700~7,800원 수준이다(서비스 이용료 16.4% + 결제망 이용료 3.3% + 해당 수수료 합계의 부가세 10% 차감). 처음에는 이 점을 감안해 가격을 정하자.

**복사·실행 예시**

```text
결정: 정가 9,900원, 출시 기념 할인가 6,900원 (할인은 '지금 사야 할 이유'를 만들어 줌)
```

### 6. ChatGPT로 '판매 글(상세페이지)' 초안 뽑기

다시 ChatGPT 입력칸으로 가서 templates의 '판매 글 작성' 프롬프트를 붙여넣고 [대괄호]를 채운 뒤 전송. AI가 '제목 / 이런 분께 추천 / 구성 / 가격' 형식의 판매 문구를 만들어 준다. 이 글이 손님을 설득하는 간판이다. 어색한 문장은 입력칸에 '더 친근한 말투로 고쳐줘'라고 보내 다듬는다.

**복사·실행 예시**

```text
출력 제목: '메일 쓰느라 30분씩 버리셨나요? 복붙 한 번이면 끝나는 비즈니스 이메일 30종'
```

### 7. 판매 플랫폼에 올리기 (크몽 추천 / 대안 플랫폼)

주소창에 kmong.com 입력 → 오른쪽 위 '회원가입' → 카카오/구글로 가입 → 로그인 후 오른쪽 위 '전문가 전환' 또는 '서비스 등록' 클릭 → 카테고리에서 '문서·글쓰기' 선택 → 제목·설명에 6단계 판매 글을 붙여넣고, 4단계 PDF는 '구매 후 자동 전달 파일'로 업로드 → 가격(5단계) 입력 → '등록' 클릭. 심사 후 노출된다.

크몽 외 대안으로 네이버 스마트스토어(디지털 상품 직판 지원)나 개인 SNS + 파일 전달 방식도 있다. 탈잉은 VOD 강의·튜터링 중심 플랫폼으로, 크몽처럼 PDF 파일을 '구매 즉시 자동 전달'하는 디지털 상품 직판 기능은 제공하지 않으므로, PDF 단독 판매 창구로는 적합하지 않다.

※핵심은 '올려서 링크가 생기는 것'. 어떤 채널이든 일단 등록하자.

**복사·실행 예시**

```text
등록 완료 화면: '서비스가 검토 요청되었습니다' → 보통 1~2일 내 판매 시작
```

## 흔한 실수와 교정
- **실수:** 완벽한 상품을 만들려고 몇 주째 안 올린다
  - **교정:** 60점짜리라도 일단 올려라. 판매하면서 후기 보고 고치는 게 100배 빠르다. '출시'가 목표지 '완벽'이 목표가 아니다.
- **실수:** ChatGPT가 만든 글을 그대로 안 읽어보고 판다
  - **교정:** AI는 가끔 어색하거나 틀린 말을 한다(이걸 '환각'이라 함). 파는 사람은 반드시 처음부터 끝까지 한 번 읽고, 어색한 곳은 '이 부분 자연스럽게 고쳐줘'로 다듬어라.
- **실수:** 가격을 너무 낮추거나 공짜로 준다
  - **교정:** 공짜는 '가치 없음' 신호다. 최소 5,000원은 받아라. 자신 없으면 할인가 형식(정가 9,900 → 6,900)으로 싸 보이게만 하고 공짜는 피한다.
- **실수:** 남의 글·이미지를 그대로 베껴 넣는다
  - **교정:** 저작권 문제로 판매 정지될 수 있다. AI가 새로 만든 글, Canva의 무료(왕관 없는) 요소만 사용하면 안전하다.

## 완료 체크리스트

- 팔 아이템 1개를 종이에 적고 동그라미 쳤다
- ChatGPT로 상품 내용물(템플릿 30종 등)을 완성해 복사했다
- Canva에서 표지를 넣고 PDF 파일로 다운로드했다
- 가격을 5,000원 이상으로 정하고, 판매 글 초안을 ChatGPT로 뽑았다
- 크몽(또는 스마트스토어)에 등록을 눌러 '검토 요청' 상태까지 갔다

## 도구

- ChatGPT (chatgpt.com) — 상품 내용물과 판매 글을 무료로 만들어 주는 AI 알바생. 2026년 현재 무료 계정 기본 모델은 GPT-5.5 Instant이며, 5시간 단위 슬라이딩 윈도우 내 고성능 모델 메시지 횟수가 제한된다(OpenAI가 정확한 수치를 공식 공표하지 않으므로 단정 불가). 한도 초과 시 경량 모델로 자동 전환된다. 프롬프트를 한 번에 상세하게 작성할수록 횟수를 아낄 수 있다.
- Canva (canva.com) — 표지를 입혀 PDF 전자책으로 포장하는 디자인 도구(무료)
- 크몽 (kmong.com) — 만든 디지털 파일을 올려 파는 한국 프리랜서 마켓. 판매 대금에서 서비스 이용료(최대 16.4%)+결제망 이용료(3.3%)+부가세가 차감되며, 9,900원 판매 시 실수령액은 약 7,700~7,800원이다.
- 네이버 스마트스토어 — 크몽 대신 쓸 수 있는 디지털 상품 직판 대안. 탈잉은 강의·튜터링 플랫폼으로 PDF 자동전달 직판에는 적합하지 않다.

## 참고 답안

예: "인스타 캡션 모음"을 골랐다면 → ChatGPT에 "감성/유머/홍보 등 상황별 인스타 캡션 30개, 이모지 포함해서 만들어줘" 요청 → Canva에서 "SNS 가이드" 템플릿으로 표지 제작 → 가격 6,900원(할인가) → 판매 글 제목 "캡션 고민 그만, 복붙 30초면 끝"으로 초안 작성.

### 상품 내용(템플릿 모음) 생성

```text
너는 [비즈니스 이메일] 전문 카피라이터야. 초보 직장인이 '복사해서 빈칸만 채우면 바로 보낼 수 있는' [상황별 비즈니스 이메일] 템플릿 30종을 만들어줘.

조건:
1) 각 템플릿은 ①번호와 제목 ②어떤 상황에 쓰는지 한 줄 설명 ③복붙용 본문 — 이렇게 3부분으로.
2) 본문 안에 [고객명],[회사명],[날짜]처럼 바꿔 쓸 빈칸을 대괄호로 넣어줘.
3) 사과·요청·거절·독촉·감사·일정조율·소개 등 자주 쓰는 상황을 골고루.
4) 말투는 정중하지만 딱딱하지 않게.
표 말고 읽기 좋은 목록 형태로 30개 전부 써줘.
```

내가 만든 디지털 상품의 판매 페이지 글을 써줘.
- 상품: [상황별 비즈니스 이메일 템플릿 30종 PDF]

아래 순서로 써줘:
1) 시선 끄는 제목 1줄 (고통 자극)
2) '이런 분께 추천' 3가지
3) '구성/혜택' 목록
4) '왜 직접 쓰지 말고 이걸 사야 하나' 설득 2문장
5) 마지막에 '지금 구매' 한 줄.
친근하고 신뢰가는 말투로, 과장 광고는 빼고.
