_여러 프롬프트를 카테고리·사용 시나리오·복붙 가능한 형식으로 묶고, 초보자도 바로 쓰도록 사용법·예시·주의사항 문서를 붙여 상품화하는 법을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, 흩어진 프롬프트 15~30개를 카테고리·시나리오·복붙 형식으로 묶고 사용 설명서를 붙인 '판매 가능한 프롬프트 팩 1개'를 완성할 수 있습니다.
:::

> "좋은 프롬프트 30개를 메모장에 모아뒀는데 아무도 안 사요." 문제는 프롬프트가 아니라 포장입니다. 초보자는 '무엇을 어떻게 쓰는지'를 사고, 팩은 그 사용법을 파는 겁니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 흩어진 프롬프트 15~30개를 카테고리·시나리오·복붙 형식으로 묶고 사용 설명서를 붙인 '판매 가능한 프롬프트 팩 1개'를 완성할 수 있습니다.

## 핵심 개념

프롬프트 팩은 '프롬프트 모음'이 아니라 '문제 해결 매뉴얼'입니다. 초보자가 돈을 내는 이유는 프롬프트 문장 자체가 아니라, 언제 어떤 프롬프트를 골라 어디에 붙여넣고 [ ] 안에 뭘 채우는지를 손 잡고 알려주기 때문입니다. 그래서 팩의 가치는 프롬프트 개수가 아니라 '카테고리 정리 + 사용 시나리오 + 복붙 형식 + 주의사항'이라는 포장에서 나옵니다. 예를 들어 같은 '블로그 글쓰기 프롬프트'라도, 그냥 나열하면 무료 자료지만 '자영업자가 인스타 홍보글 5분 만에 쓰는 순서'로 묶으면 상품이 됩니다.

### 왜 작동하는가

AI는 수많은 텍스트 목록을 보고 "비슷한 것끼리 묶는" 패턴을 이미 학습했습니다. 그래서 흩어진 프롬프트 목록을 던져주면 카테고리 이름까지 뽑아주고, 초보자용 설명 문장도 대신 초안으로 써줍니다. 당신은 "무엇을 팔지"만 정하면, 분류·문장 다듬기·안내문 작성 같은 손 많이 가는 포장 작업은 AI가 대신 해줍니다.

## 👀 따라하기 예시

카페 사장님이 그동안 써온 홍보·후기답글 프롬프트 12개를 메모장에 흩어놓고 있습니다. 이걸 "1인 자영업자용 홍보 프롬프트 팩"으로 포장해봅니다. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① 프롬프트 12개를 그대로 AI에 붙여넣고 "이걸 사용 목적별로 3~5개 카테고리로 나눠줘"라고 요청

**실제 결과**

```text
AI: "① 신메뉴·이벤트 홍보(3개) ② 고객 후기 답글(4개) ③ 인스타 캡션·해시태그(3개) ④ 예약·문의 응대(2개) — 이렇게 4개 카테고리로 나누면 자연스럽습니다."
```

> 프롬프트 개수가 많아도 AI는 목적어·동사 패턴을 보고 순식간에 폴더처럼 묶어줍니다 — 사람이 하면 30분, AI는 10초.

### 2. ② 카테고리 하나를 골라 "이 프롬프트를 [번호·이름/언제 쓰나/복붙 프롬프트/입력 예시/결과 예시] 5칸 카드로 다시 써줘"라고 요청

**실제 결과**

```text
AI: "[02. 후기 답글] 언제: 별점 리뷰가 달렸을 때 / 프롬프트: 너는 [가게종류] 사장이다. 아래 후기에 정중히 답글 써줘: [후기내용] / 입력예시: 카페, 커피가 식어서 왔어요 / 결과: 사과+재방문 유도 3문장"
```

> 형식을 통일해야 초보자가 카드마다 헤매지 않습니다. AI에게 "이 형식으로 나머지도"라고 하면 12개 전부 순식간에 통일됩니다.

### 3. ③ "이 카드들 앞에 붙일, ChatGPT 처음 쓰는 사람도 이해할 3단계 사용법 안내문 써줘"라고 요청

**실제 결과**

```text
AI: "시작하기: 스마트폰이면 ChatGPT 앱, PC면 chatgpt.com 접속 → 아래 카드에서 대괄호 [ ] 안 글자만 내 상황으로 바꿔서 붙여넣기 → 결과가 맘에 안 들면 뒤에 더 짧게 라고 덧붙이세요."
```

> 판매자 본인은 이미 익숙해서 당연하게 넘어가는 단계도, AI는 "처음 쓰는 사람" 기준으로 빠짐없이 짚어줍니다.

### 4. ④ 마지막으로 "사실 확인·개인정보·재판매 금지 주의사항 4줄 문구를 정중하게 다듬어줘"라고 요청해 완성

**실제 결과**

```text
AI: "⚠️ 본 프롬프트 결과물은 AI 생성이며 가격·법률·의학 정보는 반드시 직접 확인하세요. 개인정보·상호 실명 입력에 주의하세요. 본 팩의 재판매·재배포는 금지됩니다."
```

> 법적·신뢰 문구는 표현 하나로 분쟁 여부가 갈리는데, AI가 정중하고 명확한 문장으로 정리해줍니다.

### 완성 결과

카드 12장 + 사용법 안내문 + 주의사항이 담긴 PDF 프롬프트 팩 1개. 좋은 결과의 기준: (1) 카드마다 언제·입력예시·결과예시 3칸이 전부 채워져 있는가, (2) 처음 보는 사람도 안내문만 보고 첫 카드를 바로 써볼 수 있는가, (3) 주의사항 4줄이 빠짐없이 들어갔는가.

## 단계별 따라하기

### 1단계 — 팩의 대상과 한 문장 약속 정하기 (5분) 🙋나

'누가(대상) + 어떤 상황에서(시나리오) + 무엇을 얻는가(결과)'를 한 문장으로 적는다. 이 문장이 팩 제목과 판매 페이지의 뼈대가 된다.

**복사·실행 예시**

```text
대상='1인 자영업자', 약속='인스타·블로그 홍보 글을 하루 30분에서 5분으로 줄이는 프롬프트 25선'
```

### 2단계 — 프롬프트 카테고리 3~5개로 묶기 (10분) 🤝함께

가진 프롬프트를 사용 목적별로 폴더처럼 나눈다. 3~5개 카테고리가 초보자에게 딱 좋다. 분류가 막히면 AI에게 프롬프트 목록을 주고 카테고리를 제안받는다(아래 템플릿1).

**복사·실행 예시**

```text
① 신메뉴·이벤트 홍보 ② 고객 후기 답글 ③ 인스타 캡션·해시태그 ④ 블로그 상세글 ⑤ 예약·문의 응대
```

### 3단계 — 프롬프트마다 '복붙 카드' 형식으로 통일하기 (15분) 🙋나

각 프롬프트를 [번호·이름 / 언제 쓰나 / 복붙 프롬프트(placeholder는 [ ]) / 입력 예시 / 나오는 결과 예시] 5칸 카드로 다시 쓴다. 형식이 같아야 초보자가 헤매지 않는다.

**복사·실행 예시**

```text
[03. 고객 후기 답글] 언제: 별점 리뷰가 달렸을 때 / 프롬프트: '너는 [가게종류] 사장이다. 아래 후기에 정중히 답글 써줘: [후기내용]' / 입력예시: 카페, '커피가 식어서 왔어요' / 결과: 사과+재방문 유도 3문장
```

### 4단계 — 초보자용 사용 설명서 앞장 붙이기 (10분) 🤖A

팩 맨 앞에 '이 팩 쓰는 법 3단계(① ChatGPT 켜기 ② 원하는 카드 복사 ③ [ ] 부분만 내 상황으로 바꾸기)'와 '자주 묻는 질문'을 넣는다. AI에게 카드 목록을 주고 초보자용 안내문을 뽑게 한다(템플릿2).

**복사·실행 예시**

```text
'시작하기: 스마트폰이면 ChatGPT 앱, PC면 chatgpt.com 접속 → 아래 카드에서 대괄호 [ ] 안 글자만 바꿔서 붙여넣기 → 결과가 맘에 안 들면 뒤에 "더 짧게"라고 덧붙이세요.'
```

### 5단계 — 주의사항·저작권·환불 문구 넣기 (5분) 🙋나

'AI 결과는 반드시 사실 확인 후 사용', '개인정보·상호 실명 입력 주의', '재판매 금지', '결과 품질은 입력에 따라 달라짐' 4가지 주의문을 마지막 장에 명시한다. 신뢰와 분쟁 예방 둘 다 잡는다.

**복사·실행 예시**

```text
'⚠️ 본 프롬프트 결과물은 AI 생성이며 가격·법률·의학 정보는 반드시 직접 확인하세요. 본 팩의 재판매·재배포는 금지됩니다.'
```

### 6단계 — PDF/Notion 한 파일로 패키징하고 미리보기 만들기 (10분) 🤝함께

카드+설명서+주의사항을 Notion 페이지나 Google Docs로 만들고 PDF로 내보낸다. 표지에 제목·대상·프롬프트 개수를 적고, 목차 1장과 카드 2장을 '무료 미리보기'로 잘라 둔다.

**복사·실행 예시**

```text
표지: '자영업자 홍보 프롬프트 25선 (초보 사용설명서 포함)' → PDF 18쪽 → 앞 3쪽만 미리보기 이미지로 캡처해 판매글에 첨부
```

## 흔한 실수와 교정
- **실수:** 프롬프트만 잔뜩 나열하고 사용법을 안 넣는다. 초보자는 '이걸 어디에 붙여넣지?'에서 막혀 환불한다.
  - **교정:** 프롬프트 1개당 '언제 쓰나 + 입력 예시 + 결과 예시' 3칸을 반드시 붙인다. 프롬프트보다 사용법이 상품의 본체다.
- **실수:** placeholder를 애매하게 만든다. '[내용]'처럼 뭘 넣을지 모르게 두면 초보자가 빈칸을 못 채운다.
  - **교정:** '[가게 종류·예: 카페]', '[고객 후기 원문 그대로]'처럼 대괄호 안에 넣을 것과 예시를 함께 적는다.
- **실수:** 주의사항·재판매 금지 문구를 빼먹는다. 나중에 무단 재배포나 잘못된 AI 결과로 분쟁이 생긴다.
  - **교정:** 마지막 장에 '사실 확인 필수·개인정보 주의·재판매 금지' 3줄을 고정으로 넣어 팩 전체에 적용한다.

## 완료 체크리스트

- 팩의 대상과 한 문장 약속을 정했다
- 프롬프트를 3~5개 카테고리로 묶었다
- 모든 프롬프트를 동일한 복붙 카드 형식으로 통일했다
- 초보자용 사용 설명서 앞장과 FAQ를 붙였다
- 주의사항·재판매 금지 문구를 넣고 PDF로 미리보기까지 만들었다

## 도구

- ChatGPT (chatgpt.com) — 프롬프트 분류·설명서 초안 자동 생성
- Notion (notion.so) — 카드·목차·설명서를 한 페이지로 정리하고 PDF 내보내기
- Canva (canva.com) — 팩 표지·미리보기 이미지 디자인
- Gumroad (gumroad.com) — 완성한 PDF 프롬프트 팩 업로드·판매

## 실전 프롬프트

### 프롬프트 자동 분류·카테고리 제안

```text
너는 프롬프트 팩 큐레이터다. 아래 프롬프트 목록을 초보자가 이해하기 쉬운 카테고리 3~5개로 묶어줘. 각 카테고리에 이름, 한 줄 설명, 포함되는 프롬프트 번호를 표로 정리하고, 어디에도 안 맞거나 중복되는 것은 따로 표시해줘.
대상 사용자: [예: 1인 자영업자]
프롬프트 목록:
[여기에 프롬프트들을 번호와 함께 붙여넣기]
```

## 직접 만들기 (미션)

:::tip
이번엔 대상을 바꿔보세요. "프리랜서 디자이너"가 쓸 법한 프롬프트(견적 안내, 시안 피드백 요청, SNS 홍보 문구 등) 6~8개를 떠올려 AI에게 카테고리 3개로 묶어달라 하고, 그 중 1개 카테고리를 복붙 카드 형식으로 만들어보세요.
:::
