_헤드라인·문제제기·베네핏·사회적증거·CTA 구조로 디지털 상품 상세페이지를 쓰고 AI로 여러 버전을 생성·비교하는 카피라이팅 실습을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, 헤드라인·문제제기·베네핏·사회적증거·CTA 5블록 구조로 디지털 상품 상세페이지 카피를 직접 쓰고, AI로 3개 버전을 뽑아 비교해 최종본을 고를 수 있습니다.
:::

> 같은 상품인데 어떤 페이지는 "장바구니"만 채우고 어떤 페이지는 "결제"까지 가게 만듭니다. 그 차이는 사진이 아니라 '글의 순서'에 있습니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 헤드라인·문제제기·베네핏·사회적증거·CTA 5블록 구조로 디지털 상품 상세페이지 카피를 직접 쓰고, AI로 3개 버전을 뽑아 비교해 최종본을 고를 수 있습니다.

## 핵심 개념

상세페이지는 위에서 아래로 읽히는 '설득의 계단'입니다. 헤드라인이 3초 안에 발을 붙잡고, 문제제기가 "이거 내 얘기네" 하는 공감을 만들고, 베네핏이 '기능'이 아니라 '내 삶이 어떻게 바뀌는지'를 보여주고, 사회적증거(후기·판매수·보증)가 불안을 없애고, CTA가 지금 눌러야 할 이유를 줍니다. 카피의 핵심은 미사여구가 아니라 '고객이 이미 머릿속으로 하던 말'을 대신 써주는 것입니다. AI는 이 5블록을 여러 톤으로 빠르게 찍어내는 데 강하지만, 어떤 고객의 어떤 통증을 노릴지는 사람인 내가 정해야 합니다.

### 왜 작동하는가

AI는 수억 개의 광고·상세페이지 문장을 학습해서, 같은 정보를 여러 톤과 여러 각도로 순식간에 바꿔 씁니다. 그래서 당신은 '누구에게 어떤 통증을 팔지'만 정하면, 헤드라인 10개와 톤별 버전 3개는 AI가 몇 초 만에 대신 뽑아줍니다. 다만 어떤 후보가 진짜 손이 멈추는 카피인지 고르고, 없는 후기를 지어내지 않게 지키는 건 여전히 사람의 몫입니다.

## 👀 따라하기 예시

노션 가계부 템플릿(9,900원)을 '월급은 들어오는데 어디로 새는지 모르는 사회초년생 지현(26세)'에게 판다고 해봅시다. 제가 먼저 처음부터 끝까지 써볼게요, 눈으로 따라오세요.

### 1. ① 타깃과 팩트를 AI에 한 문장으로 던지기

**실제 결과**

```text
입력: '상품=노션 가계부 템플릿 9,900원, 타깃=월급 새는지 모르는 사회초년생 지현. 헤드라인 10개, 숫자형·질문형·결과약속형 섞어서.' → AI 출력 일부: '가계부 3번 실패한 당신을 위한, 안 쓰고 켜두기만 하는 자동 가계부' / '한 달 새는 돈 27만원, 클릭 한 번으로 보이게'
```

> 정보를 한 번에 몰아 던지면 AI가 여러 각도를 동시에 시도해줘서, 내가 직접 10개를 쓰는 것보다 고르는 게 훨씬 빠릅니다.

### 2. ② 문제제기·베네핏은 '증상→기능→결과' 순서로 변환 요청

**실제 결과**

```text
입력: '문제 3개 증상 나열하고, 자동 카테고리 기능을 결과 문장으로 바꿔줘' → AI 출력: '영수증 모으다 포기, 엑셀은 3일 만에 안 열게 됨, 카드값은 늘 예상 밖.' / '자동 카테고리라서 → 입력 없이 이번 달 지출이 한눈에.'
```

> 기능(자동 카테고리)을 그대로 두면 스펙 나열이 되지만, '라서→할 수 있다' 틀을 주면 AI가 항상 결과 중심으로 바꿔줍니다.

### 3. ③ 사회적증거는 진짜 근거만, CTA는 행동+이득+안심으로 요청

**실제 결과**

```text
입력: '베타 사용자 40명 중 32명 재구매, 7일 환불 보장 — 이걸로 CTA 만들어줘' → AI 출력: '지금 9,900원으로 시작하기 — 안 맞으면 7일 안에 100% 환불'
```

> 후기·수치를 AI에 지어내라고 하면 그럴듯하게 지어냅니다. 그래서 실제 있는 숫자만 넣으라고 못박아야 신뢰가 무너지지 않습니다.

### 4. ④ 완성 초안을 주고 톤 3버전(신뢰형/친근형/도발형) 요청 후 CTA만 비교

**실제 결과**

```text
AI 출력 비교표: 신뢰형 CTA '검증된 40명이 먼저 썼습니다' vs 도발형 CTA '이번 달도 그냥 새게 두실 건가요?'
```

> 같은 구조를 톤만 바꿔 여러 벌 만들면 실제 A/B 테스트 후보를 손쉽게 확보할 수 있고, 어떤 톤이 내 타깃에 맞는지는 감이 아니라 비교로 정할 수 있습니다.

### 완성 결과

헤드라인·문제제기·베네핏·사회적증거·CTA 5블록이 채워진 상세페이지 초안 + A/B 테스트용 CTA 2개. 좋은 결과의 기준: (1) 소리 내어 읽었을 때 '최고·완벽' 같은 빈 형용사가 하나도 없다, (2) 모든 사회적증거가 실제로 존재하는 숫자다, (3) 헤드라인이 상품 기능이 아니라 고객이 얻는 결과를 말한다.

## 단계별 따라하기

### 1단계 — 타깃 한 명과 상품 팩트 정리 (5분) 🙋나

상세페이지를 쓰기 전에 '누구에게 파는 무엇'인지를 한 문장으로 적고, 상품의 진짜 팩트(가격·용량·포함물·보장)를 표로 정리한다. 대상 고객은 '많은 사람'이 아니라 딱 한 명을 상상해 이름·상황까지 적는다.

**복사·실행 예시**

```text
상품: 노션 가계부 템플릿 / 가격: 9,900원 / 포함: 대시보드+자동 카테고리+월간리포트 / 타깃: '월급은 들어오는데 어디로 새는지 모르는 사회초년생 지현(26세)'
```

### 2단계 — 헤드라인 후보 10개 뽑기 (7분) 🤖A

1단계 정보를 AI에 붙여넣고 헤드라인만 10개를 요청한다. '숫자형·질문형·결과약속형' 세 종류를 섞어달라고 지정한 뒤, 내가 3초 안에 손이 멈추는 것 2개를 고른다.

**복사·실행 예시**

```text
AI 출력 중 채택: '가계부 3번 실패한 당신을 위한, 안 쓰고 켜두기만 하는 자동 가계부' (질문형) / '한 달 새는 돈 27만원, 클릭 한 번으로 보이게' (숫자형)
```

### 3단계 — 문제제기·베네핏 블록 쓰기 (8분) 🤝함께

문제제기는 고객이 겪는 '증상 3개'를 그대로 나열하고, 베네핏은 각 기능을 'A라서 → B할 수 있다' 형태로 바꾼다. 기능→결과 변환은 AI에 시키되, 과장·거짓 수치는 내가 지운다.

**복사·실행 예시**

```text
문제: '영수증 모으다 포기, 엑셀은 3일 만에 안 열게 됨, 카드값은 늘 예상 밖.' / 베네핏: '자동 카테고리라서 → 입력 없이 이번 달 지출이 한눈에.'
```

### 4단계 — 사회적증거·CTA 붙이기 (5분) 🙋나

실제 있는 후기·판매수·환불보장만 넣는다. 없으면 지어내지 말고 '베타 사용자 후기' '7일 환불' 같은 진짜 근거로 대체한다. CTA는 행동+이득+안심 3요소로 만든다.

**복사·실행 예시**

```text
사회적증거: '베타 참여자 40명 중 32명이 재구매 의사' / CTA: '지금 9,900원으로 시작하기 — 안 맞으면 7일 안에 100% 환불'
```

### 5단계 — AI로 3개 버전 생성·비교 (7분) 🤖A

완성한 5블록 초안을 주고 '동일 구조, 다른 톤(신뢰형/친근형/도발형)으로 3버전'을 요청한다. 표로 헤드라인·CTA만 나란히 뽑아 내가 A/B 후보 2개를 고른다.

**복사·실행 예시**

```text
신뢰형 CTA '검증된 40명이 먼저 썼습니다' vs 도발형 CTA '이번 달도 그냥 새게 두실 건가요?' → 둘을 실제 A/B 테스트 후보로 확정.
```

### 6단계 — 소리 내어 읽고 군더더기 컷 (3분) 🙋나

완성본을 소리 내어 읽으며 걸리는 문장, 중복 형용사, 근거 없는 '최고·완벽'을 지운다. 한 문장에 메시지 하나 원칙으로 자른다.

**복사·실행 예시**

```text
'정말 최고로 완벽하게 편리한 혁신적 가계부' → '켜두기만 하면 되는 가계부'
```

## 흔한 실수와 교정
- **실수:** 헤드라인에 상품 기능(용량·스펙)을 그대로 넣는다.
  - **교정:** 기능 대신 '고객이 얻는 결과나 통증 해결'을 넣는다. '자동 분류 기능' 대신 '입력 없이 새는 돈이 보이는'.
- **실수:** 후기·판매수·수치를 없는데 지어내서 넣는다.
  - **교정:** 거짓 사회적증거는 신뢰를 무너뜨리고 법적 문제도 된다. 진짜 근거(베타 후기·환불보장·무료체험)로 대체하고, 없으면 [후기] 자리만 비워 나중에 채운다.
- **실수:** AI가 뽑은 화려한 문장을 그대로 복붙한다.
  - **교정:** AI는 초안 공장일 뿐이다. 소리 내어 읽고 '최고·완벽·혁신' 같은 빈 형용사와 중복을 직접 잘라 내 상품의 진짜 언어로 다듬는다.

## 완료 체크리스트

- 타깃 고객 한 명의 상황을 한 문장으로 적었다
- 헤드라인 후보 10개 중 3초 안에 손이 멈추는 것 2개를 골랐다
- 베네핏을 '기능→결과' 형태로 모두 변환했다
- 사회적증거에 거짓 수치 없이 진짜 근거만 넣었다
- AI로 3개 톤 버전을 만들어 A/B 후보 2개를 확정했다

이번엔 당신 차례! 다른 디지털 상품(예: 온라인 클래스, 이북, 스톡 사진팩 등 본인이 정한 것) 하나를 골라, 1단계처럼 '누구에게 파는 무엇'을 한 문장으로 적고 AI에 헤드라인 10개를 요청하세요. 그중 2개를 골라 문제제기·베네핏·사회적증거·CTA까지 5블록을 채운 뒤, 톤 3버전 중 CTA 2개를 A/B 후보로 확정해보세요.
:::

## 채점 기준

| 기준 | 배점 |
| --- | --- |
| 헤드라인이 상품 스펙이 아니라 고객이 얻는 결과를 말하고 있나? | 5 |
| 사회적증거에 실제로 존재하지 않는 숫자나 후기를 지어내지 않았나? | 5 |
| 소리 내어 읽었을 때 빈 형용사(최고·완벽·혁신) 없이 한 문장에 메시지 하나만 담겼나? | 5 |
