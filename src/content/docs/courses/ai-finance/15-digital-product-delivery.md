_Gumroad·Lemon Squeezy 등으로 결제 후 파일·라이선스가 자동 전달되도록 상품을 등록하고 다운로드·업데이트·환불 흐름을 세팅하는 실습을 가르친다._

:::note[학습 목표]
- 이 레슨이 끝나면, Gumroad에 디지털 상품을 등록하고 결제 즉시 구매자에게 파일이 자동 전달되며 업데이트·환불까지 처리되는 판매 페이지를 실제로 열 수 있습니다.
:::

> 새벽 3시에 낯선 사람이 내 전자책을 사갔는데, 나는 자고 있었고 파일은 이미 그 사람 메일함에 도착해 있다. 이게 '자동 전달'이고, 오늘 그 세팅을 직접 만든다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, Gumroad에 디지털 상품을 등록하고 결제 즉시 구매자에게 파일이 자동 전달되며 업데이트·환불까지 처리되는 판매 페이지를 실제로 열 수 있습니다.

## 핵심 개념

디지털 상품 판매의 핵심은 '내가 없어도 굴러가는 전달 파이프라인'이다. 구매자가 카드로 결제하면 → 플랫폼이 결제를 검증하고 → 등록해둔 파일이나 라이선스 키가 자동 이메일·다운로드 링크로 나간다. 여기서 사람이 개입하면 그건 자동이 아니라 알바다. Gumroad와 Lemon Squeezy는 이 전 과정(결제·전달·세금계산서·환불)을 대신해주는 대표 도구로, 특히 Lemon Squeezy는 '판매자 대행(Merchant of Record)'이라 해외 부가세까지 알아서 처리한다. 오늘은 가장 빠르게 시작되는 Gumroad로 파일 자동 전달을 세우고, 업데이트 재전송과 환불 규칙까지 한 번에 잡는다.

### 왜 작동하는가

Gumroad는 결제 게이트웨이와 파일 저장소를 하나로 묶어놨어요. 그래서 카드 결제가 승인되는 순간, 그 승인 신호가 곧바로 '이 사람에게 다운로드 링크를 발급해라'는 명령이 됩니다. 당신은 파일을 한 번 올려두기만 하면, 그 뒤로 몇 명이 사든 전달은 시스템이 대신 뜁니다.

## 👀 따라하기 예시

내가 만든 'ChatGPT 프롬프트 50선' PDF를 Gumroad에 처음 등록하는 상황. 제가 먼저 처음부터 끝까지 세팅해볼게요, 눈으로 따라오세요.

### 1. ① Digital product 생성 후 Content 탭에 chatgpt-prompt-pack_v1.0.pdf 업로드

**실제 결과**

```text
저장 즉시 상품 상태가 'Automatic delivery: ON'으로 바뀌고, 미리보기 화면에 잠긴 다운로드 아이콘이 표시됨
```

> 파일이 설명란 링크가 아니라 Content 탭 안에 있어야 결제 이전엔 아무도 못 보고, 결제 후에만 잠금이 풀려요

### 2. ② 구매 후 메시지에 사용법 안내문 붙여넣기

**실제 결과**

```text
'구매 감사합니다! 첨부 PDF를 열어 5번 프롬프트부터 써보세요. 문의: hello@내메일.com' 이 receipt 이메일 본문에 자동 삽입됨
```

> 이 메시지도 자동 발송이라 사람이 매번 답장 안 써도 첫 응대가 끝나요

### 3. ③ Publish 후 시크릿창에서 PWYW $0으로 테스트 구매

**실제 결과**

```text
결제 완료 화면에 'Download' 버튼이 바로 뜨고, 47초 뒤 receipt 메일이 스팸함 아닌 받은편지함에 도착
```

> 내가 직접 구매자 입장이 되어봐야 '정말 자동으로 오는지'를 눈으로 확정할 수 있어요 — 이게 오늘의 아하 포인트

### 4. ④ v1.1 오탈자 수정본으로 교체하며 'Publish updates, notify customers' 체크

**실제 결과**

```text
기존 구매자 전원에게 '새 버전이 나왔습니다' 알림 메일이 자동 발송되고, 구매자는 같은 링크에서 최신 파일을 다시 받음
```

> 한 번 판 뒤에도 손 안 대고 업데이트가 퍼지는 게 진짜 '파이프라인'이에요

### 완성 결과

결제 즉시 파일이 자동 전달되고, 업데이트·환불까지 클릭 한 번으로 처리되는 살아있는 Gumroad 판매 페이지. 좋은 결과의 기준: (1) 파일이 Content 탭 안에 있어 결제 전엔 누구도 못 봄, (2) 테스트 구매에서 다운로드+이메일 둘 다 확인됨, (3) 환불 정책 한 문단이 페이지에 명시돼 있음

## 단계별 따라하기

### 1단계 — 팔 파일과 미리보기 준비 (10분) 🙋나

판매할 실제 파일(PDF·ZIP·Notion 링크 등)을 최종본으로 정리하고, 파일명에 버전을 붙인다. 표지 이미지 1장(1280x720 권장)과 '무엇을 얻는지' 한 줄 설명을 메모장에 적어둔다.

**복사·실행 예시**

```text
파일: chatgpt-prompt-pack_v1.0.pdf / 표지: cover.png / 한 줄: 'ChatGPT로 블로그 글 10배 빠르게 쓰는 프롬프트 50선'
```

### 2단계 — Gumroad 가입하고 상품 만들기 (5분) 🙋나

gumroad.com 가입 → 상단 'New product' → 'Digital product' 선택 → 이름·가격을 입력한다. 가격은 통화를 USD로 두면 해외 결제가 매끄럽다. 무료로 뿌려 리스트를 모으려면 'Pay what you want'에 최소값 0을 준다.

**복사·실행 예시**

```text
이름: ChatGPT Prompt Pack / 가격: $9 (또는 PWYW 최소 $0)
```

### 3단계 — 파일 업로드로 '자동 전달' 켜기 (5분) 🙋나

상품 편집 화면의 'Content' 탭에서 준비한 파일을 드래그해 올린다. 업로드하면 이 파일이 결제 완료 시 구매자에게 자동으로 다운로드 제공된다. 여러 파일이면 폴더처럼 여러 개 올려도 된다. 파일 없이 라이선스 키만 주려면 'Generate license keys'를 켠다.

**복사·실행 예시**

```text
Content 탭에 chatgpt-prompt-pack_v1.0.pdf 업로드 → 저장하면 '결제 후 자동 전달' 상태가 됨
```

### 4단계 — 결제 후 안내 메시지와 영수증 세팅 (7분) 🤝함께

'Receipt' 또는 'Content' 하단의 구매 후 메시지에 사용법·문의처를 적는다. AI에게 따뜻하고 명확한 안내문을 뽑게 한 뒤 붙여넣는다. 이 메시지는 자동 발송 이메일에 함께 나간다.

**복사·실행 예시**

```text
🤖A로 초안 → '구매 감사합니다! 첨부 PDF를 열어 5번 프롬프트부터 써보세요. 문의: hello@내메일.com'
```

### 5단계 — 테스트 구매로 자동 전달 검증 (8분) 🙋나

상품을 'Publish' 후, 시크릿창에서 본인 상품 링크를 열어 실제 소액 결제(또는 PWYW $0)로 구매해본다. 결제 직후 다운로드 화면이 뜨는지, 이메일이 도착하는지 두 곳을 모두 확인한다. 안 오면 스팸함·발신 이메일 인증을 점검한다.

**복사·실행 예시**

```text
시크릿창 결제 → 즉시 '다운로드' 버튼 노출 + 1분 내 receipt 메일 수신 확인
```

### 6단계 — 업데이트 재전송·환불 규칙 잡기 (10분) 🤝함께

파일 v1.1을 올리고 'Publish updates' 시 기존 구매자에게 새 파일 알림을 보낸다(구매자는 같은 링크에서 최신본 재다운로드 가능). 환불은 Settings에서 정책 한 줄을 명시하고, 요청 오면 구매 화면에서 'Refund' 클릭 한 번으로 처리한다.

**복사·실행 예시**

```text
오탈자 수정본 업로드 → 'Publish updates, notify customers' 체크 → 기존 구매자 전원에게 '새 버전' 메일 자동 발송
```

## 흔한 실수와 교정
- **실수:** 파일을 상품 설명란에 링크로만 붙여놓고 '자동 전달'이라 착각한다. 구매 전에도 URL이 노출돼 공짜로 새어나간다.
  - **교정:** 파일은 반드시 Content 탭에 업로드하거나 라이선스 키 기능을 써서, 결제 완료된 구매자에게만 링크가 생성되도록 한다.
- **실수:** 테스트 구매 없이 바로 홍보부터 한다. 결제는 되는데 메일이 안 나가는 상태로 손님을 받는다.
  - **교정:** 공개 직후 시크릿창에서 본인이 먼저 1회 실제 구매해 다운로드+이메일 도착을 눈으로 확인한 뒤 홍보한다.
- **실수:** 환불 규정을 안 적어두고 나중에 감정적으로 대응한다.
  - **교정:** 판매 페이지와 영수증에 환불 정책 한 문단을 미리 박아두고, 정당 사유는 Refund 버튼으로 즉시 처리해 분쟁을 막는다.

## 완료 체크리스트

- 판매 파일 최종본과 표지 이미지를 버전명 붙여 준비했다
- Gumroad에서 Digital product를 만들고 가격·통화를 정했다
- Content 탭에 파일을 업로드해 결제 후 자동 전달을 켰다
- 시크릿창 테스트 구매로 다운로드 화면과 영수증 메일을 모두 확인했다
- 업데이트 재전송 방법과 환불 정책 한 문단을 세팅했다

## 도구

- Gumroad (gumroad.com) — 가장 빠르게 시작하는 디지털 파일 자동 판매·전달
- Lemon Squeezy (lemonsqueezy.com) — 판매자 대행(MoR)으로 해외 부가세까지 자동 처리하는 결제·전달
- Canva (canva.com) — 상품 표지·미리보기 이미지 무료 제작
- ChatGPT (chat.openai.com) — 판매 카피·환불정책·업데이트 메일 초안 생성

## 참고 답안

New product → Digital product 선택 → Content 탭에 'Generate license keys' 켜거나 Notion 링크를 비공개 텍스트로 삽입 → 구매 후 메시지에 '템플릿 사용법 3줄 + 문의처' 작성 → Refund policy 한 문단 추가 → Publish → 시크릿창 PWYW $0 테스트 구매로 즉시 링크/키 수신 확인
