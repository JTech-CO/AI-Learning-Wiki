_AI를 도구로 쓰는 프리랜서 서비스(번역·글쓰기·디자인·데이터 정리)를 정의하고, 포트폴리오 샘플 1개를 AI로 빠르게 만들어 Upwork·크몽 등에 게시할 서비스 설명과 가격표를 완성한다. AI는 속도를, 사람은 품질 책임을 맡는 분업 원칙을 익힌다._

:::note[학습 목표]
- AI를 도구로 쓰는 프리랜서 서비스 1개(예: 블로그 글쓰기, 번역, 데이터 정리)를 정의하고, AI로 포트폴리오 샘플 1개를 빠르게 만든 뒤, 크몽·Upwork 등에 올릴 '서비스 설명 + 가격표' 초안을 완성한다.
:::

> 가장 빨리 첫 수익이 나는 길은 '남의 일을 대신 해주는 것'이다. AI가 속도를 10배로 만들어 준다. 오늘 팔 서비스 1개와 포트폴리오 샘플을 만든다.

## 이 레슨에서 만드는 것

AI를 도구로 쓰는 프리랜서 서비스 1개(예: 블로그 글쓰기, 번역, 데이터 정리)를 정의하고, AI로 포트폴리오 샘플 1개를 빠르게 만든 뒤, 크몽·Upwork 등에 올릴 '서비스 설명 + 가격표' 초안을 완성한다.

## 핵심 개념

프리랜싱은 '내 시간을 잘게 잘라 파는 것'이다. 디지털 상품보다 첫 수익이 빠른 대신, 일한 만큼만 돈이 된다. AI가 게임을 바꾼 지점은 '속도'다 — 블로그 글 1개를 3시간 걸려 쓰던 사람이 AI 초안 + 사람 검수로 1시간에 끝내면, 같은 시간에 3배를 번다. 핵심 분업 원칙: AI는 '초안·반복 작업'을, 사람은 '방향 설정·품질 검수·고객 책임'을 맡는다. 고객은 결과물에 돈을 내지 'AI를 썼는지'엔 관심 없다 — 단, 품질이 떨어지면 바로 떠난다. 그래서 'AI로 빠르게, 사람이 책임지고 다듬어'가 프리랜싱 성공의 한 줄이다. 첫 고객을 잡는 열쇠는 '보여줄 샘플(포트폴리오) 1개'다. 경력이 없어도 샘플이 있으면 신뢰가 생긴다.

### 왜 작동하는가

레스토랑 셰프가 재료 손질은 견습생에게 맡기고 본인은 간 보기와 플레이팅에 집중하면 훨씬 빨리, 더 많은 요리를 낼 수 있죠. AI가 바로 그 견습생입니다 — 초안 쓰기, 반복 작업을 순식간에 해치워줘서, 당신은 방향을 정하고 품질을 책임지는 셰프 역할만 하면 됩니다. 그래서 3시간 걸리던 블로그 글 1개가 AI 초안 + 사람 검수로 1시간 만에 끝나고, 같은 시간에 3배를 벌 수 있는 겁니다.

## 👀 따라하기 예시

동네 카페 사장님이 신메뉴(딸기라떼) 소개 블로그 글을 의뢰했다고 가정해볼게요. 포트폴리오 샘플이 없어서 고민 중이라면, 제가 먼저 처음부터 끝까지 만들어볼게요. 눈으로 따라오세요.

### 1. ① AI에게 재료를 던져줍니다 — "카페 신메뉴 딸기라떼 소개 블로그 글 써줘. 대상: 20~30대, 톤: 발랄하고 친근하게, 800자, 마지막에 방문 유도 문장 포함"

**실제 결과**

```text
"봄이 왔다는 신호, 바로 이 한 잔! 새콤달콤 딸기라떼가 여러분을 기다리고 있어요 🍓 신선한 생딸기를 직접 갈아 넣어… (중략) …오늘 오후, 친구랑 같이 딸기라떼 한 잔 어떠세요?"
```

> 구체적으로 대상·톤·분량·용도를 딱 정해서 시켜야 AI가 "그럴듯한 초안"을 만들어줍니다. 막연하게 시키면 밋밋한 글이 나와요.

### 2. ② AI 초안을 소리 내어 읽어보며 어색한 문장·과장된 표현을 직접 골라냅니다 — "새콤달콤" 반복, 이모지 과다 사용 확인

**실제 결과**

```text
문장 3곳 수정: 이모지 1개로 줄임, "새콤달콤" 중복 제거, 가격·위치 정보 추가 삽입
```

> 고객은 결과물에 돈을 내는 거지 AI를 썼는지엔 관심이 없어요. 하지만 어색함이 남으면 바로 신뢰를 잃습니다. 이 검수가 프리랜서의 진짜 일입니다.

### 3. ③ 실제 정보(가격 5,500원, 카페 위치, 영업시간)를 손으로 채워 넣습니다

**실제 결과**

```text
"딸기라떼는 5,500원, OO동 행복카페에서 매일 오전 10시부터 만나보실 수 있어요"
```

> AI는 이 카페의 실제 가격이나 위치를 모릅니다 — 사실 정보는 반드시 사람이 직접 채워야 오류(할루시네이션)를 막습니다.

### 4. ④ 완성본을 포트폴리오 폴더에 저장하고, 크몽 프로필에 "샘플 작업물"로 등록

**실제 결과**

```text
제목: "카페 신메뉴 블로그 글 샘플 — 딸기라떼 편" + 완성 글 첨부
```

> 경력이 없어도 "보여줄 샘플 1개"만 있으면 첫 고객의 신뢰를 얻을 수 있습니다.

### 완성 결과

800자 내외 완성된 블로그 글 1편. 좋은 결과의 기준: (1) 사실 정보(가격·위치)가 정확한가, (2) 어색한 AI 말투가 남아있지 않은가, (3) 마지막에 방문을 유도하는 문장이 자연스럽게 들어갔는가.

## 단계별 따라하기

### 1. '내가 대신 해줄 수 있는 일' 1개를 정한다

AI로 빠르게 할 수 있고 수요가 있는 서비스를 고른다. 추천: 블로그/상품 상세 글쓰기, 한↔영 번역·교정, 엑셀/데이터 정리, PPT 초안, SNS 콘텐츠 묶음. 잘 아는 분야가 있으면 그쪽으로 좁혀라('부동산 블로그 글' 처럼 좁을수록 잘 팔린다).

**복사·실행 예시**

```text
결정: '소상공인을 위한 네이버 블로그 글 작성(건당)'
```

### 2. AI로 '포트폴리오 샘플 1개'를 만든다

실제 일감처럼 가상의 의뢰를 정하고, 아래 templates의 '샘플 제작' 프롬프트로 초안을 뽑은 뒤 직접 다듬어 완성본 1개를 만든다. 이게 '경력 없음'을 이기는 무기다. 1~2개면 충분하다.

**복사·실행 예시**

```text
샘플: '동네 카페를 위한 신메뉴 소개 블로그 글' 완성본 1개
```

### 3. 서비스 설명과 가격을 정한다

아래 '서비스 설명 작성' 프롬프트로 '무엇을/누구에게/얼마에/며칠 안에' 제공하는지 명확한 설명을 만든다. 첫 가격은 시세보다 약간 낮게 잡아 후기를 빠르게 모은다(후기 5개가 가장 강력한 영업이다). 단가·작업 범위·수정 횟수를 미리 못 박는다.

**복사·실행 예시**

```text
가격: '블로그 글 1건 15,000원 / 800자 내외 / 2일 내 / 수정 1회 포함'
```

### 4. 플랫폼에 등록하고 첫 제안을 보낸다

크몽(kmong.com)·숨고는 국내 의뢰, Upwork·Fiverr는 해외 의뢰에 강하다. 프로필에 2단계 샘플과 3단계 설명을 올린다. Upwork류는 등록만으로 안 되고 '내가 먼저 일감에 제안(지원)'해야 한다 — 하루 2~3건씩 맞춤 제안을 보내라.

**복사·실행 예시**

```text
제안 첫 줄: '카페 신메뉴 블로그 글, 톤 살린 샘플 첨부합니다. 2일 내 초안 드릴게요.'
```

## 흔한 실수와 교정
- **실수:** AI가 쓴 글을 검수 없이 그대로 납품한다
  - **교정:** 고객이 떠나는 1순위 이유다. AI 초안은 '재료'일 뿐, 사실·톤·어색함을 직접 점검하고 책임지는 게 프리랜서의 일이다.
- **실수:** 경력이 없다고 등록조차 안 한다
  - **교정:** 포트폴리오 샘플 1~2개면 시작 충분하다. 첫 후기 5개를 모으는 게 경력보다 빠른 신뢰 쌓기다.
- **실수:** 작업 범위·수정 횟수를 안 정해 무한 수정에 시달린다
  - **교정:** 등록 글에 '분량·기간·수정 횟수'를 미리 못 박아라. 추가 요청은 추가 비용으로 명시한다.
- **실수:** Upwork 류에서 등록만 하고 제안을 안 보낸다
  - **교정:** 해외 플랫폼은 '내가 먼저 일감에 지원'해야 한다. 하루 2~3건 맞춤 제안을 꾸준히 보내야 첫 계약이 온다.

## 완료 체크리스트

- AI로 빠르게 할 수 있는 서비스 1개를 정했다
- AI로 포트폴리오 샘플 1개를 만들어 직접 다듬었다
- 서비스 설명과 가격(작업 범위·수정 횟수 포함)을 정했다
- 크몽/Upwork 등에 프로필을 올리거나 첫 제안 1건을 보냈다

## 도구

- ChatGPT 또는 Claude (chatgpt.com / claude.ai) — 샘플·서비스 설명 초안을 빠르게 만드는 AI. 결과물은 반드시 사람이 검수.
- 크몽 (kmong.com) / 숨고 — 국내 프리랜서 의뢰 매칭 플랫폼.
- Upwork (upwork.com) / Fiverr — 해외 의뢰 중심. 등록 후 직접 일감에 제안(지원)해야 첫 계약이 온다.
- Google Docs / 노션 — 포트폴리오 샘플을 깔끔하게 정리해 보여주는 무료 도구.

## 참고 답안

지시 예: "미용실 신규 오픈 이벤트 블로그 글 써줘. 대상: 20~40대 여성, 톤: 세련되고 신뢰감 있게, 700자, 마지막에 예약 유도 문장 포함" → AI 초안 받기 → 어색한 문장 3곳 이상 손보기 → 할인율(예: 전 메뉴 30%), 위치, 기간(예: 7월 한 달) 실제 정보로 채우기 → 완성.

## 실전 프롬프트

### 포트폴리오 샘플 제작

```text
나는 [네이버 블로그 글 작성] 프리랜서 서비스를 시작하려 해. 포트폴리오용 샘플을 만들고 싶어.
가상 의뢰: [동네 카페가 신메뉴 '흑임자 라떼'를 알리는 블로그 글]
조건: 1) 800자 내외 2) 검색에 걸리게 핵심 키워드 자연스럽게 포함 3) 친근하지만 신뢰가는 톤 4) 마지막에 방문 유도 한 줄.
완성된 샘플 글 1개를 써줘. (나는 이걸 직접 읽고 다듬어 내 포트폴리오로 쓸 거야.)
```

### 서비스 설명 + 가격표 작성

```text
프리랜서 마켓(크몽/Upwork)에 올릴 내 서비스 소개 글을 써줘.
- 서비스: [소상공인용 네이버 블로그 글 작성]
- 대상 고객: [블로그 마케팅은 하고 싶지만 글 쓸 시간이 없는 자영업자]
- 강점: [AI로 빠르게 초안 + 사람이 직접 검수해 자연스러움]
순서: 1)눈길 끄는 제목 2)이런 분께 추천 3가지 3)제공 내용/분량 4)작업 기간·수정 횟수 5)가격 옵션 3개(기본/표준/프리미엄). 과장 없이 신뢰가게.
```
