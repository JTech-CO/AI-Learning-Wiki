_Zapier/Make의 오픈소스 대안 n8n으로 무제한·셀프호스팅 자동화를 만들고 AI 노드를 끼워 넣는 실전._

:::note[학습 목표]
- 이 레슨을 끝내면, 브라우저에서 무료 n8n을 켜고 '새 이메일이 오면 → AI가 요약해서 → 내 슬랙(또는 텔레그램)으로 보내주는' 자동화 워크플로 1개를 직접 만들어 실제로 작동시킬 수 있습니다.
:::

> 매일 똑같은 클릭·복붙·정리를 손으로 반복하고 있나요? n8n이면 그 일을 '한 번 만들어 두면 24시간 알아서 도는 로봇 직원'으로 바꿔, 하루 30분~2시간을 통째로 돌려받습니다.

## 이 레슨에서 만드는 것

이 레슨을 끝내면, 브라우저에서 무료 n8n을 켜고 '새 이메일이 오면 → AI가 요약해서 → 내 슬랙(또는 텔레그램)으로 보내주는' 자동화 워크플로 1개를 직접 만들어 실제로 작동시킬 수 있습니다.

## 핵심 개념

n8n(엔에잇엔이라고 읽어요)은 '레고 블록으로 자동화를 조립하는 도구'예요. 블록 하나하나를 '노드(node)'라고 부르는데, 노드는 '하나의 작은 일'이에요 — 예: '메일 받기' 노드, 'AI에게 요약 시키기' 노드, '슬랙에 보내기' 노드. 이 노드들을 선으로 이어 붙이면, 왼쪽에서 오른쪽으로 정보가 흘러가며 일이 저절로 처리돼요. 마치 물이 파이프를 따라 흐르듯이요. Zapier·Make 같은 비슷한 도구도 있지만, n8n은 '오픈소스(무료로 공개된 프로그램)'라서 내 컴퓨터나 내 서버에 직접 깔면 횟수 제한 없이 공짜로 쓸 수 있다는 게 핵심 장점이에요. 코딩을 몰라도 마우스로 블록을 끌어다 놓으면 됩니다.

### 왜 작동하는가

컴퓨터는 사람과 달리 지치지 않고 같은 순서를 계속 반복할 수 있어요. n8n은 "메일 도착 → AI 요약 → 슬랙 전송"처럼 노드를 선으로 이어두면, 그 순서를 24시간 대신 실행해주는 로봇 직원이 됩니다. 그래서 당신은 블록을 한 번만 조립하면, 그 다음부터는 지켜보기만 하면 돼요.

## 👀 따라하기 예시

매일 아침 쌓인 메일을 하나씩 열어 내용을 확인하고 슬랙에 정리해 올리는 상황. 제가 먼저 n8n으로 이 과정을 자동화해볼게요, 눈으로 따라오세요.

### 1. ① Gmail Trigger 노드를 캔버스에 놓고 'On message received'를 선택, 구글 계정 연결

**실제 결과**

```text
Gmail Trigger 노드가 초록 테두리로 표시되고, Poll Times가 'Every 15 Minutes'로 설정됨
```

> 실행 횟수 한도(월 2,500회)를 지키려면 폴링 주기를 넉넉하게 잡는 게 핵심이에요

### 2. ② OpenAI 노드를 연결하고 Prompt에 '다음 이메일을 한국어 3줄로 요약해줘: {{ $json.snippet }}' 입력

**실제 결과**

```text
OUTPUT 패널에 '고객이 다음주 화요일 미팅을 요청했고, 견적서 재발송을 부탁했습니다. 회신 기한은 금요일입니다.' 같은 3줄 요약 텍스트가 생성됨
```

> {{ }}는 앞 노드가 넘겨준 데이터를 그대로 가져오는 자리표라서, 메일 내용마다 요약이 자동으로 바뀌어요

### 3. ③ Slack 노드를 연결하고, OUTPUT 패널의 결과 항목을 드래그해서 Text 칸에 끼워 넣기

**실제 결과**

```text
Text 칸에 '📩 새 메일 요약\n{{ $json.content }}'이 자동 삽입됨
```

> 직접 타이핑하면 키 이름을 틀리기 쉬운데, 드래그&드롭은 항상 정확한 경로를 넣어줘요

### 4. ④ Test workflow로 한 번 실행 후 오른쪽 위 토글을 Active(초록)로 전환

**실제 결과**

```text
내 슬랙 채널에 실제로 '📩 새 메일 요약 - 고객이 다음주 화요일...' 메시지 도착
```

> Active를 켜야 테스트가 아니라 진짜로 계속 도는 자동화가 됩니다

### 완성 결과

메일이 오면 자동으로 요약되어 슬랙에 도착하는 워크플로 1개. 좋은 결과의 기준: (1) 모든 노드가 선으로 이어져 초록 체크가 뜬다, (2) Active 토글이 켜져 있다, (3) 테스트 메일을 보내면 실제로 슬랙 알림이 온다.

## 단계별 따라하기

### 1) 무료 n8n 켜기 (설치 없이 시작)

브라우저(크롬 권장) 주소창에 'n8n.io' 입력 → 오른쪽 위 'Get started' 또는 'Sign up' 버튼 클릭 → 'n8n Cloud'를 고르면 설치 없이 14일 무료로 바로 써볼 수 있어요. 구글 계정으로 'Sign up with Google'을 누르면 가장 빠릅니다. 가입하면 잠시 후 'workspace'(작업 공간)가 만들어지고, 가운데가 비어 있는 캔버스(흰 그리드 화면) 화면이 떠요. 이게 우리가 블록을 조립할 작업대예요. ⚠️ 14일 트라이얼이 끝난 뒤 유료 플랜으로 업그레이드하지 않으면 워크스페이스(워크플로·연결 정보 포함)가 자동 삭제됩니다. 트라이얼 기간 내에 메뉴 Settings → Download Workflows로 백업 파일을 내려받아 두세요. (완전 무료로 계속 쓰려면 나중에 Docker로 내 컴퓨터에 설치하는 Self-host Community Edition이 있지만, 처음엔 Cloud가 제일 쉬워요.)

**복사·실행 예시**

```text
화면 가운데에 큰 '+' 버튼과 'Add first step'(첫 단계 추가)라는 글자가 보이면 성공입니다.
```

### 2) 시작 신호(트리거) 노드 넣기

캔버스 가운데 '+' 또는 'Add first step'을 클릭 → 오른쪽에 검색창이 뜨면 'Gmail' 입력 → 'Gmail Trigger'를 클릭 → 'On message received'(메일 받으면) 선택. 그러면 'Sign in with Google' 버튼이 나와요. 눌러서 본인 구글 계정으로 로그인하고 권한을 '허용'하면 연결 완료. 이게 '새 메일이 오면 자동화를 시작하라'는 출발선이에요. ⚠️ 실행 횟수(executions) 주의: n8n Cloud Starter 플랜은 월 2,500회 실행이 한도입니다. 'Poll Times'(확인 주기)를 'Every Minute'(1분)으로 설정하면 폴링만으로 한 달에 최대 43,200회 확인이 발생해 약 11일 이내에 한도를 초과하고 워크플로가 일시 정지됩니다. 연습·학습 단계에서는 Poll Times를 'Every 15 Minutes' 또는 'Every Hour'로 설정하거나, 아예 메일이 실제로 도착할 때만 카운트되는 Webhook 방식으로 전환하는 것이 좋습니다. (Gmail이 없으면 검색창에 'Schedule'을 넣어 '매일 아침 9시에 시작' 같은 시간 트리거로 대체해도 됩니다.)

**복사·실행 예시**

```text
연결 후 'Poll Times'는 'Every 15 Minutes'처럼 긴 간격으로 두는 것이 실행 횟수 절약에 유리합니다.
```

### 3) AI 요약 노드 연결하기

방금 만든 Gmail 노드 오른쪽의 작은 동그라미(연결점)에서 선을 끌어 빈 곳에 놓으면 다시 검색창이 떠요. 'OpenAI'를 검색해 선택 → 'Message a model'(또는 최신 버전에서는 'Generate a Chat Completion') 클릭. 'Credential'(열쇠) 칸에서 'Create New'를 눌러 OpenAI의 API 키를 붙여넣어요. (API 키 = AI를 쓰기 위한 비밀번호. platform.openai.com → 로그인 → 왼쪽 'API keys' → 'Create new secret key'에서 만들어 복사). Model은 'gpt-4o-mini'(저렴하고 빠름) 선택. 'Prompt'(시킬 말) 칸에 아래 templates의 요약 프롬프트를 붙여넣고, 메일 본문은 '{{ }}' 표시를 눌러 앞 노드의 'snippet' 또는 'text'를 끼워 넣어요. 참고: n8n의 'AI Agent' 노드는 다단계 추론용 고급 노드로 구조가 다릅니다. 단순 요약에는 반드시 일반 'OpenAI' 노드의 'Message a model'(또는 'Generate a Chat Completion') 작업을 사용하세요.

**복사·실행 예시**

```text
Prompt 칸 예: '다음 이메일을 한국어 3줄로 요약해줘: {{ $json.snippet }}' — 여기서 {{ $json.snippet }}는 '바로 앞에서 받은 메일 내용'을 가리키는 자리표예요.
```

### 4) 결과 보낼 노드 연결하기 (슬랙/텔레그램)

AI 노드 오른쪽 동그라미에서 또 선을 끌어 → 'Slack' 검색 → 'Send a message'(메시지 보내기) 선택 → 'Sign in with Slack'으로 본인 워크스페이스 연결. 'Channel'에서 알림 받을 채널(예: #나에게)을 고르고, 'Text'(보낼 내용) 칸에 앞 AI 노드의 결과를 끼워 넣어요. ⚠️ 출력 필드 주의: OpenAI 노드의 응답 텍스트를 참조하는 표현은 n8n 버전과 'Simplify Output' 설정 여부에 따라 다릅니다. 노드를 실행한 뒤 OUTPUT 패널에서 실제로 어떤 키 이름이 보이는지(content, text, message 등)를 먼저 확인하고, 그 키를 그대로 사용하세요. 직접 타이핑하지 말고 OUTPUT 목록의 항목을 마우스로 Text 칸에 끌어다 놓으면 경로가 자동으로 올바르게 입력됩니다. 슬랙이 없으면 'Telegram'을 검색해도 돼요(텔레그램은 @BotFather에게 /newbot 입력 → 봇 토큰 받아 연결).

**복사·실행 예시**

```text
Text 칸에 AI 결과를 넣을 때는 직접 치는 대신 OUTPUT 패널의 해당 항목을 드래그&드롭하세요. 그러면 '📩 새 메일 요약
{{ $json.content }}' 같은 식으로 정확한 경로가 자동 삽입됩니다.
```

### 5) 한 번 테스트 실행하기

화면 아래쪽 가운데의 'Test workflow'(워크플로 시험) 버튼을 클릭하면, 각 노드가 차례로 초록색 체크(✓)로 바뀌며 실행돼요. 노드를 클릭하면 오른쪽에 'INPUT'(들어온 값)과 'OUTPUT'(나온 값)이 보여서, 어디서 무엇이 만들어졌는지 눈으로 확인할 수 있어요. 빨간 X가 뜨면 그 노드를 클릭해 빨간 글씨(에러 메시지)를 읽으세요 — 대부분 '연결(로그인) 안 됨' 또는 '빈 칸'이 원인입니다.

**복사·실행 예시**

```text
성공하면 실제로 내 슬랙에 '📩 새 메일 요약 ...' 메시지가 도착해요. 이게 보이면 자동화가 살아 움직인 거예요.
```

### 6) 자동으로 켜두기 (Activate)

오른쪽 위의 'Inactive'(꺼짐) 토글 스위치를 클릭해 'Active'(켜짐, 초록색)로 바꾸세요. 이제부터는 'Test' 버튼을 누르지 않아도, 새 메일이 올 때마다 n8n이 24시간 알아서 요약→전송을 반복합니다. 워크플로 이름은 왼쪽 위 'My workflow' 글자를 클릭해 '메일 자동요약' 등으로 바꿔 저장(Ctrl+S 또는 'Save' 버튼)하세요.

**복사·실행 예시**

```text
토글이 초록색 'Active'가 되고, 이름이 '메일 자동요약'으로 저장되면 완성입니다. 본인에게 테스트 메일을 보내 설정한 Poll 주기 뒤 슬랙 알림이 오는지 확인해 보세요.
```

## 흔한 실수와 교정
- **실수:** 노드만 추가하고 노드끼리 선으로 안 이어서 정보가 안 흐른다.
  - **교정:** 노드 오른쪽의 작은 동그라미에서 다음 노드 왼쪽 동그라미까지 마우스로 선을 끌어 연결하세요. 선이 없으면 '데이터가 안 넘어갑니다'.
- **실수:** OpenAI API 키에 결제수단이 없어 AI 노드에서 'quota'(한도) 에러가 난다.
  - **교정:** 2026년 기준 OpenAI 신규 계정에는 자동 무료 크레딧이 제공되지 않습니다. platform.openai.com → 'Billing'에서 카드를 등록하고 원하는 금액(예: $5~$10)을 직접 충전하세요. gpt-4o-mini는 입력 $0.15/백만 토큰, 출력 $0.60/백만 토큰으로 매우 저렴합니다. 메일 한 통 요약에 입력 약 500 토큰 + 출력 약 150 토큰이 쓰인다면 1,000회 요약 비용은 약 $0.17 수준으로, $5 충전으로 수천 건을 처리할 수 있습니다.
- **실수:** 테스트만 누르고 'Active' 토글을 안 켜서, 실제 메일이 와도 안 돈다.
  - **교정:** 오른쪽 위 토글을 'Active'(초록색)로 바꾸세요. 테스트 실행은 '한 번만', Active는 '계속 자동'입니다.
- **실수:** {{ $json.message.content }} 같은 자리표를 손으로 잘못 타이핑해 빈 값이 들어간다.
  - **교정:** 직접 치지 말고, 앞 노드의 OUTPUT 목록에서 원하는 항목을 마우스로 끌어다 칸에 떨어뜨리면 자동으로 올바른 표현이 들어갑니다. n8n 버전에 따라 출력 필드 이름이 content, text 등으로 다를 수 있으므로, OUTPUT 패널에서 실제 키 이름을 눈으로 확인한 뒤 사용하세요.

## 완료 체크리스트

- n8n에 로그인해 빈 캔버스 화면이 떴다
- Gmail(또는 Schedule) 트리거 노드를 넣고 계정 연결을 끝냈다
- AI 노드에 OpenAI 키를 넣고 요약 프롬프트를 채웠다
- 슬랙/텔레그램 전송 노드까지 선으로 모두 이어졌다
- 'Test workflow'가 전부 초록 체크로 성공했고 실제 알림이 도착했다
- 오른쪽 위 토글을 'Active'로 켜고 워크플로를 저장했다

## 도구

- n8n — 마우스로 블록을 이어 만드는 자동화 도구. Cloud 버전은 14일 무료 트라이얼 후 최소 €24/월(Starter, 월결제 기준)이 청구됩니다. Starter 플랜은 월 2,500회 실행이 한도이며, Gmail Trigger를 1분 간격 폴링으로 설정하면 약 11일 만에 한도를 초과해 워크플로가 일시 정지될 수 있습니다. 트라이얼 만료 후 업그레이드하지 않으면 워크스페이스가 자동 삭제되므로 반드시 백업하세요. Self-host(직접 설치)는 Community Edition이 무료이지만, Docker 설치·서버 운영 능력이 필요합니다.
- Gmail — 자동화의 시작 신호(트리거)를 주는 메일
- OpenAI(gpt-4o-mini) — 메일을 자동 요약하는 저렴한 AI. 2026년 기준 입력 $0.15/백만 토큰, 출력 $0.60/백만 토큰.
- Slack / Telegram — 결과를 나에게 즉시 알려주는 알림 통로

## 참고 답안

Gmail Trigger → OpenAI(요약) 노드는 그대로 두고, 마지막 노드만 Telegram의 'Send a message'로 교체. Credential에 봇 토큰 입력 → Chat ID 설정 → OUTPUT의 요약 결과를 Text 칸에 드래그 → Test 실행 후 Active 전환.
