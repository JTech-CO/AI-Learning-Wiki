_프롬프트를 지시·맥락·입력·출력형식·제약 5개 부품으로 분해하고, 한 요소씩 바꿔가며 응답이 어떻게 달라지는지 실험해 원하는 답을 정확히 조준한다._

:::note[학습 목표]
- 아무 프롬프트나 지시·맥락·입력·출력형식·제약 5개 요소로 분해한다
- 비어 있던 칸을 내 상황으로 채워 바로 쓸 수 있는 완성 프롬프트로 합친다
- 한 부품씩만 바꿔 A/B 실험으로 어느 요소가 답을 가장 크게 바꾸는지 찾아낸다
:::

## 핵심 개념

모든 좋은 프롬프트는 **5개 부품의 조합**이에요. (1) **지시** = 시켜야 할 동작 (2) **맥락** = AI가 알아야 할 배경과 역할 (3) **입력** = 처리 대상 원재료 (4) **출력형식** = 결과의 모양(표·목록·글자수) (5) **제약** = 지켜야 할 규칙(하지 말 것·톤·분량)이죠. 요리에 비유하면 지시는 조리법, 입력은 식재료, 출력형식은 그릇, 제약은 알레르기 주의사항이에요. 답이 마음에 안 들 때 5개 중 어느 부품이 비었거나 모호한지 찾아 **그것만 고치면**, 프롬프트 전체를 다시 쓰지 않고도 답을 정확히 조준할 수 있어요.

### 왜 이게 될까?

AI는 수억 개의 문장에서 "지시가 명확할수록 답도 명확해진다"는 패턴을 익혔어요. 그래서 프롬프트를 지시·맥락·입력·출력형식·제약 5개 부품으로 또렷하게 채워주면, AI는 그 부품 하나하나를 힌트 삼아 답의 모양을 정확히 맞춰줍니다. 즉 **당신은 5칸을 채우기만 하면** 문장을 매끄럽게 잇는 일은 AI가 대신해요.

## 👀 따라하기 예시 — 카페 사장님의 "우리 카페 인스타 글 좀 써줘"

**① 5칸 표로 분해** — 원래 문장에서 채워진 칸을 확인: 지시=인스타 게시글 작성 / 맥락=(빈칸) / 입력=(빈칸) / 출력형식=(빈칸) / 제약=(빈칸).
> 💡 5칸 중 4칸이 비어 있다는 게 눈에 보이면, 답이 부실했던 이유가 AI 탓이 아니라 프롬프트 탓이라는 게 명확해져요.

**② 맥락·입력부터 채우기** — 맥락 "너는 동네 카페 SNS 담당자야" / 입력 "신메뉴 흑임자 라떼, 가격 5500원, 이번 주 출시".
> 💡 AI에게 역할(맥락)과 재료(입력)를 주면 막연한 홍보 문구가 아니라 이 카페만의 구체적인 글이 나올 준비가 돼요.

**③ 출력형식·제약까지 채워 완성** — 5칸을 모두 합친 완성 프롬프트:
> 너는 동네 카페 SNS 담당자야. 신메뉴 흑임자 라떼(5500원, 이번 주 출시) 홍보 글을 150자 이내로, 해시태그 3개 포함해서 써줘. 이모지는 2개까지, 존댓말로, 할인 언급은 하지 마.

> 💡 출력형식(150자·해시태그)과 제약(이모지·존댓말·금지어)까지 넣으면 AI가 답의 '모양'까지 통제할 수 있어요.

**④ 실제 답 확인** — 이 프롬프트를 AI에 넣어 받은 답:
> 🍵 새로 나온 흑임자 라떼, 이번 주부터 만나보세요! 고소한 흑임자와 부드러운 우유가 만났어요 ☺️ #흑임자라떼 #신메뉴 #동네카페 (148자)

> 💡 5칸을 다 채웠더니 분량·톤·해시태그 개수까지 요구한 그대로 나왔어요. 이게 5요소 해부의 힘이에요.

좋은 결과의 기준: (1) 지시·맥락·입력·출력형식·제약 5칸 중 빈칸이 없다 (2) 출력형식과 제약이 숫자나 명확한 규칙으로 측정 가능하다 (3) 이 프롬프트만 봐도 어떤 답이 나올지 예측이 된다.

## 단계별 따라하기

1. **나쁜 프롬프트 하나 준비** — 최근 AI에게 던졌다가 실망했던, 또는 지금 실제로 필요한 요청을 한 문장으로. 일부러 뭉뚱그린 짧은 문장이면 좋아요. (예: '우리 카페 인스타 글 좀 써줘' — 지시만 있고 맥락·입력·형식·제약이 전부 빠진 전형적인 나쁜 프롬프트)
2. **5개 부품으로 분해해 표로 적기** — 메모장에 지시/맥락/입력/출력형식/제약 5칸을 만들고 1단계 문장에서 각 칸에 해당하는 내용을 옮겨 적어요. 비어 있는 칸이 바로 답이 부실했던 원인. (지시=인스타 게시글 작성 / 나머지 4칸 빈칸 → 5칸 중 4칸이 비어 있음을 눈으로 확인)
3. **빈칸을 채워 완성 프롬프트 만들기** — 비어 있던 칸을 내 상황으로 채워요. 맥락엔 역할과 배경, 입력엔 실제 정보, 출력형식엔 결과 모양, 제약엔 금지·톤·분량. 채운 표를 템플릿에 붙여 하나의 프롬프트로 합쳐요.
4. **한 부품씩만 바꿔 A/B 실험** — 완성 프롬프트를 AI에 넣어 기준 답(A)을 받고, 딱 한 부품만 바꿔 다시 넣어 답(B)을 비교. 한 번에 하나만 바꿔야 무엇이 답을 바꿨는지 정확히 알 수 있어요. (출력형식을 '150자 글'에서 '표: 제목|본문|해시태그'로만 바꿔 재실행 → 같은 내용이 완전히 다른 모양으로)
5. **어느 부품이 가장 큰 변화를 냈는지 기록** — '부품 → 바꾼 내용 → 답이 어떻게 달라졌나' 3열로 한 줄씩. 내 작업에서 가장 효과가 큰 부품이 무엇인지 감이 생겨요. (제약(톤) 변경 → 반말로 → 브랜드 느낌이 확 젊어짐(효과 큼))
6. **나만의 5요소 체크리스트 저장** — 완성 프롬프트를 재사용 가능한 서식으로 메모앱에 고정. 다음 요청부터는 빈칸만 갈아끼워요. (메모앱에 '지시:__ / 맥락:__ / 입력:__ / 출력형식:__ / 제약:__' 서식을 즐겨찾기로)

## 흔한 실수 → 교정

- ✗ 5개 요소를 한 번에 다 바꾸고 답을 비교 → 무엇 때문에 답이 달라졌는지 알 수 없음 → **실험할 때는 반드시 한 부품만 바꾸고 나머지는 고정.** 변수를 하나씩 통제해야 원인이 보여요.
- ✗ 출력형식을 안 정해서 매번 답 모양이 제각각 → **'표로 / 3줄 목록으로 / 150자 이내로'처럼 결과의 모양과 분량을 항상 명시.** 형식은 답 품질을 가장 쉽게 바꾸는 부품.
- ✗ 제약을 '잘 써줘', '자연스럽게'처럼 애매하게 적음 → **제약은 측정 가능하게.** '이모지 2개 이내, 존댓말, 할인 언급 금지'처럼 지키거나 어겼는지 눈으로 판별되게.

## 실전 프롬프트

### 5요소 완성 프롬프트(가장 많이 씀)

```text
[맥락: 너는 ___ 역할이고, 상황은 ___ 이다.] [지시: ___ 을(를) 해줘.] [입력: 아래 정보를 사용해. ___] [출력형식: ___ 형태로, 분량은 ___.] [제약: ___ 은(는) 하지 말고, 톤은 ___ 로.]
```

> 확인된 작성 예시 없음

`프롬프트` `5요소` `완성`

### 기존 프롬프트 5요소로 진단

```text
다음 프롬프트를 지시·맥락·입력·출력형식·제약 5개 요소로 분해해서 표로 보여줘. 비어 있거나 모호한 요소가 뭔지 지적하고, 각 빈칸을 어떻게 채우면 좋을지 예시 질문 1개씩 제안해줘. 프롬프트: [내 프롬프트]
```

> 확인된 작성 예시 없음

`프롬프트` `진단` `5요소`

### 한 부품만 바꾼 변형 3개 받기

```text
아래 프롬프트에서 [출력형식] 요소만 3가지로 다르게 바꾼 변형 3개를 만들어줘. 나머지 요소는 그대로 두고, 각 변형이 어떤 상황에 적합한지 한 줄로. 원본 프롬프트: [내 프롬프트]
```

> 확인된 작성 예시 없음

`프롬프트` `변형` `실험`

### 제약 강화로 답 다듬기

```text
방금 준 답이 [너무 길어 / 톤이 안 맞아 / 불필요한 내용이 섞여] 있어. 지시·맥락·입력은 그대로 두고 제약만 이렇게 추가할게: [___ 금지, ___자 이내, 톤은 ___]. 이 제약을 반영해 다시 작성해줘.
```

> 확인된 작성 예시 없음

`프롬프트` `제약` `다듬기`

### 완성 프롬프트 예시 — 카페 흑임자 라떼 홍보

```text
너는 동네 카페 SNS 담당자야. 신메뉴 흑임자 라떼(5500원, 이번 주 출시) 홍보 글을 150자 이내로, 해시태그 3개 포함해서 써줘. 이모지는 2개까지, 존댓말로, 할인 언급은 하지 마.
```

> 확인된 작성 예시 없음

`프롬프트` `예시` `완성`
