_reasoning/thinking 모드가 무엇인지 알고, 어려운 문제엔 깊게·쉬운 건 빠르게 던져 비용과 정확도를 저울질해 고르는 법을 연립방정식 전후 비교로 익힌다._

:::note[학습 목표]
- ChatGPT·Gemini·Claude에서 '추론(Thinking) 모드'를 켜는 위치를 정확히 안다
- 눈앞의 질문이 빠른 모드용인지 추론 모드용인지 3초 만에 판단해 고른다
- 2026년 6월 기준 세 서비스 모두 무료로 추론을 켤 수 있고 무료는 한도가 더 빡빡함을 구분한다
:::

## 핵심 개념

AI에게는 답하는 방식이 두 가지 있어요. 하나는 **빠른 모드**(ChatGPT 기본 GPT-5.5 Instant, Gemini 3.5 Flash 기본) — 깊이 따지지 않고 바로 나오는 대로 답합니다(구구단 즉답하듯). 다른 하나는 **추론 모드**(reasoning·thinking·확장 사고) — 답하기 전에 속으로 단계를 밟아 계산·검토한 뒤 답합니다(수학을 연습장에 풀어보고 답을 적듯). 추론 모드는 더 정확하지만 더 느려요. '내일 날씨 알려줘' 같은 쉬운 건 빠른 모드, '이 계약서에서 위험한 조항 찾아줘'처럼 여러 단계로 따져야 하는 건 추론 모드. 핵심은 '항상 깊게'가 아니라 **문제 난이도에 맞춰 골라 쓰기**예요.

ChatGPT 기본값(GPT-5.5 Instant)은 어려운 질문이 들어오면 알아서 잠깐 추론으로 전환하기도 해요(자동 전환). 추론은 답하기 전에 '속으로 더 많은 토큰'을 쓰기 때문에, 무료·유료 모두 추론 모드일수록 메시지 한도가 더 빨리 찹니다 → 쉬운 건 빠른 모드로 두는 게 한도 절약.

### 왜 이게 될까?

추론 모드는 AI가 답을 바로 내놓지 않고 속으로 "이렇게 풀면 되나? 다시 검토" 하며 여러 단계를 밟은 뒤 답하는 거예요. 연습장에 풀이 과정을 적어보는 셈이죠. 계산·논리 문제에서 훨씬 정확해지지만, 그만큼 시간과 사용 한도를 더 씁니다.

> 💡 2026년 6월 기준, ChatGPT·Gemini·Claude 세 서비스 모두 무료 플랜에서 추론 모드를 직접 켤 수 있어요(무료는 한도가 더 빡빡할 뿐).

## 👀 따라하기 예시 — "사과 3개+배 2개=5000원, 사과 1개+배 4개=6000원. 각각 얼마?"

**① ChatGPT 기본(빠른 모드)에 붙여넣고 Enter** → "사과는 1000원, 배는 1000원입니다."(1~2초 즉답, 검산 없이)
> 💡 빠른 모드는 "그럴듯한 답"을 바로 뱉어요. 연립방정식처럼 단계가 필요한 문제엔 검산을 안 거쳐 틀리기 쉬워요.

**② 입력창 왼쪽 "＋" 버튼 → "Thinking" 켜기** → "Thinking..." 표시가 뜨고 몇 초~수십 초 대기
> 💡 이 스위치를 켜는 순간부터 AI가 "속으로 연습장에 풀이"를 시작해요. 느려지는 건 고장이 아니라 검토 중이라는 신호.

**③ 같은 문제를 추론 모드로 다시** → "x원, y원이라 하면 3x+2y=5000, x+4y=6000. 연립해 풀면 x=800, y=1300. 검산: 3×800+2×1300=5000 ✓, 800+4×1300=6000 ✓. 정답: 사과 800원, 배 1300원."
> 💡 추론 모드는 식을 세우고 풀고 마지막에 검산까지 해요. 이 "검산" 한 줄이 정확도를 끌어올리는 아하 포인트.

**④ 두 답을 나란히 비교** → 빠른 모드 사과=배=1000원(틀림) / 추론 모드 사과=800원, 배=1300원(맞음)
> 💡 같은 질문, 같은 AI인데 모드만 바꿨을 뿐인데 정답 여부가 갈려요. "무조건 추론"이 아니라 "문제 난이도에 맞춰 고르기".

좋은 결과의 기준: (1) 답에 이르는 단계가 눈에 보인다 (2) 마지막에 검산 문장이 있다 (3) 빠른 모드 답과 비교했을 때 실제로 더 정확하다.

## 단계별 따라하기

1. **무료 계정으로 ChatGPT 열기** — chatgpt.com 접속, 'Sign up'→구글 계정 가입. 무료 계정은 기본 모델 GPT-5.5 Instant로 답하며, 유료처럼 화면 위에 모델 고르는 드롭다운은 없다. 추론은 입력창의 '＋' 메뉴 안 'Thinking'으로.
2. **같은 쉬운 질문을 '빠른 모드'로 던져보기** — 아무것도 따로 켜지 않으면 기본 빠른 모드(GPT-5.5 Instant). 답이 거의 즉시(1~3초). (예: "대한민국의 수도는 어디야?")
3. **추론(Thinking) 모드 켜는 곳 — 무료는 입력창 '＋' 메뉴** — 입력창 왼쪽 '＋' 버튼→메뉴→'Thinking' 켜기. 무료 Thinking은 GPT-5.4 mini 추론 모델로 동작하며, 5시간마다 리셋되는 롤링 윈도우 기준 약 10개 메시지 한도(하루 고정 한도 아님). Plus·Pro는 위쪽 모델 드롭다운에서 'Thinking' 직접 선택도 가능. (메뉴 레이블은 'Think longer'처럼 살짝 다를 수 있음)
4. **어려운 문제를 추론 모드로 던지기** — 추론 모드에서 붙여넣고 Enter. 답 위에 'Thinking(생각 중...)'이 몇 초~수십 초 떴다가 답. 빠른 모드보다 느린 게 정상. (예: "사과 3개와 배 2개가 5000원, 사과 1개와 배 4개가 6000원. 각각 구하고 어떻게 풀었는지 단계별로 보여줘.")
5. **두 답을 나란히 비교하기** — 쉬운 질문은 빠른 모드로 충분, 어려운 계산은 추론 모드가 단계를 보여주며 더 믿을 만. 4번 문제를 빠른 모드로도 던져 보면 종종 계산을 틀림. (정답: 사과 800원, 배 1300원)
6. **Gemini·Claude에서도 같은 스위치 찾기(둘 다 무료로 추론 가능)** — gemini.google.com(무료) 기본 'Gemini 3.5 Flash'(빠름), 현재 모델 이름을 눌러 'Thinking' 항목을 'Standard'→'Extended'로 올리면 추론(2026년 6월 기준 무료도 가능, Extended는 토큰 빨리 씀). claude.ai(무료도 가능) 입력창 근처 'Effort' 메뉴 Low/Medium/High/Max와 'Adaptive thinking' 토글, 켜면 어려운 질문에서 추론 펼침(2026년부터 무료 플랜도, 무료는 깊은 추론 한도가 더 빡빡).
7. **나만의 판단 기준 한 줄로** — '단계가 2개 이상 필요하거나 틀리면 큰일 나는 일이면 추론 모드'. 사실 검색·번역·가벼운 글은 빠른 모드. 수학·논리·코드·돈/법/건강 판단·여러 조건을 동시에 따지는 일은 추론 모드. 평소엔 빠른 모드로 두고, 답이 이상하거나 어려우면 추론을 직접 켜고 다시. (메모: '빠른=검색·번역·요약 / 깊게=계산·논리·코드·돈·법')

## 흔한 실수 → 교정

- ✗ 모든 질문에 추론 모드를 켜둠 → **쉬운 질문엔 시간만 낭비되고 추론용 모델의 빠듯한 사용 한도도 빨리 소진.** 기본은 빠른 모드(ChatGPT는 어려우면 자동 전환), 어려울 때만 추론.
- ✗ 어려운 계산·논리 문제를 빠른 모드로 던지고 답을 믿음 → **빠른 모드는 자신 있게 틀릴 수 있음.** 수학·돈·법 판단은 꼭 추론 모드로 던지고 풀이를 확인.
- ✗ 무료 ChatGPT에서 위쪽 모델 드롭다운으로 Thinking을 찾음 → **무료 플랜엔 위쪽 모델 선택 드롭다운이 없음.** 무료에서 추론은 입력창 '＋' 메뉴의 'Thinking'으로(위쪽 드롭다운은 Plus·Pro 전용).
- ✗ 'Claude·Gemini 추론은 유료 전용'이라고 지레짐작 → **2026년 6월 기준 셋 다 무료로 추론 가능** — Gemini는 모델 메뉴의 Thinking 'Extended', Claude는 'Effort' 메뉴의 'Adaptive thinking' 토글. 무료는 한도가 더 빡빡할 뿐.
- ✗ 'Thinking(생각 중...)'이 오래 떠서 멈춘 줄 알고 새로고침 → **추론 모드는 원래 몇 초~수십 초.** 멈춘 게 아니니 기다림. 새로고침하면 처음부터 다시 풀어 한도만 더 씀.

## 도구

- 🛠 **ChatGPT** (chatgpt.com) — 기본 GPT-5.5 Instant(빠름, 어려우면 자동으로 더 생각). 추론: 무료·Go는 입력창 '＋' 메뉴 'Thinking'(GPT-5.4 mini 추론, 5시간마다 리셋 약 10개 메시지 한도), Plus·Pro는 위쪽 모델 드롭다운 'Thinking'.
- 🛠 **Gemini** (gemini.google.com) — 기본 Gemini 3.5 Flash. 모델 이름 눌러 'Thinking' Standard→Extended(무료도 가능, Extended는 한도 소모 빠름).
- 🛠 **Claude** (claude.ai) — 'Effort' 메뉴(Low/Medium/High/Max)와 'Adaptive thinking' 토글(2026년부터 무료도, 무료는 한도 빡빡).

## 실전 프롬프트

### 추론 모드에 어려운 문제 던지기(단계 풀이 요청)

```text
다음 문제를 풀어줘. 바로 답하지 말고 풀이 과정을 단계별로 보여준 뒤 마지막에 결론을 한 줄로 정리해줘. 중간에 계산이 있으면 검산도 한 번 해줘. [문제]
```

`추론 모드` `단계 풀이` `검산`

### 이 질문에 어느 모드가 맞는지 AI에게 물어보기

```text
다음 질문은 너의 '빠른 답변(Instant)'으로 충분해, 아니면 '깊게 생각하는 추론(Thinking) 모드'가 필요해? 한 줄 이유와 함께 둘 중 하나로. 질문: [내 질문]
```

`모드 선택` `판단`

### 빠른 답이 미심쩍을 때 다시 검증

```text
방금 네 답이 맞는지, 이번엔 천천히 단계별로 다시 검토해줘. 각 단계의 숫자나 논리를 직접 검산하고, 틀린 부분이 있으면 어디서 왜 틀렸는지 짚은 뒤 고친 최종 답을 한 줄로.
```

`검증` `검산` `재검토`

### 예시 — 연립방정식 단계별 풀이

```text
사과 3개와 배 2개가 5000원, 사과 1개와 배 4개가 6000원. 각각 구하고 어떻게 풀었는지 단계별로 보여줘.
```

`예시` `연립방정식` `단계 풀이`
