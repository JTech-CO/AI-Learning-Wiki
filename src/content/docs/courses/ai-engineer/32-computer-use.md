_AI가 브라우저·앱을 직접 클릭·입력해 작업을 끝내는 computer use/browser-agent의 작동·활용·안전장치._

:::note[학습 목표]
- 오늘 안에, AI가 진짜 브라우저를 열어 '특정 사이트에 들어가 정보를 찾고 그 결과를 표로 정리'하는 작업을 직접 클릭·입력으로 수행하게 시키고, 결과물(텍스트·표·캡처)을 받아볼 수 있게 됩니다. 카드 없이 무료 티어(소량 사용)로 충분히 연습할 수 있어요.
:::

> 매번 같은 사이트에 로그인해서 표를 복사하고, 양식을 채우고, 캡처를 뜨는 단순 반복… 그 30분짜리 잡일을 AI가 화면을 직접 클릭해서 대신 끝내줍니다. 손은 커피잔으로.

## 이 레슨에서 만드는 것

오늘 안에, AI가 진짜 브라우저를 열어 '특정 사이트에 들어가 정보를 찾고 그 결과를 표로 정리'하는 작업을 직접 클릭·입력으로 수행하게 시키고, 결과물(텍스트·표·캡처)을 받아볼 수 있게 됩니다. 카드 없이 무료 티어(소량 사용)로 충분히 연습할 수 있어요.

## 핵심 개념

'컴퓨터 유즈(computer use)' 또는 '브라우저 에이전트'는, AI에게 채팅으로 답만 듣는 게 아니라 *마우스와 키보드를 쥐여주는* 것입니다. AI가 화면을 눈으로 보듯 캡처해서 '여기 검색창이 있네' 하고 직접 클릭하고 글자를 칩니다. 비유하면, 똑똑하지만 손이 없던 비서에게 '손'을 달아준 것이에요. 핵심 흐름은 단순합니다: ① 내가 할 일을 말로 시킨다 → ② AI가 화면을 본다 → ③ 클릭·입력 한 동작을 한다 → ④ 바뀐 화면을 다시 본다 → ⑤ 끝날 때까지 ②~④를 반복. 여기서 '에이전트(agent)'란 *스스로 다음 행동을 정하며 일을 끝까지 진행하는 AI*를 말합니다. 사람이 한 클릭씩 알려주지 않아도, 목표만 주면 알아서 단계를 밟습니다. 2026년 현재 이런 도구는 두 갈래입니다: (가) 내 크롬에 끼워 쓰는 무료 오픈소스 확장 — 대표적으로 Nanobrowser. 내 API 키를 넣어 쓰며 사용량만 부담합니다. (나) 회사가 클라우드에서 대신 돌려주는 유료 서비스 — Anthropic의 'Claude for Chrome'(2026년 현재 Pro·Max·Team·Enterprise 등 모든 유료 플랜에서 베타로 제공되는 공식 크롬 확장. 무료 플랜은 사용 불가. Pro 플랜은 Haiku 4.5만 쓰이고, Max·Team·Enterprise는 Haiku 4.5·Sonnet 4.5·Opus 4.5 중에서 고를 수 있습니다), OpenAI의 ChatGPT 'Agent', Google 'Gemini'의 에이전트 모드 등 — 을 켜면 회사 서버가 알아서 합니다. 플랜·모델 구성은 수시로 바뀌니 정확한 건 각 공식 페이지에서 확인하세요. 이 레슨은 카드 없이 시작 가능한 (가) Nanobrowser 경로로 안내합니다.

### 왜 작동하는가

이건 AI가 "화면을 사진처럼 캡처해서 보고, 그 위에 마우스·키보드로 진짜 클릭·입력"을 반복하기 때문에 됩니다. 비유하면 눈은 있지만 손이 없던 똑똑한 비서에게 손을 달아준 거예요. 그래서 당신은 "무엇을 해줘"라는 목표 한 줄만 말하면, 클릭 하나하나는 AI가 대신 반복해서 끝내줍니다.

## 👀 따라하기 예시

오늘 목표: "네이버에서 서울 오늘 날씨를 검색해서 기온이랑 미세먼지 상태를 한 줄로 알려줘." 제가 Nanobrowser로 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① Nanobrowser 아이콘을 눌러 입력칸에 목표를 그대로 입력

**실제 결과**

```text
"네이버에서 서울 오늘 날씨를 검색하고, 기온과 미세먼지 상태를 한 줄로 알려줘." 라고 치고 엔터
```

> 말로만 시켜도 되니 처음엔 어렵게 쓰지 않아도 됩니다 — 그냥 하고 싶은 걸 말하면 돼요

### 2. ② AI가 새 탭을 열고 화면을 캡처해 검색창을 스스로 찾아 클릭

**실제 결과**

```text
새 탭이 뜨고 naver.com이 로딩된 뒤 마우스 커서가 검색창으로 이동, "서울 날씨"가 자동으로 타이핑됨
```

> AI는 사람처럼 화면을 "보고" 다음에 뭘 클릭할지 스스로 판단합니다 — 이게 채팅형 AI와 다른 점

### 3. ③ 검색 결과 화면을 다시 캡처해서 기온·미세먼지 숫자를 읽어냄

**실제 결과**

```text
"현재 기온 24°C, 미세먼지 보통" 이라는 텍스트를 채팅창에 정리해서 답변
```

> 한 번의 클릭으로 안 끝나면, AI는 화면이 바뀔 때마다 다시 보고→판단→행동을 반복합니다

### 4. ④ 결과를 확인하고, 필요하면 형식을 다듬어 재요청

**실제 결과**

```text
"표로 정리해줘"라고 한 번 더 시키면 | 항목 | 값 | 형태의 표로 바뀜
```

> 처음 결과가 마음에 안 들면 다시 말로 다듬으면 됩니다 — AI가 화면을 새로 캡처해서 다시 시도해요

### 완성 결과

완성물은 "서울 날씨 한 줄 요약(또는 표)"입니다. 좋은 결과의 기준: (1) 실제로 원하는 사이트에서 정보를 가져왔는가, (2) 내가 요청한 형식(한 줄/표)대로 정리됐는가, (3) 중간에 엉뚱한 곳을 클릭하지 않고 목표한 작업만 했는가.

## 단계별 따라하기

### 1. 어떤 도구를 쓸지 정하고 준비물 챙기기

2026년 기준 초보가 쉽게 시작하는 길은 두 가지입니다. (가) 무료 오픈소스 확장 — 크롬 웹스토어에서 'Nanobrowser'(브라우저에 끼워 기능을 더하는 작은 프로그램)를 깔면, 내 크롬 안에서 AI가 직접 클릭합니다. 단, AI를 부를 'API 키'는 내가 따로 발급해 넣습니다. (나) 설치 없이 클라우드가 대신 — Anthropic의 'Claude for Chrome'(2026년 현재 Pro·Max·Team·Enterprise 모든 유료 플랜에서 베타로 제공되는 공식 확장. 무료 플랜 불가. Pro는 Haiku 4.5만, Max·Team·Enterprise는 Haiku 4.5·Sonnet 4.5·Opus 4.5 중 선택), OpenAI ChatGPT의 'Agent'(유료 플랜), Google 'Gemini'의 에이전트 모드 같은 서비스를 켜면 회사 서버가 알아서 합니다. (주의: 'Browser Use'는 크롬 확장이 아니라 개발자용 파이썬 라이브러리이므로 웹스토어에서 검색해도 안 나옵니다. 초보용 크롬 확장은 Nanobrowser를 쓰세요. 혹시 Nanobrowser가 웹스토어에서 안 보이거나 동작이 멈춘 듯하면, 같은 방식으로 키를 넣어 쓰는 다른 오픈소스 확장으로 갈아타거나 (나) 클라우드 유료 서비스로 넘어가면 됩니다.) 이 레슨은 카드 없이 무료로 시작 가능한 (가) Nanobrowser 기준으로 안내합니다. 준비물: 크롬 브라우저, 무료 구글 계정(이미 있을 것), 그리고 다음 단계에서 만들 'API 키'(AI를 외부 프로그램이 쓰게 해주는 비밀번호 같은 긴 글자) 하나.

**복사·실행 예시**

```text
오늘 목표 예시 한 줄: "네이버에서 '서울 오늘 날씨'를 검색하고, 기온과 미세먼지 상태를 한 줄로 알려줘."
```

### 2. 무료 AI API 키 만들기 (5분) — 무료 조건 먼저 확인

브라우저 확장이 AI를 부르려면 'API 키'가 필요합니다. Google Gemini는 소량 사용에 한해 카드 없이 무료 티어를 줍니다. 다만 *무료는 조건부*입니다: ① 무료 티어는 분당 요청 수(RPM)·분당 토큰 수(TPM)·하루 요청 수(RPD) 세 가지 한도가 모두 적용됩니다. 2026년 6월 기준 대표 Flash 모델의 무료 한도는 다음과 같습니다 — Gemini 2.5 Flash: 15 RPM / 1,000,000 TPM / 1,500 RPD, Gemini 3 Flash: 10 RPM / 250,000 TPM / 1,500 RPD, Gemini 3.5 Flash: 무료 티어 제공(2026년 5월 출시), 한도는 AI Studio 화면에서 확인. 한도는 '키 1개당'이 아니라 '프로젝트당'이라서 키를 여러 개 만들어도 양이 늘지 않습니다. Google은 사전 공지 없이 한도를 조정할 수 있으므로, 정확한 실시간 한도는 aistudio.google.com 의 'API key'/'Plan & billing' 화면에서 내 프로젝트의 실제 할당량(quota)을 직접 확인하세요. 연습·소량엔 충분하지만 대량 자동화엔 곧 막힙니다. ② 무료로 쓸 수 있는 모델은 'Flash'·'Flash-Lite' 계열로 한정됩니다(2026년 6월 기준 무료 추천 모델: Gemini 2.5 Flash(gemini-2.5-flash), 그 외 Gemini 2.5 Flash-Lite·Gemini 3 Flash·Gemini 3.5 Flash 등 Flash 계열). Pro 계열(예: Gemini 3.1 Pro)은 2026년 4월 1일부터 무료 티어에서 빠져 결제가 켜진 유료 전용입니다. ③ EU·영국·스위스 등 일부 지역은 무료 없이 결제(billing) 등록을 요구할 수 있고, 한 번 결제를 켜면 그 프로젝트는 무료 티어 조건이 바뀌어 과금이 시작될 수 있습니다. 발급: 크롬 주소창에 aistudio.google.com 을 칩니다 → 구글 계정 로그인 → 'Get API key'(API 키 받기) 클릭 → 'Create API key'(키 생성) 클릭 → AIza...로 시작하는 긴 글자를 복사 아이콘으로 복사 → 메모장에 잠깐 붙여둡니다. 키는 비밀번호처럼 다루세요(노출 금지). 막히면: 'Get API key'가 안 보이면 새로고침(F5), 약관 창이 뜨면 'I agree' 체크 후 진행. '무료가 안 된다(country/billing)' 메시지가 뜨면 그 지역은 결제 등록이 필요한 경우이니, (나) 클라우드 유료 서비스 사용을 고려하세요.

**복사·실행 예시**

```text
복사된 키 예시 모양: AIzaSyB1xK...(실제는 약 39자). 이 한 줄이 다음 단계의 빈칸에 들어갑니다.
```

### 3. Nanobrowser 확장 설치하고 키 넣기

크롬 주소창에 'chrome web store nanobrowser'를 검색하거나 chromewebstore.google.com 으로 가서 'Nanobrowser'를 찾습니다 → 파란 '크롬에 추가' 버튼 클릭 → 뜨는 작은 창에서 '확장 프로그램 추가' 클릭. 설치되면 크롬 오른쪽 위 퍼즐 모양(🧩) 아이콘을 눌러 Nanobrowser를 '고정(압정 아이콘)'하면 항상 보입니다. 이제 그 아이콘 클릭 → 톱니바퀴(설정, Settings) → 'Model'/'API' 항목에서 공급사를 'Gemini'로 고르고, 모델은 무료 티어 현재 기본 추천인 Gemini 2.5 Flash 를 고른 뒤(목록 표기는 gemini-2.5-flash 처럼 보일 수 있음. 이게 안 보이면 화면에 보이는 다른 'flash'가 들어간 최신 무료 모델을 선택), 2단계에서 복사한 키를 붙여넣기 → 저장(Save). (참고: Gemini 3.1 Pro 같은 Pro 계열은 결제가 켜진 유료 전용이라 무료 키로 고르면 quota·권한 오류가 날 수 있습니다. 무료로 연습할 땐 Gemini 2.5 Flash·Gemini 2.5 Flash-Lite·Gemini 3 Flash·Gemini 3.5 Flash 같은 무료 Flash를 쓰세요. 반대로 gemini-2.0-flash, gemini-2.0-flash-lite 같은 모델은 2026년 6월 1일자로 종료되어 더 이상 선택하면 안 됩니다 — Gemini 2.5 Flash로 쓰세요.) 막히면: 키를 붙였는데 'invalid'(잘못됨)라고 뜨면 키 앞뒤 빈칸이 묻어왔을 수 있으니 다시 깔끔히 복사해 넣으세요. 모델 이름 오류가 나면 설정의 모델 드롭다운에서 실제 목록에 있는 'flash' 모델로 바꾸세요.

**복사·실행 예시**

```text
설정 화면에 보이는 칸: Provider=[Gemini], Model=[Gemini 2.5 Flash (무료 Flash)], API Key=[여기에 AIza... 붙여넣기]
```

### 4. 첫 명령 — 아주 쉬운 작업부터 시키기

Nanobrowser 아이콘을 클릭하면 채팅창처럼 생긴 입력칸이 나옵니다. 여기에 *말로* 목표를 적고 엔터(또는 Run/실행 버튼)를 누르면, AI가 새 탭을 열고 화면을 캡처하며 직접 클릭하기 시작합니다. 화면에 마우스가 저절로 움직이고 글자가 쳐지는 게 보입니다. 처음엔 결과를 눈으로 확인하기 쉬운 *단순한 한 가지*를 시키세요. AI가 중간에 '이 사이트로 가도 될까요?' 같은 확인을 물으면 'Yes/계속'을 눌러 진행시킵니다. 막히면: AI가 엉뚱한 데를 클릭하면 'Stop'(정지) 버튼을 누르고, 지시문을 더 구체적으로 바꿔 다시 시키세요(5단계). 무료 티어 한도를 넘기면 '429'나 'rate limit/quota' 같은 오류가 뜨는데, 잠시(1~2분) 기다렸다 다시 시도하면 됩니다.

**복사·실행 예시**

```text
입력: "naver.com 에 가서 검색창에 '서울 날씨'를 입력하고 검색해. 검색 결과 맨 위에 보이는 현재 기온을 나에게 한 줄로 알려줘."
```

### 5. 지시문을 '구체적으로' 다듬어 정확도 올리기

에이전트는 목표가 또렷할수록 잘합니다. 좋은 지시문 공식 = ①어디로(사이트) + ②무엇을(행동) + ③어떻게 끝내(결과 형태). 한 번에 너무 많은 걸 시키지 말고 작업을 잘게 나누세요. '표로 정리해줘', '3개만', '날짜·금액 두 칸으로'처럼 *결과 모양*을 못박으면 헛도는 걸 막습니다. 한국어로 그대로 적어도 됩니다. 막히면: 같은 화면에서 계속 맴돌면, 지시에 '만약 로그인 창이 뜨면 멈추고 나에게 물어봐'처럼 *예외 상황 대처*를 미리 적어주세요.

**복사·실행 예시**

```text
개선된 입력: "① finance.naver.com 으로 가 → ② 'USD 환율'을 검색 → ③ 미국 달러의 현재 매매기준율 숫자만 찾아, '오늘 1달러 = ___원' 형식으로 한 줄로 답해. 광고는 무시해."
```

### 6. 결과 받고 표·캡처로 저장하기

AI가 작업을 끝내면 채팅칸 아래에 결과를 글로 정리해줍니다. 여러 줄·표 형태를 원하면 지시에 '표로(마크다운 표)'라고 적으세요. 결과를 드래그해 복사한 뒤 메모장·구글 시트·한글에 붙여넣으면 그대로 자료가 됩니다. 화면 증거가 필요하면 끝난 화면에서 키보드 캡처(Mac: Cmd+Shift+4 / Windows: Win+Shift+S)로 영역 캡처를 뜨세요. 막히면: 표가 깨져 보이면 구글 시트에 붙여넣을 때 '특수 붙여넣기 → 텍스트만'을 쓰면 칸이 정리됩니다.

**복사·실행 예시**

```text
받은 결과 예시: | 항목 | 값 | / | 현재 기온 | 24°C | / | 미세먼지 | 보통 | — 이걸 시트에 붙이면 두 칸짜리 표 완성.
```

### 7. 안전장치 — AI에게 시키면 안 되는 것 선 긋기

에이전트는 *진짜로* 클릭하므로, 잘못하면 진짜로 결제·전송·삭제를 합니다. 그래서 규칙 세 가지를 몸에 익히세요. (1) 은행·카드·결제·계정 비밀번호가 걸린 작업은 *AI에게 맡기지 말고* 사람이 직접. (2) '구매', '전송', '삭제' 같은 *되돌릴 수 없는 마지막 버튼*은 지시문에 '누르기 직전에 멈추고 나한테 물어봐'를 항상 넣기. (3) 처음 보는 사이트나 로그인이 필요한 곳은 *읽기(정보 찾기)*까지만 시키기. AI는 화면에 뜬 가짜 안내문에 속을 수도 있으니(프롬프트 인젝션), 돈·개인정보가 얽히면 항상 사람이 최종 확인합니다. 참고로 Claude for Chrome 같은 공식 유료 서비스도 금융·결제 등 고위험 사이트를 기본 차단하고 위험 행동 전 사용자 확인을 받는 안전장치를 두고 있습니다.

**복사·실행 예시**

```text
안전 지시 예시: "장바구니에 담는 것까지만 하고, '결제하기' 버튼은 절대 누르지 마. 거기서 멈추고 나에게 알려줘."
```

## 흔한 실수와 교정
- **실수:** 'Browser Use'를 크롬 확장으로 알고 웹스토어에서 찾다가 시작부터 막힌다.
  - **교정:** Browser Use는 개발자용 파이썬 라이브러리다. 초보용 크롬 확장은 'Nanobrowser'를 설치한다.
- **실수:** 무료 키로 연습하면서 유료 전용 Pro 모델(예: Gemini 3.1 Pro)을 골라 quota·권한 오류를 만난다.
  - **교정:** 무료 티어에서는 'flash'가 들어간 무료 모델(기본 추천 Gemini 2.5 Flash(gemini-2.5-flash), 그 외 Gemini 2.5 Flash-Lite·Gemini 3.1 Flash-Lite 등)을 고른다. Pro 계열은 2026년 4월 1일부터 결제가 켜진 유료 전용이다.
- **실수:** 이미 종료된 모델 이름(gemini-2.0-flash, gemini-2.0-flash-lite)을 설정에 넣어 '모델 없음' 오류를 만난다.
  - **교정:** 2.0 계열은 2026년 6월 1일자로 종료됐다. 설정 드롭다운에 실제로 보이는 현재 무료 Flash 모델(Gemini 2.5 Flash 등)을 고른다.
- **실수:** '무료니까 끝까지 공짜'라 믿고 대량으로 돌리거나, 키를 여러 개 만들면 양이 는다고 착각하다 429/quota 오류로 멈춘다.
  - **교정:** 무료 티어는 분당·하루 한도(예: Flash 분당 약 15회, 하루 1,500회 안팎)가 '키'가 아닌 '프로젝트'당 걸리고 지역·결제 조건이 붙는다. 정확한 한도는 추측 말고 AI Studio 화면의 실제 quota를 확인하고, 한도 초과 시 잠시 기다리거나 대량은 유료 전환·클라우드 서비스를 쓴다.
- **실수:** 지시가 막연해서 AI가 엉뚱한 데를 클릭하고 헤맨다.
  - **교정:** '어디로 + 무엇을 + 어떤 형식으로 끝내'를 한 문장에 다 넣고, 결과 모양(표·한 줄·3개만)을 못박는다.
- **실수:** 은행·결제·로그인이 걸린 작업까지 AI에게 통째로 맡긴다.
  - **교정:** 돈·비밀번호·개인정보가 얽히면 사람이 직접. AI에겐 '읽기·찾기'까지만, 마지막 버튼 직전에 멈추라고 지시한다.
- **실수:** API 키를 채팅·화면 캡처·메신저에 그대로 공유해 노출한다.
  - **교정:** API 키는 비밀번호처럼 취급. 노출됐으면 aistudio.google.com에서 그 키를 삭제(Delete)하고 새로 만든다.

## 완료 체크리스트

- Nanobrowser가 크롬 확장이고 'Browser Use'(파이썬 라이브러리)와 다르다는 걸 이해했다.
- 무료 Gemini API 키를 만들어 메모장에 안전하게 복사하고, 무료 티어가 한도(프로젝트당, RPM·TPM·RPD 세 가지 모두 적용)·지역·모델(Flash 계열만) 조건부임을 확인했으며 AI Studio 화면에서 내 실제 quota를 봤다.
- Nanobrowser 확장을 설치하고 설정에 무료 Flash 모델(Gemini 2.5 Flash(gemini-2.5-flash) 또는 현재 목록에 있는 다른 Flash 모델)과 키를 넣어 저장했다.
- 쉬운 한 가지 작업(날씨·환율 찾기)을 AI가 직접 클릭해 끝내는 걸 눈으로 봤다.
- 결과를 표나 한 줄로 받아 시트·메모장에 붙여넣어 자료로 남겼다.
- 결제·전송·삭제 같은 위험 행동은 '직전에 멈춰'라고 지시하는 습관을 들였다.

## 도구

- Nanobrowser (크롬 확장, 오픈소스) — 내 크롬 안에서 AI가 직접 클릭·입력. 확장은 무료, 내 API 키로 사용량만 부담. OpenAI·Anthropic·Gemini·Ollama 등 지원. 멈추거나 안 보이면 같은 방식의 다른 오픈소스 확장으로 대체 가능
- Google AI Studio (aistudio.google.com) — Gemini API 키 발급처. 소량 무료 티어(한도는 프로젝트당·지역 조건부, 실시간 quota는 화면에서 직접 확인). 무료는 Flash 계열로 한정(2026년 6월 기준 무료 Flash 모델: Gemini 2.5 Flash·Gemini 2.5 Flash-Lite·Gemini 3 Flash·Gemini 3.5 Flash 등. Pro 계열은 2026년 4월부터 유료 전용). 주요 무료 한도 예시 — Gemini 2.5 Flash: 15 RPM / 1,000,000 TPM / 1,500 RPD, Gemini 3 Flash: 10 RPM / 250,000 TPM / 1,500 RPD. 모델별 한도가 다르며 Google이 예고 없이 변경할 수 있으므로 항상 AI Studio 화면에서 직접 확인
- Claude for Chrome (Anthropic 공식 크롬 확장) — 2026년 현재 Pro·Max·Team·Enterprise 모든 유료 플랜에서 베타로 제공(무료 플랜 불가). 설치 후 클라우드가 대신 클릭. Pro 플랜은 Haiku 4.5만, Max·Team·Enterprise는 Haiku 4.5·Sonnet 4.5·Opus 4.5 중 선택. 최신 구성은 claude.com 공식 페이지에서 확인
- ChatGPT Agent / Gemini 에이전트 모드 — 설치·키 없이 클라우드가 대신 클릭(유료 플랜)
- Browser Use (참고) — 크롬 확장이 아닌 개발자용 파이썬 라이브러리. 직접 코딩해 자동화할 때 사용
- Google 시트 — AI가 뽑은 표 결과를 붙여넣어 정리·보관
