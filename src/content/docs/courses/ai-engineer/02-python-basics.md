_변수·자료형·리스트·함수·import 등 파이썬 최소 문법을 읽고 쓰며, 무엇보다 AI(ChatGPT/Claude)가 준 코드를 브라우저(Colab)에서 직접 돌리고 에러까지 고쳐 "한 달 용돈 자동 계산기"를 손으로 완성한다._

:::note[학습 목표]
- 설치 없이 웹브라우저(Google Colab)만으로 파이썬 코드를 직접 실행한다
- 변수·리스트·함수·import 등 AI 코드의 90%를 차지하는 5가지 문법을 읽고 쓴다
- AI가 준 코드를 내 손으로 돌리고, 빨간 에러를 그대로 복사해 AI 도움으로 고친다
:::

## 핵심 개념

파이썬은 **컴퓨터에게 시키는 말**이에요. 사람 말과 비슷해서 영어 단어 몇 개만 알면 읽히고, 딱 **5가지**만 알면 AI가 주는 코드의 90%가 눈에 들어와요.

- **① 변수** = 이름표 붙인 상자 (예: `용돈 = 50000` → '용돈'이라는 상자에 5만원을 넣음)
- **② 자료형** = 상자 안 내용물의 종류 (숫자 `50000`, 글자 `"치킨"`, 참/거짓)
- **③ 리스트** = 여러 칸짜리 상자 (`간식 = ["치킨", "피자"]`, 0번·1번 칸으로 셈)
- **④ 함수** = 자주 쓰는 동작을 미리 만들어 둔 '버튼' (`print("안녕")`은 화면에 글자를 찍는 버튼)
- **⑤ 모듈(import)** = 남이 만든 도구상자를 빌려오기 (`import math`처럼 필요한 기능을 가져와 바로 씀)

이 5가지가 AI가 주는 모든 코드의 90%를 차지해요.

### 왜 이게 될까?

AI는 이미 수백만 줄의 파이썬 코드를 학습해서 당신이 원하는 프로그램을 순식간에 코드로 뽑아줘요. 그런데 그 코드는 **사람이 눈으로 읽고 어딘가에 붙여넣어 실행 버튼을 눌러야** 비로소 살아나요. 그래서 딱 5개 문법(변수·자료형·리스트·함수·import)만 알아두면 AI가 차려준 코드를 척척 받아 돌리고 에러도 스스로 고칠 수 있어요.

## 👀 따라하기 예시 — 용돈 50000원에서 지출을 뺀 남은 돈 계산 (Colab에서)

**① 변수부터** Colab 새 셀에 `이번달용돈 = 50000` / `print(이번달용돈)` → `50000`
> 💡 `=`는 비교가 아니라 상자에 값을 담는 동작. 이름표를 먼저 붙여야 나중에 계산에 써먹을 수 있어요.

**② 지출 항목을 리스트로 묶기** `지출 = [12000, 8000, 5000]` / `print(sum(지출))` → `25000`
> 💡 따로따로 적지 않고 대괄호 `[ ]` 하나에 묶으면 `sum()`이라는 도구로 한 번에 다 더할 수 있어요. 아하 포인트!

**③ 나만의 버튼(함수)으로 계산 정리** `def 남은돈(용돈, 지출): return 용돈 - sum(지출)` / `print(남은돈(50000, [12000, 8000, 5000]))` → `25000`
> 💡 같은 계산을 매달 반복할 거라면 `def`로 버튼을 하나 만들어두고 숫자만 바꿔 누르면 끝.

**④ 일부러 에러를 내고 AI에게 고쳐달라** 입력 `print(남은돈)` ← 괄호 없이 씀 → 결과 `<function 남은돈 at 0x...>` 이상한 글자 → AI에게 "이거 왜 이래?" 물으면 "함수를 실행하려면 괄호 안에 값을 넣어야 해요. `print(남은돈(50000, [12000,8000,5000]))`으로 고쳐보세요"
> 💡 에러는 실패가 아니라 안내문. 빨간 글씨를 그대로 복사해 AI에게 물어보면 대부분 한 번에 해결돼요.

좋은 결과의 기준: (1) Shift+Enter로 눌렀을 때 에러 없이 숫자가 딱 나온다 (2) 용돈이나 지출 숫자를 바꿔도 다시 계산해서 맞는 값이 나온다 (3) 코드를 소리 내어 읽었을 때 "용돈에서 지출 합을 뺀다"는 뜻이 그대로 읽힌다.

## 단계별 따라하기

1. **설치 없이 실행할 곳 열기 (Google Colab)** — 파이썬을 컴퓨터에 깔 필요 없음. 크롬 주소창에 `colab.research.google.com` 입력, 구글 계정으로 로그인. '+ 새 노트'(New notebook) 클릭 → 빈 회색 칸(셀)이 하나. 이 칸이 코드를 쓰는 곳. (회사·학교 계정은 권한이 막힐 수 있으니 개인 gmail로)
2. **첫 줄 실행해 보기 (print)** — 회색 셀 안을 클릭하고 입력. 셀 왼쪽 ▶(재생) 버튼이나 Shift+Enter로 실행. `print()`는 '괄호 안 내용을 화면에 보여줘'라는 함수. 글자는 반드시 따옴표 `" "`로 감쌈. (입력: `print("내 첫 코드 성공!")` → 결과: `내 첫 코드 성공!`)
3. **변수에 값 담기 (상자에 넣기)** — 새 셀은 결과 아래 '+ 코드' 버튼. `=`는 '오른쪽 값을 왼쪽 이름표 상자에 넣어라'(같다는 비교가 아님!). 이름은 한글도 됨. 담아둔 값은 print로 꺼내 봄. (`이번달용돈 = 50000` / `저금 = 10000` / `print(이번달용돈 - 저금)` → `40000`)
4. **리스트로 여러 개 묶기** — 지출 항목이 여러 개면 대괄호 `[ ]` 안에 콤마로 나열. 이게 리스트(여러 칸 상자). `sum()`은 '다 더해줘' 함수, `len()`은 '몇 개인지 세줘' 함수. 칸 번호는 0부터 시작(첫 칸이 0번). (`지출 = [12000, 8000, 5000]` / `print("총 지출:", sum(지출))` / `print("항목 수:", len(지출))` → `총 지출: 25000` / `항목 수: 3`)
5. **함수로 나만의 버튼 만들기** — 같은 계산을 반복하면 `def`로 '나만의 버튼'. `def 함수이름(받을값):`으로 쓰고 다음 줄은 반드시 한 칸 들여쓰기(스페이스 4번 또는 Tab). `return`은 '이 답을 돌려줘'. 들여쓰기가 어긋나면 에러. (`def 남은돈(용돈, 지출): return 용돈 - sum(지출)` / `print(남은돈(50000, [12000, 8000]))` → `30000`)
6. **import로 도구 빌려 쓰기** — 남이 만든 도구상자(라이브러리)를 `import`로 불러옴. 예로 `datetime`은 '날짜·시간 도구'. 한 줄 `import datetime`만 쓰면 오늘 날짜를 바로 가져올 수 있음. AI 코드에 `import`로 시작하는 줄이 보이면 '도구 빌려오는 줄'. (`import datetime` / `print("오늘:", datetime.date.today())` → `오늘: 2026-06-22`)
7. **AI에게 코드 받아 직접 돌리고 고치기 (진짜 목표)** — ChatGPT(chatgpt.com) 또는 Claude(claude.ai)에 템플릿 프롬프트를 붙여넣고 받은 코드를 통째로 복사. Colab의 새 셀에 붙여넣고 Shift+Enter. 빨간 에러가 나면 그 빨간 글씨 전체를 복사해 AI에게 "이 에러 떴어, 고쳐줘"라고 다시 붙여넣으면 끝. (에러 마지막 줄(Error로 끝나는 줄)만 봐도 원인 힌트가 있음)

## 흔한 실수 → 교정

- ✗ 글자를 따옴표 없이 씀 (`print(안녕)`) → **글자(문자)는 반드시 따옴표로 감싼다:** `print("안녕")`. 숫자는 따옴표 없이 그대로.
- ✗ 함수 안 줄을 들여쓰기 안 해서 `IndentationError` → **`def` 다음 줄, `if` 다음 줄은 무조건 앞에 스페이스 4칸(또는 Tab).** 줄들의 시작 위치를 세로로 맞춘다.
- ✗ `=`와 `==`를 헷갈림 → **`=`는 '상자에 넣기'(저장), `==`는 '같은지 비교'.** 값을 담을 땐 항상 `=` 하나.
- ✗ AI 코드를 그냥 보기만 하고 안 돌려봄 → **반드시 Colab 셀에 붙여넣고 Shift+Enter로 직접 실행.** 에러가 나야 배운다 — 에러는 실패가 아니라 안내문.
