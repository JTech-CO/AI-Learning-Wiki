_AI를 제대로 쓰려면 꼭 아는 5개 단어(모델·프롬프트·토큰·컨텍스트·온도)를 이해하고, 같은 질문을 2배 좋은 답으로 바꿔본다._

:::note[학습 목표]
- 모델·프롬프트·토큰·컨텍스트·온도 5개 단어를 한 줄로 설명한다
- 막연한 프롬프트를 자세한 주문서로 바꿔 답 품질을 끌어올린다
- 컨텍스트(대화 기억)가 대화창 단위로만 유지됨을 확인한다
:::

## 핵심 개념

AI(ChatGPT 같은 챗봇)는 '엄청 똑똑한 자동완성 기계'다. 글을 주면 그 다음에 올 단어를 한 개씩 맞춰가며 답을 만든다.

- **모델**: AI의 '두뇌 종류'. 신입(저렴·빠름)부터 베테랑 박사(똑똑·느림)까지 골라 쓴다.
- **프롬프트**: 내가 AI에게 주는 '주문서'. '아무거나'보다 '안 매운 김치찌개 2인분'이 잘 나오듯, 자세할수록 답이 좋다.
- **토큰**: AI가 글을 세는 '낱개 단위'. 글자보다 조금 큰 조각(한글은 1글자가 1~2토큰). 한 번에 읽고 쓸 수 있는 토큰 수가 정해져 있다.
- **컨텍스트**: AI가 '지금 기억하는 대화 범위'. 책상 위 공간 같아서 너무 길어지면 앞 내용을 까먹는다.
- **온도(temperature)**: 다음 토큰 확률 분포를 조절하는 생성 파라미터다. 낮추면 선택의 무작위성이 줄지만 사실성이 보장되지는 않는다.

### 내 말이 AI 답으로 바뀌는 길

`📝 프롬프트(내 주문서)` → `✂️ 토큰 쪼개기(낱개 분해)` → `🧠 모델 두뇌(다음 단어 예측)` → `🎛 온도 조절(정확↔창의)` → `💬 답변 생성`

### 왜 이게 될까?

AI는 인터넷 속 수억 개 문장을 학습해 '다음에 올 단어'를 잘 맞히는 기계다. 그래서 주문서(프롬프트)만 자세히 써주면 이어질 좋은 답은 AI가 통계적으로 골라준다. 당신은 '무엇을 원하는지'만 정확히 말하면 된다.

## 👀 따라하기 예시 — 부산 2박3일 여행

**①** 막연하게 '여행 계획 짜줘' → 두루뭉술한 일반론
> 💡 프롬프트가 짧으면 '다음 단어'를 고를 단서가 없어 무난한 답으로 도망간다.

**②** '나는 30대 직장인. 2박3일 부산, 맛집 위주, 차 없이 지하철, 하루 3곳씩 표로' → 지하철역까지 표로 정리
> 💡 누가·무엇을·형식·분량을 다 적으니 '다음 단어'를 정확히 예측한다.

**③** 같은 창에서 '1일차는 여유롭게 2곳만' → 앞 표를 기억하고 1일차만 수정
> 💡 이게 컨텍스트 — 이 대화창 안의 내용을 계속 참고한다.

**④** New chat 후 '1일차 어디였지?' → "이전 대화 내용이 없어서 모르겠어요"
> 💡 새 채팅은 기억이 지워진 백지. 컨텍스트는 대화창 단위로만 유지된다 — 아하 포인트!

좋은 결과의 기준: (1) 바로 쓸 수 있는 표·목록 형식인가 (2) 내 조건(인원·이동·기간)이 반영됐나 (3) 같은 창에서 이어 물으면 앞 내용을 기억하나.

## 단계별 따라하기

1. **ChatGPT 무료 계정 만들기** — `chatgpt.com` → 'Sign up' → 'Continue with Google'. 무료·카드 불필요.
2. **채팅창 위치 확인하고 첫 질문** — 맨 아래 입력창에 쓰고 Enter/↑. 답이 한 글자씩 = 토큰을 하나씩 만드는 모습.
3. **나쁜 vs 좋은 프롬프트 비교** — '여행 계획 짜줘' vs '30대 직장인, 2박3일 부산, 맛집 위주, 지하철, 하루 3곳, 표로'.
4. **모델 바꿔보기** — 유료 플랜은 입력창(웹)·상단(앱)에서 모델 선택. 무료는 GPT-5.5 Instant 자동. 빠른 건 Instant, 논리·코드는 Thinking.
5. **컨텍스트 체험** — 같은 창은 기억, 'New chat'은 백지. 길어지면 앞 내용을 잊을 수 있으니 중요 정보는 다시 적는다.
6. **출력 성격을 지시문으로 조절** — 정확형 '사실만, 짧게, 추측 금지' / 창의형 '재밌게, 아이디어 10개, 엉뚱해도 좋아'.
7. **토큰 한계 이해** — 너무 긴 글은 토막 내서 주거나 '핵심만 5줄로'처럼 출력 길이를 정한다.

## 흔한 실수 → 교정

- ✗ '알아서 잘 해줘' 막연 → **주문서를 자세히.** 누가·무엇을·형식·길이를 한 줄씩.
- ✗ AI 답을 100% 사실로 믿음 → **환각 주의. 숫자·날짜·이름은 다른 곳에서 확인.**
- ✗ 긴 대화가 이상해지는데 같은 창을 계속 끔 → **컨텍스트가 꽉 찬 것. 'New chat'으로 새로.**
- ✗ 어려운 문제도 빠른 모델로만 → **논리·코드·긴 분석은 Thinking 계열로.**

## 실전 프롬프트

### 무엇이든 좋은 답 받는 만능 주문서

```text
역할: 너는 [분야] 전문가야. 상황: 나는 [내 상황·수준]. 원하는 것: [구체적 결과물]을 만들어줘. 조건: [형식(표·목록·줄 수)], [말투], [빼야 할 것]. 모르면 추측하지 말고 나에게 되물어봐.
```

> 확인된 작성 예시 없음

`프롬프트` `만능`

### 긴 글 요약 (토큰 절약형)

```text
아래 글을 ①핵심 3줄 ②중요한 숫자·날짜 ③내가 해야 할 일, 이렇게 세 부분으로만 요약해줘. 추측은 빼고 글에 있는 내용만 써줘. [여기에 긴 글 붙여넣기]
```

> 확인된 작성 예시 없음

`프롬프트` `요약`

### 근거가 필요한 사실 확인 요청

```text
[질문]에 대해 사실만 간단히 답해줘. 확실하지 않으면 '확실하지 않음'이라고 말해. 꾸미는 말 없이 핵심만.
```

> 확인된 작성 예시 없음

`프롬프트` `정확`

### 아이디어를 넓게 탐색하는 요청

```text
[주제]에 대한 신선한 아이디어 10개를 줘. 뻔한 건 빼고, 엉뚱하고 새로운 것 위주로. 각 아이디어는 한 줄로.
```

> 확인된 작성 예시 없음

`프롬프트` `창의`

:::
