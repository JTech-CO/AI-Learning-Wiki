_ChatGPT·Claude·Gemini·오픈모델의 강점·가격·용도를 비교해, 작업마다 알맞은 모델과 추론(thinking) 모드를 고르는 실무 판단을 익힌다._

:::note[학습 목표]
- 작업(글·코드·최신정보·이미지·계산)마다 맞는 모델을 1초에 고른다
- 무료에서 '깊게 생각하기(추론)'가 어디까지 되는지 안다
- 나만의 '작업→모델' 1줄 규칙표를 만든다
:::

## 핵심 개념

AI 모델은 **'직원'**이라고 생각하면 쉬워요. 회사에 직원이 여럿이고 각자 잘하는 일이 다르죠. ChatGPT·Claude·Gemini는 서로 다른 회사가 만든 '서로 다른 직원'이라 잘하는 일이 달라요. 그래서 **'제일 좋은 AI 하나'를 찾는 게 아니라 '이 일에 맞는 AI'를 고르는 게 핵심.**

또 요즘 AI엔 **'깊게 생각하기(추론)'** 기능이 있어요 — '천천히 꼼꼼히 풀어줘'처럼, 어려운 문제일수록 정확도가 오릅니다. 단 2026년 기준 무료에서 되는 방식이 셋 다 달라요:
- **ChatGPT(무료)**: 입력칸 '+'→'Thinking' 메뉴로 켤 수 있지만 5시간 롤링 윈도우 기준 소량 한도(GPT-5.4 mini Thinking).
- **Gemini(무료)**: 토글 없이 어려운 질문이면 더 똑똑한 모델을 '자동으로' 잠깐 빌려줌.
- **Claude(무료)**: '자동'으로만 더 생각. 수동 토글(Extended Thinking)은 유료 전용. → 무료 Claude는 버튼 찾지 말고 '단계별로 천천히 풀어줘'.

### 왜 이게 될까?

셋은 같은 'AI' 이름표지만 다른 회사가 다른 데이터로 훈련한 '다른 직원'이에요. 그래서 글 잘하는 직원, 최신 뉴스에 빠삭한 직원, 그림 잘 그리는 직원이 따로. 당신은 '이 일, 누구한테 맡길까'만 1초에 판단하면 됩니다.

## 👀 따라하기 예시 — 조카용 분수 곱셈 자료

**①** 작업을 쪼갠다: 작업1=비유 설명(글), 작업2=삽화(이미지)
> 💡 한 AI가 다 잘하는 게 아니라 일마다 맞는 직원이 다르니 먼저 쪼갠다.

**②** 글쓰기는 Claude에 → 다정한 피자 비유 설명
> 💡 Claude·ChatGPT는 설명·비유에 강함. Claude가 톤이 더 다정.

**③** 그림은 Gemini 앱에 → 무료 하루 약 20장(ChatGPT 무료는 하루 2~3장)
> 💡 이미지는 Gemini 앱 무료 한도가 훨씬 넉넉.

**④** 계산이 헷갈리면 '단계별로 천천히 풀어줘' 추가
> 💡 이 한마디가 무료 계정에서도 추론 모드를 끌어내는 열쇠. 어려운 문제에만.

좋은 결과의 기준: (1) 비유가 나이 수준에 맞나 (2) 그림이 내용과 어울리나 (3) 계산 과정이 단계별로 보이나.

## 작업별 모델 가이드

1. **글/번역/요약/아이디어** → Claude 또는 ChatGPT.
2. **코드(프로그램) 만들기** → Claude 1순위, ChatGPT 2순위.
3. **최신 뉴스·실시간 정보·유튜브 요약** → Gemini(구글 검색 내장).
4. **이미지 만들기** → Gemini 앱 무료 하루 약 20장 > ChatGPT 무료 2~3장.
5. **어려운 계산·다단계 계획** → 추론을 쓴다('단계별로 천천히 풀어줘').

## 단계별 따라하기

1. **무료 계정 3개 만들기** — chatgpt.com / claude.ai / gemini.google.com. 카드 없이 무료.
2. **작업을 5종류로 나누기** — 위 가이드로 어디에 속하는지.
3. **추론 모드 — 무료에서 어디까지** — ChatGPT '+→Thinking'(소량), Gemini·Claude 무료는 '단계별로 천천히 풀어줘'.
4. **같은 질문 3곳에 던져 비교** — 두세 번 해보면 다음엔 안 비교해도 안다.
5. **최신 정보는 Gemini(또는 검색 켜기)** — AI는 '지식 컷오프' 이후를 모른다. ChatGPT는 검색 아이콘, Claude도 무료 웹검색 지원.
6. **긴 문서/파일은 Claude** — 2026년 기준 Claude 현행 모델 컨텍스트 100만 토큰(책 약 40권). 클립으로 첨부 후 요약.
7. **나만의 1줄 규칙표 붙여두기** — 글=Claude / 코드=Claude / 최신=Gemini / 이미지=Gemini 앱 / 어려우면 '단계별로 천천히'.

## 흔한 실수 → 교정

- ✗ '제일 좋은 AI 하나'로 모든 일 → **일마다 잘하는 AI가 다르다. 작업별로 바꿔 쓴다.**
- ✗ 최신 뉴스·환율을 그냥 물어 그대로 믿음 → **지식 컷오프 이후는 모른다. Gemini나 검색 아이콘, 출처 확인.**
- ✗ 간단한 질문에도 추론 모드를 켜 무료 횟수 낭비 → **쉬운 질문엔 안 쓴다. 수학·긴 코드·복잡한 계획에만.**
- ✗ Claude 무료에서 Extended Thinking 토글을 찾아 헤맴 → **무료엔 수동 토글이 없다(유료 전용). '단계별로 천천히 풀어줘'.**
- ✗ 유료부터 결제 → **셋 다 무료로 충분히 써본 뒤 가장 자주 쓰는 한 곳만 유료로.**

## 도구

- 🛠 **Claude** (claude.ai) — 긴 글·코드·긴 문서 요약. 2026년 기준 컨텍스트 100만 토큰. 어려운 질문엔 자동 추론, 수동 Extended Thinking은 유료.
- 🛠 **ChatGPT** (chatgpt.com) — 범용. 무료 '+→Thinking'(GPT-5.4 mini Thinking, 소량)·웹검색. 이미지는 무료 하루 2~3장.
- 🛠 **Gemini** (gemini.google.com) — 최신 검색·유튜브/이미지 분석·구글 연동. 무료 이미지 하루 약 20장(2026-03 이후 축소, 변동 가능).

## 실전 프롬프트

### 모델 비교용 (세 곳에 똑같이 붙여넣기)

```text
[내가 하려는 일을 한 문장으로]. 초등학생도 이해할 만큼 쉽게, 예시 1개를 들어 설명해줘.
```

`모델선택` `비교`

### 글쓰기·다듬기 (Claude/ChatGPT)

```text
아래 글을 [더 정중하게 / 더 짧게 / 더 친근하게] 다듬어줘. 어색한 표현은 자연스럽게 고치고, 바꾼 이유도 한 줄로 알려줘. [여기에 내 글 붙여넣기]
```

`모델선택` `글쓰기`

### 최신 정보 검색 (Gemini/검색 켠 ChatGPT)

```text
[찾고 싶은 최신 정보]를 오늘 기준으로 알려줘. 출처 링크도 함께 보여줘.
```

`모델선택` `검색`

### 어려운 계산·계획 (무료에서도 정확도 올리기)

```text
다음 문제를 단계별로 천천히 풀어줘. 중간 계산도 보여주고, 마지막에 정답만 한 줄로 다시 정리해줘. (ChatGPT라면 +→Thinking을 먼저 켜면 더 좋다) [문제 내용]
```

`모델선택` `추론`
