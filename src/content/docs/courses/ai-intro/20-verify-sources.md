_'출처를 알려줘'라고 요청한 뒤 그 출처가 실제로 존재하고 내용이 맞는지 검색으로 직접 대조하는 습관을 실습한다._

:::note[학습 목표]
- 기관·연도·제목·URL까지 구체적으로 출처를 요구한다
- 제목을 큰따옴표로 정확히 검색하고 링크를 직접 연다
- 원문에서 숫자·주장을 Ctrl+F로 대조해 진짜/왜곡/가짜를 판정한다
:::

## 핵심 개념

AI 챗봇은 사실이 아닌 내용을 사실처럼 말하는 **환각**을 일으키며, 특히 논문 제목·저자·URL·통계 출처를 실제처럼 지어내는 데 능해요. 그래서 **"출처를 알려줘"라고 요청하는 것만으로는 부족**하고, 받은 출처를 직접 검색해 실제로 존재하는지, 그 내용이 AI가 말한 것과 일치하는지 대조해야 합니다. AI가 "Kim(2021)의 연구"를 인용하면 그 제목을 구글·스칼라에 그대로 붙여넣어 실제로 나오는지 확인하는 습관이죠. 이 한 가지가 가짜 정보를 인용해 창피를 당하거나 잘못된 결정을 내리는 것을 막아줘요.

### 왜 이게 될까?

AI는 진짜/가짜 문장을 구분하지 않고 '그럴듯하게 이어지는 말'을 만들어요. 진짜 논문 제목과 가짜 제목이 구조상 똑같이 자연스러우면 AI에겐 차이가 없죠. 하지만 검색엔진은 실제로 존재하는 문서만 찾아줘요. '제목 그대로 검색 + 링크 클릭 + Ctrl+F 대조' 세 가지면 AI가 못 하는 '진짜인지 확인'을 대신할 수 있어요.

## 👀 따라하기 예시 — '성인 73% 하루 3시간+ 스마트폰'

**①** 출처 구체적으로 되묻기: "조사기관·발표연도·보고서 제목·원문 링크를 표로" → AI가 기관·링크 제시
> 💡 '출처 있음'이 아니라 '제목·기관·링크'까지 받아야 검색·대조 가능.

**②** 제목을 큰따옴표째 그대로 검색 → 결과 0건(비슷한 실제 보고서는 다른 URL)
> 💡 단어만 검색하면 '비슷한 게 나오니 맞겠지' 착각. 따옴표+정확한 제목이 핵심.

**③** AI가 준 링크 직접 클릭 → 404 Not Found
> 💡 형식이 그럴듯해도 링크가 열리는지가 1차 판정 기준.

**④** 근거 대며 되묻기: "링크는 404, 검색에도 없어. 확인 안 되면 확실치 않다고 해" → "확인할 수 없습니다, 추정치였을 수 있습니다"
> 💡 근거를 대며 되물으면 AI가 잘못을 인정하고 신뢰도를 낮춘다.

좋은 결과의 기준: (1) 제목을 정확히 그대로 검색했나 (2) 링크를 직접 열어봤나 (3) 판정 근거를 한 문장 남겼나.

## 단계별 따라하기

1. **출처 없는 주장 하나 고르기** — 의견이 아니라 검증 가능한 사실 주장(숫자·연구·인용).
2. **구체적 출처 요구** — '기관명·발표연도·보고서 제목·링크'까지. 애매하면 '정확한 원문 제목과 URL'.
3. **출처 제목을 그대로 검색** — 큰따옴표로 감싸 구글에. 학술이면 Scholar에도.
4. **링크를 직접 열어 내용 대조** — 404·엉뚱하면 가짜. 열리면 숫자를 Ctrl+F로 원문 대조.
5. **판정하고 AI에 되묻기** — 진짜/왜곡/가짜 판정. 가짜·왜곡이면 근거 대며 정정 유도.
6. **나만의 검증 루틴 메모** — '제목 검색 → 링크 클릭 → Ctrl+F 대조' 3단계 체크.

## 흔한 실수 → 교정

- ✗ URL을 줬다는 것만으로 사실이라 믿음 → **반드시 직접 클릭.** 404·엉뚱하면 가짜.
- ✗ 제목을 대충 단어만 검색해 '비슷한 게 나오니 맞겠지' → **큰따옴표로 정확히 그대로 검색.** 숫자까지 Ctrl+F 대조.
- ✗ 출처가 존재하기만 하면 내용도 맞다고 가정 → **원문을 열어 그 숫자·주장이 정말 있는지 확인.** 실존 자료 왜곡 인용도 많다.

## 도구

- 🛠 **구글** (google.com) — 출처 제목 정확 검색·링크 존재 확인.
- 🛠 **구글 스칼라** (scholar.google.com) — 논문·학술자료 실존 대조.
- 🛠 **Ctrl+F 페이지 내 찾기** — 원문에서 숫자·문구 대조.
- 🛠 **ChatGPT/Claude** (chat.openai.com, claude.ai) — 출처 재요구·정정 유도.

## 실전 프롬프트

### 출처 표로 요구하기

```text
방금 답변에서 [검증하려는 주장]에 대한 출처를 알려줘. 조사기관/저자, 발표연도, 정확한 보고서·논문 제목, 원문 URL을 표로 정리해줘. 추측하지 말고, 확실하지 않은 항목은 '불확실'이라고 표시해줘.
```

`출처` `검증`

### 환각 여부 자가점검 요청

```text
방금 네가 준 출처가 실제로 존재하는 자료인지, 아니면 형식만 그럴듯하게 만들어진 것일 수 있는지 솔직하게 알려줘. 원문 제목과 URL을 다시 정확히 확인해서 알려주고, 확신이 없으면 '검증 필요'라고 말해줘.
```

`출처` `자가점검`

### 검색 결과로 대조 판정

```text
내가 [보고서 제목]을 구글에 검색했더니 [검색 결과: 안 나옴 / 다른 숫자 / 일치함]. 이 결과를 보면 네가 준 출처와 숫자가 맞는 거야, 아니면 정정이 필요한 거야? 근거와 함께 판정해줘.
```

`출처` `판정`

### 출처 없으면 답변 재작성

```text
[주제]에 대해 답하되, 실제로 확인 가능한 공개 출처가 있는 내용만 말해줘. 출처를 댈 수 없는 주장은 아예 빼거나 '출처 불명'이라고 표시해줘.
```

`출처` `재작성`
