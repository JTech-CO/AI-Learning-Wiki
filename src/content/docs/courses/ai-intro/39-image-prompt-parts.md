_이미지 생성 프롬프트를 주제·스타일·구도·색감·분위기로 나눠 작성하면 원하는 그림에 가까워짐을 여러 시도로 익힌다._

:::note[학습 목표]
- 이미지 프롬프트를 5요소(주제·스타일·구도·색감·분위기)로 조립한다
- 한국어 5요소를 영어 프롬프트로 변환한다
- 결과가 아쉬우면 요소 하나만 바꿔 재시도한다
:::

## 핵심 개념

이미지 생성 AI는 문장을 **'지시'가 아니라 '재료 목록'**으로 읽어요. 그래서 "고양이"처럼 재료가 하나면 AI가 나머지를 마음대로 채워 매번 다른 결과가 나오죠. 프롬프트를 **주제(무엇)·스타일(그림체)·구도(카메라 위치·배치)·색감(색 팔레트)·분위기(감정·조명)** 다섯 요소로 나눠 각각 채우면 AI가 상상할 여지가 줄어 원하는 그림에 가까워져요. "고양이 사진"이 아니라 "수채화풍, 창가에 앉은 주황 고양이, 로우앵글, 따뜻한 파스텔, 나른한 오후 햇살"처럼 주문하는 것. 한 번에 완벽할 필요 없이, 한 요소씩 바꿔 3번쯤 시도하면 감이 잡혀요.

### 왜 이게 될까?

이미지 생성기는 문장을 '빈칸을 채울 재료 목록'으로 읽어요. 재료가 하나('고양이')뿐이면 나머지 빈칸을 AI가 그때그때 채우니 매번 달라지죠. 5칸을 미리 채우면 상상할 여지가 줄어 머릿속 그림에 훨씬 가까워집니다.

## 👀 따라하기 예시 — 창가에 앉은 고양이

**①** 5요소 뼈대: 주제=창가 주황 고양이 / 스타일=수채화 / 구도=로우앵글 클로즈업 / 색감=따뜻한 파스텔 / 분위기=나른한 오후 햇살
> 💡 빈칸을 하나라도 남기면 AI 마음대로 채워지니 5칸을 다 채운다.

**②** 쉼표로 이어 한 문장: '수채화 스타일, 창가에 앉은 주황 고양이, 로우앵글 클로즈업, 따뜻한 파스텔, 나른한 오후 햇살'
> 💡 순서는 주제→스타일→구도→색감→분위기가 무난.

**③** AI에 영어로 다듬게: 'watercolor painting, orange cat sitting by a window, low angle close-up, warm pastel palette, drowsy afternoon sunlight'
> 💡 이미지 모델은 영어에 더 강해 번역 한 스텝만 거쳐도 적중률이 크게 오른다.

**④** 결과에서 딱 하나만 교체: 'low angle close-up' → 'top-down flat lay', 나머지 4요소 유지
> 💡 한꺼번에 여러 곳 바꾸면 뭐가 효과였는지 모른다. 하나씩.

좋은 프롬프트의 기준: (1) 5칸이 빠짐없이 채워졌나 (2) 영어로 옮겼나 (3) 요소 하나만 바꿔 재시도할 수 있는 형태인가.

## 단계별 따라하기

1. **5요소 뼈대 노트에 그리기** — 주제/스타일/구도/색감/분위기 5줄을 한국어로.
2. **5요소를 한 문장으로 합치기** — 쉼표로 이어서.
3. **AI에게 영어 프롬프트로 다듬게** — 이미지 모델은 영어에 강함.
4. **이미지 생성기에 넣고 첫 결과** — 첫 결과는 초안.
5. **딱 한 요소만 바꿔 다시** — 마음에 안 드는 부분 하나의 단어만 교체.
6. **성공 프롬프트 5요소 표로 저장** — 다음엔 주제 칸만 바꿔 재사용.

## 흔한 실수 → 교정

- ✗ '멋진 고양이 그려줘' 주제 하나만 → **'멋진' 같은 추상어는 해석 불가. 스타일·구도·색감·분위기 4칸을 최소 단어 하나씩이라도.**
- ✗ 결과가 별로면 프롬프트를 통째로 새로 씀 → **마음에 안 드는 요소 딱 하나만 단어 교체, 나머지 고정.**
- ✗ 한국어 프롬프트를 그대로 넣고 포기 → **ChatGPT/Claude로 영어 변환 후 넣으면 적중률이 크게 오른다.**

## 도구

- 🛠 **Bing Image Creator** (bing.com/images/create) — 무료 이미지 생성, DALL·E 기반.
- 🛠 **ChatGPT** (chat.openai.com) — 한국어 5요소를 영어 프롬프트로 변환.
- 🛠 **Claude** (claude.ai) — 5요소 채우기 아이디어·스타일 단어 사전.
- 🛠 **Google 메모/메모장** — 성공 프롬프트를 5요소 표로 저장.

## 실전 프롬프트

### 5요소 → 영어 이미지 프롬프트 변환 (가장 먼저)

```text
아래 한국어 5요소를 이미지 생성 AI용 영어 프롬프트 한 줄로 바꿔줘. 미사여구는 빼고 시각적 단어 위주로, 각 요소가 다 들어가게 해줘.
주제: [주황 고양이가 창가에 앉음] 스타일: [수채화] 구도: [로우앵글 클로즈업] 색감: [따뜻한 파스텔] 분위기: [나른한 오후 햇살]
```

> 확인된 작성 예시 없음

`이미지` `프롬프트`

### 빈 5요소 채우기 아이디어 요청

```text
내가 만들고 싶은 그림은 [한 문장 설명]이야. 이걸 주제/스타일/구도/색감/분위기 5요소로 나눠서, 각 요소에 어울리는 구체적 단어를 3개씩 후보로 제안해줘. 표로 보여줘.
```

> 확인된 작성 예시 없음

`이미지` `아이디어`

### 한 요소만 바꿀 후보 뽑기

```text
지금 이 이미지 프롬프트를 쓰고 있어: [현재 영어 프롬프트]. 결과에서 [불만인 점, 예: 구도가 밋밋함]이 마음에 안 들어. 이 요소 하나만 바꿀 수 있는 대체 단어 5개를 제안해줘. 나머지는 그대로 둘 거야.
```

> 확인된 작성 예시 없음

`이미지` `수정`

### 스타일 단어 사전 만들기

```text
이미지 생성에서 자주 쓰는 '스타일' 키워드를 초보가 알아둘 만한 것 10개만, 한국어 뜻과 영어 표기를 함께 표로 정리해줘. 예: 수채화(watercolor).
```

> 확인된 작성 예시 없음

`이미지` `스타일`

## 채점 기준

| 기준 | 배점 |
| --- | --- |
| 5칸(주제·스타일·구도·색감·분위기)을 빠짐없이 채웠나 | 5 |
| 추상어('멋진','예쁜') 대신 구체 단어를 썼나 | 5 |
| 결과가 아쉬울 때 바꿀 요소 하나를 미리 정해뒀나 | 5 |
