_PDF·회의록·기사·계약서 같은 긴 문서 1개를 AI에 올리고, 핵심 요지·결정사항·할 일을 3~5줄로 요약받는다._

:::note[학습 목표]
- 막연한 '요약해줘' 대신 뽑을 항목(결정·할 일·안건)을 구체적으로 지정한다
- PDF·워드 파일을 AI에 올려(드래그/붙여넣기) 요약을 받는다
- 숫자·날짜·이름을 원문 쪽수와 대조해 사실을 검증한다(환각 주의)
:::

## 핵심 개념

AI 요약은 '아주 빠르게 다 읽어주는 비서'에게 일을 시키는 것입니다. 책을 통째로 친구에게 주고 '이 책에서 결론만 말해줘'라고 부탁하는 것과 똑같아요. 차이는 친구는 1시간 걸리지만 AI는 몇 초면 끝낸다는 점입니다. 여기서 '요약(summary)'은 긴 내용을 짧게 줄여 핵심만 남긴 글입니다.

중요한 건 두 가지예요.

1. 문서를 AI에게 **'보여주기'** (파일을 끌어다 놓거나 붙여넣기)
2. 무엇을 뽑아줄지 **'구체적으로 부탁하기'** (예: 결정사항·할 일·날짜)

막연히 '요약해줘'보다 '결정사항을 불릿으로 정리해줘'가 훨씬 좋은 답을 줍니다. 이 레슨은 무료 가입만으로 끝까지 따라 할 수 있게 **Claude(클로드)**를 기준으로 안내합니다(2026년 기준 무료 플랜이 PDF·워드 업로드·요약을 정식 지원).

### 문서 요약 흐름

`📄 긴 문서(PDF·회의록)` → `📎 AI에 올리기(드래그/붙여넣기)` → `💬 원하는 형식 지시(결정·할일·안건)` → `✅ 5줄 요약(복사해 사용)`

### 왜 이게 될까?

AI는 이미 회의록·보고서·기사 같은 글을 수억 건 읽으며 "중요한 문장 찾는 법"을 익혔어요. 그래서 10페이지를 처음부터 끝까지 읽지 않아도, 어디에 결정사항이 있고 어디가 잡담인지 순식간에 골라냅니다. 당신은 "무엇을 뽑을지"만 콕 집어 말하면, 읽고 추리는 일은 AI가 대신 해줍니다.

## 👀 따라하기 예시 — 10페이지 회의록 PDF 요약

**① claude.ai 입력창에 회의록.pdf를 끌어다 놓는다** → 입력창 위에 '📄 6월 팀회의록.pdf' 카드 표시(업로드 완료)
> 💡 파일을 직접 "보여주면" AI가 10페이지 전체를 몇 초 만에 다 읽습니다. 타이핑할 필요가 없어요.

**② "결정사항 / 담당자별 할 일 / 다음 안건을 불릿으로, 5줄 이내로" 구체적으로 부탁**
```
- 결정: 신규 랜딩페이지 디자인 A안 채택
- 할 일: 김OO – 시안 최종본 7/10까지, 박OO – 개발 착수 7/8부터
- 다음 안건: 7월 3주차 사용자 테스트 결과 공유
```
> 💡 "요약해줘"라고만 하면 뭘 남길지 헷갈려 합니다. 항목을 콕 집으면 필요한 것만 정확히 뽑아줘요.

**③ "할 일을 담당자 / 내용 / 마감일 3칸 표로"라고 이어서 부탁**
```
| 담당자 | 내용 | 마감일 |
|---|---|---|
| 김OO | 시안 최종본 | 7/10 |
| 박OO | 개발 착수 | 7/8 |
```
> 💡 파일을 다시 올릴 필요 없이, 같은 대화 안에서 이어 부탁하면 AI가 문서를 계속 기억한 채 답 형태만 바꿔줍니다.

**④ "두 번째 결정사항은 몇 쪽 어느 문장이 근거야?"라고 사실 확인** → "3쪽 두 번째 문단 '최종적으로 A안을 채택하기로 합의함'이 근거입니다."
> 💡 AI가 가끔 없는 내용을 그럴듯하게 지어낼 수 있어요(환각). 숫자·날짜·이름은 원문 쪽수로 1분만 대조하면 안심하고 공유할 수 있습니다.

좋은 결과의 기준: (1) 결정·할 일·안건이 항목별로 분리됐나 (2) 숫자·날짜·이름이 원문과 맞나 (3) 남에게 그대로 보내도 이해되는 길이인가.

## 단계별 따라하기

1. **요약할 문서 1개 준비** — PDF·워드(.docx)·긴 텍스트. 없으면 긴 뉴스 기사 본문을 복사(Ctrl+C)해 두어도 됨. 설치할 프로그램 없음.
2. **Claude에 무료 가입·로그인** — `claude.ai` → 'Sign up' → 'Continue with Google'(30초). 화면이 영어여도 입력은 한국어로 하면 한국어로 답함.
3. **문서 파일을 입력창에 끌어다 놓기** — 드래그 앤 드롭, 또는 더하기(＋)/클립(📎) → 'Upload from computer'. 텍스트만 있으면 붙여넣기(Ctrl+V)도 가능. (무료 플랜: 파일당 30MB, 대화당 최대 20개)
4. **무엇을 뽑을지 구체적으로 부탁** — 아래 템플릿을 붙여넣고 Enter.
5. **답을 읽고 모자라면 한 번 더 다듬기** — '더 짧게 핵심 3줄만', '할 일을 마감일 표로' 등 이어서 부탁(다시 올릴 필요 없음).
6. **결과 복사 → 메모·메신저에 붙이기** — 답변 아래 복사 아이콘 → 카카오톡·노션·메모장에 붙여넣기.
7. **(선택) 사실 확인** — '이 결정사항이 문서 몇 페이지에 있는지 알려줘'로 원문과 1분 대조.

## 흔한 실수 → 교정

- ✗ '요약해줘' 한 마디만 → **뽑을 항목을 콕 집는다**('결정사항·할 일·안건을 불릿으로').
- ✗ 한 번에 문서 5~10개를 우르르 → **1개씩.** 여러 개면 AI가 섞고, 무료 플랜 대화 횟수도 빨리 닳음.
- ✗ AI 답을 100% 믿고 바로 공유 → **숫자·날짜·이름은 '몇 페이지에 있어?'로 원문 1분 대조 후 공유.**
- ✗ 사진으로 찍은 문서라 글자가 안 읽힘 → **원본 PDF·텍스트로 올린다.** 100쪽 넘는 PDF는 필요한 부분만 잘라 올림.

## 도구

- 🛠 **Claude** (claude.ai) — 무료 플랜에서도 PDF·워드를 끌어다 놓아 요약, 가장 쉬움. 파일당 30MB·대화당 20개.
- 🛠 **ChatGPT** (chatgpt.com) — ＋/클립으로 PDF 올려 같은 방식. 무료 플랜은 하루 파일 업로드 약 3개 제한.
- 🛠 **NotebookLM** (notebooklm.google.com) — 구글 계정 무료, 문서 여러 개를 모아 근거 출처(몇 번 문서·어느 부분)까지 표시해 요약.

## 실전 프롬프트

### 회의록 → 결정·할일·안건 정리

```text
이 회의록에서 다음 3가지를 각각 불릿으로 정리해줘. (1) 확정된 결정사항 (2) 담당자별 할 일(담당자 이름 포함) (3) 다음 회의 안건. 전체 5줄 이내로 짧게, 한국어로.
```

`요약` `회의록`

### 긴 기사·보고서 → 핵심 요지

```text
이 문서를 처음 보는 사람도 1분 안에 이해하게 핵심만 3줄로 요약해줘. 그 아래에 '꼭 기억할 포인트' 3개를 불릿으로 덧붙여줘. 어려운 용어는 괄호로 쉽게 풀이해줘.
```

`요약` `기사`

### 계약서·약관 → 주의할 점 뽑기

```text
이 [계약서/약관]에서 내가 손해 볼 수 있거나 주의해야 할 조항만 골라서, 각 항목을 '쉬운 설명 + 왜 주의해야 하는지' 형식으로 알려줘. 5개 이내로.
```

`요약` `계약서` `법률`

### 할 일을 표로 정리

```text
이 문서에 나온 할 일들을 '담당자 / 할 일 내용 / 마감일' 3칸짜리 표로 정리해줘. 마감일이 안 적혀 있으면 '미정'으로 표시해줘.
```

`요약` `표` `할일`
