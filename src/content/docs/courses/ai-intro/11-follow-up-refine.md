_첫 답이 아쉬울 때 '더 짧게', '예를 들어줘', '좀 더 격식 있게'처럼 이어서 요청해 결과를 점점 원하는 방향으로 좁히는 대화법을 익힌다._

:::note[학습 목표]
- 첫 답은 '초안'으로 받아들이고 후속 요청으로 다듬는다
- 한 번에 한 가지씩만 바꿔 원인을 명확히 한다
- '방금 그거에서 ~만 바꿔줘'로 이어가고, 나빠지면 되돌린다
:::

## 핵심 개념

AI와의 대화는 한 번에 완벽한 답을 뽑는 '자판기'가 아니라, **조각가가 돌을 조금씩 깎아내는 과정**에 가까워요. 첫 답은 언제나 초안일 뿐이고, '더 짧게', '예를 들어줘', '좀 더 격식 있게' 같은 짧은 후속 요청으로 방향을 좁혀갑니다. 핵심은 처음부터 완벽한 질문을 짜내려 애쓰지 말고, **일단 받은 뒤 '무엇이 아쉬운지'를 한 가지씩 말로 지적하는 것.** AI는 앞선 대화를 기억하므로 매번 처음부터 설명할 필요 없이 '방금 그거에서 ~만 바꿔줘'로 이어가면 돼요. 이 반복이 초보와 능숙한 사용자를 가르는 실질적 차이예요.

### 왜 이게 될까?

AI는 대화 내내 앞서 나눈 말을 다 기억해요. 그래서 처음 답이 마음에 안 들어도 '방금 그거에서 ~만 바꿔줘' 한마디면 됩니다. 아쉬운 점 한 가지만 짚으면 나머지 다듬는 일은 AI가 대신 해줘요.

## 👀 따라하기 예시 — 친구 생일 축하 메시지

**①** "친구 생일 축하 메시지 하나 써줘" → 길고 형식적인 5문장
> 💡 완벽한 질문을 고민 말고, 일단 초안부터 받아야 뭘 고칠지 보인다.

**②** 아쉬운 점 딱 하나(길이)만 정함
> 💡 한 번에 여러 개 고치면 뭐가 효과였는지 안 보인다.

**③** "방금 그거 두 문장으로 줄이고 반말로 바꿔줘" → 짧고 친근하게
> 💡 처음부터 다시 안 써도 앞 대화를 기억해 이어진다.

**④** "우리가 같이 여행 갔던 얘기를 한 줄 넣어줘" → 나만의 메시지로
> 💡 개인 디테일 한 줄이 진짜 나만의 메시지를 만든다 — 아하 포인트!

좋은 결과의 기준: (1) 처음보다 확실히 나아졌나 (2) 한 가지씩만 고쳐 원인이 명확한가 (3) 그대로 써도 될 만큼 자연스러운가.

## 단계별 따라하기

1. **일단 첫 답을 받아본다** — 완벽한 질문 고민 말고 한 문장으로 던져 초안 확보.
2. **무엇이 아쉬운지 딱 한 가지만** — '길다/딱딱하다/밋밋하다' 중 가장 걸리는 것 하나.
3. **짧은 후속 요청으로 좁힌다** — '더 짧게', '반말로', '이모지 넣어서'처럼 짧게.
4. **구체 요청으로 한 번 더** — '예를 들어줘', '더 구체적으로', '~한 느낌 빼줘'. 매번 한 가지씩.
5. **마음에 들 때까지 반복하고 멈춘다** — 나빠졌으면 '아까 버전이 나았어, 그걸로 돌아가서 ~만'.
6. **잘 통한 후속 표현을 메모** — '두 문장으로', '반말로', '예를 하나 넣어줘'를 모아 재사용.

## 흔한 실수 → 교정

- ✗ 첫 답이 아쉬우면 대화를 지우고 처음부터 새 질문 → **지우지 말고 '방금 그거에서 ~만 바꿔줘'로 이어가라.** AI는 앞 대화를 기억한다.
- ✗ '더 짧게, 격식 있게, 예시도, 반말로' 한 번에 몰아 요청 → **한 번에 한 가지씩.** 어떤 요청이 뭘 바꿨는지 보인다.
- ✗ 막연히 '별로야', '다시 해줘' → **무엇이 어떻게 아쉬운지 콕 집어라.** '너무 길어→절반으로', '딱딱해→친구한테 말하듯이'.

## 실전 프롬프트

### 길이·말투 다듬기 (가장 자주 씀)

```text
방금 답변에서 [내용은 그대로 두고 / 핵심만 남기고] 길이를 [두 문장]으로 줄이고, 말투는 [친근한 반말 / 정중한 존댓말]로 바꿔줘.
```

> 확인된 작성 예시 없음

`다듬기` `길이` `말투`

### 예시로 구체화

```text
방금 설명이 조금 추상적이야. 실제 [일상 / 직장 / 학교] 상황을 가정한 구체적인 예시를 하나 넣어서 다시 설명해줘.
```

> 확인된 작성 예시 없음

`다듬기` `예시`

### 격식·대상 조정

```text
이 글을 [상사에게 보내는 / 처음 만난 사람에게 하는] 상황에 맞게 좀 더 [격식 있고 정중하게 / 편하고 캐주얼하게] 고쳐줘. 내용은 유지해줘.
```

> 확인된 작성 예시 없음

`다듬기` `격식`

### 이전 버전으로 되돌리기

```text
방금 바꾼 게 오히려 별로야. [두 번 전 / 처음] 버전으로 돌아가서, 거기서 [이 부분]만 바꿔줘.
```

> 확인된 작성 예시 없음

`다듬기` `되돌리기`
