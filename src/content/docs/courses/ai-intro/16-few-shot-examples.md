_원하는 입력·출력 예시를 1~3개 함께 주면(few-shot) AI가 형식과 스타일을 그대로 따라 함을 실습으로 익힌다._

:::note[학습 목표]
- few-shot(예시 1~3개)으로 형식·말투를 복제한다
- 예시 입력/출력/새 입력을 라벨로 명확히 구분한다
- 잘 작동한 few-shot 묶음을 재사용 템플릿으로 저장한다
:::

## 핵심 개념

**few-shot(퓨샷)**은 "몇 개의 예시를 보여준다"는 뜻이에요. 규칙을 말로 길게 설명하는 대신 **"입력→출력" 짝을 1~3개 보여주면** AI가 그 패턴을 스스로 읽어내 똑같은 형식·스타일로 결과를 만들어요. 신입에게 "지난달 보고서 이렇게 썼으니 이대로 써"라고 샘플을 건네는 것과 같죠. 형식이 까다롭거나(표·이모지·말투) 말로 설명하기 애매한 감성이 있을 때 특히 강력해요. **예시가 곧 규칙이 되므로, 좋은 예시 하나가 긴 지시문 열 줄을 이깁니다.**

### 왜 이게 될까?

AI는 '패턴을 읽어내는 눈'을 가졌어요. 잘 만든 예시 하나만 보여주면 그 안의 형식·말투·길이를 스스로 찾아내 따라 합니다. 완벽한 예시 1개만 만들면 나머지 수십 건은 AI가 그 패턴대로 처리해줘요.

## 👀 따라하기 예시 — 고객센터 답장 템플릿

**① 원하는 결과 모습 먼저** "3문장, 정중한 존댓말, 마지막에 이모지 하나"로 못박기
> 💡 형식을 먼저 못박아야 예시를 쓸 때 흔들리지 않는다.

**② 모범 예시 1개를 완벽하게** (입력: 배송이 늦어요 / 출력: "고객님, 배송 지연으로… 🙇")
> 💡 예시가 곧 규칙이라 이 하나를 대충 쓰면 뒤가 전부 대충 나온다.

**③ 예시+새 입력을 라벨로 구분** → 새 입력 "색상이 사진과 달라요"에 같은 3문장·존댓말·이모지로 답
> 💡 라벨로 나누니 AI가 따라할 부분과 대답할 부분을 안 헷갈린다.

**④ 예시를 2개로 늘려 정확도** → '사이즈가 안 맞아요'에도 흔들림 없이
> 💡 서로 다른 상황 예시 2개면 '진짜 패턴'과 '특수 사정'을 구분해 더 안정적.

좋은 결과의 기준: (1) 모든 답장이 형식을 그대로 지키나 (2) 상황에 맞는 내용만 바뀌나 (3) 예시 문장이 그대로 복사되지 않나.

## 단계별 따라하기

1. **원하는 결과 딱 하나 정하기** — 형식·길이·말투를 구체적으로.
2. **모범 예시 1개를 손으로 완벽하게** — 대충 X. 이 하나가 견본.
3. **예시 붙이고 새 입력 주기** — '예시:' + 견본 + '같은 형식으로 답해줘' + 새 입력.
4. **예시를 2~3개로 늘려 정확도** — 서로 다른 상황, 형식은 통일.
5. **예시 자체를 AI에게 더 만들게** — 견본 1개 주고 '이 형식으로 다른 상황 예시 2개 만들어줘'.
6. **완성된 few-shot을 저장해 재사용** — 새 입력만 바꿔 붙이면 같은 품질.

## 흔한 실수 → 교정

- ✗ 예시를 대충/미완성으로 줌 → **예시 = 규칙. 하나만큼은 시간 들여 완벽하게.**
- ✗ 예시들끼리 형식이 제각각(표/줄글) → **모든 예시의 형식·길이·말투를 통일.** 내용(상황)만 다르게.
- ✗ 예시와 새 입력 경계가 불분명해 예시까지 되풀이 → **'예시 출력:', '새 입력:' 라벨로 구분** + '설명 말고 결과만'.

## 실전 프롬프트

### 예시 하나로 형식 따라 하게 (가장 많이 씀)

```text
아래는 내가 원하는 결과의 예시야. 이 형식과 말투를 그대로 따라서 새 입력에 답해줘.
[예시 입력]: [여기에 상황 하나]
[예시 출력]: [내가 원하는 완벽한 결과물]
[새 입력]: [실제로 처리할 내용]
```

`few-shot` `예시`

### 예시 2~3개로 정확도 올리기

```text
아래 예시들의 형식·길이·말투를 정확히 똑같이 따라 해줘. 설명은 하지 말고 결과만 줘.
예시1 입력: [상황A] 예시1 출력: [원하는 결과A]
예시2 입력: [상황B] 예시2 출력: [원하는 결과B]
새 입력: [실제 내용]
```

`few-shot` `정확도`

### AI에게 예시 자체를 더 만들게 하기

```text
아래는 내가 만든 견본 예시 1개야. 이 형식(길이·말투·구조)을 그대로 유지하면서, 서로 다른 상황의 예시 [2]개를 네가 추가로 만들어줘.
견본 입력: [상황] 견본 출력: [결과]
```

`few-shot` `생성`

### 표·목록 같은 까다로운 형식 복제

```text
아래 표 예시와 완전히 같은 열 구성과 줄 형식으로, 새 데이터를 정리해줘. 열 순서·이모지·줄바꿈까지 똑같이.
[예시 표]: [여기에 완성된 표 한 줄 붙여넣기]
[정리할 새 데이터]: [원자료]
```

`few-shot` `형식`
