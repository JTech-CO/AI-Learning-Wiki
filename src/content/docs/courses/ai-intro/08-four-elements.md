_프롬프트를 지시·맥락·예시·출력형식 네 부분으로 나눠, 같은 요청을 4요소를 갖춰 다시 쓰면 답이 확 좋아짐을 전후 비교로 확인한다._

:::note[학습 목표]
- 프롬프트를 지시(무엇을)·맥락(왜/누구를 위해)·예시·출력형식으로 나눈다
- 빈약한 요청을 4요소로 채워 바로 쓸 수 있는 결과를 받는다
- '좋게'라는 애매한 형용사를 예시와 형식 지정으로 대체한다
:::

## 핵심 개념

좋은 프롬프트는 마법 주문이 아니라 **잘 쓴 업무 지시서**예요. 신입에게 일을 시킬 때 "무엇을(지시), 왜·누구를 위해(맥락), 이런 느낌으로(예시), 이 형태로 줘(출력형식)"를 알려주면 결과가 좋아지듯, AI도 똑같아요. AI는 눈치가 없어서 당신 머릿속 배경을 모르기 때문에, **빠진 정보만큼 스스로 지어내(추측해)** 엉뚱한 답을 냅니다. 이 네 조각을 채워 넣는 순간 답 품질이 확 오르고 재요청 시간이 사라져요.

### 왜 이게 될까?

AI는 당신 머릿속 배경을 볼 수 없어 요청에 빠진 정보만큼 스스로 추측해 채웁니다. '지시·맥락·예시·출력형식' 4조각을 미리 채워주면 추측할 여지가 사라지고, 신입에게 명확한 지시서를 준 것처럼 바로 쓸 수 있는 결과가 나와요.

## 👀 따라하기 예시 — 흑임자 라떼 인스타 캡션

**① 지시만** "카페 인스타 글 써줘" → "☕오늘도 힘내세요! …#카페추천 #맛집" (아무 카페에나 붙는 뻔한 말)
> 💡 배경이 없으니 AI가 '추측'으로 빈칸을 채웠어요.

**② 맥락 추가** "연남동 1인 카페 사장, 손님은 20~30대 직장인, 주말 흑임자 라떼 신메뉴, 톤 담백하게" → 과녁이 좁혀짐
> 💡 맥락 한 줄이 답 절반을 결정해요.

**③ 예시 추가** "좋은 톤 → '오늘도 수고한 나에게, 고소한 한 잔.' / 싫은 것 → '★대박신상★ 강추!!!'" → 톤이 정확히 맞춰짐
> 💡 '담백하게'는 사람마다 기준이 달라요. 실물 예시를 주면 흉내 낼 대상이 생겨요.

**④ 출력형식** "캡션 3개, 각 40자 이내, 끝에 해시태그 3개, 번호로 구분" → 세 개 다 길이·구조 동일
> 💡 형식을 숫자로 못박으니 고민 없이 골라 올릴 수 있어요.

좋은 결과의 기준: (1) 누구를 위한 글인지 한눈에 보임 (2) 원하는 톤이 실제로 느껴짐 (3) 추가 편집 없이 바로 쓸 수 있는 길이·형식.

## 단계별 따라하기

1. **나쁜 프롬프트 하나 준비** — 평소 쓰던 두루뭉술한 요청을 넣어 '전(before)' 샘플로 남긴다.
2. **지시(무엇을)를 한 문장으로** — '써줘' 대신 '~를 작성해줘' + 개수·분량.
3. **맥락(왜·누구를 위해) 붙이기** — (1)나는 누구 (2)독자는 누구 (3)목적. 여기서 답 품질 절반이 갈린다.
4. **예시로 원하는 느낌 보여주기** — 좋아하는 문장 1개, 피하고 싶은 나쁜 예 1개.
5. **출력형식 지정** — 글자 수, 해시태그 개수, 표/목록, 번호 매기기.
6. **4요소 합쳐 다시 요청하고 전/후 비교** — 무엇이 좋아졌는지 한 줄로 기록.

## 흔한 실수 → 교정

- ✗ 지시만 던지고 맥락을 안 줌 → **내가 누구·독자 누구·목적을 한두 문장이라도 붙인다. 맥락 한 줄이 답 절반.**
- ✗ '좋게 써줘', '자연스럽게'처럼 추상적 형용사 → **말 대신 예시.** 좋은 예/나쁜 예를 실물로.
- ✗ 출력형식 미지정 → 매번 제멋대로 → **분량·개수·형식을 숫자로 못박는다.** 형식은 재작업을 없애는 가장 싼 요소.

## 실전 프롬프트

### 4요소 만능 프롬프트

```text
[지시] 아래 요청을 수행해줘: [무엇을 만들지 결과물과 개수]
[맥락] 나는 [나/우리 소개]이고, 이 결과물의 독자는 [대상]이야. 목적은 [왜 필요한지]. 톤은 [원하는 분위기].
[예시] 이런 느낌이 좋아: [좋아하는 예 1개]. 이런 건 피해줘: [싫은 예 1개].
[출력형식] [분량·개수·형식(목록/표/해시태그 등)]로 줘.
```

`프롬프트` `만능` `4요소`

### 내 프롬프트 4요소 점검받기

```text
다음은 내가 쓴 프롬프트야: "[내 프롬프트 붙여넣기]". 이걸 지시·맥락·예시·출력형식 4요소로 나눠서 표로 보여주고, 어떤 요소가 비어 있는지 짚은 다음, 4요소를 모두 갖춘 개선본으로 다시 써줘.
```

`프롬프트` `점검`

### 맥락이 부족할 때 AI가 되묻게 하기

```text
[내 요청]을 해줘. 단, 좋은 답을 위해 맥락(내가 누구인지, 대상은 누구인지, 목적)이 부족하다면 바로 답하지 말고 나에게 먼저 3가지 질문을 해줘. 내가 답하면 그때 결과를 만들어줘.
```

`프롬프트` `맥락`

### 출력형식만 빠르게 조이기

```text
방금 준 답변을 내용은 그대로 두고 형식만 바꿔줘: [원하는 형식 예 - 표로 / 3개 항목 번호로 / 각 100자 이내 / 해시태그 3개 추가].
```

`프롬프트` `형식`
