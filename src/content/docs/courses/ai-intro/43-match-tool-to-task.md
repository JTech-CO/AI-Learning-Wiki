_글쓰기·요약·이미지·코딩·검색 등 목적별로 어떤 종류의 AI 도구가 적합한지 매칭하고, 하나의 작업 흐름에 여러 도구를 조합하는 감각을 익힌다._

:::note[학습 목표]
- 작업을 '동사'로 쪼개 동사마다 맞는 도구 종류를 매칭한다
- 조사→초안→이미지→검토처럼 여러 도구를 릴레이로 잇는다
- 재사용할 '동사→도구' 흐름표 한 장을 만든다
:::

## 핵심 개념

AI 도구는 만능이 하나 있는 게 아니라 **잘하는 일이 서로 다른 전문가 여러 명**에 가까워요. 글쓰기·요약·아이디어는 대화형 챗봇(ChatGPT·Claude), 최신 정보 조사는 검색형(Perplexity), 이미지는 생성형, 코드는 코딩 특화 도구가 강하죠. 진짜 실력은 한 도구를 깊게 파는 게 아니라 **'이 작업은 무엇을 요구하는가'를 먼저 묻고 거기에 맞는 도구를 고르는 매칭 감각.** 실전 작업은 대부분 한 도구로 안 끝나니, **조사 → 초안 → 이미지 → 검토처럼 여러 도구를 릴레이로 잇는 흐름**을 짜는 게 핵심이에요.

### 왜 이게 될까?

검색형은 최신 문서를 긁어와 출처를 붙이는 훈련을, 챗봇은 문장을 이어 쓰는 훈련을, 이미지 생성기는 그림 훈련을 따로 받았어요. **동사(조사하다·쓰다·그리다)를 먼저 정하고** 그 동사가 제일 잘하는 도구로 갈아끼우면, 나는 순서만 지휘하고 결과물의 질은 도구가 끌어올려줍니다.

## 👀 따라하기 예시 — 카페 창업 블로그 글 1편

**①** 동사 분해: 조사·요약·쓰다·그리다·검토하다 5단계 흐름표
> 💡 동사가 다르면 필요한 도구도 달라서 먼저 쪼갠다.

**②** '조사하다'는 검색형(Perplexity): "2026 동네 카페 창업 트렌드 3가지, 출처 링크 포함" → 출처와 함께
> 💡 최신·사실은 검색형이 출처를 붙여 챗봇 환각을 미리 막는다.

**③** '쓰다'는 챗봇(Claude), 단 조사 재료를 붙여넣고 "이 재료로 초보 사장 톤 800자, 소제목 3개"
> 💡 맨입으로 '써줘'가 아니라 재료를 쥐여주면 사실에 근거한 글이 나온다.

**④** '그리다'는 이미지 도구(Bing Image Creator): "아늑한 카페 외관, 따뜻한 조명, 일러스트, 가로형"
> 💡 글쓰기 챗봇에 그림을 억지로 시키지 않고 그림 전문 도구로 넘기는 게 릴레이의 핵심.

좋은 결과의 기준: (1) 조사 단계에 출처 링크가 실제로 붙나 (2) 초안이 조사 재료에 근거해 사실과 안 어긋나나 (3) 재사용할 흐름표가 한 장으로 정리됐나.

## 단계별 따라하기

1. **작업을 '동사'로 쪼개기** — 조사하다·요약하다·쓰다·그리다·검토하다. 동사 하나 = 도구 후보 하나.
2. **동사마다 도구 종류 매칭** — 최신·출처=검색형, 자유 글·아이디어=챗봇, 그림=이미지 생성, 코드=코딩 특화. 브랜드보다 '종류'를 먼저.
3. **조사 도구로 재료 모으기** — 출처 링크 붙었는지 확인하고 메모에.
4. **챗봇으로 초안 쓰기** — 모은 재료를 붙여넣고 '이 재료로'. 환각이 크게 준다.
5. **이미지 도구로 대표 그림** — 글쓰기 챗봇에 그림을 시키지 말고 이미지 전용 도구로.
6. **챗봇으로 검토하고 흐름표 완성** — 오탈자·사실오류 점검 후 '동사→도구' 표로 저장.

## 흔한 실수 → 교정

- ✗ 익숙한 도구 하나(ChatGPT)로 조사·이미지·코드까지 전부 → 어정쩡 → **동사로 쪼갠 뒤 종류별 도구로 갈아끼운다.**
- ✗ 조사 없이 챗봇에 바로 '써줘' → 환각 → **검색형으로 출처 재료를 모아 '이 재료만 써서' 초안.**
- ✗ 매번 도구 조합을 처음부터 고민 → **성공한 '동사→도구' 흐름표를 저장해 재사용.**

## 도구

- 🛠 **ChatGPT** (chat.openai.com) — 글쓰기·요약·아이디어 만능 챗봇.
- 🛠 **Claude** (claude.ai) — 긴 글 초안·검토·정리에 강함.
- 🛠 **Perplexity** (perplexity.ai) — 출처 링크가 붙는 검색형 조사 AI.
- 🛠 **Bing Image Creator** (bing.com/create) — 무료 이미지 생성.

## 실전 프롬프트

### 1) 조사 (검색형 AI에 붙여넣기)

```text
나는 [주제]에 대한 글을 쓰려고 해. 2026년 기준 최신 핵심 정보 3~5가지를 알려줘. 각 항목마다 반드시 출처 링크를 함께 달아주고, 확실하지 않은 건 '불확실'이라고 표시해줘.
```

> 확인된 작성 예시 없음

`도구조합` `조사`

### 2) 초안 쓰기 (챗봇에 재료와 함께)

```text
아래는 내가 모은 조사 재료야: [조사 결과 붙여넣기] 이 재료만 사용해서 [독자: 예 초보 사장]를 위한 [분량: 예 800자] 글 초안을 써줘. 톤은 [예: 친근하고 쉬운], 소제목 3개로 구성하고, 재료에 없는 내용은 지어내지 마.
```

> 확인된 작성 예시 없음

`도구조합` `초안`

### 3) 대표 이미지 만들기 (이미지 생성 도구에)

```text
[장면 묘사: 예 아늑한 동네 카페 외관], [분위기: 따뜻한 조명], [스타일: 일러스트], [비율: 가로형 썸네일]. 글자는 넣지 말고 깔끔하게.
```

> 확인된 작성 예시 없음

`도구조합` `이미지`

### 4) 검토·다듬기 (챗봇에)

```text
아래 글의 오탈자, 어색한 문장, 사실이 틀릴 수 있는 부분을 표로 정리해줘. '원문 / 문제 / 수정안' 3칸으로 보여주고, 확인이 필요한 사실 주장에는 ⚠️ 표시를 해줘. [글 붙여넣기]
```

> 확인된 작성 예시 없음

`도구조합` `검토`
