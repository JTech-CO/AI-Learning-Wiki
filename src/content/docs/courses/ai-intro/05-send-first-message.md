_입력창에 첫 질문을 타이핑해 전송하고, 새 대화·전송·재생성 버튼의 위치와 역할을 익힌다._

:::note[학습 목표]
- 입력창·전송(▲)·새 대화(+)·재생성(↻) 위치를 구분한다
- 완벽하지 않은 짧은 질문도 편하게 보내 답을 받는다
- 같은 대화 안에서 후속 질문으로 이어간다
:::

## 핵심 개념

AI 채팅 화면은 아주 단순해요. 맨 아래 긴 **'입력창'**에 하고 싶은 말을 적고, 오른쪽 끝 **'전송(종이비행기 ▲)'**을 누르면 AI가 답을 씁니다. 위쪽의 **'새 대화(+ / New chat)'**는 지금까지 대화를 접고 완전히 새 주제로 시작하는 버튼이고, 답 아래 **'재생성(↻)'**은 같은 질문에 답을 다시 써달라는 버튼이에요. 문자 메시지 보내는 것과 똑같아서 어렵게 생각할 필요가 없어요.

### 왜 이게 될까?

AI는 사람들이 주고받은 수억 개의 대화를 학습해 다음에 올 말을 예측해요. 그래서 완벽한 문장을 안 써도, 짧게 '김치볶음밥 레시피'라고만 던져도 자연스러운 답으로 채워줍니다. 당신은 궁금한 걸 던지기만 하면 돼요.

## 👀 따라하기 예시 — 저녁 메뉴 물어보기

**①** 입력창에 "김치볶음밥 만드는 법을 3줄로 알려줘" (전송 전, 커서만 깜빡)
> 💡 존댓말도 완성형 문장도 필요 없어요. 떠오르는 그대로.

**②** 전송(▲) → "1. 밥과 김치를 잘게 썹니다. 2. …"
> 💡 글자를 한 줄씩 써 내려가는 '타이핑되는 느낌'이 정상.

**③** 마음에 안 들어 재생성(↻) → 같은 질문을 다른 표현으로 다시
> 💡 첫 답이 별로면 그냥 다시 눌러보면 돼요 — 아하 포인트!

**④** 새 대화 안 열고 이어서 "초등학생 기준으로 다시 알려줘"
> 💡 같은 대화 안이면 방금 얘기를 기억해 이어받아요. 새 대화(+)는 완전히 다른 주제일 때만.

좋은 결과의 기준: (1) 원한 정보가 답에 담겼나 (2) 재생성으로 다시 받아봤나 (3) 후속 질문으로 자연스럽게 이어졌나.

## 단계별 따라하기

1. **화면 세 곳 눈으로 찾기** — ①맨 아래 입력창 ②전송(▲) ③새 대화(+). 아직 누르지 말고 위치만.
2. **입력창에 첫 질문 타이핑** — 맞춤법·존댓말 신경 X. 아직 Enter X.
3. **전송하고 답 기다리기** — ▲/Enter → 글자가 한 줄씩 나오는 걸 지켜본다.
4. **재생성(↻)으로 다른 답 받기** — 마음에 들 때까지 눌러도 됨.
5. **새 대화(+)로 주제 바꾸기** — 화면을 비우고 다른 주제로. 이전 대화는 왼쪽 목록에 저장됨.
6. **이어서 되묻기** — 새 대화 안 열고 '더 자세히', '쉽게'를 이어 쓰면 앞 내용을 기억한 채 답한다.

## 흔한 실수 → 교정

- ✗ 완벽한 문장으로 써야 답을 준다고 오래 망설임 → **반말·오타·짧은 말도 다 알아듣는다. '김치볶음밥 레시피'만 던져도 답이 온다.**
- ✗ 질문 바꿀 때마다 새 대화(+)를 눌러 앞 내용이 끊김 → **이어지는 질문은 같은 대화에. 완전히 다른 주제일 때만 새 대화.**
- ✗ 답이 별로면 창을 닫고 포기 → **재생성(↻)을 누르면 다른 답. '더 짧게', '예시 들어'로 되물어도 됨.**

## 실전 프롬프트

### 첫 질문 (가장 쉬운 시작)

```text
[궁금한 것 한 가지]를 초등학생도 이해할 만큼 쉽게 3줄로 알려줘.
```

> 확인된 작성 예시 없음

`시작` `대화`

### 더 자세히 되묻기

```text
방금 답변에서 [궁금한 부분]을 예시를 들어 더 자세히 설명해줘.
```

> 확인된 작성 예시 없음

`대화` `후속질문`

### 쉽게 다시 써달라기

```text
방금 답변이 조금 어려웠어. 전문 용어 없이 더 쉬운 말로 다시 써줘.
```

> 확인된 작성 예시 없음

`대화` `다듬기`

### 새 주제로 바꾸기

```text
이제 다른 이야기를 하고 싶어. [새 주제]에 대해 초보자용으로 알려줘.
```

> 확인된 작성 예시 없음

`대화` `주제전환`

## 직접 만들기 (미션)

:::tip
이제 당신 차례! '내일 서울 날씨에 맞는 옷차림을 알려줘' 같은 편한 질문을 타이핑해 전송하세요. 답이 오면 재생성(↻)을 눌러 다른 답을 받아보고, 이어서 '초등학생도 이해하게 다시 알려줘'처럼 같은 대화 안에서 후속 질문을 보내보세요.
:::
