_실제 필요(행사 안내문+홍보 이미지, 또는 자료 요약 보고서)를 정해 프롬프트 설계·초안 생성·사실 검증·수정 반복을 거쳐 바로 쓸 수 있는 완성 결과물 하나를 만든다._

:::note[학습 목표]
- '초안 → 검증 → 수정' 짧은 반복으로 완성물을 만든다
- 날짜·장소·가격·이름·링크를 원본과 대조해 검증한다
- 바로 배포·제출 가능한 결과물 1개를 손에 남긴다
:::

## 핵심 개념

캡스톤은 배운 걸 **'진짜 쓸 물건' 하나로 합치는 마무리 과제**예요. 핵심은 완벽한 한 방이 아니라 **'초안 → 검증 → 수정'을 짧게 반복**하는 것. AI는 빠른 초안과 대안을 만드는 데 강하지만, **날짜·장소·가격·이름 같은 사실은 반드시 사람이 확인**해야 해요. '무엇을 만들지 한 문장으로 정하기'에서 시작해 실제로 배포·제출 가능한 완성물로 끝냅니다. **결과물이 손에 남는 것이 유일한 성공 기준.**

### 왜 이게 될까?

AI는 수많은 안내문·홍보 이미지 패턴을 학습해 사실만 정확히 던져주면 초안을 순식간에 뽑아요. 당신이 할 일은 **'사실 모으기'와 '틀린 부분 잡아내기'**뿐. 완성 속도를 가르는 건 AI 실력이 아니라 당신이 재료(날짜·장소·가격)를 얼마나 정확히 챙기고 검증하느냐예요.

## 👀 따라하기 예시 — 독서모임 안내문 + 홍보 이미지

**①** 사실부터 메모: 날짜 3/22(토) 14~16시 / 장소 합정 북카페 '페이지' 2층 / 참가비 5,000원 / 신청 링크 / 문의 번호
> 💡 이 목록이 없으면 AI가 빈칸을 지어낸다. 재료 먼저가 순서 1번인 이유.

**②** 사실 못박아 프롬프트: '아래 정보만 사용, 없는 값은 지어내지 마. 제목 3안 + 본문 초안 + 이미지 문구'
> 💡 '지어내지 말라' 한 줄이 팩트체크 부담을 절반으로.

**③** 초안을 원본과 한 줄씩 대조: '3월 22일(일)' 발견 → 실제 22일은 토요일 → '(토)'로 수정
> 💡 AI는 요일 계산을 종종 틀린다. 날짜·주소·링크는 100% 사람이 검증.

**④** 번호로 묶어 한 번에 수정: '1)요일 (토) 2)본문 5줄 이내 3)신청 링크 강조 4)부드럽게'
> 💡 한 번에 하나씩 고치면 왔다 갔다. 번호로 모아 던지면 1~2회에 끝.

좋은 결과의 기준: (1) 숫자·고유명사·링크가 원본과 100% 일치 (2) 5줄 이내로 짧고 신청 링크가 눈에 띔 (3) 이미지 글씨가 안 깨지고 정확히 보임.

## 단계별 따라하기

1. **만들 결과물 한 문장으로** — 누가·무엇·언제까지 + 형식·분량·마감. 애매하면 못 만든다.
2. **재료(사실) 먼저 모으기** — 날짜·시간·장소·주소·참가비·신청 링크·문의·준비물. 빠진 값은 AI가 지어낸다.
3. **프롬프트 설계해 초안 생성** — 사실을 붙이고 대상·톤·분량·형식 지정 + '없는 값은 지어내지 말라'.
4. **사실 검증(팩트체크)** — 모든 숫자·고유명사·링크를 메모와 대조. 요일 확인, 지도앱으로 주소, 링크 클릭 테스트.
5. **수정 지시로 다듬기** — 고칠 점을 번호로 한 번에. 최대 2회 반복하고 멈춘다.
6. **이미지 생성 & 최종 배포** — 글자 오타·잘림 확인. 깨지면 Canva에서 텍스트를 직접 얹는다. 채널 업로드 or 파일 저장.

## 흔한 실수 → 교정

- ✗ 처음부터 완벽한 결과물을 한 번에 → **'초안→검증→수정' 짧은 반복.** 첫 출력은 재료일 뿐.
- ✗ AI가 채운 날짜·주소·가격·링크를 그대로 믿고 배포 → **모든 숫자·고유명사·링크를 원본과 한 줄씩 대조, 링크는 클릭 테스트.**
- ✗ '예쁘게 만들어줘' 막연 → **대상·톤·분량·형식·색감을 숫자·예시로 구체화. 고칠 땐 번호로 한 번에.**

## 도구

- 🛠 **ChatGPT** (chatgpt.com) — 초안 작성·수정 반복·요약 보고서.
- 🛠 **Claude** (claude.ai) — 긴 자료 요약·사실 검증 대조.
- 🛠 **Canva** (canva.com) — 이미지에 정확한 텍스트 얹기·최종 편집.
- 🛠 **Google 지도** (maps.google.com) — 장소·주소 실재 여부 검증.

## 실전 프롬프트

### 1) 안내문·보고서 초안 생성 (가장 먼저)

```text
너는 실무 카피라이터야. 아래 '확정 정보'만 사용해서 [행사 안내문]을 작성해줘. 없는 정보는 절대 지어내지 말고 [빈칸]으로 남겨줘.
[대상 독자]: [예: 20~30대 독서모임 회원]
[톤]: [예: 친근한 존댓말] [분량]: [예: A4 반 페이지, 본문 5줄 이내]
[형식]: 제목 3안 + 본문 + 이미지에 넣을 짧은 문구 1줄
확정 정보: - 행사명:[ ] - 날짜/시간:[ ] - 장소/주소:[ ] - 참가비:[ ] - 신청 방법/링크:[ ] - 문의:[ ] - 준비물:[ ]
```

> 확인된 작성 예시 없음

`캡스톤` `초안`

### 2) 수정 반복 지시

```text
방금 초안에서 아래 항목만 고쳐서 전체 다시 써줘. 나머지는 그대로 유지해. 1) [예: 날짜 요일을 (토)로 수정] 2) [예: 본문을 5줄 이내로] 3) [예: 존댓말로 톤 통일] 4) [예: 마지막 줄에 신청 링크 강조]
```

> 확인된 작성 예시 없음

`캡스톤` `수정`

### 3) 홍보 이미지 프롬프트

```text
[정사각형 1:1] SNS 홍보 이미지를 만들어줘. 주제: [행사명] 분위기: [예: 따뜻하고 차분한, 책과 커피] 색감: [예: 베이지+짙은 녹색] 이미지 안 글자: [핵심 문구 1줄, 예: '3월 독서모임 · 3/22(토) 오후 2시'] 주의: 글자는 정확히 이 문장만 오타 없이. 여백을 두어 나중에 텍스트를 얹을 수 있게.
```

> 확인된 작성 예시 없음

`캡스톤` `이미지`

### 4) 자료 요약 보고서용 (대안 과제)

```text
아래 붙여넣은 자료를 [1페이지 요약 보고서]로 정리해줘. 구성: 1)핵심 요약 3줄 2)주요 내용 불릿 5개 3)결론/제안 2줄. 규칙: 자료에 없는 수치·주장은 넣지 말고, 불확실하면 '자료에 없음'이라 표기해줘. [여기에 자료 붙여넣기]
```

> 확인된 작성 예시 없음

`캡스톤` `보고서`
