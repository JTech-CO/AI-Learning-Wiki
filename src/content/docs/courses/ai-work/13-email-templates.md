_자주 보내는 안내·요청·거절 메일을 변수 자리만 남긴 재사용 템플릿으로 만들어, 매번 처음부터 쓰던 10분을 몇 초로 줄인다._

:::note[학습 목표]
- 자주 보내는 이메일 3종을 '고정부'와 '변수부'로 나눠 재사용 템플릿으로 만든다
- AI에게 원본 메일을 던져 대괄호 변수형 템플릿과 톤을 뽑고 우리 말투로 다듬는다
- Gmail 템플릿 기능에 저장해 다음부터 몇 초 만에 변수만 채워 보낸다
:::

## 핵심 개념

이메일 템플릿화의 핵심은 **'매번 바뀌는 부분'과 '항상 똑같은 부분'을 분리**하는 거예요. 이름·날짜·금액처럼 매번 바뀌는 곳만 `[이름]` `[날짜]` 같은 변수 자리(플레이스홀더)로 남기고, 나머지 문장은 한 번만 잘 써서 고정해요. 카페 알바생이 '아메리카노 나왔습니다'를 매번 새로 고민하지 않듯, 잘 만든 템플릿은 뇌를 거의 안 쓰고도 정중하고 일관된 메일을 뽑아요. Gmail의 '템플릿' 기능이나 텍스트 확장 도구를 붙이면 단축키 몇 글자로 전체 본문이 튀어나와요.

### 왜 이게 될까?

AI는 수억 통 이메일 패턴을 학습해 "안녕하세요 ~님"으로 시작해 "감사합니다"로 끝나는 정중한 문장 구조를 알아요. **"누구에게, 무슨 용건으로"만 알려주면** 문장을 다듬고 이어붙이는 지루한 작업은 AI가 해요. 당신은 뼈대(변수)만 정하고 살(문장)은 AI에게 맡기는 셈이에요.

## 👀 따라하기 예시 — "미팅 자료 요청" 템플릿

**① AI에게 원본 메일과 목적을 그대로 던지기** "다음은 내가 자주 보내는 자료 요청 메일이야. 이름·회사·자료명·마감일이 바뀌는 걸 감안해서 재사용 템플릿으로 만들어줘. [원문 붙여넣기]"
> 💡 원본을 그대로 주면 AI가 우리 말투를 흉내내기 쉬워요. 처음부터 다시 쓰라면 어색한 번역투가 나와요.

**② AI가 변수 자리를 자동으로 뽑아 초안** "안녕하세요 [수신자명]님, [프로젝트명] 관련하여 [자료명] 자료를 [마감일]까지 공유해주시면 감사하겠습니다…"
> 💡 아하 포인트: AI는 이름·날짜·자료명처럼 '바뀔 확률이 높은 명사'를 스스로 골라 변수화해요. 사람이 하나하나 찾을 필요 없어요.

**③ 내가 실제 말투로 다듬기** "번거로우시겠지만"을 우리 팀이 안 쓰는 표현이라 "편하실 때"로 교체.
> 💡 AI는 뼈대를 만들 뿐, 우리 회사만의 말투는 사람이 결정해야 진짜 내 것이 돼요.

**④ Gmail 템플릿으로 저장해 즉시 재사용** [설정]→[고급]→템플릿 켜기 → 새 메일에 붙여넣고 [⋮]→[템플릿]→[초안을 템플릿으로 저장] → "자료요청_v1" 등록.
> 💡 한 번 저장하면 다음부터 클릭 3번, 변수 채우기 10초예요.

좋은 결과의 기준: (1) 대괄호 변수가 실제로 바뀔 부분에만 정확히 붙어있다 (2) 우리 회사 말투와 어긋나지 않는다 (3) 다음에 3초 안에 채워 보낼 만큼 간단하다.

## 단계별 따라하기

1. **최근 보낸 메일함에서 반복 메일 3종 찾기** — [보낸편지함] 최근 2~4주치를 훑어 내용이 거의 같은 메일 3종류를 고른다. '안내형(공지·일정)', '요청형(자료·확인 부탁)', '거절형(정중한 사양)' 성격별 하나씩이면 커버 범위가 넓다.
2. **한 메일에서 고정부와 변수부를 색칠하듯 나누기** — 매번 바뀌는 단어(이름·회사·날짜·금액·링크)를 대괄호 변수로. 변수 이름은 `[고객명]`처럼 뜻이 바로 보이게, 문장 구조는 손대지 않는다.
3. **AI로 나머지 2종을 같은 틀로 뽑고 톤 다듬기** — 첫 템플릿 프롬프트로 요청형·거절형 초안을 받는다. 우리 회사가 안 쓰는 표현·과한 존댓말을 실제 말투로 교체. 거절형 '유감스럽게도 부득이하게'→'이번에는 어렵겠습니다'.
4. **Gmail 템플릿 기능에 3종 저장** — 오른쪽 위 [설정]→[모든 설정 보기]→[고급] 탭에서 '템플릿'을 [사용]으로 켠다. 새 메일에 본문 붙여넣고 [⋮ 더보기]→[템플릿]→[초안을 템플릿으로 저장]. 이름: '온보딩안내_v1','자료요청_v1','정중거절_v1'.
5. **실전 발송으로 변수 빠짐 테스트** — 본인 이메일로 3종 발송. `[ ]` 대괄호가 남아있으면 안 채운 것 → 자주 빠뜨리는 변수는 템플릿 맨 위에 '※ 채울 것: [고객명][날짜]' 체크줄을 둔다.
6. **팀·본인용 템플릿 대장 관리** — 구글 문서·노션에 '이메일 템플릿 대장' 페이지를 만들어 3종 전문·변수 목록을 붙인다. 새 상황마다 AI에게 '이 대장 톤에 맞춰 [상황]용 템플릿 추가해줘'로 확장.

## 흔한 실수 → 교정

- ✗ 변수를 `[ ]`로 남기지 않고 특정 이름·날짜를 그대로 박아둠 → 재사용 시 '김민수'가 그대로 나가 사고. **바뀔 수 있는 모든 고유명사·숫자·링크는 무조건 대괄호 변수로.** '이 단어가 다음 메일에서도 똑같을까?'를 물어 아니면 변수화.
- ✗ 템플릿을 너무 많이(10종 이상) 만들어 오히려 고르느라 시간 낭비 → **안내·요청·거절 3종으로 시작.** 같은 템플릿을 3번 이상 반복해 실제로 필요할 때만 추가.
- ✗ 발송 전 변수를 다 채웠는지 확인 안 해 `[금액]`이 대괄호째 나감 → **본문에서 `[` 를 Ctrl/Cmd+F로 검색해 대괄호가 하나도 안 남았는지 확인.** '※ 채울 변수' 체크줄 습관화.

## 도구

- 🛠 **Gmail 템플릿** (mail.google.com) — 설정>고급에서 켜고 본문 저장·삽입.
- 🛠 **ChatGPT** (chat.openai.com) — 실제 메일을 변수형 템플릿으로 변환.
- 🛠 **Text Blaze** (blaze.today) — 단축키로 이메일 본문 자동 확장.
- 🛠 **노션** (notion.so) — 팀 공용 템플릿 대장.

## 실전 프롬프트

### 반복 메일 3종 한 번에 템플릿화 (가장 먼저)

```text
너는 한국 비즈니스 이메일 카피라이터야. 아래 내 실제 메일을 재사용 템플릿으로 바꿔줘. 규칙: (1)매번 바뀌는 부분은 [고객명][날짜]처럼 뜻이 보이는 대괄호 변수로 (2)문장 톤은 정중하되 과하지 않게 (3)제목 줄도 템플릿으로 (4)맨 위에 '※ 채울 변수' 목록. [실제 보낸 메일 붙여넣기] 그리고 같은 톤으로 '요청형(자료 부탁)'과 '거절형(정중한 사양)' 템플릿도 각각 추가로.
```

> 확인된 작성 예시 없음

`이메일` `템플릿` `변수`

### 정중한 거절 메일 템플릿

```text
정중하게 제안을 거절하는 한국어 이메일 템플릿을. 상대가 기분 상하지 않게 (1)제안에 감사 (2)이번엔 어렵다는 명확한 결론 (3)여지 한 줄. 변수는 [상대이름][제안내용][거절사유], 3~5문장으로 짧게.
```

> 확인된 작성 예시 없음

`이메일` `거절` `템플릿`

### 자료·확인 요청 메일 템플릿

```text
상대에게 자료·확인을 요청하는 한국어 이메일 템플릿을. (1)무엇을 (2)언제까지 (3)왜 필요한지 순서. 부담 안 주는 정중한 톤, 변수는 [상대이름][요청항목][기한][사유]. 마지막에 '회신 부탁드립니다' 한 줄.
```

> 확인된 작성 예시 없음

`이메일` `요청` `템플릿`

### 기존 템플릿 톤 통일

```text
아래 이메일 템플릿 3종의 인사말·맺음말·존댓말 수준을 하나로 통일해줘. 우리 팀은 [격식있는/친근한] 톤, 이모지는 [쓰지 않음/가볍게 허용]. 변수 자리([ ])는 그대로 두고 문장만. [템플릿 3종 붙여넣기]
```

> 확인된 작성 예시 없음

`이메일` `톤` `통일`

## 채점 기준

| 기준 | 배점 |
