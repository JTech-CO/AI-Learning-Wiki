_매번 손으로 하던 복붙을 코드 한 줄 없이 로봇에게 넘긴다. '구글 폼에 새 응답이 오면 → 구글 시트에 한 줄 추가'되는 트리거→액션 1단계 자동화를 노코드 툴로 직접 만들고 실제로 테스트한다._

:::note[학습 목표]
- 반복 수작업을 '무엇이 오면(트리거) → 무엇을 한다(액션)' 한 문장으로 쪼갠다
- 구글 폼 새 응답 → 구글 시트 행 추가 1단계 자동화를 Zapier로 직접 만든다
- 실제 폼 제출 1건으로 자동 적재를 테스트하고 Zap을 ON으로 켠다
:::

## 핵심 개념

노코드 자동화의 심장은 **트리거(Trigger)**와 **액션(Action)** 두 단어예요. 트리거는 '어떤 일이 벌어지면'(예: 새 폼 응답 도착), 액션은 '이걸 해라'(예: 시트에 행 추가). Zapier나 Make 같은 툴은 서로 다른 앱 사이에 **'보이지 않는 배달부'**를 두고, 트리거가 울리면 데이터를 집어서 액션 앱에 꽂아줘요. 우리가 매일 하는 복붙·알림 확인·옮겨적기의 90%는 사실 이 1단계 배달로 대체할 수 있어요.

### 왜 이게 될까?

자동화 툴(Zapier)은 앱과 앱 사이를 24시간 지키고 서 있는 배달부예요. **"트리거"라는 신호**(폼 응답 도착)를 감지하면 정해둔 **"액션"**(시트에 행 추가)을 그대로 실행합니다. 딱 한 번 "무엇이 오면 → 무엇을 한다"만 정해두면, 그다음부터 복붙은 로봇이 대신해요.

## 👀 따라하기 예시 — "무료 특강 신청" 폼 응답을 매번 시트에 손으로 옮겨 적는 상황

**① 트리거 앱 지정** — Zapier에서 Create → Zaps, 트리거 앱을 Google Forms로: Trigger 앱 Google Forms / Event New Form Response, 계정 연결 완료.
> 💡 트리거는 "어떤 일이 벌어지면"을 정의 — 여기서 자동화의 시작점이 정해져요.

**② 감지할 폼 특정** — "무료 특강 신청" 폼을 지정: 폼 목록에서 선택 → Zapier가 폼의 질문 필드(이름, 연락처)를 자동으로 읽어옴.
> 💡 폼을 특정해야 Zapier가 어떤 필드가 오는지 미리 파악해요(그래서 폼에 가짜 응답이 미리 있어야 함!).

**③ 액션 앱 + 열 매핑** — 액션 앱으로 Google Sheets → Create Spreadsheet Row 선택 후 열 매핑: 이름 열 ← [폼 이름 답변], 연락처 열 ← [폼 연락처 답변]로 드래그 연결.
> 💡 액션은 "이걸 해라" — 트리거가 가져온 데이터를 어느 칸에 꽂을지 짝지어주는 단계예요.

**④ 테스트 → Publish(ON)** — Test step으로 확인 후 진짜 폼 제출 → Publish(ON): 시트 맨 아래에 "홍길동, 010-1234-5678" 행이 몇 초 만에 자동 등장, Zap 상태 = 파란 On.
> 💡 테스트만 하고 Publish를 안 누르면 아무 일도 안 일어나요 — 반드시 ON 확인이 '아하 포인트'.

좋은 결과의 기준: (1) 실제 폼 제출 후 시트에 새 행이 자동으로 생김 (2) Zap 상태가 On (3) 이름·연락처가 정확한 열에 매핑됨.

## 단계별 따라하기

1. **자동화할 반복 작업 한 문장으로 정의** — '무엇이 오면(트리거) → 무엇을 한다(액션)' 형식으로 딱 한 문장. 앱 2개(어디서 오고 → 어디로 가고)를 명확히. (예: '구글 폼(수강 신청서)에 새 응답이 오면 → 구글 시트(신청자 명단)에 이름·연락처 행을 추가')
2. **준비물 만들기: 폼과 시트** — forms.google.com에서 새 폼을 만들고 질문 2개(이름, 연락처). 폼 상단 '응답' 탭 → 초록 시트 아이콘을 눌러 연결된 스프레드시트를 자동 생성.
3. **Zapier 가입하고 새 Zap 만들기** — zapier.com에 구글 계정으로 무료 가입. 왼쪽 위 'Create' → 'Zaps'. 트리거 칸에 'Google Forms', 이벤트는 'New Form Response'를 고르고 내 구글 계정을 연결(Connect).
4. **액션 붙이기: 시트에 행 추가** — 트리거 아래 액션 칸에 'Google Sheets' → 'Create Spreadsheet Row'. 스프레드시트=아까 응답 시트, 워크시트 선택 후, 각 열(이름·연락처)에 폼 응답 필드를 드래그해 매핑.
5. **테스트하고 진짜 폼 제출로 검증** — 'Test step'을 눌러 샘플 데이터가 시트에 들어가는지 확인. 그다음 실제로 내 폼을 열어 가짜 응답 1건을 제출하고, 시트에 자동으로 새 행이 생기는지 눈으로. (폼에 '홍길동 / 010-1234-5678' 제출 → 몇 초~2분 내 시트 맨 아래에 자동 등장)
6. **Zap 켜고 이름 붙여 저장** — 오른쪽 위 'Publish'(또는 토글 ON)를 눌러 활성화. Zap 이름을 알아보기 쉽게. 앞으로 폼 응답은 자동으로 쌓임. (Zap 이름='[신청] 폼→시트 자동적재' / 상태: ON / 이제 손 복붙 0회)

## 흔한 실수 → 교정

- ✗ Zap을 테스트만 하고 'Publish'(ON)를 안 눌러서, 실제 폼 응답이 와도 아무 일도 안 일어남 → **만들기 마지막에 반드시 오른쪽 위 Publish/토글을 ON으로.** Zap 목록에서 상태가 파란 'On'인지 눈으로 확인.
- ✗ 액션 앱에서 스프레드시트는 골랐는데 '워크시트(시트 탭)'를 안 골라 매핑 칸이 안 뜸 → **Spreadsheet를 고른 뒤 바로 아래 Worksheet 드롭다운에서 실제 탭**(보통 '설문지 응답 시트1')을 반드시 선택해야 열별 매핑이 나타남.
- ✗ 트리거를 만든 폼에 응답이 하나도 없어서 Zapier가 필드를 못 찾아 테스트가 실패 → **Zap을 만들기 전에 폼에 가짜 응답 1건을 먼저 제출.** 그래야 Zapier가 필드 구조를 읽어와 매핑할 수 있음.

## 도구

- 🛠 **Zapier** (zapier.com) — 트리거→액션 노코드 자동화, 무료 플랜 제공.
- 🛠 **Google Forms** (forms.google.com) — 트리거로 쓸 폼(응답 수집).
- 🛠 **Google Sheets** (sheets.google.com) — 액션 대상 스프레드시트(데이터 적재).
- 🛠 **Make** (make.com) — Zapier 대안 노코드 자동화 툴(무료 한도 넉넉).

## 실전 프롬프트

### 내 반복작업을 트리거→액션으로 쪼개기

```text
나는 [반복하는 수작업, 예: 폼 응답을 시트에 옮겨적기]을 매일/매주 하고 있어. 이걸 노코드 자동화로 바꾸려고. 이 작업을 '트리거(무엇이 오면)'와 '액션(무엇을 한다)' 1단계로 쪼개서, 어떤 앱→어떤 앱 연결인지, Zapier에서 어떤 Trigger/Action 이름을 골라야 하는지.
```

> 확인된 작성 예시 없음

`프롬프트` `트리거` `액션` `자동화`

### 자동화 아이디어 10개 브레인스토밍

```text
나는 [내 일/역할, 예: 1인 온라인 강사]야. 매일 반복하는 단순 작업을 트리거→액션 1단계 노코드 자동화로 바꿀 수 있는 현실적인 아이디어를 10개 표로. 열: 트리거 앱, 액션 앱, 이 자동화가 아껴주는 시간. 무료 툴로 가능한 것 위주로.
```

> 확인된 작성 예시 없음

`프롬프트` `아이디어` `자동화`

### 막힌 지점 디버깅 도우미

```text
Zapier에서 [Google Forms → Google Sheets] Zap을 만들었는데 [증상, 예: 폼을 제출해도 시트에 행이 안 생겨]. 초보자가 이 상황에서 확인해야 할 체크리스트를 흔한 원인 순서대로. 필드 매핑, 워크시트 선택, Zap ON 여부까지.
```

> 확인된 작성 예시 없음

`프롬프트` `디버깅` `Zapier`

### 필드 매핑 문구 정리

```text
내 구글 폼 질문은 [이름, 연락처, 신청동기]이고, 시트 열은 [이름, 연락처, 메모]야. Zapier 'Create Spreadsheet Row' 액션에서 각 시트 열에 어떤 폼 답변 필드를 연결해야 하는지 1:1 매핑 표로.
```

> 확인된 작성 예시 없음

`프롬프트` `필드 매핑` `Zapier`

## 채점 기준

| 기준 | 배점 |
| --- | --- |
| 내 Zap 상태가 파란 On인가, 아니면 테스트만 하고 꺼둔 채인가 | 5 |
