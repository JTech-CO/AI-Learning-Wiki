_엑셀 함수도 피벗표 만드는 법도 몰라도 괜찮다. 표 파일(엑셀·CSV)을 AI에 올려 항목별 합계 피벗표·막대/선 차트를 만들고, AI가 짚어주는 추세·이상치를 읽어 회의 자료로 바로 쓴다._

:::note[학습 목표]
- 매출·회비·성적 같은 표 파일(엑셀·CSV)을 AI에 올려 항목별 합계 피벗표를 만든다
- 같은 데이터를 한글 깨짐 없는 막대·선 차트로 그려 추세를 한눈에 본다
- 급감한 항목·이상한 숫자를 글로 짚어주는 코멘트를 받아 엑셀·이미지로 내보낸다
:::

## 핵심 개념

'피벗표'는 영수증 100장을 **카테고리별로 모아 합계를 낸 요약표**예요. 흩어진 줄들을 '식비 12만원, 교통 8만원'처럼 묶는 것이죠. '차트'는 그 표를 그림(막대·선)으로 바꾼 것이고요. 예전엔 엑셀에서 마우스로 끌어 만들었지만, 이제는 **데이터 파일만 올리고 한국어로 부탁**하면 AI가 화면 뒤에서 진짜 계산기(파이썬 코드)를 돌려 숫자를 정확히 계산하고 차트 이미지까지 그려줍니다. 우리는 '카테고리별로 묶어서 막대 차트로 보여줘'라고 말만 하면 돼요.

> 💡 2026년 현재 ChatGPT·Claude 모두 채팅창에서 파일을 올려 차트 그리기를 무료 플랜에서도 일정 범위 제공해요. 무료는 하루 사용 횟수 제한이 엄격해 금방 한도에 걸리고, 대용량·복잡한 분석은 제한될 수 있어요. 유료(월 약 $20)는 한도가 넓어 안정적입니다. ('터미널 기반 Claude Code'는 Pro 이상 개발자용 에이전트로, 'claude.ai 채팅창 코드 실행'과는 별개예요.)

### 왜 이게 될까?

AI는 수십만 개의 엑셀·CSV 표로 '합계 내기·묶어서 정리하기·그래프로 그리기'를 학습했어요. 그래서 파일만 던지고 말로 부탁하면 뒤에서 진짜 계산기(파이썬 코드)를 돌려 정확한 숫자를 뽑고 그림까지 그려줍니다. 우리는 **'무엇을 어떤 기준으로 묶을지'만 정해주면** 되죠.

## 👀 따라하기 예시 — 카페 3개월치 음료·베이커리 매출 CSV

**① 피벗표 요청** 파일 첨부하고 "카테고리별 매출 합계 피벗표 만들어줘" → 음료 760 / 베이커리 620
> 💡 표를 미리 안 만들어도 돼요. '어떻게 묶을지'만 말하면 계산은 AI가 합니다.

**② 차트로 바꾸기** "월별·카테고리별 막대 차트로 그려줘, 한글로" → x축(1·2·3월)에 음료·베이커리 막대가 색깔별로
> 💡 표만 봐선 흐름이 안 보이는데, 그림으로 바꾸면 '어? 음료가 계속 줄어드네'가 한눈에 보여요.

**③ 이상치 짚기** "가장 크게 떨어진 항목과 이상치를 3줄로" → 1) 음료 320→150 절반 이상 급감 2) 베이커리는 꾸준히 상승 3) 3월 음료가 유독 낮아 재고·프로모션 점검 필요
> 💡 숫자·그림만으론 '그래서 뭐가 문제인지'가 안 잡히는데, 말로 짚어달라면 회의에서 바로 쓸 한 줄이 나와요.

**④ 파일로 내보내기** "방금 피벗표를 엑셀 파일로 만들어서 다운로드 링크" → 매출_피벗표.xlsx
> 💡 화면 결과를 바로 내 컴퓨터 파일로 챙겨야 회의 자료에 붙여넣을 수 있어요.

좋은 결과의 기준: (1) 표의 합계가 원본 숫자와 검산했을 때 맞는지 (2) 차트 글자가 한글로 깨짐 없이 나오는지 (3) 분석 코멘트가 '왜 주목해야 하는지'까지 짚는지.

## 단계별 따라하기

1. **준비물 확인** — AI 계정과 데이터 파일. ChatGPT·Claude 모두 채팅창에서 파일을 올려 파이썬 코드로 분석·차트화를 무료 플랜에서도 기본 제공해요(하루 한도 엄격). 유료(Plus/Pro, 월 $20)는 한도가 넓어요. 파일은 .xlsx든 CSV든 상관없어요.

   예시 데이터(CSV):
   ```
   월,카테고리,매출
   1월,음료,320
   1월,베이커리,180
   2월,음료,290
   2월,베이커리,210
   3월,음료,150
   3월,베이커리,230
   ```

2. **새 대화 열고 파일 첨부** — 입력창 왼쪽 클립(📎) 또는 '＋' → 'Upload from computer' → 파일 선택. 입력창 위에 파일 카드가 뜨면 성공.
3. **피벗표부터 요청** — 파일 카드가 붙은 상태에서 '무엇을 어떻게 묶을지'를 적고 전송. ("올린 파일에서 카테고리별로 매출 합계를 낸 피벗표를. 행은 카테고리, 값은 매출 합계로.")
4. **막대·선 차트로 그려달라고** — 같은 대화창에서 이어서. ("방금 표를 월별·카테고리별 매출을 비교하는 막대 차트로. x축은 월, 막대 색은 카테고리로 구분. 글자는 한글로.") 이미지 우클릭 '이미지 저장'으로 회의 자료에. (무료 한도 소진 시 다음 날 또는 아래 7단계로 우회)
5. **이상치·추세를 글로 설명받기** — "이 데이터에서 전월 대비 가장 크게 떨어진 항목과 눈에 띄는 이상치를 3줄로. 왜 주목해야 하는지도 한 줄씩."
6. **결과 내보내기(엑셀/이미지)** — "방금 피벗표를 엑셀 파일(.xlsx)로 만들어서 다운로드 링크를." 차트는 이미지 저장. 파워포인트·보고서에 붙이면 끝.
7. **막히면** — (a) '사용량 한도 초과'/차트 안 그려짐 → 무료 일일 한도. ①수 시간 기다려 리셋 ②Plus/Pro($20)로 업그레이드 ③파일 대신 데이터를 텍스트로 붙여넣고 '카테고리별 합계 내서 정리해줘'(차트는 안 나오지만 요약 표·코멘트는 가능, 소규모 데이터에 유효). (b) 차트 글자가 네모(□) → '한글 폰트로 다시 그려줘'. (c) 숫자가 이상하면 '계산 과정을 표로 보여줘'로 검산.

## 흔한 실수 → 교정

- ✗ 무료 계정으로는 파일 올려 차트를 못 그린다고 지레 포기 → **2026년 현재 ChatGPT·Claude 모두 무료 플랜에서 하루 한도 내 파일 분석·차트를 지원**해요. 한도가 엄격해 금방 소진될 수 있지만 기능 자체가 막힌 건 아니에요. 먼저 시도하고, 소진되면 수 시간 기다리거나 유료를 검토.
- ✗ '파일 분석 불가' 메시지에 무조건 몇 시간 뒤 재시도 → 원인은 2가지. ①일일·5시간 사용량 한도 초과(기다리면 리셋) ②플랜 잠금(현재 플랜에서 미지원, 업그레이드 필요). **메시지를 읽어 구분**하세요. 한도 초과면 기다림, 플랜 잠금이면 업그레이드 또는 텍스트 붙여넣기 우회.
- ✗ 파일을 첨부 안 하고 '내 매출 분석해줘'라고만 → **AI는 안 올린 파일을 볼 수 없어요.** 반드시 클립(📎)으로 파일을 먼저 붙이고 파일 카드를 확인한 뒤 요청.
- ✗ '그냥 분석해줘'처럼 막연 → **'무엇을, 어떤 기준으로, 어떤 차트로'를 콕** 집으세요. '카테고리별 매출 합계를 막대 차트로'처럼 구체적일수록 정확해요.
- ✗ AI가 준 숫자를 검산 없이 그대로 → 중요한 보고라면 **'계산 과정을 표로 보여줘'로 합계를 확인.** 특히 행이 빠지거나 단위가 섞이면 틀릴 수 있어요.

## 도구

- 🛠 **ChatGPT (고급 데이터 분석)** (chat.openai.com) — 파일 올려 피벗표·차트·이상치 분석을 한국어로. 무료도 일일 한도 내 접근하나 엄격, Plus(월 $20)는 넓음.
- 🛠 **Claude (채팅 내 코드 실행)** (claude.ai) — 채팅창에서 파이썬을 실행해 PNG 차트까지. 무료도 일일 한도 내 지원, 긴 데이터·꼼꼼한 설명에 강함. (터미널 Claude Code는 개발자용 Pro 이상, 별개)
- 🛠 **Excel·구글 시트** — 원본 데이터를 만들거나 CSV로 저장, 한도 소진 시 텍스트 붙여넣기 우회.

## 실전 프롬프트

### 피벗표 만들기

```text
올린 [파일이름] 파일에서 [카테고리]별로 [매출]의 합계를 낸 피벗표를. 행은 [기준], 열은 [월/분기 등], 값은 [합계/평균]으로.
```

`피벗표` `데이터 분석` `집계`

### 비교 막대 차트

```text
방금 표를 [월]별로 [카테고리]를 비교하는 막대 차트로. 글자는 한글로, 색으로 항목을 구분하고, 각 막대 위에 숫자도. (차트가 안 그려지면 무료 플랜 한도 — 유료 업그레이드 필요)
```

`차트` `막대 차트` `시각화`

### 이상치·급변 찾기

```text
이 데이터에서 전[월] 대비 가장 크게 [오른/내린] 항목 3개와, 평균에서 크게 벗어난 이상치를. 각 항목을 한 줄로 쉽게 설명하고, 왜 주목해야 하는지 덧붙여.
```

`이상치` `추세` `인사이트`

### 한 번에 보고서 만들기

```text
올린 데이터로 (1)[기준]별 피벗표 (2)추세를 보여주는 막대 또는 선 차트 1개 (3)핵심 인사이트 3가지를 순서대로. 비전문가도 이해하게 쉬운 말로.
```

`보고서` `피벗표` `차트`

### 무료 플랜 우회 — 텍스트로 분석

```text
아래 표를 그대로 읽고 [기준]별 합계를 표로 정리해줘. 그다음 가장 크게 변한 항목 3개를 한 줄씩 쉽게. (데이터를 여기에 붙여넣기)
```

`무료 플랜` `우회` `텍스트 분석`
