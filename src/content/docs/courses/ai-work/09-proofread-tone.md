_이미 쓴 메일·메시지·공지문을 붙여넣어 맞춤법·비문 교정을 받은 뒤 '더 정중하게/간결하게/친근하게' 같은 후속 지시로 톤을 조정하고, AI 결과를 그대로 쓰지 않고 어색한 표현만 직접 골라내 발송용 최종본을 완성한다._

:::note[학습 목표]
- 내 초안을 붙여넣어 맞춤법·비문 교정과 톤 조정까지 받아 발송용 최종 텍스트를 완성한다
- 교정과 톤 변경을 한 번에 시키지 않고 '교정 먼저 → 톤 나중에' 두 단계로 나눈다
- AI 결과를 소리 내어 읽으며 없는 약속·날조된 사실을 골라내 직접 고친다
:::

## 핵심 개념

AI는 **'글을 잘 고치는 비서'**예요. 내가 쓴 글을 붙여넣고 '맞춤법 고쳐줘', '더 정중하게 바꿔줘'라고 하면 원하는 대로 다시 써 줍니다. 여기서 **'톤(tone)'은 말투의 느낌** — 같은 내용도 '정중한 말투', '친근한 말투'로 분위기를 바꿀 수 있어요.

중요한 건, **AI 결과를 무조건 복붙하지 말고 한 번 읽어보기**입니다. AI는 가끔 어색한 표현이나 내가 안 한 말을 끼워 넣기 때문에, 마지막 점검은 사람이 해야 해요. **'AI가 90% 하고 내가 10% 검수'**가 핵심입니다.

흐름: 📝 내 초안 붙여넣기 → ✏️ 맞춤법·비문 교정 → 🎚 톤 바꾸기 지시 → 👀 결과 읽고 검수 → ✅ 최종.

### 왜 이게 될까?

AI는 수억 개 문장을 학습해 **'자연스러운 한국어'가 어떤 느낌인지 감을 익혔어요.** 어색한 문장을 넣으면 국어 선생님처럼 어디가 걸리는지 짚어 고쳐줍니다. 나는 **'무슨 느낌으로' 고칠지만 정하면** 문장 다듬기는 AI가 해줘요.

## 👀 따라하기 예시 — 배송 지연 사과 메일

**① 초안 붙여넣고 교정만** "아래 글을 맞춤법과 비문만 먼저 교정해줘, 내용은 바꾸지 마" → 틀린 곳만 깨끗이 정리됨
> 💡 교정과 톤 변경을 동시에 시키면 결과가 뒤섞여요. 먼저 '틀린 곳'만 깨끗이.

**② 같은 대화창에서 톤 변경** "더 정중한 톤으로, 진정성 있게, 길이는 절반으로" → 분위기와 분량이 한 번에 조정됨
> 💡 AI는 바로 위 답변을 기억해 '그 글을'이라고만 해도 알아들어요. 새로 안 붙여도 됩니다.

**③ 소리 내어 읽으며 검수** '최대한 빠르게 조치하겠습니다'는 날짜가 없어 모호 → '7월 10일까지 발송'으로 수정
> 💡 AI가 없는 약속·애매한 표현을 슬쩍 넣을 때가 있어요. 발송 전 사람이 검수.

**④ 걸리는 한 문장만 콕 집어 재요청** '이 점 양해 부탁드립니다'를 더 부드럽게 3개 요청 → 3안 제시
> 💡 전체를 다시 시킬 필요 없이 걸리는 한 문장만 따옴표로 집어내면 돼요.

좋은 결과의 기준: (1) 맞춤법·비문 없음 (2) 원하는 톤(정중·간결 등)이 느껴짐 (3) 내가 안 한 약속·날조된 사실 없음.

## 단계별 따라하기

1. **ChatGPT 켜기** — chatgpt.com → Sign up → Continue with Google. 무료로 충분해요.
2. **내 초안 붙여넣기** — 고칠 글을 복사(Ctrl+C) → 입력칸에 붙여넣기(Ctrl+V). 글 위에 '아래 글을' 지시 한 줄을 꼭 붙인다.
3. **Enter로 교정 먼저** — 톤은 건드리지 말고 맞춤법·띄어쓰기·어색한 문장만. '교정 먼저 → 톤 나중에' 두 단계로.
4. **톤 바꾸기(같은 대화창)** — 새 글을 안 붙이고 '더 정중하게', '진정성 있게', '절반 길이로' 등 구체적으로. 예: '방금 교정한 글을 사과 진정성이 느껴지게 더 정중한 톤으로, 전체 길이 절반으로.'
5. **결과 소리 내어 읽으며 검수** — 어색한 문장, AI가 넣은 없는 약속('내일까지 보내드리겠습니다')을 확인. 사실과 다른 부분은 직접 지운다. '빠른 시일 내'→'6월 25일까지'.
6. **어색한 부분만 콕 집어 재요청(선택)** — 그 문장만 따옴표로. '이 점 양해 부탁드립니다'가 딱딱한데 더 부드러운 표현 3개.
7. **복사해서 발송** — 답변 아래 복사 → 메일·카톡에 붙여넣기 → 받는 사람·제목 확인 후 전송.

## 흔한 실수 → 교정

- ✗ 교정과 톤 변경을 한 번에 → **'교정 먼저, 톤 나중에' 두 단계로 나누면 깔끔하고 통제하기 쉽다.**
- ✗ AI 결과를 읽지 않고 복붙 발송 → **AI는 가끔 없는 약속·날짜를 지어낸다. 발송 전 소리 내어 읽고 사실 확인.**
- ✗ '좋게 바꿔줘'처럼 막연 → **'정중하게', '절반 길이로', '받는 사람은 고객'처럼 톤·길이·대상을 구체적으로.**
- ✗ 마음에 안 들면 처음부터 다시 붙여넣기 → **같은 대화창에서 '더 짧게', '그 문장만 부드럽게' 이어서.** AI가 앞 내용을 기억한다.

## 실전 프롬프트

### 1단계 교정만(내용 보존)

```text
아래 글의 맞춤법, 띄어쓰기, 비문(말이 안 되는 문장)만 자연스럽게 교정해줘. 내용이나 길이, 말투는 바꾸지 마. [내 초안 붙여넣기]
```

> 확인된 작성 예시 없음

`교정` `맞춤법` `1단계`

### 2단계 톤+길이 조정

```text
방금 교정한 글을 [더 정중한 / 더 친근한 / 더 진정성 있는] 톤으로 바꾸고, 전체 길이를 [절반으로 / 3문장 이내로] 줄여줘. 받는 사람은 [고객 / 상사 / 동료]야.
```

> 확인된 작성 예시 없음

`톤` `길이` `2단계`

### 어색한 한 문장만 다듬기

```text
이 문장이 어색해: '[어색한 문장]'. 같은 뜻이지만 더 자연스러운 표현 3개를 제안해줘. 상황은 [예: 고객에게 보내는 사과 메일]이야.
```

> 확인된 작성 예시 없음

`다듬기` `문장` `대안`

### 검수(AI가 사실을 지어냈는지)

```text
이 답변에서 내가 원본에 안 적었던 내용(날짜, 약속, 숫자 등)을 네가 추가한 부분이 있으면 전부 표시해줘.
```

> 확인된 작성 예시 없음

`검수` `환각` `사실확인`
