_데이터 집계→AI 요약→슬라이드·이메일 생성까지 이어지는 주간 보고서 자동화 파이프라인을 처음부터 끝까지 직접 만들어 배포한다. 매주 2시간씩 태우던 보고서 작업을 버튼 한 번으로 줄이는 AI 실무 코스 캡스톤._

:::note[학습 목표]
- 스프레드시트 데이터를 자동 집계해 AI가 요약하고 슬라이드·이메일 초안까지 만드는 '주간보고 자동화' 파이프라인을 직접 배포한다
- 데이터 집계·AI 요약·슬라이드/이메일 생성·트리거 네 블록을 따로 검증한 뒤 파이프로 잇는다
- '표에 있는 숫자만 사용'과 발송 전 사람 확인 단계로 가짜 수치·오발송을 막는다
:::

## 핵심 개념

주간보고 자동화는 네 개의 블록이 **릴레이처럼 이어지는 구조**예요 — (1)**데이터 집계**: 흩어진 숫자를 한 시트로 모음 (2)**AI 요약**: 숫자를 사람이 읽을 문장으로 (3)**슬라이드/이메일 생성**: 요약을 발표·전달 형태로 찍어냄 (4)**트리거**: 매주 정해진 시각에 자동 실행. 핵심은 '완벽한 하나의 마법'이 아니라, **각 블록을 따로 검증한 뒤 파이프로 잇는 것**이에요.

### 흐름

공장 컨베이어처럼 앞 블록의 출력이 뒤 블록의 입력이 됩니다. 그래서 **데이터 형식(열 이름·단위)만 고정해두면** 나머지는 기계가 반복해요. 처음엔 수동으로 한 바퀴 돌려 결과를 눈으로 확인하고, 그다음 시간 트리거를 붙여 무인화하는 순서가 안전합니다.

### 왜 이게 될까?

AI는 숫자표를 문장으로 바꾸는 요약 훈련을 수억 건 거쳤기 때문에, **표만 정확히 주면** 사람이 읽을 보고서 톤으로 즉시 옮겨요. 여러분은 raw 데이터를 깨끗하게 모으는 일만 하면 되고, 요약·슬라이드 개요·이메일 문장은 AI가 릴레이로 이어받습니다. 사람은 '숫자를 맞게 모으고 검산하는 역할', AI는 '그 숫자를 말이 되게 풀어내는 역할' — 이 분업이 매주 반복되면 **2시간이 5분으로** 줄어요.

## 👀 따라하기 예시 — 6월 마지막 주 신규가입·이탈률 보고

6월 마지막 주, 신규가입·이탈률 숫자를 raw 시트에 막 모아둔 상태에서 요약부터 발송 직전까지 따라가 봅니다.

**① 검산 먼저** summary 시트에서 이번주 합계를 확인 → 신규가입 142건 (전주 118건 대비 +18%), 이탈률 3.1% (전주 3.4%).
> 💡 AI에게 넘기기 전에 사람이 먼저 숫자를 눈으로 확인해야 잘못된 값이 그대로 보고서로 나가지 않아요.

**② AI 요약** summary 표를 통째로 복사해 '표에 있는 숫자만 사용, 경영진 3줄 + 상세 5줄' 형식으로 요청 → 핵심: 신규가입 142건 전주 대비 +18%, 목표(120건) 초과. 이탈률 3.1%로 0.3%p 개선. + 상세 5줄(채널별, 개선 원인 추정 등).
> 💡 '표에 있는 숫자만 사용하라'는 지시가 없으면 AI가 그럴듯한 가짜 수치를 지어낼 수 있어요. 이 한 줄이 가장 중요한 안전장치예요.

**③ 슬라이드·이메일 찍어내기** 2단계 요약을 그대로 넣어 슬라이드 개요와 이메일 초안 요청 → 슬라이드 개요(제목 '6/29주 주간보고', 불릿 3개), 이메일 제목 '[주간보고] 6/29주 — 신규가입 목표 118% 달성' + 본문 3문단.
> 💡 같은 요약을 재료로 형태만 바꿔 찍어내는 게 핵심이라, 숫자를 다시 설명할 필요 없이 프롬프트만 바꾸면 돼요.

**④ 발송은 나중에** Apps Script에서 `MailApp.sendEmail` 대신 먼저 `Logger.log`로 결과만 확인 → 실행 로그에 이메일 제목·본문이 그대로 출력(아직 아무에게도 발송 안 됨).
> 💡 자동 발송을 바로 켜면 검증 안 된 보고서가 팀장에게 실제로 나갈 위험이 있어요. 최소 2주는 눈으로 확인하는 단계를 거쳐야 안전해요.

좋은 결과의 기준: (1) 요약 속 모든 숫자가 summary 시트 원본과 정확히 일치 (2) 경영진 3줄만 읽어도 이번주 상태를 판단 가능 (3) 자동 발송 전 최소 2주는 사람이 초안을 확인하는 단계를 거침.

## 단계별 따라하기

1. **원본 데이터를 한 시트에 고정** — 구글 스프레드시트를 새로 만들고 시트 이름을 `raw`로. 1행에 열 제목(날짜·지표명·값·담당)을 고정하고, 흩어진 소스(엑셀·CRM 내보내기)를 복사해 이 시트에만 붙여넣기로 모은다.
   > raw 1행: `날짜 | 지표명 | 값 | 담당` → 2행: `2026-06-29 | 신규가입 | 142 | 김민지`
2. **집계 시트를 함수로 만들기** — `summary` 시트를 추가하고 지표별 주간 합계를 QUERY나 SUMIF로. 지난주 대비 증감도 한 열에. 숫자가 맞는지 손으로 한 번 검산.
   ```
   =SUMIF(raw!B:B,"신규가입",raw!C:C)   → 이번주 신규가입 합계
   증감열: =(이번주-지난주)/지난주
   ```
3. **AI 요약 프롬프트 붙이기** — summary 시트의 숫자 표를 통째로 복사해 붙여넣고 '경영진 3줄 + 상세 5줄' 형식 지정. (AI: '핵심: 신규가입 142건(전주 대비 +18%)으로 목표 초과. 이탈률은 3.1%로 안정적…')
4. **슬라이드와 이메일 초안 생성** — 3단계 요약을 넣어 구글 슬라이드용 개요(제목/불릿)와 상사에게 보낼 이메일 본문을 각각. 슬라이드는 Gamma나 구글 슬라이드에 붙여 5분 안에.
5. **Apps Script로 파이프 잇기** — 스프레드시트 확장프로그램 > Apps Script를 열고, summary 범위를 텍스트로 읽어 AI API(또는 수동 붙여넣기 함수)로 넘기고 결과를 이메일 초안으로. 처음엔 `MailApp.sendEmail` 대신 `Logger.log`로 출력만 확인.
   ```
   var data = sheet.getRange('summary!A1:D20').getValues();
   Logger.log(data);
   ```
6. **매주 금요일 자동 실행 트리거 걸기** — Apps Script 왼쪽 시계 아이콘(트리거) > 트리거 추가에서 '시간 기반 > 주 단위 > 금요일 오후 4~5시'. 첫 주는 수동 실행 로그와 자동 실행 결과가 같은지 대조.

## 흔한 실수 → 교정

- ✗ 원본 raw 시트의 열 제목을 매주 바꾸거나 단위를 섞어 씀(`142` vs `142명` vs `'142'`) → **1행 열 제목과 값의 형식을 처음에 고정하고 절대 바꾸지 않는다.** 숫자 열은 순수 숫자만 넣어 함수가 깨지지 않게.
- ✗ AI에게 표를 안 주고 '지난주 실적 요약해줘'라고만 해서 그럴듯하지만 가짜인 숫자를 받음 → **반드시 summary 시트의 실제 표를 붙여넣고 '표에 있는 숫자만 사용, 없으면 모른다고 하라'고 명시한다.**
- ✗ 처음부터 자동 발송(`sendEmail`)을 켜서 검증 안 된 보고서가 팀장에게 실제로 나감 → **최소 2주는 `createDraft`(초안 생성)나 `Logger.log`까지만 쓰고 사람이 눈으로 확인 후 보낸다.** 자동 발송은 신뢰가 쌓인 뒤에.

## 도구

- 🛠 **구글 스프레드시트** (sheets.google.com) — 데이터 집계·함수 계산.
- 🛠 **구글 Apps Script** (script.google.com) — 파이프 연결·시간 트리거·Gmail 초안.
- 🛠 **ChatGPT / Claude** (chatgpt.com / claude.ai) — 숫자를 요약 문장으로 변환.
- 🛠 **Gamma** (gamma.app) — 요약 개요를 슬라이드로 자동 생성.

## 실전 프롬프트

### 주간 데이터 요약(가장 먼저)

```text
너는 데이터 분석 비서야. 아래는 우리 팀 주간 지표 표야(열: 날짜/지표명/값/전주대비). [summary 시트 표 붙여넣기] 다음 형식으로 한국어 요약: 1)경영진용 핵심 3줄(가장 중요한 변화만, 숫자 포함) 2)지표별 상세 5줄(증감 원인 추정 포함, 확실치 않으면 '추정' 표기) 3)다음 주 주의 지표 1개. 과장 없이 표에 있는 숫자만 사용.
```

> 확인된 작성 예시 없음

`요약` `데이터` `안전장치`

### 슬라이드 개요 생성

```text
아래 주간 요약을 구글 슬라이드 5장 개요로. 각 장마다 [제목]과 불릿 3개. [3단계 AI 요약 붙여넣기] 1장 표지, 2장 핵심 요약, 3장 지표 상세, 4장 이슈/리스크, 5장 다음 주 액션. 불릿은 각 20자 이내.
```

> 확인된 작성 예시 없음

`슬라이드` `출력형식`

### 상사 보고 이메일 초안

```text
아래 주간 요약을 팀장에게 보낼 이메일로 정중하게. [3단계 AI 요약 붙여넣기] 제목은 '[주간보고] [주차] — [핵심성과]' 형식. 본문은 인사→핵심 3줄→첨부(슬라이드) 안내→마무리, 총 4문단 이내. 군더더기 없이.
```

> 확인된 작성 예시 없음

`이메일` `보고` `출력형식`

### Apps Script 디버깅 도우미

```text
구글 Apps Script로 스프레드시트 summary 범위를 읽어 Gmail 초안을 만들려는데 에러가 나. [에러 메시지] [내 코드] 원인과 수정 코드를 한국어 주석과 함께. 초보라 한 줄씩 설명 부탁.
```

> 확인된 작성 예시 없음

`apps-script` `디버깅`
