_엑셀/CSV 실측 데이터를 AI(무료로 시작 가능한 Claude.ai 또는 ChatGPT Plus)에 올려 추세·이상치를 분석하고, 경영진용 KPI 요약·차트를 5분 만에 받은 뒤 핵심 숫자를 원본과 대조해 검증한다._

:::note[학습 목표]
- 내 실제 매출·가입·정산 CSV를 AI에 업로드해 자동 분석 차트와 '전월 대비 급변 항목' 표를 받는다
- 경영진이 바로 읽는 3줄 KPI 요약을 숫자와 함께 뽑아 한 장짜리 리포트로 정리한다
- 요약 속 핵심 숫자를 원본 CSV와 직접 대조해 AI의 환각을 걸러낸다
:::

## 핵심 개념

AI 데이터 분석은 **'엑셀을 아주 잘 다루는 조수에게 표를 던져주고 말로 시키는 것'**이에요. 예전엔 함수·피벗테이블을 내가 직접 짰지만, 이제는 "카테고리별 매출 추이 그려줘"라고 한국어로 부탁하면 AI가 뒤에서 코드를 돌려 계산하고 그래프까지 그려줘요.

**KPI**는 '회사가 잘 되는지 보는 핵심 숫자'(예: 이번 달 매출, 신규 가입자 수)이고, **이상치(outlier)**는 '튀는 값', 즉 평소와 너무 다른 숫자예요. 단, 어떤 도구든 AI는 가끔 숫자를 틀리게 말하므로(환각) 마지막엔 꼭 원본과 대조해야 해요. '코드로 계산했다'고 해도 100% 믿지 말고 핵심 숫자는 직접 검산하세요.

> 💡 **2026년 기준 현황** — ChatGPT의 데이터 분석 기능(구 Code Interpreter, 현재 Advanced Data Analysis)은 서버에서 파이썬 코드를 실행해 계산·차트를 만드는데, 이 기능(코드 실행·차트)은 Plus(월 20달러) 이상 유료 플랜에서만 안정적이에요. 무료(Free)는 파일 업로드·기본 텍스트 대화는 되나 파이썬 코드 실행·차트 생성은 실질적으로 사용 불가 또는 극히 제한적이에요. 반면 **Claude.ai**는 무료 플랜에서도 CSV를 올려 분석하고 결과를 'Artifact' 미리보기 창에 차트로 보여줘요. 2025년 11월부터 기존 자바스크립트 기반 '분석 도구'를 더 강력한 코드 실행 환경으로 업그레이드해, 계산·분석은 물론 스프레드시트·CSV·문서 같은 다운로드 파일 생성과 복잡한 멀티스텝 워크플로까지 지원해요.

### 흐름

🔀 AI 선택(둘 다 무료 시작) → 🔒 개인정보·학습설정 → 📄 CSV 업로드 → 📊 차트+급변표 → ✅ 원본 대조

### 왜 이게 될까?

AI는 수억 개의 표·차트·통계 코드를 학습해서 "카테고리별 매출 추이 그려줘"라고 말만 해도 뒤에서 파이썬 코드를 짜고 실행해 계산·그래프까지 만들어요. CSV 한 장 올리고 한국어로 부탁만 하면 예전엔 며칠 걸리던 피벗테이블·함수를 5분 만에 끝낼 수 있어요. 단, AI도 가끔 숫자를 잘못 말하니(환각) 핵심 숫자는 꼭 원본과 대조하세요.

## 👀 따라하기 예시 — 3~4월 매출 CSV(월, 카테고리, 매출, 가입수)를 Claude.ai에

**① CSV 올리고 역할·데이터·원하는 결과를 또박또박** → "너는 데이터 분석가야. 첨부 CSV는 우리 회사 월별·카테고리별 매출/가입수야. 1)카테고리별 매출 추이 꺾은선 그래프, 2)전월 대비 20% 이상 급변 항목 표, 3)경영진용 3줄 요약."
> 💡 역할+데이터설명+원하는형식을 다 적을수록 헤매지 않고 한 번에 정확하게 나와요.

**② AI가 코드를 실행해 그래프와 표** → Artifact 창에 꺾은선 그래프 + "인터넷 매출 1,200만→900만 (-25%)" 급변 표가 떠요.
> 💡 Claude.ai 무료 플랜도 코드 실행 환경이라 계산과 차트를 직접 만들어요 — 아하 포인트.

**③ 핵심 숫자를 원본 CSV와 손으로 대조** → 원본 2026-04 인터넷 9,000,000 → (9,000,000-12,000,000)/12,000,000 = -25% → 일치.
> 💡 "코드로 계산했다"고 100% 믿지 않고 검산하는 게 진짜 실력이에요. AI도 가끔 틀려요.

**④ 검증된 내용을 한 장짜리 리포트 형식으로** → 아래처럼 그대로 복사해 붙일 완성물이 나와요.

```
# 2026년 3~4월 KPI 요약
## 핵심 3줄
1. 인터넷 매출 -25%(1,200만→900만) 급감, 즉시 점검
2. TV 매출 +38%(450만→620만) 호조
3. 전체 가입수 110→96명(-13%)
```
> 💡 제목·차트설명·3줄요약 순서로 정리해달라면 그대로 복사해 붙일 완성물이 나와요.

좋은 결과의 기준: (1) 핵심 숫자가 원본과 정확히 일치 (2) 급변 항목이 %와 함께 명확 (3) 3줄 요약만 읽어도 무슨 일이 일어났는지 바로 이해.

## 단계별 따라하기

1. **분석할 데이터를 CSV로 준비** — 첫 줄은 반드시 '제목 줄'(예: 월, 카테고리, 매출, 가입수). 합계 줄·빈 줄·색칠된 메모는 지운다(AI가 헷갈림). 엑셀은 '파일→다른 이름으로 저장→CSV UTF-8(쉼표로 분리)', 구글 시트는 '파일→다운로드→쉼표로 구분된 값(.csv)'.
2. **어떤 AI로 할지 정하기(무료 시작 vs 유료)** — Claude.ai는 무료 플랜에서 CSV 분석·차트(Artifact)가 되고 2025년 11월 업그레이드로 다운로드 파일 생성·멀티스텝까지 지원해, 예산 없이 바로 시작하려면 가장 추천. ChatGPT의 파이썬 기반 Advanced Data Analysis(코드 실행·차트)는 2026년 기준 Plus(월 20달러) 이상 유료에서만 안정적이라 무료로는 실질 사용이 어렵다.
3. **AI 열고 파일 올리기** — [Claude.ai] 로그인 → 입력창 클립 아이콘 → CSV 선택. [ChatGPT Plus] 로그인(Plus 상태) → 입력창 '+' → 파일 추가. 파일이 입력창 위에 작은 카드로 뜨면 성공. (ChatGPT 무료는 업로드는 되어도 코드 실행·차트가 작동 안 하므로 Claude.ai 사용)
4. **무엇을 분석할지 또박또박 부탁** — '역할 → 데이터 설명 → 원하는 결과 → 형식'을 다 적는다. 예: "너는 데이터 분석가야. 첨부 CSV는 우리 회사 월별·카테고리별 매출과 가입수야. 1)카테고리별 매출 추이 꺾은선 2)전월 대비 20% 이상 급변 항목 표 3)경영진이 5초 안에 읽을 3줄 요약, 숫자 꼭 포함."
5. **나온 차트와 표 확인** — ChatGPT Plus는 주로 이미지, Claude는 'Artifact' 미리보기. 차트가 안 떴거나 한글이 깨지면 '코드로 직접 그래프를 그려서 보여줘. 한글이 깨지면 영어 라벨로 대체'. ChatGPT 무료에서 코드 실행이 안 되면 Claude.ai로.
6. **숫자가 진짜 맞는지 원본과 대조(가장 중요)** — AI는 '코드로 계산했다'고 해도 가끔 환각·방식 차이로 미세하게 어긋난다. 요약의 핵심 숫자 1~2개를 원본 CSV에서 직접 찾아 비교. 못 믿겠으면 '4월 인터넷 매출 숫자를 원본 그대로(계산하지 말고) 다시 보여줘'.
7. **한 장짜리 리포트로 내보내기** — '지금까지 내용을 제목·차트설명·3줄요약·주의사항 순서의 깔끔한 리포트로. 마크다운 표로.' → 드래그해 복사해 구글 문서·노션에, 차트는 우클릭 '이미지 저장'(Claude는 Artifact 우상단 다운로드).
8. **다음 달엔 5분 컷으로 반복** — 대화 목록에서 '…→이름 변경'으로 '월간 KPI 리포트'로 저장. 다음 달엔 새 CSV만 올리고 '같은 형식으로 이번 달 리포트 만들어줘' 한 줄.

## 흔한 실수 → 교정

- ✗ 'ChatGPT 무료로 차트·코드 실행이 된다'고 믿고 무료로 시작했다가 막힘 → **2026년 기준 ChatGPT의 Advanced Data Analysis는 Plus(월 20달러) 이상에서만. 무료로 데이터 분석·차트를 시작하려면 Claude.ai, 코드 실행이 꼭 필요하면 Plus 구독.**
- ✗ 무료 한도(파일·메시지 수)를 '정확히 몇 개'라고 외워서 그대로 믿음 → **OpenAI는 무료 한도를 고정 수치로 못 박지 않고 트래픽에 따라 수시로 바꾼다. '어떤 기능이 내 플랜에서 실제로 작동하는지'를 직접 확인하고, 막히면 Claude.ai로 대체하거나 Plus로 전환.**
- ✗ 'AI가 코드로 계산했으니 숫자는 무조건 정확하다'고 믿음 → **도구마다 계산 방식이 다르고 코드 실행이라도 환각·방식 차이로 어긋날 수 있다. 핵심 숫자 1~2개는 반드시 원본 CSV와 직접 대조.**
- ✗ 합계 줄·빈 줄·병합된 셀이 섞인 표를 그대로 올림 → **올리기 전에 합계/소계/메모 줄을 지우고 첫 줄은 제목, 그 아래는 순수 데이터만. 안 그러면 AI가 합계를 데이터로 착각.**
- ✗ '분석해줘'라고만 두루뭉술하게 요청 → **'무엇을 / 어떤 그래프로 / 몇 줄 요약으로'를 구체적으로.**
- ✗ 민감한 업무 데이터(고객명·전화번호·정산액)를 아무 설정 없이 그대로 올림 → **(1)분석에 필요 없는 이름·연락처 열은 업로드 전 삭제하거나 'A고객'으로 가리고 (2)개인 계정은 올린 대화·파일이 기본값에서 모델 학습에 쓰일 수 있으니, ChatGPT는 설정→데이터 제어(Data Controls), Claude.ai는 설정→개인정보(Privacy)에서 '모델 개선에 사용'을 끈다. 회사 기밀은 Business/Enterprise/Team 계정을 쓰면 기본적으로 학습에 안 쓰인다.**

## 도구

- 🛠 **Claude.ai (무료 플랜)** — CSV 업로드·분석·차트(Artifact)가 무료로 가능. 2025년 11월 업그레이드로 다운로드 파일 생성·멀티스텝까지. 가벼운 KPI 리포트의 무료 시작점으로 추천.
- 🛠 **ChatGPT Plus (월 20달러)** — 파이썬 기반 Advanced Data Analysis를 안정적으로 실행. 2026년 기준 이 기능은 Plus 이상에서만. 정밀·대용량 분석이 잦다면 적합.
- 🛠 **Google 시트 / Excel** — 원본 정리와 마지막 숫자 대조 검증(검산 필수).
- 🛠 **노션 / 구글 문서** — 완성된 KPI 리포트를 붙여 공유·보관.

## 실전 프롬프트

### 따라하기 예시 — 역할·데이터·형식 한 번에

```text
너는 데이터 분석가야. 첨부 CSV는 우리 회사 월별·카테고리별 매출/가입수야. 1)카테고리별 매출 추이 꺾은선 그래프, 2)전월 대비 20% 이상 급변 항목 표, 3)경영진용 3줄 요약.
```

`데이터 분석` `역할부여` `예시`

### 기본 KPI 분석 요청

```text
너는 데이터 분석가야. 첨부한 CSV는 [무슨 데이터: 월별 카테고리별 매출]야. 1)[보고싶은 것: 카테고리별 매출 추이]를 그래프로. 2)전월 대비 [20%] 이상 급변한 항목을 표로. 3)경영진이 5초 안에 읽을 3줄 요약을 숫자 포함해.
```

`KPI` `데이터 분석` `템플릿`

### 원본 대조 검증

```text
방금 요약에서 핵심 숫자([4월 인터넷 매출]) 3개를 원본 CSV의 값 그대로 다시 보여줘. 계산을 거치지 말고 표의 원래 숫자만. 그리고 그 숫자로 변화율을 어떻게 계산했는지 식도.
```

`검증` `환각` `검산`

### 리포트 1장으로 정리

```text
지금까지 분석을 '제목 / 핵심 3줄 / 급변 항목 표 / 주의사항' 순서의 깔끔한 마크다운 리포트로. [회사명/기간]을 제목에 넣어줘.
```

`리포트` `출력형식` `요약`

### 그래프 다시 그리기(깨질 때)

```text
그래프가 [안 보여 / 한글이 깨져]. 코드로 직접 그려서 보여줘. 한글 폰트가 깨지면 영어 라벨로 대체.
```

`차트` `한글깨짐` `트러블슈팅`

## 직접 만들기 (미션)

:::tip
✍️ 이제 당신 차례! 본인의 실제 매출·가입·정산 CSV(또는 월, 카테고리, 매출, 가입수 예시 데이터)를 Claude.ai에 올려 (1)카테고리별 추이 그래프 (2)전월 대비 20% 이상 급변 항목 표 (3)경영진용 3줄 요약을 요청해보세요. 그런 다음 요약 속 숫자 1개를 골라 원본과 직접 대조해보세요.
:::
