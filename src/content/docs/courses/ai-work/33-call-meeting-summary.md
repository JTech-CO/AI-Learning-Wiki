_통화 요약 텍스트나 미팅 노트를 붙여넣어 핵심 결정·고객 니즈·다음 액션(누가·언제)을 3칸 표로 구조화하고 CRM 메모로 정리한다. 통화 뒤 다시 정리하느라 쓰던 10분이 30초로 줄어든다._

:::note[학습 목표]
- 통화·회의 메모를 붙여넣어 핵심 결정·고객 니즈·다음 액션(누가·언제)을 표로 구조화한다
- '요약해줘' 대신 칸 이름을 미리 지정해 바로 쓸 수 있는 표를 받는다
- 받은 결과를 CRM·카톡·엑셀 등 붙일 곳에 맞춰 형식(탭 구분 등)을 골라 옮긴다
:::

## 핵심 개념

AI 요약은 **핵심만 뽑아내는 똑똑한 형광펜**이에요. 긴 통화 메모를 던지면 중요한 줄에 형광펜을 긋고 종류별로 분류해줍니다. 비결은 딱 하나, **'어떤 칸으로 나눠줘'를 미리 알려주는 것**. 그냥 '요약해줘'라고 하면 줄글이 나오지만, '결정사항·고객요청·다음액션 세 칸으로 정리해줘'라고 하면 바로 쓸 수 있는 표가 나와요.

한 가지 더. AI가 만든 표(`|` 파이프 형식)를 엑셀에 그냥 붙이면 한 칸에 뭉쳐 들어가요. 엑셀에 칸칸이 넣고 싶을 땐 '탭으로 구분'을 요청하거나 구글 시트에 붙이면 됩니다. AI에게 **빈 칸이 뚫린 양식(템플릿)**을 주고, 받은 결과를 어디에 붙일지에 맞춰 형식을 고르는 게 핵심이에요.

### 흐름

📝 통화 메모 텍스트 붙여넣기 → 🤖 AI에 양식 지시(3칸으로 정리 요청) → 📊 구조화 표(결정·요청·액션) → ✅ CRM 붙여넣기(다음 콜 예약).

### 왜 이게 될까?

AI는 수억 건의 회의록·통화 메모를 학습해 어떤 문장이 '결정'이고 '요청'이고 '할 일'인지 패턴으로 압니다. 아무 메모나 던지고 '몇 칸으로 나눠줘'만 정해주면 분류는 AI가 해줘요. 형광펜을 손으로 긋는 대신, 어디에 칠할지만 알려주는 셈이죠.

## 👀 따라하기 예시 — 고객 김OO 통화 손메모

> 인터넷+TV 결합 문의, KT→SK 희망하나 인터넷도 KT라 망설임, 사은품 현금 문의, 다음주 화요일 오전 재통화.

**① 양식 지시문 + 오늘 날짜를 먼저** — ChatGPT 입력창에 "아래 통화 메모를 [결정사항 / 고객 요청 / 다음 액션(누가·언제)] 3칸 표로 정리해줘. 오늘은 6월 24일(수)이야."
> 💡 칸 이름을 미리 정해줘야 줄글이 아니라 바로 쓸 수 있는 표가 나와요 — 아하 포인트.

**② 그 아래 원본 메모를 그대로 붙여넣고 엔터**
> 💡 맞춤법·줄바꿈이 엉망이어도 AI는 문맥으로 알아서 읽어요. 다듬어 넣을 필요 없어요.

**③ AI가 몇 초 만에 표를 생성** — `| 결정사항: SK 결합 견적 검토 | 고객 요청: 사은품 현금 지급액 확인 | 다음 액션: 상담사, 다음주 화요일 오전 재통화 |`
> 💡 '요약해줘'가 아니라 '칸으로 나눠줘'라 했기에 바로 CRM에 붙일 표가 나왔어요 — 지시문 한 줄의 힘.

**④ 날짜가 애매하면 같은 창에서 바로 고쳐 달라고** — '다음주 화요일'을 정확한 날짜로 → '6월 30일(화) 오전 재통화'.
> 💡 새 대화 열 필요 없이 이어서. 단, AI가 계산한 요일은 달력으로 한 번 더 확인.

좋은 결과의 기준: (1) 각 칸이 한눈에 읽히는 짧은 문장 (2) 다음 액션에 '누가·언제'가 구체적 (3) 메모에 없는 내용을 지어내지 않음.

## 단계별 따라하기

1. **ChatGPT(또는 Claude) 열기** — chatgpt.com. 가입 없이 'Stay logged out'으로 바로 채팅할 수 있으나, 비로그인은 짧은 시간 메시지 수 제한(수치 비공개·수시 변동)에 기록도 저장되지 않아요. 자주 하면 무료 가입(구글/이메일) 권장 — 한도 넉넉하고 대화가 저장돼 양식을 다시 입력할 필요가 없어요. (Claude는 claude.ai 무료 가입)
2. **통화 메모를 손에 준비** — 녹음 없어도 됩니다. 통화 메모·카톡·끄적인 글 아무거나. 맞춤법 틀려도 AI가 알아서. 드래그해 복사(Ctrl+C).
3. **양식(템플릿) 지시문을 함께 붙여넣기** — 맨 위에 '어떻게 정리해줘'를 한 줄 + 메모를 붙이고 엔터. 날짜를 정확히 받으려면 '오늘은 O월 O일이야'를 꼭 함께.
4. **결과 표 확인하고 빠진 곳 채우기** — '다음 액션' 칸에 날짜가 비었거나 '다음주 화요일'처럼 애매하면 같은 창에서 이어서 고쳐 달라고. **중요: AI가 환산한 날짜·요일은 한 번 직접 확인(달력·휴대폰).** AI가 요일 계산을 틀리는 경우가 종종 있어요.
5. **표를 복사해 CRM/메모장/엑셀에 붙여넣기** — CRM 메모칸·카톡·메모장엔 그대로. 엑셀에 '칸칸이' 넣으려면 (A)AI에게 '표를 탭으로 구분한 텍스트로도 줘'라고 요청해 엑셀에 붙이거나 (B)구글 시트에 먼저 붙이면 칸이 자동 분리돼요 (또는 엑셀 [데이터]→[텍스트 나누기]).
6. **(선택) 나만의 양식 저장** — 3번 지시문을 메모장·카톡 '나에게 보내기'에 저장. 다음 통화 땐 지시문 복사 → 메모 붙이기만. (새 대화 기록을 남기려면 무료 가입 상태)

## 흔한 실수 → 교정

- ✗ 그냥 '요약해줘'라고만 해서 줄글이 나옴 → **'어떤 칸으로 나눠줘'를 꼭 적는다.** 칸 이름(결정/요청/다음액션)을 직접 정해주면 바로 쓸 수 있는 표가 된다.
- ✗ AI 표를 엑셀에 붙였더니 한 칸에 다 뭉쳐 들어감 → AI가 만드는 표(`|` 파이프)는 엑셀이 칸으로 인식 못 함. **'탭으로 구분한 텍스트로 줘'라고 다시 요청**하거나 구글 시트를 거친다 (또는 [데이터]→[텍스트 나누기]). CRM 메모칸·카톡엔 그냥 붙여도 됨.
- ✗ AI가 메모에 없는 내용을 그럴듯하게 지어냄(환각) → **'노트에 없는 내용은 지어내지 마. 추측이면 (추정) 표시'**를 넣는다. 날짜·금액은 원본과 한 번 대조.
- ✗ AI가 '다음주 화요일'을 엉뚱한 날짜·요일로 환산 → AI는 요일 계산을 종종 틀림. **'오늘은 O월 O일이야'를 알려주고 받은 날짜는 달력으로 직접 확인.**
- ✗ 비로그인으로 쓰다 '메시지 한도 도달'로 막힘 → **무료 가입(구글/이메일, 1분)**만 하면 한도 풀리고 대화도 저장. 잠깐 기다리는 것보다 가입이 빠름.
- ✗ 고객 이름·전화번호 같은 민감정보를 그대로 넣기 망설여짐 → **이름은 '김OO', 번호는 '010-****'로 가려도** 요약 품질은 그대로. 핵심은 대화 내용이지 개인정보가 아님.

## 도구

- 🛠 **ChatGPT** (chatgpt.com) — 메모 붙여넣고 표로 요약. 'Stay logged out'으로 바로 쓰나 한도·기록 미저장, 자주 쓰면 무료 가입 권장.
- 🛠 **Claude** (claude.ai) — 긴 메모·여러 통화를 한꺼번에 정리하는 데 강함. 무료 플랜 사용량 제한.
- 🛠 **Otter.ai** — 실제 녹음 자동 받아쓰기. 무료(Basic)는 월 300분·통화당 30분·파일 가져오기 3회 제한, Otter AI Chat은 무료 약 20회.
- 🛠 **Fireflies.ai** — 회의 녹음 자동 전사. 무료는 저장 800분·AI크레딧 20개로 Smart 요약 제한.
- 🛠 **Fathom** — 녹음·전사는 무료 무제한, 고급 AI 요약·액션아이템은 무료 월 5회.
- 🛠 **구글 시트** — AI 표를 엑셀 칸으로 옮길 중간 다리.
- 🛠 **카카오톡 '나에게 보내기'** — 양식 지시문 저장·재사용.

## 실전 프롬프트

### 통화 메모 → 3칸 액션 표(기본)

```text
아래 통화 메모를 표로 정리해줘. 칸은 [결정사항] / [고객 요청] / [다음 액션(누가·언제)] 3개로. 표 아래에 '고객 등급 단서' 한 줄도. 추측은 (추정)이라고 표시하고, 메모에 없는 내용은 지어내지 마. 오늘은 [오늘 날짜]야 — '다음주 화요일' 같은 표현은 정확한 날짜로.
=== 통화 메모 ===
[붙여넣기]
```

> 확인된 작성 예시 없음

`통화요약` `액션아이템` `표` `CRM`

### 엑셀에 칸칸이 넣기(탭 구분)

```text
아래 통화 메모를 [결정사항] / [고객 요청] / [다음 액션(누가·언제)] 3칸으로 정리하되, 엑셀에 바로 붙일 수 있게 '각 칸을 탭(Tab)으로 구분한 텍스트'로 출력해줘. (첫 줄은 칸 이름) 오늘은 [오늘 날짜]야. 다음 콜 시점은 정확한 날짜로 환산.
[붙여넣기]
```

> 확인된 작성 예시 없음

`엑셀` `탭구분` `형식`

### CRM 한 줄 메모로 압축

```text
아래 통화 내용을 CRM 메모칸에 들어갈 '한 줄 요약'으로. 형식: 결정:___ / 요청:___ / 다음:___(정확한 날짜). 오늘은 [오늘 날짜]야.
[붙여넣기]
```

> 확인된 작성 예시 없음

`CRM` `한줄요약`

### 회의 노트 → 할 일 담당자 배정

```text
아래 회의 노트에서 '할 일(액션 아이템)'만 뽑아 표로. 칸: [할 일] / [담당자] / [기한]. 담당자가 안 나오면 '미정'. 노트에 없는 내용은 절대 지어내지 마. 날짜는 오늘([오늘 날짜]) 기준으로 환산.
[붙여넣기]
```

> 확인된 작성 예시 없음

`회의록` `액션아이템` `담당자`

### 다음 통화용 준비 멘트 만들기

```text
아래 지난 통화 요약을 바탕으로, 다음 통화 때 내가 꺼낼 '오프닝 멘트 3줄'과 '꼭 물어볼 질문 3개'를. 자연스러운 구어체로.
[붙여넣기]
```

> 확인된 작성 예시 없음

`후속통화` `준비멘트`
