_발표 주제나 기존 문서 한 줄을 Gamma에 넣어 8~10장짜리 슬라이드 초안을 10분 만에 만들고, 슬라이드별 자연어 지시로 다듬은 뒤 PDF·PPTX·링크로 내보낸다._

:::note[학습 목표]
- 발표 주제나 기존 문서를 넣어 8~10장짜리 슬라이드 초안을 생성한다
- 특정 슬라이드를 클릭해 자연어 지시로 내용을 다듬고 수치를 직접 검증한다
- 발표 형태에 맞춰 PDF·PPTX·링크 중 알맞은 형식으로 내보낸다
:::

## 핵심 개념

AI 슬라이드 도구는 **'요리 밀키트'**와 같아요. 재료(주제·문서)만 넣으면 AI가 구조·레이아웃·이미지를 자동으로 차려줍니다. 그중 **Gamma**는 모던하고 깔끔한 2026 테크 기업 느낌의 **웹 네이티브 포맷**으로, 링크 공유에 특히 강해요. 다만 Gamma는 고정 16:9 슬라이드가 아니라 내용에 맞춰 늘어나는 **'카드' 방식**이라, 전통적인 슬라이드 덱보다 **'공유 문서'에 가깝습니다.** 최종 목적지가 Gamma 링크면 매끄럽지만, 표준 슬라이드를 기대하는 고객에게 넘길 땐 마찰이 생길 수 있어요. 2026년엔 리서치를 대신 해주는 **Agent 기능**이 더해져 첫 초안 품질이 가장 강력한 도구로 평가됩니다. PowerPoint 사용자라면 **Plus AI**가 PowerPoint·Google Slides 툴바에 직접 붙는 애드인이라, 기존 환경을 떠나지 않고 프롬프트로 전체 덱을 생성하거나 슬라이드를 다듬을 수 있어요.

**흐름:** ① 📝 주제·문서 입력(개요 붙여넣기) → ② ⚡ AI 초안 생성(8~10장 자동) → ③ 💬 슬라이드별 지시(자연어로 수정) → ④ 📤 내보내기(PDF/PPTX/링크).

### 왜 이게 될까?

Gamma는 수많은 발표 자료를 학습해, 주제 한 줄만 던져도 '어떤 구조로 몇 장, 어떤 순서로' 이야기를 풀지 스스로 짜요. **'무엇을 말할지'만 정하면 '어떻게 배치할지'는 AI가** 맡습니다. 재료만 냉장고에 넣어두면 셰프가 코스 요리 순서를 짜주는 것과 같아요.

## 👀 따라하기 예시 — 우리 동네 카페, 1년 매출 보고

**① 개요 한 줄 붙여넣기** "우리 동네 카페 1년 매출 보고, 8장" → 표지·매출 추이·베스트 메뉴·재방문율·이슈·다음 분기 계획 순으로 8장 카드 초안 자동 생성.
> 💡 주제 하나만 줬는데 발표의 '기승전결'을 AI가 알아서 짜요 — 아하 포인트.

**② 카드 수·테마·언어 지정** "8장, 깔끔한 비즈니스 테마, 한국어" → 전체 덱이 통일된 색상·폰트로 한 번에 재구성.
> 💡 장수를 미리 정해두면 나중에 잘라내는 수고 없이 딱 필요한 만큼만.

**③ 슬라이드별로 콕 집어 수정** 3번 슬라이드 클릭 후 "재방문율 통계 한 줄 추가, 막대 차트로" 지시 → '재방문율 42%' 문구와 막대 차트가 해당 슬라이드에만 추가.
> 💡 전체를 다시 만들지 않고 딱 그 슬라이드만 콕 집어 고쳐요 — AI 슬라이드의 진짜 힘.

**④ 내보내기** PDF로 내보내기 → 8장 덱이 하나의 PDF로 다운로드, 이메일 첨부 가능 상태.
> 💡 발표 형태(화면공유·이메일·편집)에 따라 링크·PDF·PPTX 중 골라야 마찰이 없어요.

좋은 결과의 기준: (1) 숫자·통계가 원본 자료와 실제로 일치하는지 (2) 기본 테마 그대로가 아니라 표지만이라도 손으로 다듬었는지 (3) 상대가 요구하는 파일 형식(PDF/PPTX/링크)에 맞췄는지.

## 단계별 따라하기

1. **재료 넣기** — 발표 주제 한 줄이나 기존 문서·메모를 붙여넣는다. Gamma는 프롬프트·개요·파일 업로드를 모두 받는다. (예: '우리 동네 카페 1년 매출 보고' 개요를 붙여넣어 8장 덱 생성 요청)
2. **장수·톤 지정** — 생성 전 카드(슬라이드) 수와 테마·언어를 고른다. Gamma Free는 프롬프트당 카드 수가 제한되니 8~10장 정도로. (예: 카드 8장, 깔끔한 비즈니스 테마, 한국어)
3. **슬라이드별로 다듬기** — 특정 슬라이드를 클릭해 자연어로 지시한다. 사실·수치는 반드시 직접 검증. (예: '재방문율 통계 한 줄 추가', '이 슬라이드 더 깔끔하게', '3번 장에 막대 차트로 바꿔줘')
4. **내보내기** — 발표 형태에 맞게. 화면 공유용은 링크, 배포용은 PDF, 편집 필요 시 PPTX. (예: PDF로 내보내 이메일 첨부하거나 링크를 복사해 슬랙에 공유)

## 흔한 실수 → 교정

- ✗ AI가 만든 수치·통계를 검증 없이 그대로 사용 → **모든 숫자·인용은 원본 자료와 대조.** AI는 그럴듯한 값을 지어낼 수 있다.
- ✗ 한 번에 20장짜리 완벽한 덱을 기대 → **8~10장 초안으로 시작해 슬라이드별로 반복 수정.** Free 플랜은 크레딧이 빨리 소진되니 재생성을 아낀다.
- ✗ 고객에게 표준 PPT가 필요한데 Gamma 링크만 준비 → **PPTX로 내보내 레이아웃을 점검하거나, 처음부터 Plus AI(PowerPoint 애드인)로 작업.**
- ✗ 기본 테마 그대로 제출해 '전형적인 AI 덱' 느낌 → **브랜드 색·로고를 적용하고 표지·핵심 슬라이드는 손으로 다듬는다.**

## 도구

- 🛠 **Gamma** — 프롬프트·문서에서 웹 네이티브 슬라이드 덱 초안 생성, Agent 리서치. (Free 크레딧 400회 1회성 제공, Plus 약 $8~12/월부터, Pro $18~25/월)
- 🛠 **Plus AI** — PowerPoint·Google Slides 애드인으로 기존 환경에서 AI 슬라이드 생성·편집. (무료 티어 제공, 유료 약 $12/월)
- 🛠 **Microsoft 365 Copilot** — Microsoft 생태계 사용자용, PowerPoint에 통합돼 조직 문서·데이터에서 덱 생성.
- 🛠 **Canva AI** — 디자인 중심, 이미지·비주얼이 강하고 100개 이상 언어 번역.
- 🛠 **ChatGPT·Claude·Gemini** — 발표 개요·핵심 메시지·발표 대본 초안 텍스트 브레인스토밍.

## 실전 프롬프트

### 문서 → 덱 초안

```text
아래 내용을 8장짜리 발표 덱으로 만들어줘. 각 장은 제목+핵심 3줄, 첫 장은 표지, 마지막 장은 요약/다음 단계. 한국어. [문서/개요 붙여넣기]
```

`Gamma` `슬라이드 생성` `초안`

### 슬라이드 다듬기

```text
이 슬라이드에 [재방문율 42%] 통계를 한 줄로 추가하고, 텍스트를 절반으로 줄여 더 깔끔하게. 핵심만 남겨.
```

`Gamma` `수정` `자연어 지시`

### 차트로 시각화

```text
이 장의 월별 매출 수치를 막대 차트로 시각화하고, 가장 높은 달을 강조 색으로 표시해줘.
```

`Gamma` `차트` `시각화`

### 발표 스크립트

```text
완성된 이 덱을 5분 발표용으로, 슬라이드별 발표 대본(구어체, 각 30초)으로 만들어줘.
```

`Gamma` `발표 대본` `스크립트`
