_단순 한 문장을 넘어 [역할 + 대상 + 과제 + 형식 + 제약 + 예시] 6칸을 의도적으로 조립해 명령서를 설계하고, 같은 과제를 3단계로 강화하며 답이 어떻게 좋아지는지 눈으로 비교한다._

:::note[학습 목표]
- 어떤 과제든 [역할 + 대상 + 과제 + 형식 + 제약 + 예시] 6칸을 채워 'AI에게 주는 명령서'를 직접 설계한다
- 같은 과제를 맨몸 → 역할+대상 → 형식+제약+예시 3단계로 강화하며 답이 좋아지는 걸 눈으로 비교한다
- 3단계 답을 정리한 '프롬프트 레시피 카드' 1장을 완성한다
:::

## 핵심 개념

AI에게 주는 명령(프롬프트)은 **'심부름 쪽지'와 같다**. '우유 사와'라고만 적으면 심부름꾼이 헤맨다. '편의점에서(맥락) 서울우유 1L(구체 과제) 1개를 흰 봉투에(형식) 2,800원 안으로(제약) 사와'라고 적으면 정확히 온다. 명령서에 6가지 칸을 채워줄수록 답이 또렷해진다.

- **역할** — 누구처럼 행동할지
- **대상** — 누구한테 쓸 글인지
- **과제** — 정확히 뭘 해야 하는지
- **형식** — 어떤 모양으로 답할지
- **제약** — 지켜야 할 규칙
- **예시** — 원하는 답 견본

한 칸씩 추가할 때마다 답이 어떻게 좋아지는지 직접 보는 게 핵심이다.

### 왜 이게 될까?

AI는 수억 개 글을 읽어뒀지만 **당신이 뭘 원하는지는 모른다**. 명령서에 역할·대상·형식·예시 같은 힌트를 많이 줄수록 그 힌트에 딱 맞는 답을 골라 쓴다. '원하는 그림'만 구체적으로 그려주면 그 그림대로 채우는 건 AI가 대신한다.

## 👀 따라하기 예시 — 학급 재활용 캠페인 표어

**① 맨몸** "학급 재활용 캠페인 문구를 써줘" → "재활용을 합시다! 지구를 지킵시다!…" (길고 밍밍)
> 💡 과제만 던지면 '누구한테, 어떤 느낌으로'를 몰라 가장 무난하고 긴 답으로 도망가요.

**② 역할+대상 추가** "너는 환경 카피라이터야. 초등학생 대상으로…" → "두근두근 분리수거 챔피언 도전! / 오늘부터 우리 반, 지구 지킴이!"
> 💡 역할이라는 '직업 가면'을 씌우면 그 말투로, 대상을 알려주면 그 눈높이로 좁혀져요.

**③ 형식+제약+예시 추가** "표어 3개, 각 12자 이내, 어려운 한자어 금지. 예: '분리수거, 지구 살리기'" → "①분리수거, 지구 사랑 ②오늘 한 번, 내일 지구 ③우리 반이 지킨다"
> 💡 숫자로 못 박고 예시 한 줄을 보여주면 '바로 쓸 길이와 느낌'까지 맞춰줘요.

**④ 세 답 나란히 비교** 1단계 길고 평범 → 2단계 톡톡 튐 → 3단계 그대로 포스터에 붙일 완성품
> 💡 칸을 하나씩 채울 때마다 답이 눈에 띄게 좋아지는 걸 직접 보는 게 핵심이에요.

좋은 결과의 기준: (1) 대상 눈높이 말투 (2) 정해준 개수·길이 준수 (3) 예시로 보여준 느낌과 결이 맞음.

## 단계별 따라하기

1. **ChatGPT 무료로 켜기** (chatgpt.com, 계정 없이도). 한국어로 쓰면 한국어로 답한다.
2. **먼저 '맨몸 명령'을 던져 기준점 만들기** — "학급 재활용 캠페인 문구를 써줘". 두루뭉술·길고 애매한 답이 정상.
3. **역할+대상 추가(2단계 강화)** — "너는 환경 카피라이터야. 초등학생 대상으로 학급 재활용 캠페인 문구를 써줘." 이전 답과 비교.
4. **형식+제약+예시 추가(3단계 완성)** — "…표어 3개, 각 12자 이내, 어려운 한자어 금지. 예: '분리수거, 지구 살리기'". 예시 한 줄이 가장 강력.
5. **세 답을 옮겨 '레시피 카드' 만들기** — 표(단계 | 나온 답 | 느낀 점).
6. **다른 과제에 같은 6칸 적용** — "너는 학교 도서부 선생님이야(역할). 우리 반 친구들에게(대상) 독서주간 안내문을 써줘(과제). 3문장, 줄바꿈해서(형식). 잔소리 느낌 빼고(제약). 예: '이번 주는 책과 친해지는 시간!'(예시)".

## 흔한 실수 → 교정

- ✗ 과제만 한 줄 던지고 실망 → **별로인 게 당연.** 역할·대상부터 한 칸씩 추가하며 같은 대화창에서 다시. 칸을 채울수록 또렷해진다.
- ✗ 예시 칸을 비워둔다(가장 아까운 실수) → **'원하는 느낌'을 말로 설명하기 어렵다면 견본 한 줄이 가장 빠르다.** 예시 한 줄이 설명 열 줄보다 강하다.
- ✗ 한 명령에 너무 많은 걸 막 섞음 → **6칸 순서대로(역할→대상→과제→형식→제약→예시), 줄바꿈으로 칸을 나누면** 더 잘 알아듣는다.
- ✗ 형식·제약 미지정 → 답이 너무 김 → **'표어 3개, 각 12자 이내'처럼 개수·길이를 숫자로 못 박는다.**

## 실전 프롬프트

### 만능 6칸 명령서

```text
너는 [역할: 예-환경 카피라이터]야. [대상: 예-초등학생]을 대상으로 [과제: 예-재활용 표어]를 만들어줘. 형식은 [형식: 예-표어 3개, 각 12자 이내]. 조건: [제약: 예-어려운 한자어 금지]. 원하는 느낌 예시: "[예시 견본 한 줄]"
```

> 확인된 작성 예시 없음

`프롬프트` `6칸` `만능`

### 글쓰기용(안내문·편지·공지)

```text
너는 [역할]야. [대상]이 읽을 [무엇: 안내문/편지/공지]을 써줘. [몇] 문장 이내, [말투: 친근한/정중한]으로. [넣을 핵심내용]은 포함하고 [빼고 싶은 것]은 빼줘. 비슷한 느낌 예시: "[견본 한 줄]"
```

> 확인된 작성 예시 없음

`프롬프트` `글쓰기`

### 비교·강화 실험용

```text
[과제]를 3가지 버전으로 보여줘. 1번은 아무 조건 없이, 2번은 '[역할]'을 맡아서, 3번은 '[형식+제약+예시]'까지 반영해서. 세 버전을 표로 나란히 비교해줘.
```

> 확인된 작성 예시 없음

`프롬프트` `비교` `강화`
