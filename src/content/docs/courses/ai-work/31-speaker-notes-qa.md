_완성된 발표 슬라이드로 슬라이드별 말할 스크립트와 청중의 날카로운 예상질문 15개+모범답변을 AI로 만들어, 발표를 소리 내어 리허설한다. 발표 실력은 타고나는 게 아니라 '스크립트'와 '예상질문 리허설'로 만들어진다._

:::note[학습 목표]
- 슬라이드 내용을 텍스트로 정리해 슬라이드별 구어체 발표 스크립트를 AI로 뽑는다
- 우호·중립·적대(반박형) 3유형으로 예상질문 15개와 모범답변을 준비한다
- AI에게 까다로운 청중 역할을 시켜 모의 Q&A로 최소 1회 소리 내어 리허설한다
:::

## 핵심 개념

발표의 90%는 무대 위가 아니라 **준비 단계에서 결정**돼요. 슬라이드가 완벽해도 막상 입을 떼면 말이 막히고, Q&A에서 예상 못한 질문을 받으면 머리가 하얘지죠. 여기서 챙길 자산은 딱 두 가지예요.

- **발표노트(speaker notes)** — 각 슬라이드에서 무엇을 말할지 정리한 것. 슬라이드에 **안 적힌** 설명, 다음 장으로 넘어가는 전환 문장, 슬라이드별 시간 배분까지 담아요.
- **예상질문과 모범답변** — 청중이 던질 만한 질문. 특히 발표의 약점을 파고드는 **반박형 질문**을 미리 준비하면 Q&A에서 무너지지 않아요.

AI는 슬라이드 내용을 주면 이 둘을 초안으로 빠르게 만들어주고, '까다로운 청중' 역할로 모의 Q&A까지 해줘요. **발표 코치를 옆에 두고 리허설하는 셈**이에요.

### 왜 이게 될까?

AI는 수만 건의 발표·Q&A 사례를 학습해서, 슬라이드 텍스트만 봐도 "청중이 여기서 뭘 물어볼지" 패턴을 알아요. 슬라이드 내용과 청중 정보만 던져주면 스크립트 초안과 날카로운 예상질문은 AI가 먼저 뽑고, **당신은 숫자·근거를 채우고 소리 내어 리허설하는 데만 집중**하면 돼요.

## 👀 따라하기 예시 — 팀장급 5명 앞 "AI 재고관리 도입 제안" 10분 발표

슬라이드 7장은 완성했지만 대본은 없는 상태예요.

**① 슬라이드를 텍스트로 정리해 붙여넣기** — 7장을 "번호: 제목/핵심 불릿"으로: `1.표지 2.문제:월40시간낭비 3.해결:바코드스캔 4.효과:오차율12%→1% 5.비용:300만원 6.일정:8주 7.Q&A`
> 💡 AI가 발표 전체 흐름을 한눈에 봐야 슬라이드별 스크립트 분량과 전환을 맞춰줘요.

**② 시간·청중을 알려주고 슬라이드별 스크립트 요청** — "10분 발표, 청중=팀장급 결정권자" → 3번 스크립트: "앞서 본 40시간 낭비, 어떻게 줄일까요? 핵심은 바코드 스캔입니다. 입고 즉시 스캔 한 번이면(0.5초 멈춤) 재고 수량이 자동 반영됩니다. 다음 장에서 실제 효과 숫자를 보시죠."
> 💡 시간과 청중 수준을 안 알려주면 대본을 너무 길게 쓰거나 톤을 잘못 잡아요 — 핵심 힌트예요.

**③ 3유형으로 예상질문 15개 뽑기** — "우호적·중립·적대(반박형) 3유형, 특히 약점 파고드는 질문 강조" → 적대형: "오차율 12%→1%는 어디서 나온 수치?", "초기 300만원 회수까지 몇 개월?", "직원 교육 저항은?"
> 💡 실전 Q&A는 항상 반박형 질문에서 무너져요. 우호적 질문만 준비하면 아무 의미 없어요.

**④ 모범답변의 숫자를 [___]로 비워 직접 채우기** — "월 40시간 인건비 절감이 약 [___]원이므로..." → 시급을 넣어 "월 80만원 절감, 약 4개월 회수"로 확정.
> 💡 AI는 그럴듯한 숫자를 지어내요. 근거 숫자는 반드시 내가 검증한 값으로 채워요.

좋은 결과의 기준: (1) 스크립트가 슬라이드 글자를 그대로 읽지 않고 화면 밖 설명을 담음 (2) 적대형 질문이 최소 5개 이상 (3) 답변 속 숫자가 전부 실제 데이터로 채워짐.

## 단계별 따라하기

1. **슬라이드 내용을 텍스트로 뽑기** — 각 슬라이드 제목과 핵심 불릿을 번호와 함께 텍스트로. PowerPoint는 '보기 > 개요' 모드, Google Slides는 슬라이드별 내용 복사. 표지·목차·감사 슬라이드도 번호 붙여 포함.
2. **슬라이드별 발표 스크립트 생성** — 텍스트를 붙여넣고 슬라이드마다 말할 스크립트를. 발표 총 시간(예: 10분)과 청중(예: 팀장급 결정권자)을 꼭 알려줘야 톤과 분량이 맞아요.
3. **예상질문 15개 뽑기** — 우호적·중립·적대(반박형) 3가지 유형으로. 특히 발표의 약점(비용·리스크·근거)을 파고드는 적대적 질문을 강조해 달라고. (예: '오차율 12%→1%는 어디서?', '초기 300만원이면 회수 몇 개월?', '직원 교육 저항?', '스캐너 고장 시 대안?')
4. **모범답변 작성 + 약점 보강** — 질문 각각에 '30초 이내 구두 답변'을 AI로 만들되, 근거 숫자나 출처가 필요한 답은 내가 직접 사실을 채워요. AI가 지어낸 숫자를 그대로 쓰면 안 돼요. **답을 못 하는 질문이 있으면 그게 발표의 진짜 구멍.**
5. **AI와 모의 Q&A 리허설** — AI에게 까다로운 청중 역할을 시키고 실제로 소리 내어 답. AI가 한 번에 하나씩 질문하고 내 답에 꼬리 질문을 하게 설정하면 실전과 가장 비슷해요. 막히는 질문은 4단계 답변을 다시 손봐요.
6. **발표노트에 옮기고 시간 체크** — 확정한 스크립트를 실제 슬라이드의 '발표자 노트'란에 붙여넣고, 타이머로 1회 전체 리허설하며 시간 측정. 초과하면 슬라이드별 스크립트를 줄여요.

## 흔한 실수 → 교정

- ✗ 슬라이드에 적힌 글자를 그대로 읽는 스크립트를 만듦 → **발표노트는 슬라이드에 '안 적힌' 배경·이유·전환을 담는 곳.** AI에게 '슬라이드 텍스트 반복 금지, 화면 밖 설명만'이라고 지시.
- ✗ 우호적 예상질문만 준비하고 반박형 질문을 피함 → **실전에서 무너지는 건 항상 적대적 질문.** (C)적대형 7개를 반드시 뽑고, 답을 못 하는 질문 = 발표의 진짜 구멍으로 삼아 먼저 보강.
- ✗ AI가 만든 모범답변의 숫자·출처를 검증 없이 그대로 외움 → **AI는 그럴듯한 숫자를 지어냄.** 답변 속 모든 수치는 [___]로 비워 뽑은 뒤 내가 실제 데이터로 채우고, 못 채우면 그 답변은 쓰지 말 것.

## 도구

- 🛠 **ChatGPT** (chat.openai.com) — 스크립트·예상질문·모의 Q&A 생성.
- 🛠 **Claude** (claude.ai) — 긴 발표 내용 요약·모범답변 정리에 강함.
- 🛠 **PowerPoint / Google Slides** (slides.google.com) — 발표자 노트란에 스크립트 저장.
- 🛠 **스마트폰 타이머** — 전체 리허설 시간 측정과 슬라이드별 시간 배분.

## 실전 프롬프트

### 슬라이드별 발표 스크립트 (가장 먼저)

```text
너는 발표 코치야. 아래는 내 발표 슬라이드 내용이야. 청중은 [팀장급 결정권자], 총 발표 시간은 [10분], 발표 목적은 [도입 승인]이야. 각 슬라이드별로 실제로 소리 내어 말할 구어체 스크립트를. 조건: (1)슬라이드에 안 적힌 배경 설명과 다음 장으로 넘어가는 전환 문장 포함 (2)각 슬라이드 예상 소요 시간 표기 (3)너무 딱딱하지 않게, 잠깐 멈추는 포인트는 (…)로. 슬라이드 내용: [붙여넣기]
```

> 확인된 작성 예시 없음

`발표` `스크립트` `발표노트`

### 예상질문 15개 (우호·중립·적대)

```text
아래 발표 내용에 대해 청중이 던질 예상질문 15개를. 유형을 3가지로: (A)우호적 3개 (B)중립적 확인 5개 (C)적대적·반박형 7개. 특히 (C)는 이 발표의 약점 — 비용 근거, 수치의 출처, 실행 리스크, 반대 논거 — 를 날카롭게 파고드는 질문으로. 실제 회의에서 나올 법한 현실적인 표현으로. 발표 내용: [붙여넣기]
```

> 확인된 작성 예시 없음

`발표` `예상질문` `반박형`

### 모범답변 초안 (숫자는 내가 검증)

```text
아래 예상질문 각각에 대해 30초 이내로 말할 수 있는 구두 답변 초안을. 규칙: (1)결론부터 말하고 근거는 뒤에 (2)구체적 숫자나 출처가 필요한 부분은 내가 채우도록 [___]로 비워두고 절대 임의로 지어내지 마 (3)답하기 곤란한 질문은 '답변 준비가 약함'이라고 솔직히 표시. 질문 목록: [붙여넣기]
```

> 확인된 작성 예시 없음

`발표` `모범답변` `할루시네이션`

### 모의 Q&A 리허설 (까다로운 청중 역할)

```text
지금부터 너는 내 발표를 듣는 까다로운 [투자심사역/팀장]이야. 아래 발표 내용을 근거로 예상질문을 '한 번에 하나씩' 던져줘. 내가 답하면 그 답의 허점을 파고드는 꼬리 질문을 이어서. 내가 '그만'이라고 할 때까지 계속하고, 마지막에 내 답변 중 가장 약했던 3가지와 개선 포인트를. 그럼 첫 질문부터. 발표 내용: [붙여넣기]
```

> 확인된 작성 예시 없음

`발표` `모의Q&A` `리허설`
