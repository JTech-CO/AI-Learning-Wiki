_표·불릿·JSON·글자수·말투를 지시문으로 못박아 AI 답변을 손질 없이 바로 붙여쓸 수 있는 형태로 받아낸다. 매번 표로 다시 정리하던 복붙 노동이 통째로 사라진다._

:::note[학습 목표]
- '무엇을' 묻기 전에 '어떤 모양으로' 줄지를 먼저 지시문으로 못박는다
- 표의 열 이름·불릿 개수·JSON 키·글자 수 상한·말투 다섯 가지를 지정해 결과를 실무에 바로 꽂는다
- 형식이 어긋나면 내용은 놔두고 형식만 다시 지시해 재작업 시간을 없앤다
:::

## 핵심 개념

AI는 형식을 지정하지 않으면 자기 마음대로 **줄글로** 답해요. 그래서 우리가 다시 표로 옮기고, 길이를 자르고, 말투를 고칩니다. 핵심은 '무엇을' 묻기 전에 **'어떤 모양으로' 줄지를 먼저 못박는 것**이에요. 식당에서 "스테이크 주세요"가 아니라 "미디엄으로, 소스는 따로, 접시 말고 도시락에 담아주세요"처럼요. 표의 열 이름, 불릿 개수, JSON 키, 글자 수 상한, 말투(존댓말/반말) **다섯 가지**를 지정하면 결과가 바로 실무에 꽂힙니다.

### 왜 이게 될까?

AI는 형식을 콕 집어 말해주지 않으면 편한 대로 줄글로 답해요. 열 이름·불릿 개수·JSON 키처럼 '모양'을 미리 문장으로 못박으면 그 모양 그대로 채워 넣습니다. **형식 문장 한 줄만 추가하면 복붙 노동은 AI가 대신 끝내요.**

## 👀 따라하기 예시 — 노션 표에 마케팅 아이디어 5개

**① 붙일 곳부터 떠올리기** — 노션 표에 넣을 거니까 표 형식이 필요.
> 💡 붙일 곳을 먼저 정해야 어떤 모양을 요구할지 결정돼요.

**② 열 이름을 직접 지정** — "이번 달 마케팅 아이디어 5개를 표로. 열: 아이디어 | 예상비용 | 기대효과(상중하). 표 외 설명 금지."
> 💡 열 이름을 내가 정해야 원하는 정보가 안 빠져요.

**③ AI 출력** — `| 아이디어 | 예상비용 | 기대효과 |` (5행 표)
> 💡 '표 외 설명 금지'로 표만 딱 나와 바로 복붙 가능해요.

**④ 형식이 어긋나면 형식만 재지시** — "형식이 틀렸어. 표 하나만 남기고 나머지 다 지워서 다시 줘."
> 💡 내용은 이미 맞았으니 형식만 고치면 돼요.

좋은 결과의 기준: (1) 표 밖에 잡설이 하나도 없다 (2) 지정한 열 이름·개수가 정확히 지켜짐 (3) 복붙 즉시 쓸 수 있는 상태.

## 단계별 따라하기

1. **결과물을 어디에 붙일지 정하기** — 엑셀? 노션 표? 코드? 카톡 공지? 붙일 곳이 형식을 결정해요. 노션→표, 슬랙→짧은 불릿+존댓말.
2. **표로 받기, 열 이름 직접 지정** — "아래 열을 가진 마크다운 표로만: [열1] | [열2] | [열3]". 예: "추천 도서 5권을 표로. 열: 제목 | 저자 | 한줄이유 | 난이도(상중하). 표 외 설명 금지."
3. **불릿·글자수 못박기** — "불릿 5개, 각 40자 이내, 존댓말"처럼 개수·길이·말투를 숫자로. '간결하게' 대신 숫자.
4. **JSON으로 받기(자동화용)** — "JSON만 출력. 코드블록·설명 금지. 스키마: {키:타입}". 예: `{"감정":"긍정|부정|중립","핵심어":["문자열"],"별점":0~5 정수}`.
5. **말투·금지사항 추가** — 대상에 맞춘 말투('임원 보고 톤')와 하지 말 것('전문용어 금지', '서론 없이 바로'). 금지 지시가 형식을 더 강하게 고정해요.
6. **어긋나면 형식만 다시 지시** — 내용은 놔두고 "형식이 틀렸어. 표로만, 설명 빼고 다시."

## 흔한 실수 → 교정

- ✗ '간결하게', '표로 깔끔하게' 애매 → **숫자로 못박는다.** '불릿 5개, 각 30자 이내, 열 3개'.
- ✗ JSON 요청했는데 앞에 설명이 붙어 파싱 실패 → **'JSON만 출력. 코드블록·설명·인사말 전부 금지' 명시 + 키/타입 스키마 직접.**
- ✗ 형식이 틀렸을 때 질문 전체를 처음부터 다시 → **내용은 그대로, 형식만 재지시.** '표 밖 문장 빼고 표 하나만 다시.'

## 실전 프롬프트

### 만능 표 출력

```text
[주제]에 대해 정리해줘. 반드시:
- 출력 형식: 마크다운 표 하나만. 표 앞뒤 설명 금지.
- 열: [열이름1] | [열이름2] | [열이름3]
- 행 개수: [예 5]개
- 말투: 존댓말, 이모지 금지
```

> 확인된 작성 예시 없음

`프롬프트` `출력형식` `표`

### 글자수·불릿 고정

```text
[내용/자료]를 요약해줘.
- 불릿 [5]개로만.
- 각 항목 [30]자 이내.
- 존댓말, 서론·결론 없이 불릿만.
- 전문용어는 쉬운 말로.
```

> 확인된 작성 예시 없음

`프롬프트` `출력형식` `불릿`

### JSON만 출력(자동화용)

```text
아래 [텍스트]를 분석해 JSON만 출력. 코드블록(백틱)과 설명 문장 절대 금지.
스키마: {"[키1]":"[타입/허용값]","[키2]":["문자열 배열"],"[키3]":0~5 정수}
텍스트: [붙여넣기]
```

> 확인된 작성 예시 없음

`프롬프트` `출력형식` `json`

### 보고용 톤+금지사항

```text
[주제]를 [대상: 예 임원]에게 보고하는 형식으로.
- 결론 먼저 1문장, 근거 3불릿.
- 전체 [120]자 이내, 존댓말.
- 인사말·서론 생략, 숫자는 **굵게**.
```

> 확인된 작성 예시 없음

`프롬프트` `출력형식` `말투`
