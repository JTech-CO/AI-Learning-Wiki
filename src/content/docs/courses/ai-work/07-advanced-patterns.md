_예시 몇 개(few-shot)·단계적 사고(chain-of-thought)·생각-행동 반복(ReAct)·시스템 프롬프트라는 고급 패턴 4개로 두루뭉술한 답 대신 '바로 쓸 결과물'을 받아낸다. 같은 질문인데 답 품질이 갈리는 건 머리가 아니라 이 패턴을 아느냐의 차이다._

:::note[학습 목표]
- few-shot·chain-of-thought·ReAct·system 프롬프트 4가지 패턴을 각각 직접 만든다
- 네 패턴을 한 프롬프트에 섞어 '바로 쓸 결과물 1개'(예: 상품 후기 5개)를 손에 쥔다
- 계산·최신정보·역할 유지처럼 상황별로 어떤 패턴을 쓸지 고른다
:::

## 핵심 개념

프롬프트는 AI에게 주는 **'주문서'**예요. 같은 질문인데 어떤 사람은 바로 쓸 답을 받고, 나는 두루뭉술한 답만 받아 다섯 번씩 다시 묻는다면 — 차이는 '머리'가 아니라 **프롬프트 패턴 4개를 아느냐**입니다. 고급 패턴 4가지는 이래요.

1. **few-shot = '예시 몇 개'** — 원하는 답 샘플 2~3개를 먼저 보여주면 AI가 그 틀을 따라 해요('이 사진처럼 만들어줘').
2. **chain-of-thought(CoT) = '생각의 사슬'** — '천천히 단계별로 풀어줘'라고 하면 머릿속 풀이를 한 줄씩 적으며 가서 실수가 줄어요.
3. **ReAct = Reason(생각) + Act(행동)** — '생각하고 → 자료를 찾고 → 그 자료로 또 생각'을 반복해요.
4. **system 프롬프트 = 미리 박아두는 '역할·규칙표'** — '너는 친절한 초등 수학 선생님이고 어려운 말은 금지'라고 정하면 대화 내내 그 인격을 유지해요.

### 왜 이게 될까?

AI는 인터넷 수억 개 글의 **'패턴'을 통째로 익혀둔 존재**예요. 예시 몇 개만 보여주면(few-shot) 틀을 바로 따라 그리고, '단계별로' 한마디만 붙여도(CoT) 종이 위에 풀듯 차근차근 풀어 실수가 줄어요. **'무엇을 원하는지'만 보여주면 '어떻게 만들지'는 AI가 채웁니다.**

## 👀 따라하기 예시 — 쇼핑몰 신상품 후기 5개 (few-shot+CoT+system 합치기)

**① 규칙부터 못박기(system)** "너는 쇼핑몰 카피라이터. 후기는 한 문장, 이모지 1개, 과장 금지."
> 💡 규칙을 먼저 정해두면 뭘 시키든 인격 유지, 매번 다시 설명 안 해도 돼요.

**② 예시 2개로 견본(few-shot)** "상품: 우산 / 후기: 바람에도 안 뒤집혀서 출근길이 든든해요 ☔" / "상품: 양말 / 후기: 발에 딱 붙는데 안 조여서 하루 종일 편해요 🧦"
> 💡 '이 사진처럼'을 보여주는 것 — 말투·길이가 자동으로 맞춰져요.

**③ 단계별 생각(CoT)+요청** "1)보온병 2)무릎담요 3)LED스탠드 4)칫솔살균기 5)차량용방향제 — 먼저 각 상품 장점을 한 줄로 생각한 뒤 후기를 써줘" → [생각: 보온병=오래 따뜻함] → [후기: …]
> 💡 '장점부터 생각'을 시키면 엉뚱한 특징을 넣는 실수가 확 줄어요.

**④ 마음에 안 들면 이어서** "3번이 너무 길어, 더 짧게" → 3번만 수정
> 💡 한 번에 완벽할 필요 없어요. 대화하듯 이어서 다듬는 게 실전이에요.

좋은 결과의 기준: (1) 5개 모두 한 문장·이모지 1개로 통일 (2) 각 상품 실제 장점 반영 (3) 과장 없이 자연스러움.

## 단계별 따라하기

1. **ChatGPT 무료 계정 켜기** — chatgpt.com → Sign up → Continue with Google. 유료 결제창은 'Maybe later'로 무료 계속.
2. **few-shot** — 원하는 결과 샘플 2~3개를 보여준 뒤 빈칸 하나만 남긴다. 예시 길이·말투를 일정하게. 예 '상품: 무선 이어폰 / 후기: … 상품: 텀블러 / 후기:'
3. **chain-of-thought** — 계산·논리·순서 질문 끝에 '천천히 단계별로 풀어줘'. 결과만 필요하면 '마지막에 답만 한 줄로 정리해줘'. 암산 대신 종이에 적으며 푸는 것.
4. **system 프롬프트** — 대화 첫 메시지로 '너는 ○○이고 △△ 규칙을 지켜'. 더 확실히: 계정 아이콘 → Settings → Customize ChatGPT → 'How would you like ChatGPT to respond?'에 규칙 저장(모든 대화에 자동 적용).
5. **ReAct** — AI가 모르는 걸 '검색해서' 답하게. 입력칸 왼쪽 지구본 아이콘(Search the web)을 클릭하거나 'web에서 찾아봐'. 프롬프트에 '①생각 ②검색 ③결론' 순서 + [생각]/[검색]/[결론] 라벨. 무료 5시간 rolling 한도(약 10회) 주의.
6. **합치기** — 한 프롬프트에 system+few-shot+CoT를 섞어 결과물 1개 완성. 마음에 안 들면 이어서 고친다.

## 흔한 실수 → 교정

- ✗ few-shot 예시들의 길이·말투가 제각각 → **예시 2~3개를 같은 문장 수·같은 톤으로 통일.** 예시가 곧 견본.
- ✗ 어려운 계산·논리도 그냥 답만 물어 틀린 숫자를 자신 있게 → **끝에 '천천히 단계별로 풀어줘'(CoT).**
- ✗ 최신·사실 정보(가격·날짜)를 추측으로 → **ReAct로 'web에서 검색해서 근거로 답해' + 출처 요청.**
- ✗ 역할·규칙을 매번 다시 설명 → **system 프롬프트나 Customize ChatGPT에 한 번 박아둠.**

## 도구

- 🛠 **ChatGPT** (chatgpt.com) — 무료로 4개 패턴 연습, 웹검색 내장, 5시간당 약 10회.
- 🛠 **Claude** (claude.ai) — 긴 글·정확한 추론에 강해 CoT/few-shot이 깔끔.

## 실전 프롬프트

### few-shot — 예시 그대로 따라 쓰기

```text
아래 예시와 똑같은 형식·말투로 써줘.
예시1) [입력]: [결과]
예시2) [입력2]: [결과2]
[새 입력]:
```

`프롬프트` `few-shot` `예시`

### chain-of-thought — 단계별로 풀게 하기

```text
[질문/문제] 천천히 단계별로 풀이 과정을 보여주고, 마지막 줄에 '답:'으로 결론만 정리해줘.
```

`프롬프트` `chain-of-thought` `추론`

### system — 역할·규칙 박아두기

```text
지금부터 너는 [역할]이야. 규칙: ①[말투/길이] ②[반드시 포함] ③[절대 하지 말 것]. 이 규칙으로 [요청]을 해줘.
```

`프롬프트` `system` `역할`

### ReAct — 생각·검색·결론으로 답하게 하기

```text
다음 순서로 답해줘. 1)[생각] 알아야 할 핵심 질문 2)[검색] web에서 '[검색어]' 찾기 3)[결론] 찾은 내용으로 [최종 요청]. 각 단계에 라벨을.
```

`프롬프트` `ReAct` `웹검색`
