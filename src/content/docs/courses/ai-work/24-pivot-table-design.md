_매출 원장 수천 줄을 붙여넣고 밤새 마감 보고서를 만드는 대신, 행·열·값·그룹·계산 필드로 원자료 한 장을 목적별 요약 피벗테이블 3종으로 3분 만에 재구성한다._

:::note[학습 목표]
- 원자료 한 장을 행·열·값·필터로 배치해 목적에 맞는 요약 피벗테이블을 설계한다
- 날짜를 월·분기로 그룹화하고, 원자료에 없는 지표(이익률)를 계산 필드로 만든다
- 관점을 바꿔 목적별 요약표 3종을 뽑고 슬라이서로 상호작용 대시보드를 만든다
:::

## 핵심 개념

피벗테이블은 '한 줄 = 하나의 거래'로 쌓인 세로형 원자료를 클릭 몇 번으로 요약표로 뒤집는 도구예요. 핵심은 **4개의 상자** — **행**(무엇별로 나눌지, 예: 지역), **열**(가로로 쪼갤 기준, 예: 월), **값**(무엇을 집계할지와 방법, 예: 매출 합계), **필터**(전체 범위 좁히기)입니다. 여기에 날짜를 '월·분기'로 묶는 **그룹화**와, 원자료에 없는 새 지표(예: 이익률=이익/매출)를 만드는 **계산 필드**를 더하면, 같은 데이터로 완전히 다른 관점의 표를 얼마든지 만들 수 있어요. 원자료는 절대 건드리지 않고 요약만 바꾸므로 **실수해도 안전**합니다.

### 왜 이게 될까?

엑셀 피벗 엔진은 수천 줄 원자료를 사람처럼 한 줄씩 세지 않고, 지정한 기준(행·열)으로 즉시 그룹핑한 뒤 집계 알고리즘(합계·평균 등)을 한 번에 돌려요. "무엇별로 보고 싶은지"(행·열·값)만 정해주면 5,000줄을 훑어 더하는 지루한 계산은 엔진이 대신합니다. 원자료는 그대로 두고 요약 관점만 바꾸는 구조라 몇 번을 다시 배치해도 원본은 안전해요.

## 👀 따라하기 예시 — 매출 원장 2,340줄로 "지역×월 매출 + 이익률" 만들기

원장 열: 주문일·지역·상품·수량·매출·원가.

**① 표로 변환** 원자료 아무 셀 클릭 → `Ctrl+T`로 표 변환 → "표1" 생성, 열 머리글에 필터 화살표(▼) 자동.
> 💡 표로 만들어야 데이터가 늘어도 피벗이 새 행을 자동으로 알아챔 — 매번 범위를 다시 잡는 수고를 없애요.

**② 행·열·값 배치** 삽입 → 피벗테이블 → 새 워크시트, 행=지역·열=주문일(월)·값=합계:매출 → 서울·부산·대구 행, 1·2·3월 열로 매출 자동 채움.
> 💡 값이 처음엔 "개수"로 뜨는 경우가 많은데, 텍스트 없는 숫자 열이면 엑셀이 알아서 "합계"를 골라요. 안 그러면 값 필드 설정에서 직접 바꿉니다.

**③ 날짜 그룹화** 날짜 열 우클릭 → 그룹 → 월+분기 동시 선택 → "1분기(1·2·3월) ▸ 2분기…" 식 접이식 2단 헤더.
> 💡 하나하나 나열된 날짜를 분기 단위로 묶어야 "3개월씩 흐름"이 한눈에 보여요 — 아하 포인트.

**④ 계산 필드** 피벗테이블 분석 → 계산 필드 → 이름=이익률, 수식=`(매출-원가)/매출` → 값 영역에 "이익률" 신규, 서울 1분기 32%, 부산 1분기 27% 식 % 서식.
> 💡 원자료에 없던 지표를 원자료를 건드리지 않고 만든 것 — 계산 필드는 피벗 안에서만 사는 가상의 숫자라 원본이 안전해요.

좋은 결과의 기준: (1) 값 라벨이 "합계"인지 확인 (2) 이익률이 평균의 평균이 아니라 (매출합-원가합)/매출합으로 계산 (3) 날짜가 월·분기로 깔끔하게 그룹화.

## 단계별 따라하기

1. **원자료를 표(Table)로 정리** — 첫 행은 반드시 열 제목(주문일·지역·상품·수량·매출·원가), 빈 행·병합셀·소계 행이 없어야 함. 데이터 아무 셀 클릭 → `Ctrl+T`. 표로 만들면 데이터가 늘어도 피벗이 자동으로 새 행 인식.
2. **피벗테이블 삽입하고 행·열·값 배치** — 표 안 클릭 → 삽입 → 피벗테이블 → '새 워크시트'. 필드 목록에서 지역을 '행', 주문일을 '열', 매출을 '값'으로 드래그. 값이 '개수'로 뜨면 값 필드 클릭 → '값 필드 설정' → '합계'.
3. **날짜를 월·분기로 그룹화** — 열의 날짜 값 아무 셀 우클릭 → '그룹' → '월'과 '분기' 함께 선택. 날짜가 텍스트로 인식돼 그룹이 안 되면 원자료 주문일 열 서식을 '날짜'로 먼저.
4. **계산 필드로 이익률 만들기** — '피벗테이블 분석' → 필드·항목 및 집합 → 계산 필드. 이름=이익률, 수식=`(매출-원가)/매출` 입력 후 추가. 결과 셀을 % 서식으로.
5. **목적별 요약표 3종으로 재배치** — 필드를 드래그해 관점을 바꿔 ①지역×월 매출 ②상품×분기 이익률(행=상품, 열=분기, 값=평균:이익률) ③필터=지역(부산), 행=상품, 값=합계:수량 후 내림차순. AI에게 '어떤 배치가 무엇을 보여주는지' 물어 검증.
6. **슬라이서로 상호작용 대시보드화** — 피벗 선택 → '피벗테이블 분석' → 슬라이서 삽입 → 지역·상품 체크. 버튼형 필터가 생겨 클릭만으로 요약표가 실시간 변경. 여러 피벗을 '보고서 연결'로 묶으면 슬라이서 하나가 전체를 제어.

## 흔한 실수 → 교정

- ✗ 값이 '합계'가 아니라 '개수'로 집계돼 매출 총합이 이상하게 작게 나옴 → **값 영역에 빈칸이나 텍스트가 섞이면 엑셀이 자동으로 '개수'로 잡음.** 값 필드 클릭 → 값 필드 설정 → '합계'. 원자료 숫자 열에 섞인 텍스트·빈칸을 먼저 정리.
- ✗ 지역별 이익률들을 그냥 평균 내서 전체 이익률로 사용 → **비율은 평균의 평균이 아님.** 계산 필드로 (매출합-원가합)/매출합처럼 '합계끼리 나눠야' 정확. 개별 행 이익률을 다시 평균 내면 왜곡.
- ✗ 원자료가 바뀌었는데 피벗 숫자가 그대로 → **피벗은 자동 갱신 안 됨.** 피벗 우클릭 → '새로 고침'. 새 행이 반영 안 되면 데이터 원본이 표(Ctrl+T)가 아니라 고정 범위라 그런 것 — 원본을 표로 바꾸면 자동 확장.

## 실전 프롬프트

### 피벗 설계 코치(가장 먼저)

```text
나는 엑셀 피벗테이블을 설계 중이야. 내 원자료 열은 [주문일, 지역, 상품, 수량, 매출, 원가]이고, 알고 싶은 건 [지역별 월 매출 추세와 상품별 이익률]이야. 이 목적을 위해 행/열/값/필터에 각각 어떤 필드를 넣어야 하는지, 값의 집계 방식(합계·평균·개수)까지 콕 집어 표로 정리해줘. 왜 그렇게 배치하는지 한 줄 이유도.
```

`피벗테이블` `설계` `행·열·값`

### 계산 필드 수식 만들기

```text
엑셀 피벗테이블 계산 필드를 만들고 싶어. 원자료 열은 [매출, 원가, 수량]이야. 나는 [이익률, 개당 평균단가, 원가율]을 피벗에서 보고 싶어. 각각 계산 필드에 넣을 정확한 수식과, 결과 셀에 적용할 표시 서식(%, 통화 등)을 알려줘. 계산 필드에서 하면 안 되는 흔한 함정도 하나.
```

`계산 필드` `수식` `이익률`

### 내 요약표 해석·검증

```text
아래는 내가 만든 피벗 요약표야: [표 붙여넣기]. 이 표에서 읽어낼 수 있는 인사이트 3가지와, 배치가 목적에 안 맞아 오해를 부를 수 있는 지점 1가지를 지적해줘. 그리고 '경영진 한 줄 보고' 문장으로 요약해줘.
```

`표 해석` `검증` `인사이트`

### 원자료 진단

```text
피벗을 만들기 전에 원자료를 점검하고 싶어. 내 데이터 첫 5줄은 다음과 같아: [붙여넣기]. 피벗이 깨지거나 집계가 틀릴 수 있는 문제(빈칸, 텍스트로 저장된 숫자·날짜, 소계 행, 병합셀 등)를 찾아 목록으로, 각각 어떻게 고치는지 알려줘.
```

`원자료` `진단` `데이터 정리`

## 직접 만들기 (미션)

✍️ 이제 당신 차례! "상품×분기 이익률" 표를 직접 만들어보세요 — 행=상품, 열=분기(월 그룹화 후 분기만 접기), 값=이익률(계산 필드 재사용). 필터에 지역을 넣고 "부산"만 골라, 상품별 이익률이 어떻게 달라지는지 비교해보세요.
:::

## 채점 기준

| 기준 | 배점 |
| --- | --- |
| 값 필드가 '개수'가 아니라 '합계'/계산 필드로 정확히 잡혀 있나 | 5 |
| 이익률을 개별 행 평균이 아니라 합계 대 합계 비율로 계산했나 | 5 |
| 필터에서 지역을 바꿨을 때 표 전체가 자동으로 다시 계산되는 것을 확인했나 | 5 |
