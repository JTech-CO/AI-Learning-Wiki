_읽을 시간 없는 긴 자료(보고서 PDF·회의록·메일 스레드)를 AI에 넣어 핵심 요약·결정사항·내 액션 항목을 표로 뽑고, 숫자 1~2개를 원문과 대조해 '믿을 수 있는 요약본'을 만든다._

:::note[학습 목표]
- 긴 문서를 AI에 넣어 ①핵심 요약 ②결정사항 ③내 할 일과 마감일을 표로 받는다
- '요약해줘' 대신 '무엇을·어떤 형식으로' 뽑을지 콕 집어 지시한다
- 숫자·날짜 1~2개를 원문과 직접 대조해 환각(지어낸 내용)을 걸러낸다
:::

## 핵심 개념

AI 요약은 **'똑똑하지만 게으른 비서'**에게 일을 시키는 것과 같아요. 그냥 '요약해'라고 하면 비서는 가장 편한 방식(앞부분만 대충)으로 일합니다. 그래서 **'무엇을, 어떤 형태로'** 뽑을지 콕 집어 말해야 해요(예: '결정된 것 / 아직 안 정해진 것 / 내가 할 일'을 표로). 주의할 점은 AI가 가끔 원문에 없는 내용을 그럴듯하게 지어낸다는 것(**'환각'=AI가 헛것을 본다**)이에요. 그래서 마지막에 숫자·날짜 1~2개를 원문에서 직접 찾아 맞는지 확인하는 **'대조' 단계**가 꼭 필요합니다.

### 왜 이게 될까?

AI는 수억 건의 문서·회의록을 학습해 긴 글에서 '핵심이 뭔지' 패턴을 알아요. '무엇을 어떤 형태로 뽑을지'만 지시하면 처음부터 끝까지 읽고 나누는 힘든 일은 AI가 대신 합니다. 다만 없는 걸 지어내기도 해서, 숫자 하나는 사람이 직접 대조해야 진짜 믿을 수 있는 요약이 돼요.

## 👀 따라하기 예시 — 팀 주간 회의록 2페이지(예산·일정·담당자 섞임)

**① 원문 통째로 붙여넣기** 회의록 원문을 통째로 복사해 입력창에 붙여넣는다.
> 💡 AI는 원문을 다 봐야 정확히 요약해요. 일부만 주면 일부만 압니다.

**② 표로 콕 집어 요청** '①결정된 것 ②아직 안 정해진 것 ③내가 할 일과 마감일'을 표로 요청 → `|결정된 것: 예산 2,800만원 확정, 시안 B안 채택 |미정: 런칭일 재논의 |내 할 일: 홍길동 시안B 6/30까지|`
> 💡 '요약해줘'만 하면 아무거나 편한 대로 나와요. 형태를 정하면 빠뜨리는 게 확 줄어요 — 아하 포인트.

**③ 숫자 하나를 원문과 대조** 표에서 숫자 하나(예산 2,800만원)를 원문에서 Ctrl+F로 검색해 실제 있는지 확인 → '예산은 2,800만원으로 확정합니다' 일치.
> 💡 AI도 가끔 숫자를 헛짚어요(환각). 한 번 대조로 신뢰도가 급상승합니다.

**④ 검증된 표 공유** 검증된 표를 팀 메신저에 붙이고, 내 할 일은 캘린더에 마감일과 함께 넣는다.
> 💡 검증까지 끝난 요약은 그대로 공유해도 안심할 '완성물'이에요.

좋은 결과의 기준: (1) 원문에 없는 내용이 섞이지 않았나 (2) 숫자·날짜를 대조해 확인했나 (3) 내가 뭘 언제까지 해야 하는지 한눈에 보이나.

## 단계별 따라하기

1. **도구 열고 로그인** — chatgpt.com → Sign up → Continue with Google. 무료로 충분. (Claude=claude.ai, Gemini=gemini.google.com, 화면 거의 같음)
2. **요약할 원문 복사** — 회의록·워드는 드래그 후 Ctrl+C. PDF는 드래그 복사하거나 입력창 왼쪽 클립(📎)으로 첨부. ※ChatGPT 무료는 파일 첨부 하루 3개 제한(24시간 초기화). 스캔본 PDF는 글자 복사 불가 → 📎 첨부.
3. **'역할+형식'을 콕 집은 프롬프트** — '요약해줘'는 금지. '아래 회의록을 요약해줘. 이렇게 표로 정리해줘:' + 원문 붙여넣기. 표로 받으면 눈에 잘 들어온다.
4. **결과 확인하고 더 캐묻기** — 두루뭉술하거나 빠진 게 있으면 원문 다시 안 붙이고 추가 질문(AI가 대화 기억). '내 액션 항목만 마감일 빠른 순으로 다시 정렬해줘'.
5. **★숫자 1~2개를 원문과 직접 대조(가장 중요)** — 표에서 핵심 숫자·날짜 하나 골라 원문에서 Ctrl+F로 검색해 눈으로 확인. 틀렸으면 'AI에게 예산은 2,800만원이 맞아. 표 수정해줘'.
6. **최종본 저장·전달** — 검증한 표를 복사해 메일·메신저·메모에. 표가 깨지면 '메일에 붙이기 좋게 글머리표 목록으로'. 내 할 일은 캘린더·할 일 앱에.

## 흔한 실수 → 교정

- ✗ '요약해줘'만 입력해 두루뭉술한 줄글 → **'무엇을(결정·미결·내 할 일) 어떤 형식으로(표)' 콕 집어 지시한다.** 형식 지정하면 빠지는 항목이 확 줆.
- ✗ AI 요약을 그대로 믿고 검증 없이 보고에 사용 → **숫자·날짜 1~2개를 원문에서 Ctrl+F로 직접 대조한다.** AI는 가끔 그럴듯하게 지어냄(환각).
- ✗ 너무 긴 문서를 한 번에 붙여 잘리거나 앞부분만 처리 → **아주 길면 절반씩 나눠 두 번, PDF는 📎 첨부.** '전체를 빠짐없이 다 읽고 처리했는지 마지막에 알려줘' 덧붙이기.
- ✗ 회사 기밀·고객 개인정보를 그대로 붙여넣기 → **이름·전화·계좌 등 민감정보는 [홍길동]처럼 가린 뒤 붙인다.** 회사 규정 있으면 사내 승인 AI 도구.

## 도구

- 🛠 **ChatGPT** (chatgpt.com) — 무료·PDF 첨부 가능(하루 3개 제한).
- 🛠 **Claude** (claude.ai) — 아주 긴 문서 요약에 강함.
- 🛠 **Gemini** (gemini.google.com) — 구글 계정으로 바로 사용. 무료는 채팅만, Docs·Drive·Gmail 사이드패널·인라인 AI는 Google AI Pro($19.99/월)·Ultra($249.99/월) 유료 필요.

## 실전 프롬프트

### 회의록 → 결정·미결·내 할 일 표

```text
아래는 [회의 이름] 회의록이야. 한국어로 처리해줘. 다음 3가지를 각각 표로: ①결정된 사항 ②아직 정해지지 않은(미결) 안건 ③내가([내 이름]) 맡은 액션 항목 — 항목/마감일/협업 대상 열로. 원문에 없는 내용은 절대 지어내지 말고, 불확실하면 '원문에 명시 안 됨'.
---
[회의록 전체 붙여넣기]
```

> 확인된 작성 예시 없음

`요약` `회의록` `표` `액션항목`

### 긴 메일 스레드 → 핵심 정리

```text
아래는 길게 이어진 메일 스레드야. ①지금까지 논의의 핵심을 5줄 이내로 ②상대방이 나에게 요청한 것 ③내가 답장에서 꼭 답해야 할 질문 목록. 시간 순서가 헷갈리면 가장 최근 메일 기준.
---
[스레드 붙여넣기]
```

> 확인된 작성 예시 없음

`요약` `메일` `스레드`

### 긴 보고서·PDF → 3단 요약

```text
아래(또는 첨부) 문서를 한국어로 요약해줘. 1)한 문장 핵심 결론 2)중요 수치·데이터 5개(원문 표현 그대로, 위치도) 3)내가 취해야 할 행동 3가지. 수치는 반드시 원문 그대로, 추측은 '(추정)'.
---
[문서 붙여넣기/PDF 첨부]
```

> 확인된 작성 예시 없음

`요약` `보고서` `PDF` `수치`

### 검증(대조)

```text
방금 요약에서 [숫자/날짜, 예: 예산 3,000만원]가 원문과 정확히 일치하는지 다시 확인해줘. 원문 해당 문장을 그대로 인용하고, 다르면 바로잡아줘.
```

> 확인된 작성 예시 없음

`검증` `대조` `환각`
