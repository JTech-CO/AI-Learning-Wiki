_Cursor·Windsurf·Claude Code 등 2026년 주요 AI 코딩 에이전트의 장단점과 과금 구조를 비교하고, 작업 유형(일상 자동완성 vs. 대규모 리팩터링 vs. 멀티파일 에이전트)에 따라 도구를 조합하는 실전 워크플로를 익힌다._

:::note[학습 목표]
- Cursor·Windsurf·Claude Code의 차이와 과금을 이해하고, 내 작업(자동완성/리팩터링/멀티파일 작업)에 맞는 도구를 골라 실제 워크플로로 조합할 수 있다.
:::

> AI 코딩 도구가 너무 많아 뭘 써야 할지 모른 채 월 5만원씩 구독료만 나가고 있다면, 작업 유형별로 딱 맞는 도구를 고르는 법을 배워야 한다. 잘못 고르면 돈도 시간도 두 배로 든다.

## 이 레슨에서 만드는 것

Cursor·Windsurf·Claude Code의 차이와 과금을 이해하고, 내 작업(자동완성/리팩터링/멀티파일 작업)에 맞는 도구를 골라 실제 워크플로로 조합할 수 있다.

## 핵심 개념

AI 코딩 에이전트는 코드를 대신 써주는 'AI 비서'다. 비유하면, 자동완성 도구는 '받아쓰기 잘하는 비서'(내가 말하면 빠르게 옆에서 채워줌), 에이전트 도구는 '심부름 보내는 비서'(여러 파일을 알아서 돌아다니며 큰 일을 처리). Cursor는 둘 다 잘하는 만능 에디터, Windsurf는 흐름을 자동으로 읽는 에이전트형, Claude Code는 터미널(검은 명령어 창)에서 큰 작업을 척척 해내는 전문가형이다. 도구는 하나만 쓰는 게 아니라, 일에 따라 갈아 쓰는 '연장통'으로 생각하면 된다.

### 왜 작동하는가

AI 코딩 도구는 수백만 개 프로젝트의 코드 패턴을 학습해서, 당신이 "뭘 하고 싶은지"만 말하면 어디 파일을 열지, 뭘 고칠지 스스로 찾아냅니다. 그래서 자동완성형(Cursor Tab)은 옆에서 받아쓰고, 에이전트형(Claude Code·Windsurf)은 심부름꾼처럼 여러 파일을 돌아다니며 큰 일을 대신 처리해줍니다. 당신은 "무엇을" 원하는지만 정확히 말하면, "어떻게"는 도구가 알아서 합니다.

## 👀 따라하기 예시

"로그인 페이지에 비밀번호 찾기 기능을 추가해야 하는데, 어떤 도구로 어떻게 시작해야 할지 모르겠다" — 제가 먼저 처음부터 끝까지 골라서 보여드릴게요, 눈으로 따라오세요.

### 1. ① 먼저 작업 유형부터 판단합니다: "비밀번호 찾기 기능"은 로그인 화면 + 이메일 발송 로직 + DB 처리까지 여러 파일을 건드려야 하는 일이에요.

**실제 결과**

```text
판단: "한 줄 자동완성"이 아니라 "여러 파일 걸친 기능 추가" → 에이전트형 도구가 필요함
```

> 작업 유형부터 정해야 도구를 잘못 골라 시간 낭비하지 않아요

### 2. ② 터미널을 열고 claude 라고 입력한 뒤, "로그인 페이지에 비밀번호 찾기 기능 추가해줘, 이메일로 재설정 링크 보내는 방식으로"라고 말합니다.

**실제 결과**

```text
Claude Code 응답 예: "3개 파일을 수정하겠습니다: login.js(찾기 링크 추가), reset.js(신규 생성), email-service.js(발송 함수 추가). 진행할까요? (y/n)"
```

> 에이전트가 스스로 관련 파일을 찾아 계획부터 보여주는 게 핵심 — 무작정 코드만 뱉지 않아요

### 3. ③ y를 누르기 전에 diff(변경 전후 비교)를 한 번 훑어봅니다. reset.js 파일이 새로 생기는 걸 확인.

**실제 결과**

```text
화면에 빨강(삭제)/초록(추가) 줄이 표시됨 — email-service.js에 sendResetEmail() 함수가 새로 추가된 것이 보임
```

> 승인 전에 diff를 보는 습관이 "AI가 엉뚱하게 고쳐도 모르고 넘어가는" 사고를 막아줘요

### 4. ④ 승인 후 Cursor로 돌아와 결과를 눈으로 다듬습니다. 버튼 문구나 색깔처럼 자잘한 건 Cursor Tab 자동완성으로 빠르게 수정.

**실제 결과**

```text
Cursor에서 "비밀번호 찾기" 버튼 텍스트를 클릭하고 수정 시작하니 회색 글씨로 "재설정 링크 보내기" 자동완성 제안이 뜸
```

> 큰 뼈대는 에이전트(Claude Code), 잔손질은 자동완성(Cursor) — 도구를 갈아 쓰는 게 핵심 전략이에요

### 완성 결과

완성물: 로그인 페이지에 "비밀번호 찾기" 링크 → 이메일 재설정 기능까지 연결된 3개 파일. 좋은 결과의 기준: (1) diff를 확인하고 승인했는가 (2) 큰 작업은 에이전트, 잔손질은 자동완성으로 나눠 썼는가 (3) 실제로 테스트해서 이메일이 오는지 확인했는가.

## 단계별 따라하기

### 내 작업 유형부터 정하기

오늘 할 일이 ①코드 한 줄씩 짜며 자동완성 받기 ②기존 코드 전체 정리(리팩터링) ③여러 파일 걸친 기능 추가 중 무엇인지 적는다. 이게 도구 선택의 출발점이다.

**복사·실행 예시**

```text
"로그인 페이지에 비밀번호 찾기 기능 추가" → 여러 파일 수정 = 에이전트형 필요
```

### Cursor 설치·기본 워크플로 익히기

cursor.com에서 다운로드 후 설치. VS Code와 똑같이 생겼다. 코드 입력 중 회색 글씨가 뜨면 Tab키로 자동완성. 채팅창은 Ctrl+L(맥은 Cmd+L), 코드 직접 수정 지시는 Ctrl+K. 무료 플랜은 제한적, Pro는 월 $20.

**복사·실행 예시**

```text
함수 위에서 Ctrl+K → "이 함수에 에러 처리 추가해줘" 입력 → 미리보기 후 Accept 클릭
```

### Claude Code로 대규모 작업 돌리기

터미널에서 npm install -g @anthropic-ai/claude-code 설치 후, 프로젝트 폴더에서 claude 명령어 입력. 채팅으로 큰 작업을 시키면 여러 파일을 알아서 읽고 수정한다. 과금은 API 사용량 기반(쓴 만큼) 또는 Claude Pro/Max 구독 포함.

**복사·실행 예시**

```text
터미널에 claude 입력 후 → "전체 프로젝트에서 fetch를 axios로 바꿔줘" → 변경사항 보여주면 y로 승인
```

### Windsurf로 흐름 자동 파악 작업하기

windsurf.com(구 Codeium)에서 설치. Cascade라는 에이전트 패널이 코드 맥락을 자동으로 읽어 다음 작업을 제안한다. 자동완성은 무료 제공, 에이전트 기능은 크레딧 기반 유료. 흐름 중심 작업에 강하다.

**복사·실행 예시**

```text
Cascade 패널에 "이 컴포넌트를 모바일 반응형으로 만들어줘" → 관련 파일 자동 탐색 후 수정
```

### 작업별 도구 조합 워크플로 만들기

하나로 다 하려 하지 말고 조합한다. 일상 코딩은 Cursor 자동완성, 대형 리팩터링·멀티파일은 Claude Code, 빠른 맥락 파악은 Windsurf. 내 주력 1개 + 보조 1개로 시작해 익숙해지면 늘린다.

**복사·실행 예시**

```text
평소 Cursor로 코딩 → 큰 기능 추가할 땐 터미널 열고 Claude Code 호출 → 결과를 Cursor에서 확인·다듬기
```

## 흔한 실수와 교정
- **실수:** 모든 작업을 비싼 에이전트 도구로 돌려 과금 폭탄을 맞음
  - **교정:** 한 줄 자동완성 같은 작은 작업은 Cursor Tab으로 충분. 에이전트는 여러 파일 걸친 큰 작업에만 쓴다.
- **실수:** AI가 수정한 코드를 안 보고 전부 Accept해서 엉뚱하게 망가짐
  - **교정:** 승인 전 반드시 변경사항(diff) 미리보기를 확인. 의심되면 한 파일씩 부분 승인한다.
- **실수:** 도구를 3개 다 깔아놓고 매번 헷갈려 시간만 씀
  - **교정:** 주력 1개(Cursor 추천)부터 2주 써본 뒤 보조 도구를 추가한다.
- **실수:** 무료 플랜 제한에 막혀 작업이 자꾸 끊김
  - **교정:** 가벼운 사용은 Windsurf 무료 자동완성, 본격 사용은 월 $20 Cursor Pro로 정리하면 비용 예측이 쉽다.

## 완료 체크리스트

- 오늘 작업이 자동완성/리팩터링/멀티파일 중 무엇인지 정했다
- 주력 도구 1개를 설치하고 자동완성·채팅 단축키를 익혔다
- 에이전트 작업 시 변경 파일 목록을 먼저 확인했다
- AI 수정안을 diff로 검토한 뒤 승인했다
- 각 도구의 과금 방식(구독/사용량)을 파악해 예산을 정했다

## 도구

- Cursor — 만능 AI 에디터, 일상 코딩·자동완성 주력
- Claude Code — 터미널 기반, 대규모 멀티파일 작업
- Windsurf — 맥락 자동 파악 에이전트, 흐름 중심 작업
- GitHub Copilot — 보조 자동완성, IDE 내장형 대안

## 참고 답안

판단: 회원가입 폼 + DB 조회 로직 등 여러 파일 → 에이전트형(Claude Code 또는 Windsurf) 필요. 지시문 예시: "회원가입 시 이메일 입력하면 DB에서 중복 확인하고, 중복이면 빨간 글씨로 경고 메시지 보여줘." 승인 전에 어떤 파일이 몇 개 바뀌는지, DB 조회 함수가 새로 생기는지 diff로 확인 후 y.


`eduverse` `agentic-coding-tools`

```text
이 프로젝트에서 [변경 대상 예: 모든 console.log]를 [원하는 결과 예: 로깅 라이브러리 사용]로 바꿔줘. 변경 전에 어떤 파일을 수정할지 목록부터 보여주고, 내 승인을 받은 뒤 진행해줘.
```
