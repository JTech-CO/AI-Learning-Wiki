_LoRA·QLoRA로 소비자 GPU(RTX 4070 수준)에서 7B–13B 모델을 수 시간 만에 도메인 특화 파인튜닝하고, 대형 교사 모델에서 소형 학생 모델로 지식을 증류해 추론 비용을 대폭 낮추는 파이프라인을 구축한다. SFT·DPO·GRPO 기법 비교와 Hugging Face TRL/Unsloth 실습을 포함한다._

:::note[학습 목표]
- LoRA와 QLoRA 기법을 사용해 소비자 GPU에서 고성능 모델을 파인튜닝하고, 대형 모델에서 지식을 증류해 추론 비용을 줄일 수 있다.
:::

> 소비자 GPU만으로도 7B–13B 모델을 도메인 맞춤형으로 변신시킬 수 있다면, 누구든 AI 전문가가 될 수 있다.

## 이 레슨에서 만드는 것

LoRA와 QLoRA 기법을 사용해 소비자 GPU에서 고성능 모델을 파인튜닝하고, 대형 모델에서 지식을 증류해 추론 비용을 줄일 수 있다.

## 핵심 개념

LoRA(Low-Rank Adaptation)와 QLoRA(Quantized LoRA)는 기존 대형 모델을 최소한의 파라미터로 조정하여 도메인 특화 모델을 생성하는 기법이다. GPU 메모리 제약을 극복하고 추론 비용을 낮추며, 대형 모델의 지식을 소형 모델로 증류해 성능을 유지하면서 비용을 줄인다.

### 왜 작동하는가

거대한 모델(7B~13B) 전체를 다시 학습시키려면 GPU 수십 장이 필요하지만, LoRA는 원래 가중치는 그대로 얼어붙여 두고 아주 작은 '보조 행렬'만 새로 학습시킵니다. 마치 두꺼운 원서 교과서 전체를 다시 쓰는 대신, 우리 도메인에 맞는 '부록 노트'만 얇게 끼워 넣는 셈이죠. QLoRA는 여기에 4비트 양자화까지 더해 원본 모델을 압축한 채로 그 부록 노트를 학습시키니, 소비자용 GPU 한 장으로도 도메인 전용 모델을 만들 수 있는 겁니다.

## 👀 따라하기 예시

사내 고객상담 로그 5,000건을 가진 스타트업이 "우리 회사 말투로 답하는 상담봇"을 만들고 싶어합니다. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① 데이터 정제 — 상담 로그 5,000건 중 중복·개인정보 제거, (질문, 답변) 쌍으로 정리

**실제 결과**

```text
정제 전 5,000건 → 정제 후 3,820건 (질문-답변) JSONL. 예: {"input":"환불 언제 되나요?","output":"환불은 영업일 기준 3~5일 소요됩니다."}
```

> 쓰레기 데이터를 넣으면 아무리 좋은 기법도 쓰레기 모델이 나옵니다 — 정제가 8할입니다.

### 2. ② LoRA 설정 — Unsloth로 7B 모델 로드 후 rank=16짜리 LoRA 어댑터 부착

**실제 결과**

```text
trainable params: 41,943,040 / total params: 7,241,748,480 (0.58%만 학습)
```

> 전체 파라미터의 1%도 안 되는 부분만 건드리니 GPU 메모리도 적게 쓰고 학습도 훨씬 빠릅니다.

### 3. ③ 파인튜닝 실행 — 3 epoch, QLoRA 4bit 양자화로 학습

**실제 결과**

```text
epoch 1 loss 1.84 → epoch 3 loss 0.62, 학습 시간 42분 (RTX 4090 1장)
```

> loss가 꾸준히 떨어지는 게 핵심 — 갑자기 0에 가까워지면 오히려 과적합 의심 신호입니다.

### 4. ④ 지식 증류 — 13B 대형 모델의 답변 스타일을 이 소형 7B 모델에 재학습

**실제 결과**

```text
증류 후 응답 자연스러움 평가 점수 6.1 → 7.8 (10점 만점, 사람 평가)
```

> 큰 모델의 '감각'을 작은 모델에 옮기면, 가벼운 모델로도 비슷한 품질을 냅니다.

### 완성 결과

우리 회사 말투로 답하는 7B 상담봇 어댑터 파일(수백 MB, 원본 모델은 그대로 유지). 좋은 결과의 기준: (1) 회사 정책과 다른 답을 하지 않는다 (2) 처음 보는 질문에도 말투가 일관된다 (3) 추론 속도가 원본 대비 크게 느려지지 않는다.

## 단계별 따라하기

1. 도메인 데이터 수집 및 정제: 수집·클리닝·분할·라벨링

2. LoRA/QLoRA 설정: Hugging Face TRL, Unsloth 라이브러리 사용

3. 파인튜닝: 7B–13B 모델로 도메인 맞춤형 파인튜닝

4. 지식 증류: 대형 모델에서 소형 모델로 증류

5. 모델 평가 및 최적화: 성능·추론속도·비용 분석
