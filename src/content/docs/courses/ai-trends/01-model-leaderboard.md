_변동이 빠른 LLM을 이름이나 단일 순위로 고르지 않고, 공식 모델·가격 문서와 내 업무 벤치마크로 비교하는 갱신형 선택 가이드다._

:::note[학습 목표]
- 공식 모델·가격 문서에서 후보 모델의 현재 기능과 과금 단위를 확인한다
- 내 실제 업무 표본으로 품질·속도·비용·안정성을 같은 조건에서 비교한다
- 단일 최고 모델이 아니라 작업별 기본 모델과 대체 모델을 결정한다
:::

> 이 문서는 고정 순위표가 아니라 **수시 갱신하는 비교 방법과 공식 확인 링크**다. 모델명·가격·지원 기능은 자주 바뀌므로 사용 직전에 공식 문서를 다시 확인한다.

## 1. 후보 목록을 공식 문서에서 만든다

- [OpenAI 모델 목록](https://platform.openai.com/docs/models) · [OpenAI API 가격](https://openai.com/api/pricing/)
- [Anthropic 모델 개요](https://docs.anthropic.com/en/docs/about-claude/models/overview) · [Anthropic 가격](https://docs.anthropic.com/en/docs/about-claude/pricing)
- [Google Gemini 모델](https://ai.google.dev/gemini-api/docs/models) · [Gemini API 가격](https://ai.google.dev/gemini-api/docs/pricing)

블로그의 오래된 비교표보다 위 링크의 현재 모델 ID, 지원 입력, 컨텍스트, 도구, 배치·캐시 가격을 먼저 본다.

## 2. 같은 작업으로 비교한다

실제로 반복하는 작업에서 개인정보를 제거한 표본 10~30개를 준비한다. 각 모델에 동일한 시스템 지침, 입력, 출력 형식, 최대 재시도 횟수를 적용한다.

평가 항목:

- **정확성:** 필수 사실과 제약을 지켰는가
- **형식 준수:** JSON·표·문서 형식을 안정적으로 지키는가
- **지연 시간:** 첫 토큰과 전체 완료 시간이 업무 흐름에 맞는가
- **비용:** 입력·출력·캐시·도구 호출까지 포함한 작업 1건 비용은 얼마인가
- **운영성:** 속도 제한, 지역, 데이터 정책, 버전 고정 방식이 요구사항에 맞는가

## 3. 단일 점수 대신 작업별로 선택한다

| 작업 | 우선 지표 | 확인할 것 |
| --- | --- | --- |
| 짧은 분류·추출 | 형식 준수, 비용, 속도 | 작은 모델로 기준을 통과하는가 |
| 긴 문서 분석 | 근거 누락, 컨텍스트, 인용 | 문서 위치를 추적할 수 있는가 |
| 코딩·에이전트 | 테스트 통과율, 도구 사용 | 실패 후 복구와 중단 조건이 있는가 |
| 이미지·음성 포함 | 지원 모달리티, 품질 | 입력 형식과 출력 권리를 확인했는가 |
| 고위험 의사결정 | 검증 가능성, 정책 | 인간 검토와 감사 로그가 있는가 |

## 4. 선택 기록을 남긴다

결정 날짜, 모델 ID, API 버전, 프롬프트 버전, 표본 해시, 통과율, p50/p95 지연, 평균 비용을 기록한다. 다음 갱신 때 같은 표본을 다시 돌려 회귀를 확인한다.

## 완료 체크리스트

- 후보별 공식 모델·가격 링크를 열어 확인했다
- 실제 업무 표본과 합격 기준을 먼저 고정했다
- 작업별 기본 모델과 장애 시 대체 모델을 정했다
- 재평가 날짜와 담당자를 기록했다

## 실전 프롬프트

### 업무별 모델 평가표 만들기

```text
아래 [업무]에 사용할 AI 모델을 비교하려고 한다. 먼저 평가 기준과 합격선을 표로 설계해줘. 정확성·형식 준수·지연 시간·작업 1건 비용·재시도 안정성을 반드시 포함하고, 실제 입력 표본 10개를 어떻게 익명화해 만들지도 제안해줘. 특정 모델을 미리 1등으로 정하지 말고, 동일 조건으로 비교할 수 있는 테스트 절차를 작성해줘.

[업무]: [설명]
[필수 출력 형식]: [JSON/표/문서]
[허용 지연]: [초]
[월 처리량]: [건]
```

#### 고객 문의 분류 예시

**입력**

```text
[업무]: 한국어 고객 문의를 환불/배송/계정/기타로 분류
[필수 출력 형식]: JSON {category, confidence, reason}
[허용 지연]: 2초
[월 처리량]: 50,000건
```

**기대 결과**

평가 항목, 표본 구성, 합격선, 측정 방법, 비용 계산식이 포함된 비교표

> 💡 가격은 실행 당일 각 공급자의 공식 가격 페이지에서 다시 확인한다.

`model-selection` `benchmark` `wiki-authored`
