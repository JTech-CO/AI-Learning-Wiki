_웹훅과 봇으로 팀 채널에 이벤트를 흘려보내는 자동화._

:::note[학습 목표]
- 주문 발생·에러 발생·새 신청 같은 이벤트가 생기면 슬랙이나 디스코드 채널에 자동으로 메시지가 뜨게 만들 수 있다. 코딩 없이 웹훅 주소 하나만으로 시작한다.
:::

> 매번 이메일이나 상황판을 새로고침하며 확인하는 건 시간 낭비다. 중요한 일이 생기면 슬랙·디스코드 채널로 알림이 자동으로 날아오게 만들면 팀 전체가 실시간으로 같은 정보를 본다.

## 이 레슨에서 만드는 것

주문 발생·에러 발생·새 신청 같은 이벤트가 생기면 슬랙이나 디스코드 채널에 자동으로 메시지가 뜨게 만들 수 있다. 코딩 없이 웹훅 주소 하나만으로 시작한다.

## 핵심 개념

웹훅(Webhook)은 '특정 채널로 메시지를 보낼 수 있는 비밀 우편함 주소'다. 이 주소로 정해진 형식의 데이터를 보내면 곧바로 채널에 글이 올라온다. 봇(Bot)은 여기에 '읽고 반응까지 하는' 기능이 더해진 자동 직원이다. 비유하면, 웹훅은 회사 정문에 붙은 '민원함 주소'고, 봇은 그 옆에 앉아 편지도 읽고 답장도 하는 안내 직원이다. 처음엔 편지만 넣는 웹훅부터 시작하면 쉽다.

### 왜 작동하는가

웹훅은 슬랙·디스코드 서버가 미리 열어둔 '우편함 주소'예요. 그 주소로 정해진 형식(JSON)의 데이터를 던지기만 하면, 저쪽 서버가 알아서 채널에 글로 옮겨 적어줘요. 그래서 당신은 주소 하나 복사하고 POST로 데이터만 보내면, 나머지(화면에 띄우기·읽음 표시)는 슬랙·디스코드가 대신 해줍니다.

## 👀 따라하기 예시

신규 주문이 들어올 때마다 #주문알림 채널에 자동으로 뜨게 만들고 싶어요. 제가 먼저 슬랙 웹훅으로 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① api.slack.com/messaging/webhooks에서 앱 만들고 Incoming Webhooks 켜기

**실제 결과**

```text
발급된 주소: https://hooks.slack.com/services/T00/B00/XXXXXX
```

> 이 주소 하나가 곧 '#주문알림 채널로 가는 문'이에요. 앱 코드는 몰라도 이 주소만 있으면 끝.

### 2. ② Postman에서 POST + Body(raw/JSON)로 {"text":"테스트"} 전송

**실제 결과**

```text
채널에 '테스트' 메시지 즉시 표시됨
```

> GET이 아니라 꼭 POST! 그리고 곧은 큰따옴표(") 아니면 서버가 에러를 뱉어요.

### 3. ③ 실제 주문 데이터로 메시지 내용 바꾸기

**실제 결과**

```text
{"text":"🔔 새 주문 #1024\n금액: 32,000원"}
```

> text 안에 \n으로 줄바꿈하면 한 메시지 안에 여러 줄 정보를 깔끔하게 담을 수 있어요.

### 4. ④ Zapier로 '구글폼 새 응답 → 이 웹훅 주소로 전송' 연결

**실제 결과**

```text
폼 제출 3초 후 #주문알림에 자동 게시
```

> 손으로 매번 보낼 필요 없이, 트리거(사건)가 생기면 자동으로 쏘게 만드는 게 진짜 자동화예요.

### 완성 결과

이벤트가 생기면 사람 손 없이 슬랙/디스코드 채널에 뜨는 실시간 알림 파이프라인. 좋은 결과의 기준: (1) POST+올바른 키(text/content)로 매번 성공 전송, (2) 채널이 알림 종류별로 나뉘어 안 시끄러움, (3) 웹훅 주소는 코드·문서에 노출 안 됨.

## 단계별 따라하기

### 어디에 알림 받을지 채널 정하기

슬랙 앱에서 알림 받을 채널(예: #알림)을 하나 만든다. 왼쪽 채널 목록 위 '+' → '채널 생성'. 디스코드면 서버에서 채널 왼쪽 '+'로 새 텍스트 채널을 만든다. 남들과 안 섞이게 전용 채널을 쓰는 게 좋다.

**복사·실행 예시**

```text
채널 이름: #주문알림
```

### 웹훅 주소 발급받기 (슬랙)

브라우저에서 api.slack.com/messaging/webhooks 접속 → 'Create your Slack app' → 'From scratch' → 앱 이름·워크스페이스 선택. 앱 설정 화면 왼쪽 'Incoming Webhooks' → 스위치를 On → 'Add New Webhook to Workspace' → 채널 선택 → 'Allow'. 그러면 https://hooks.slack.com/... 로 시작하는 긴 주소가 나온다. 이걸 복사한다.

**복사·실행 예시**

```text
https://hooks.slack.com/services/T00/B00/XXXXXX
```

### 웹훅 주소 발급받기 (디스코드)

디스코드 채널 이름 옆 톱니바퀴(채널 편집) → '연동(Integrations)' → '웹후크(Webhooks)' → '새 웹후크' → 이름 정하고 '웹후크 URL 복사'. 이 주소로 데이터를 보내면 해당 채널에 글이 올라온다.

**복사·실행 예시**

```text
https://discord.com/api/webhooks/12345/abcde
```

### 테스트 메시지 한 번 쏴보기

코딩 없이 확인하려면 Postman(무료 앱) 또는 웹사이트 reqbin.com을 쓴다. 메서드를 'POST'로 두고, URL 칸에 복사한 웹훅 주소를 붙인다. Body를 'raw/JSON'으로 선택하고 슬랙은 {"text":"테스트"}, 디스코드는 {"content":"테스트"}를 넣고 'Send'. 채널에 '테스트'가 뜨면 성공이다.

**복사·실행 예시**

```text
슬랙 Body: {"text":"첫 알림 성공!"}
```

### 실제 이벤트와 연결하기 (자동화)

매번 손으로 쏘지 말고, Zapier나 Make(둘 다 무료 시작 가능) 같은 자동화 도구를 쓴다. '이런 일이 생기면(트리거)' → 'Webhook으로 이 주소에 메시지 보내기(액션)'를 연결한다. 예: 구글폼 새 응답 → 슬랙 웹훅으로 알림. 코딩 아는 사람은 자기 서버 코드에서 이 주소로 POST 요청을 보내면 된다.

**복사·실행 예시**

```text
구글폼 응답 → Zapier → #신청알림 자동 게시
```

### 메시지 예쁘게 꾸미기(선택)

슬랙은 text 대신 blocks, 디스코드는 embeds를 쓰면 제목·색·항목을 넣은 카드 형태로 만들 수 있다. 처음엔 그냥 text/content로 충분하니, 익숙해진 뒤에 시도한다.

**복사·실행 예시**

```text
슬랙: {"text":"🔔 새 주문 #1024\n금액: 32,000원"}
```

## 흔한 실수와 교정
- **실수:** 웹훅 주소를 공개 문서나 깃허브에 그대로 올림
  - **교정:** 주소를 아는 사람은 누구나 채널에 글을 쓸 수 있다. 비밀번호처럼 취급하고, 노출됐으면 즉시 삭제 후 새로 발급받는다.
- **실수:** 메서드를 GET으로 보내 아무 일도 안 일어남
  - **교정:** 웹훅은 반드시 'POST'로 보내야 한다. 도구에서 메서드 드롭다운을 POST로 바꾼다.
- **실수:** 슬랙에 {"content":...}, 디스코드에 {"text":...}처럼 키를 헷갈림
  - **교정:** 슬랙은 text, 디스코드는 content다. 각 서비스에 맞는 키 이름을 쓴다.
- **실수:** 따옴표를 한글 따옴표(“ ”)로 써서 오류
  - **교정:** JSON은 반드시 곧은 큰따옴표(")만 인정한다. 스마트폰 자동변환·한글 따옴표를 지운다.
- **실수:** 모든 알림을 한 채널에 몰아넣어 시끄러움
  - **교정:** 주문·에러·문의처럼 종류별로 채널을 나누고, 정말 급한 것만 @멘션을 붙인다.

## 완료 체크리스트

- 알림 전용 채널을 만들었다
- 웹훅 주소를 발급받아 안전한 곳에 저장했다
- POST + JSON으로 테스트 메시지가 채널에 떴다
- 실제 이벤트(폼·주문 등)와 자동화로 연결했다
- 웹훅 주소를 외부에 노출하지 않았다
- 알림 종류별로 채널을 나눴다

## 도구

- Slack — 팀 채널·Incoming Webhooks 발급
- Discord — 서버 채널·웹후크 URL 발급
- Zapier — 코딩 없이 이벤트↔웹훅 연결
- Make — 무료로 시작하는 자동화 시나리오
- Postman/ReqBin — 웹훅 테스트 전송

## 참고 답안

1) #문의알림 채널 생성 → 2) 톱니바퀴(채널 편집) → 연동 → 웹후크 → 새 웹후크 → URL 복사 → 3) Postman: POST, Body raw/JSON, {"content":"새 문의가 도착했습니다!"} → Send → 채널에 메시지 표시 확인

## 실전 프롬프트

### 슬랙 기본 알림 Body

```text
{"text":"[이모지] [알림제목]\n[항목1]: [값1]\n[항목2]: [값2]"}
```

> 확인된 작성 예시 없음

`eduverse` `bot-webhooks`

### 디스코드 기본 알림 Body

```text
{"content":"[이모지] [알림제목] — [값1] / [값2]"}
```

> 확인된 작성 예시 없음

`eduverse` `bot-webhooks`

### 자동화 설계 요청 프롬프트

```text
나는 [트리거: 예 구글폼 새 응답]가 생기면 [슬랙/디스코드]의 [채널명] 채널에 알림을 보내고 싶어. Zapier/Make로 웹훅을 연결하는 순서를 클릭 위치까지 초보용으로 알려줘. 보낼 메시지에는 [넣고 싶은 항목들]이 들어가면 좋겠어.
```

> 확인된 작성 예시 없음

`eduverse` `bot-webhooks`

### 슬랙 카드형(blocks) 요청

```text
슬랙 웹훅으로 [제목]과 [항목1: 값], [항목2: 값]을 카드 형태로 보이게 하는 blocks JSON을 만들어줘. 복붙해서 바로 쓸 수 있게.
```

> 확인된 작성 예시 없음
