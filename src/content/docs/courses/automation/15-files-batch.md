> "IMG_4821.JPG", "IMG_4822.JPG"... 폴더에 사진 800장이 순서 없이 쌓여 있고, 손으로 하나씩 이름 바꾸다 보면 손목이 나가기 직전입니다. 사람이 30분 걸릴 일을 컴퓨터는 3초 만에 끝낼 수 있습니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 폴더 안 수백 개 파일을 규칙에 맞게 한 번에 이름변경·정리·이동·변환하는 스크립트를 AI에게 만들게 해서 직접 돌릴 수 있습니다.

## 핵심 개념

파일 일괄 자동화의 핵심은 "사람이 규칙만 말하고, 반복 실행은 컴퓨터가 한다"입니다. 예를 들어 "2024년 찍은 사진 파일 이름을 '여행_001.jpg'처럼 순번을 붙여라"는 규칙을 정하면, 스크립트가 폴더를 훑으며 그 규칙을 800번 자동으로 적용합니다. 스크립트란 컴퓨터에게 주는 '작업 지시서'일 뿐이고, 요즘은 코드를 몰라도 AI에게 상황을 설명하면 지시서를 대신 써 줍니다. 가장 중요한 안전장치는 '원본 복사본에서 먼저 테스트'인데, 잘못된 규칙 한 줄이 수백 개 파일을 되돌릴 수 없게 망가뜨릴 수 있기 때문입니다.

### 왜 작동하는가

AI는 수억 줄의 코드와 스크립트를 학습해서, 당신이 "무엇을 어떻게 바꿔라"라고 말만 하면 그 규칙을 실행하는 진짜 프로그램을 몇 초 만에 써 줍니다. 그래서 당신은 규칙만 또박또박 말하면 되고, 800개 파일에 그 규칙을 하나하나 적용하는 지루한 반복은 AI가 짠 스크립트가 대신 해줍니다.

## 👀 따라하기 예시

다운로드 폴더에 "화면 캡처 2024-05-01 오후 3.22.png" 같은 이름의 스크린샷 200장이 뒤죽박죽 쌓여 있는 상황. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① 규칙을 한 문장으로 정리: "png 파일 전부 → 스크린샷_날짜_순번.png 형식으로"

**실제 결과**

```text
목표 메모: "OS: 윈도우 11 / 대상: Downloads의 png / 규칙: 스크린샷_촬영날짜_3자리순번.png"
```

> 컴퓨터도 AI도 애매한 말은 못 알아들어요. 규칙을 문장 하나로 못 줄이면 아직 준비가 안 된 거예요.

### 2. ② AI에게 그대로 붙여넣어 스크립트 요청

**실제 결과**

````text
AI 응답: "네, 파워셸 스크립트를 만들었습니다. Get-ChildItem으로 png 파일을 모두 찾아 촬영 날짜순으로 정렬한 뒤, 001부터 3자리 순번을 붙여 이름을 바꿉니다. 코드: ```Get-ChildItem *.png | Sort-Object LastWriteTime | ForEach-Object -Begin {$i=1} -Process { Rename-Item $_.FullName -NewName (\"스크린샷_{0}_{1:000}.png\" -f $_.LastWriteTime.ToString(\"yyyy-MM-dd\"), $i); $i++ }```"
````

> AI는 "순번"이라는 말만 듣고도 자릿수를 맞춰야 정렬이 안 꼬인다는 걸 알아서 001, 002로 짜줘요. 이게 바로 아하 포인트!

### 3. ③ 복사본 폴더에서만 먼저 실행

**실제 결과**

```text
복사본(Downloads-복사본)에서 실행 결과: "스크린샷_2024-05-01_001.png, 스크린샷_2024-05-01_002.png ... 200개 모두 정상 변경, 중복 0건"
```

> 원본은 절대 건드리지 않아요. 복사본에서 사고가 나도 원본은 무사하니까요.

### 4. ④ dry-run(미리보기)으로 최종 확인 후 원본에 적용

**실제 결과**

```text
dry-run 목록: "IMG_100.png → 스크린샷_2024-05-01_001.png (총 200개, 중복 0건, 빠진 파일 0개)" 확인 → 원본 경로로 바꿔 실제 실행 완료
```

> 진짜로 이름을 바꾸기 전에 "이렇게 바뀔 거예요" 목록만 먼저 보여주면, 사고 나기 전에 눈으로 걸러낼 수 있어요.

### 완성 결과

재사용 가능한 rename_photos.ps1 스크립트 파일 하나. 좋은 결과의 기준: (1) 파일명 규칙이 항상 같은 자릿수로 정렬됨 (2) 원본은 복사본 테스트 후에만 딱 한 번 적용됨 (3) dry-run에서 중복·누락 0건 확인됨.

## 단계별 따라하기

### 1단계 — 무엇을 어떻게 바꿀지 규칙을 한 문장으로 적기 (5분) 🙋나

자동화하려는 목표를 '무엇을(대상) → 어떻게(규칙)'로 종이나 메모장에 한국어로 또박또박 적습니다. 파일 종류, 현재 이름 형태, 원하는 결과 이름을 예시로 함께 씁니다.

**복사·실행 예시**

```text
목표: 다운로드 폴더의 png 파일 전부 → '스크린샷_2024-05-01_01.png' 형식으로 날짜와 순번을 붙여 이름변경. 지금 이름: 화면 캡처 2024-05-01 오후 3.22.png
```

### 2단계 — 안전을 위해 폴더 통째로 복사본 만들기 (2분) 🙋나

작업할 폴더를 마우스 우클릭 → 복사 → 같은 위치에 붙여넣기 해서 '폴더명-복사본'을 만듭니다. 모든 테스트는 반드시 이 복사본에서만 합니다. 원본은 손대지 않습니다.

**복사·실행 예시**

```text
'여행사진' 폴더를 복사해 '여행사진-복사본' 생성 → 스크립트는 복사본 경로로만 지정
```

### 3단계 — AI에게 스크립트를 대신 짜 달라고 요청하기 (5분) 🤖A

ChatGPT나 Claude에 아래 첫 번째 템플릿을 붙여넣고, [ ] 안을 1단계에서 적은 내 규칙과 운영체제(윈도우/맥)로 채웁니다. AI가 준 스크립트 코드 전체를 복사합니다.

**복사·실행 예시**

```text
프롬프트에 'OS: 윈도우 11 / 대상: C:\\Users\\me\\Downloads 의 png / 규칙: 스크린샷_촬영날짜_순번.png' 입력 → AI가 파워셸 스크립트 제공
```

### 4단계 — 복사본에서 먼저 실행해 결과 확인하기 (5분) 🤝함께

AI가 알려준 실행 방법대로 복사본 폴더에서만 스크립트를 돌립니다. 파일 몇 개 이름이 규칙대로 바뀌었는지 눈으로 확인합니다. 이상하면 AI에게 '이렇게 나왔다'며 결과를 그대로 붙여 넣어 고칩니다.

**복사·실행 예시**

```text
실행 후 '스크린샷_2024-05-01_01.png'로 정상 변경 확인 → 순번이 1,2,3 대신 1,10,11로 꼬이면 두 번째 템플릿으로 수정 요청
```

### 5단계 — 실전 미리보기(dry-run)로 위험 요소 걸러내기 (3분) 🤝함께

AI에게 '실제로 바꾸기 전에 어떤 파일이 어떻게 바뀔지 목록만 먼저 보여주는 모드를 넣어 달라'고 요청합니다. 목록을 훑어 겹치는 이름이나 빠진 파일이 없는지 점검합니다.

**복사·실행 예시**

```text
dry-run 출력: 'IMG_1.jpg → 여행_001.jpg / IMG_2.jpg → 여행_002.jpg ... 총 812개, 중복 0건' 확인 후 진짜 실행
```

### 6단계 — 원본에 적용하고 반복 작업으로 저장하기 (5분) 🙋나

복사본에서 완벽히 검증된 스크립트를 원본 폴더 경로로 바꿔 한 번 실행합니다. 이 스크립트 파일을 '자동화모음' 폴더에 이름 붙여 저장해 두면 다음 달에도 클릭 한 번으로 재사용합니다.

**복사·실행 예시**

```text
경로를 '여행사진-복사본'→'여행사진'으로 수정 후 실행 → 스크립트를 'rename_photos.ps1'로 저장
```

## 흔한 실수와 교정
- **실수:** 원본 폴더에서 바로 스크립트를 테스트해 파일이 뒤죽박죽 되고 되돌릴 수 없게 됨
  - **교정:** 실행 전 반드시 폴더를 통째로 복사해 '복사본'에서만 테스트하고, 검증이 끝난 뒤에야 원본에 딱 한 번 적용합니다.
- **실수:** 순번을 1,2,3으로만 붙여서 파일이 1,10,11,2 순서로 뒤섞임
  - **교정:** AI에게 '자릿수를 맞춰 001,002,010으로 만들어 달라'고 요청해 정렬이 항상 올바르게 유지되도록 합니다.
- **실수:** AI가 준 코드를 이해 못한 채 실행하고, 오류가 나면 포기함
  - **교정:** 오류 메시지 전체를 그대로 복사해 AI에게 '이 오류가 났어, 초보자용으로 고쳐줘'라고 붙여넣으면 대부분 즉시 해결됩니다.

## 완료 체크리스트

- 자동화 규칙을 '무엇을 → 어떻게' 한 문장으로 적었다
- 작업 폴더의 복사본을 만들고 그 안에서만 테스트했다
- AI가 준 스크립트로 복사본에서 실제 결과를 눈으로 확인했다
- 미리보기(dry-run)로 중복·누락 파일이 없는지 점검했다
- 검증된 스크립트를 원본에 적용하고 재사용하도록 저장했다

## 도구

- ChatGPT (https://chat.openai.com) — 규칙을 말하면 스크립트를 대신 작성
- Claude (https://claude.ai) — 긴 파일 목록·오류 붙여넣고 스크립트 수정
- PowerShell (윈도우 기본 내장) — 윈도우에서 스크립트 실행
- 터미널/Automator (macOS 기본 내장) — 맥에서 스크립트 실행
