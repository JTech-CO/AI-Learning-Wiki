_자동화 데이터의 그릇: 리스트/딕셔너리/집합을 만들고 순회·가공하기._

:::note[학습 목표]
- 여러 데이터를 리스트/딕셔너리/집합에 담고, for문으로 순회하며 원하는 값만 골라내거나 가공할 수 있다.
:::

> 자동화로 모은 데이터(고객 100명, 상품 목록, 매출 숫자)를 하나씩 손으로 다루면 평생 걸린다. 리스트·딕셔너리·집합은 그 데이터를 담고 한 번에 처리하는 '그릇'이다.

## 이 레슨에서 만드는 것

여러 데이터를 리스트/딕셔너리/집합에 담고, for문으로 순회하며 원하는 값만 골라내거나 가공할 수 있다.

## 핵심 개념

세 가지는 물건을 담는 서로 다른 상자다. 리스트[]는 '번호표 붙은 사물함'이라 순서대로 줄 세운다(0번, 1번, 2번...). 딕셔너리{}는 '이름표 붙은 서랍'이라 '이름'으로 물건을 찾는다('가격'→3000). 집합set은 '중복 못 들어가는 방'이라 같은 게 여럿이면 하나만 남는다. for문은 상자 속 물건을 하나씩 꺼내 보는 '손'이다. 이 그릇들에 데이터를 담아야 컴퓨터가 한 번에 처리한다.

### 왜 작동하는가

컴퓨터는 리스트·딕셔너리·집합이라는 그릇에 데이터를 담아두면, for문으로 눈 깜짝할 새 수백 번을 반복해서 훑어줍니다. 그래서 당신은 데이터를 어떤 그릇에 담을지만 정하면, 하나씩 확인하고 골라내는 지겨운 반복 작업은 컴퓨터가 대신 해줍니다.

## 👀 따라하기 예시

카페 사장님이 방문 고객 명단(이름+나이)을 정리해서 성인 고객만 골라내고 싶어하는 상황. 제가 먼저 해볼게요, 눈으로 따라오세요.

### 1. ① 고객 데이터를 딕셔너리 리스트로 담기

**실제 결과**

```text
customers = [{'이름':'박서준', '나이':22}, {'이름':'김하늘', '나이':16}, {'이름':'이도윤', '나이':31}]
```

> 엑셀 표 한 줄(한 명)을 딕셔너리 하나로, 표 전체를 리스트로 담으면 컴퓨터가 표를 이해합니다.

### 2. ② for문으로 한 명씩 훑어보기

**실제 결과**

```text
for c in customers:\n    print(c['이름'], c['나이'])\n# 박서준 22 / 김하늘 16 / 이도윤 31
```

> 손으로 하나씩 열어보는 대신 for가 대신 꺼내 보여줍니다.

### 3. ③ 조건으로 성인만 골라내기

**실제 결과**

```text
for c in customers:\n    if c['나이'] >= 20:\n        print(c['이름'])\n# 박서준 / 이도윤
```

> if 조건 한 줄만 추가하면 원하는 것만 걸러집니다 — 이게 바로 아하 포인트!

### 4. ④ set으로 방문 도시 중복 제거하기

**실제 결과**

```text
cities = ['서울', '부산', '서울']\nprint(set(cities))  # {'서울', '부산'}
```

> 중복 없는 방(set)에 넣으면 자동으로 하나만 남습니다.

### 완성 결과

성인 고객 이름만 뽑힌 결과. 좋은 결과의 기준: ① 원하는 조건에 맞는 값만 출력됨 ② 오타·KeyError 없이 실행됨 ③ for/if 아래 들여쓰기가 4칸으로 맞춰짐

## 단계별 따라하기

### 리스트 만들고 하나씩 순회하기

대괄호 [ ]로 만들고 쉼표로 구분. for 문으로 안의 값을 하나씩 꺼낸다. Google Colab(colab.research.google.com) 새 노트에 코드 붙이고 좌측 ▶ 실행.

**복사·실행 예시**

```text
fruits = ['사과', '바나나', '귤']
for f in fruits:
    print(f)
# 사과 / 바나나 / 귤 이 한 줄씩 출력
```

### 딕셔너리로 이름표 붙여 저장하기

중괄호 { } 안에 '키':값 형태로 짝지어 넣는다. 키(이름표)로 값을 꺼낸다.

**복사·실행 예시**

```text
product = {'이름':'우유', '가격':2500}
print(product['가격'])  # 2500
product['재고'] = 10  # 새 항목 추가
```

### 집합으로 중복 제거하기

set()으로 리스트를 감싸면 같은 값이 자동으로 하나만 남는다. 방문자 명단 중복 정리에 유용.

**복사·실행 예시**

```text
names = ['철수','영희','철수','민수']
unique = set(names)
print(unique)  # {'철수','영희','민수'}
```

### 딕셔너리 여러 개를 리스트에 담아 표처럼 다루기

딕셔너리(한 줄=한 명)를 리스트에 넣으면 엑셀 표가 된다. for로 순회하며 특정 조건만 골라낸다.

**복사·실행 예시**

```text
people = [{'이름':'김','나이':25},{'이름':'이','나이':17}]
for p in people:
    if p['나이'] >= 20:
        print(p['이름'])  # 김 (성인만)
```

### 막힐 때 AI에게 코드 설명 요청하기

에러가 나면 코드 전체+에러 메시지를 복사해 ChatGPT에 붙인다. 아래 템플릿 사용.

**복사·실행 예시**

```text
KeyError: '가격' → 딕셔너리에 '가격' 키가 없다는 뜻. 오타 확인 후 AI에 질문
```

## 흔한 실수와 교정
- **실수:** 리스트를 [1,2,3)처럼 괄호를 다르게 닫음
  - **교정:** 여는 [ 와 닫는 ] 를 짝 맞춰라. 딕셔너리는 { }, 함수 호출은 ( )로 서로 다르다.
- **실수:** 딕셔너리에서 없는 키를 부르면 KeyError
  - **교정:** product['색깔']이 없으면 에러. product.get('색깔')을 쓰면 없어도 None을 돌려줘 안전하다.
- **실수:** 리스트 첫 번째를 fruits[1]로 찾음
  - **교정:** 번호는 0부터 시작한다. 첫 번째는 fruits[0], 두 번째가 fruits[1]이다.
- **실수:** for문 안 코드에 들여쓰기(띄어쓰기)를 안 함
  - **교정:** for 줄 다음은 반드시 스페이스 4칸(또는 Tab) 들여써야 반복 대상으로 인식된다.

## 완료 체크리스트

- 리스트 [ ]를 만들고 for문으로 하나씩 출력했다
- 딕셔너리 { }에서 키로 값을 꺼내봤다
- set()으로 중복을 제거해봤다
- 딕셔너리 리스트에서 조건에 맞는 항목만 골라냈다
- 에러가 나면 코드+에러를 AI에 붙여 물어봤다
