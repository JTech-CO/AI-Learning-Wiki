_명령을 받고 응답하는 텔레그램 봇으로 대화형 자동화 구현._

:::note[학습 목표]
- 이 레슨이 끝나면, 내가 보낸 명령어에 원하는 대로 응답하는 텔레그램 봇을 만들어 실제로 대화할 수 있습니다.
:::

> "오늘 환율 알려줘" 한마디에 즉시 답하는 나만의 봇, 서버도 없이 20분이면 만듭니다. 카톡 대신 텔레그램인 이유는 딱 하나 — 봇 API가 무료이고 승인 절차가 없어서, 지금 당장 코드 없이도 시작할 수 있기 때문입니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 내가 보낸 명령어에 원하는 대로 응답하는 텔레그램 봇을 만들어 실제로 대화할 수 있습니다.

## 핵심 개념

텔레그램 봇은 '전화 받는 직원'과 같습니다. 사용자가 /명령어 를 보내면(입력), 봇 프로그램이 그 뜻을 알아듣고(처리), 답장을 보냅니다(출력). 이 세 단계를 이어주는 것이 텔레그램이 제공하는 무료 Bot API이고, @BotFather 라는 공식 봇에게 말 몇 마디만 하면 나만의 봇 계정과 '토큰(비밀 열쇠)'을 즉시 발급받습니다. 처음엔 코드 한 줄 없이 자동화 도구(Make)로 연결하고, 익숙해지면 파이썬 몇 줄로 직접 로직을 넣으면 됩니다.

### 왜 작동하는가

AI는 이미 수만 개의 파이썬 챗봇 코드를 학습해서, "이런 명령어에 이렇게 답하는 봇"이라고 말만 하면 그 뼈대 코드를 곧바로 만들어냅니다. 그래서 당신은 "무엇을 원하는지"만 정하면 되고, ApplicationBuilder니 핸들러니 하는 문법은 AI가 대신 써줍니다. 즉, 봇 기획자는 당신이고 타이핑은 AI가 하는 셈이죠.

## 👀 따라하기 예시

"/오늘할일" 이라는 명령어를 보내면 미리 정해둔 할일 목록을 답장해주는 봇을 만드는 상황 — 제가 먼저 처음부터 끝까지 보여드릴게요, 눈으로 따라오세요.

### 1. ① AI에게 "/오늘할일 명령어에 할일 3개를 답장하는 python-telegram-bot 핸들러 코드를 짜줘" 라고 요청

**실제 결과**

```text
async def todo(update, context):\n    await update.message.reply_text("오늘 할일: 1)운동 2)독서 3)정리")\napplication.add_handler(CommandHandler("오늘할일", todo))
```

> 명령어 이름과 답장 내용만 말했는데, AI가 async 문법·핸들러 등록까지 통째로 채워줍니다 — 이게 바로 아하 포인트입니다.

### 2. ② 코드를 Replit의 TOKEN 아래에 붙여넣고 Run

**실제 결과**

```text
콘솔에 "봇 실행 중..." 로그 출력
```

> 내 토큰이 이미 코드 위쪽에 들어있으니, 붙여넣기만 하면 바로 연결됩니다.

### 3. ③ 텔레그램에서 실제로 /오늘할일 전송

**실제 결과**

```text
봇: 오늘 할일: 1)운동 2)독서 3)정리
```

> 내가 상상한 대화가 화면에 그대로 뜨는 순간, "이게 진짜 되네" 하는 확신이 생깁니다.

### 4. ④ "할일이 없으면 다른 문구를 보여줘" 라고 AI에게 조건 추가 요청

**실제 결과**

```text
if not todos:\n    await update.message.reply_text("오늘은 할일이 없어요, 푹 쉬세요!")\nelse:\n    ...(기존 응답)
```

> 한 줄 요청만 더해도 AI가 조건문(if/else)까지 알아서 붙여줍니다 — 코드를 몰라도 로직은 내가 설계하는 겁니다.

### 완성 결과

"/오늘할일" 명령어에 할일 목록으로 답장하는 실제 작동 봇 코드. 좋은 결과의 기준: (1) 명령어 전송 시 오차 없이 즉시 응답, (2) 조건(할일 없음 등)에 따라 다른 문구 출력, (3) 토큰이 코드 안에 노출되지 않고 안전하게 보관됨.

## 단계별 따라하기

### 1단계 — BotFather로 봇 만들기 (5분) 🙋나

텔레그램 앱에서 검색창에 @BotFather 를 찾아 대화를 열고 /newbot 을 보냅니다. 봇 이름(아무거나)과 사용자명(반드시 bot 으로 끝나야 함)을 차례로 입력합니다. 마지막에 나오는 긴 문자열이 '토큰'이며, 이건 비밀번호처럼 절대 공개 금지입니다.

**복사·실행 예시**

```text
/newbot → 이름: 내환율봇 → 사용자명: my_rate_helper_bot → 발급 토큰: 7891234567:AAH...(메모장에 안전하게 복사)
```

### 2단계 — 봇과 첫 인사하고 chat_id 확인 (3분) 🙋나

방금 만든 봇 링크(t.me/사용자명)를 눌러 대화방을 열고 Start 를 누른 뒤 아무 말이나 보냅니다. 그다음 브라우저에서 아래 주소를 열어 내 chat_id 를 찾습니다: https://api.telegram.org/bot토큰/getUpdates

**복사·실행 예시**

```text
화면에 나온 JSON 중 "chat":{"id":123456789 ... 여기 123456789 가 내 chat_id
```

### 3단계 — 명령·응답 로직 설계 (5분) 🤖A

코드를 짜기 전에 봇이 어떤 명령에 어떻게 답할지 표로 정리합니다. AI에게 아래 템플릿1을 붙여넣어 명령어 목록과 응답 예시를 뽑아달라고 시킵니다.

**복사·실행 예시**

```text
/start → 환영 인사, /help → 사용법, /환율 → 오늘 원달러 환율 안내 문구
```

### 4단계 — 파이썬으로 봇 코드 받기 (5분) 🤖A

설치 없이 브라우저에서 도는 Replit(replit.com)에 새 Python 프로젝트를 만들고, 템플릿2로 AI에게 python-telegram-bot 라이브러리 기반 코드를 요청해 붙여넣습니다. 코드 맨 위 TOKEN 자리에 내 토큰을 넣습니다.

**복사·실행 예시**

```text
application = ApplicationBuilder().token("내토큰").build() 형태로 시작하는 20줄짜리 코드
```

### 5단계 — 실행하고 실제 대화 테스트 (4분) 🤝함께

Replit에서 Run 을 누르면 콘솔에 '봇 실행 중' 로그가 뜹니다. 텔레그램으로 돌아가 /start, /help, 내가 만든 명령어를 하나씩 보내 답장이 오는지 확인합니다. 답이 없으면 콘솔의 빨간 오류 줄을 복사해 AI에게 물어봅니다.

**복사·실행 예시**

```text
나: /환율 → 봇: 오늘 원/달러 환율은 약 1,300원입니다 (예시 응답)
```

### 6단계 — 자동 응답 규칙 1개 추가 (3분) 🤖A

명령어(/)가 아닌 일반 문장에도 반응하도록 키워드 규칙 하나를 넣습니다. 템플릿3으로 '안녕' 이 들어오면 인사하는 핸들러를 AI에게 추가 요청하고 코드에 붙여 다시 Run 합니다.

**복사·실행 예시**

```text
나: 안녕 봇아 → 봇: 안녕하세요! 무엇을 도와드릴까요?
```

## 흔한 실수와 교정
- **실수:** 토큰을 채팅이나 공개 코드에 그대로 노출한다.
  - **교정:** 토큰은 비밀번호다. 실수로 공개했다면 BotFather에서 /revoke 로 즉시 재발급받아 이전 토큰을 무효화한다.
- **실수:** 봇 사용자명을 bot 으로 끝내지 않아 BotFather가 계속 거절한다.
  - **교정:** 사용자명은 반드시 소문자/숫자/밑줄로 끝을 '...bot' 형태로 만든다. 예: my_rate_helper_bot.
- **실수:** Run 을 멈추면 봇이 응답하지 않는데 '고장 났다'고 착각한다.
  - **교정:** 봇 코드는 실행 중일 때만 대답한다. Replit 창을 닫으면 멈춘다. 항상 켜두려면 Replit의 Always On(유료) 또는 클라우드 배포가 필요하다는 점을 기억한다.

## 완료 체크리스트

- @BotFather에서 /newbot 으로 봇을 만들고 토큰을 안전하게 저장했다
- 봇과 대화를 시작(Start)하고 내 chat_id 를 확인했다
- 명령어와 응답을 표로 설계했다
- Replit에서 봇 코드를 실행해 '실행 중' 로그를 확인했다
- 텔레그램에서 /start·/help 및 내 명령어에 실제 답장을 받았다

## 도구

- 텔레그램 (telegram.org) — 봇을 만들고 대화하는 메신저 앱
- @BotFather (t.me/BotFather) — 봇 생성·토큰 발급 공식 봇
- Replit (replit.com) — 설치 없이 브라우저에서 파이썬 봇 실행
- python-telegram-bot (python-telegram-bot.org) — 봇 코드용 무료 파이썬 라이브러리

## 참고 답안

AI에게 "고마워 라는 단어가 포함된 메시지가 오면 정해진 문구로 답하는 핸들러를 만들어줘" 라고 요청 → 아래와 같은 코드를 받게 됩니다.\nasync def thanks(update, context):\n    if "고마워" in update.message.text:\n        await update.message.reply_text("천만에요! 언제든 불러주세요 :)")\napplication.add_handler(MessageHandler(filters.TEXT, thanks))\n그 다음 Replit에서 Run 후 텔레그램에 "고마워" 를 보내 실제로 답장이 오는지 확인합니다.
