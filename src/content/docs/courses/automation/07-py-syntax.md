_자동화에 필요한 최소 문법: 변수, 문자열·숫자·불리언, 기본 연산과 출력._

:::note[학습 목표]
- 이 레슨이 끝나면, 변수에 값을 담고 문자열·숫자·불리언을 구분해 기본 연산 결과를 print로 출력하는 파이썬 코드를 직접 짜서 실행할 수 있습니다.
:::

> 매일 30분씩 하던 엑셀 정리, 사실은 코드 5줄이면 컴퓨터가 대신 해줍니다. 그 5줄을 이해하는 첫 열쇠가 바로 변수·자료형·연산입니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 변수에 값을 담고 문자열·숫자·불리언을 구분해 기본 연산 결과를 print로 출력하는 파이썬 코드를 직접 짜서 실행할 수 있습니다.

## 핵심 개념

변수는 값에 붙이는 '이름표'입니다. name = "봉이"처럼 =로 값을 담고, 나중에 그 이름을 부르면 담긴 값이 튀어나옵니다. 파이썬의 값에는 종류(자료형)가 있어서, 따옴표로 감싼 문자열(str), 숫자(int·float), 참/거짓을 나타내는 불리언(True·False)이 대표적입니다. 종류가 다르면 할 수 있는 연산도 달라집니다 — 숫자끼리는 더하기·곱하기, 문자열끼리는 이어붙이기가 됩니다. 이 세 가지 자료형과 =, +, print()만 알아도 자동화 스크립트의 90%는 읽고 고칠 수 있습니다.

### 왜 작동하는가

파이썬은 사람이 쓴 문장을 그대로 이해하지 못하고, "이름표(변수) = 값" 같은 아주 단순한 규칙만 압니다. 그래서 우리가 규칙에 맞게 name = "봉이"처럼 적어주면, 컴퓨터는 그 이름표를 기억해뒀다가 부를 때마다 값을 꺼내줍니다. 즉 당신이 할 일은 "이름표 붙이고 종류 맞춰 연산 걸기"뿐이고, 나머지 계산과 출력은 파이썬이 대신 해줍니다.

## 👀 따라하기 예시

편의점 알바 시급 계산기를 만드는 상황이에요. 제가 먼저 처음부터 끝까지 만들어볼게요, 눈으로 따라오세요.

### 1. ① 이름표부터 답니다: wage = 10000, hours = 6

**실제 결과**

```text
wage = 10000\nhours = 6
```

> 숫자는 따옴표 없이! 나중에 계산에 쓸 값이니까요.

### 2. ② 종류를 헷갈릴 때 type()으로 확인

**실제 결과**

```text
print(type(wage))\n# <class 'int'>
```

> 자료형을 모르고 연산하면 꼭 한 번은 에러가 나요. 확인하는 습관이 아하 포인트!

### 3. ③ 숫자끼리 연산해서 결과 만들기

**실제 결과**

```text
pay = wage * hours\nprint(pay)\n# 60000
```

> 숫자(int)끼리는 * / + - 가 바로 됩니다. 종류가 같아야 연산이 통해요.

### 4. ④ f-string으로 문장에 자연스럽게 끼워 출력

**실제 결과**

```text
print(f"오늘 급여는 {pay}원입니다.")\n# 오늘 급여는 60000원입니다.
```

> str(pay)로 일일이 바꾸는 대신 f"{pay}"면 파이썬이 알아서 문자열로 바꿔줘요.

### 완성 결과

실행하면 "오늘 급여는 60000원입니다."가 정확히 찍히는 짧은 파이썬 코드. 좋은 결과의 기준: (1) 에러 없이 실행됨 (2) 숫자·문자열이 섞인 곳은 f-string이나 str()로 처리됨 (3) 변수 이름만 봐도 뭘 담았는지 알 수 있음.

## 단계별 따라하기

### 1단계 — 실행 환경 열기 (3분)

브라우저에서 replit.com 또는 Google Colab(colab.research.google.com)에 접속해 새 Python 노트/파일을 만듭니다. 설치가 전혀 필요 없고, 코드를 적고 실행(▶) 버튼만 누르면 됩니다. 🙋나

**복사·실행 예시**

```text
Colab에서 '새 노트' 클릭 → 빈 셀에 print("안녕, 파이썬") 입력 → Shift+Enter로 실행 → 아래에 '안녕, 파이썬' 출력
```

### 2단계 — 변수에 값 담기 (5분)

= 기호로 이름표에 값을 붙입니다. 왼쪽이 이름, 오른쪽이 값입니다. 문자열은 반드시 따옴표로 감싸고, 숫자는 따옴표 없이 씁니다. 🙋나

**복사·실행 예시**

```text
name = "봉이"
age = 14
height = 158.5
각각 이름표에 문자열, 정수, 실수가 담깁니다.
```

### 3단계 — 자료형 확인하기 (4분)

type() 안에 변수를 넣어 실행하면 그 값의 종류가 나옵니다. 헷갈릴 때마다 type()으로 확인하는 습관을 들이세요. 🙋나

**복사·실행 예시**

```text
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
print(type(height)) # <class 'float'>
```

### 4단계 — 숫자·문자열 연산해보기 (6분)

숫자 변수끼리는 + - * / 로 계산하고, 문자열끼리는 +로 이어붙입니다. 서로 다른 종류를 섞으면 오류가 나니, 숫자를 문자열로 바꿀 땐 str()을 씁니다. 🙋나

**복사·실행 예시**

```text
total = 3 + 4 * 2      # 11 (곱하기 먼저)
greeting = "안녕, " + name  # '안녕, 봉이'
msg = name + "는 " + str(age) + "살"  # '봉이는 14살'
```

### 5단계 — 불리언과 비교 (5분)

==(같다), >(크다), <(작다) 같은 비교는 True 또는 False를 돌려줍니다. 이 참/거짓 값이 나중에 자동화의 '조건 판단'의 재료가 됩니다. 🙋나

**복사·실행 예시**

```text
is_teen = age >= 13   # True
print(is_teen)
print(10 == 10, 5 > 8) # True False
```

### 6단계 — 결과를 보기 좋게 출력 (4분)

f-string을 쓰면 문자열 안에 {변수}를 넣어 값을 자동으로 끼워 넣습니다. str() 변환 없이 깔끔하게 출력됩니다. 완성한 코드를 AI에게 검토받아 보세요. 🤝함께

**복사·실행 예시**

```text
print(f"{name}는 {age}살이고 키는 {height}cm입니다.")
# 봉이는 14살이고 키는 158.5cm입니다.
```

## 흔한 실수와 교정
- **실수:** 문자열에 따옴표를 안 붙여서 name = 봉이 라고 쓴다.
  - **교정:** 문자열은 반드시 따옴표로 감싼다: name = "봉이". 따옴표가 없으면 파이썬은 그것을 '변수 이름'으로 착각해 NameError를 낸다.
- **실수:** 숫자와 문자열을 그냥 + 로 붙여 age + "살" 처럼 써서 TypeError가 난다.
  - **교정:** 숫자를 문자열로 바꿔서 붙인다: str(age) + "살". 또는 f-string으로 f"{age}살" 처럼 쓴다.
- **실수:** 값 비교(같은가?)에 = 하나를 써서 age = 14 라고 쓴다.
  - **교정:** 할당은 =, 비교는 ==. '같은지 확인'은 반드시 == 두 개를 쓴다: age == 14.
