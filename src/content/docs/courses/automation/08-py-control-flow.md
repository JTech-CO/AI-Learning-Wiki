_조건 분기와 반복으로 "여러 개를 자동 처리"하는 자동화의 핵심 제어 흐름._

:::note[학습 목표]
- 이 레슨이 끝나면, 리스트 안의 여러 데이터를 for로 하나씩 돌면서 if로 조건에 맞는 것만 골라내는 파이썬 자동화 스크립트를 직접 짜서 돌릴 수 있습니다.
:::

> 엑셀 300줄을 손으로 하나씩 검사하다 눈이 빠질 것 같았던 적 있나요? 조건(if)과 반복(for)을 알면, 컴퓨터가 "300줄이든 30만 줄이든" 똑같이 눈 깜짝할 사이에 처리합니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 리스트 안의 여러 데이터를 for로 하나씩 돌면서 if로 조건에 맞는 것만 골라내는 파이썬 자동화 스크립트를 직접 짜서 돌릴 수 있습니다.

## 핵심 개념

자동화의 핵심은 딱 두 가지입니다. "여러 개를 하나씩 훑는 것(반복, for/while)"과 "상황에 따라 다르게 처리하는 것(조건, if/elif/else)". 사람이 엑셀에서 눈으로 훑으며 형광펜 칠하는 일을 코드로 옮기면, for가 커서를 한 줄씩 내리고 if가 형광펜을 칠할지 말지 결정합니다. 반복 횟수를 미리 아는 상황(리스트 전체 순회 등)은 for, 조건이 만족될 때까지 끝을 모르고 도는 상황(입력 대기, 재시도 등)은 while을 씁니다. 이 셋의 조합만으로 성적 분류, 지출 필터링, 대량 파일 이름 바꾸기 같은 실무 반복작업의 90%를 없앨 수 있습니다.

### 왜 작동하는가

컴퓨터는 지치지 않고 같은 동작을 초 단위로 반복할 수 있어요. for가 리스트를 한 줄씩 넘기는 동안, if가 매번 "이 값이 조건에 맞나?"를 판단하죠. 그래서 사람이 300줄을 눈으로 훑는 대신, 이 원리로 짠 코드는 30만 줄도 똑같은 속도로 훑어줍니다.

## 👀 따라하기 예시

반 학생 30명의 시험 점수 리스트가 있어요. 합격자만 골라내고 등급까지 매겨야 하는데, 제가 먼저 처음부터 끝까지 코드를 짜볼게요. 눈으로 따라오세요.

### 1. ① 리스트를 만들고 for로 한 줄씩 꺼내 확인

**실제 결과**

```text
scores = [88, 42, 95, 60]\nfor s in scores:\n    print("점수:", s)\n\n# 출력\n점수: 88\n점수: 42\n점수: 95\n점수: 60
```

> 먼저 데이터가 제대로 들어왔는지, for가 한 바퀴씩 정확히 도는지부터 눈으로 확인하고 시작해요.

### 2. ② if/else로 합격·불합격 붙이기

**실제 결과**

```text
for s in scores:\n    if s >= 60:\n        print(s, "합격")\n    else:\n        print(s, "불합격")\n\n# 출력\n88 합격\n42 불합격\n95 합격\n60 합격
```

> 조건문 하나만 추가했을 뿐인데, 전체 데이터가 자동으로 두 그룹으로 갈라졌어요. 이게 반복+조건의 힘입니다.

### 3. ③ elif로 A/B/F 등급까지 세분화

**실제 결과**

```text
for s in scores:\n    if s >= 90:\n        grade = "A"\n    elif s >= 60:\n        grade = "B"\n    else:\n        grade = "F"\n    print(s, grade)\n\n# 출력\n88 B\n42 F\n95 A\n60 B
```

> 위에서부터 순서대로 검사하다 처음 맞는 곳에서 멈추기 때문에, 높은 기준(90)을 맨 위에 둬야 꼬이지 않아요.

### 4. ④ AI에게 "내 진짜 파일로 확장해줘" 요청

**실제 결과**

```text
나: "이 코드를 내 엑셀 파일(성적.xlsx)의 점수 열에 적용하고, 합격자만 새 파일로 저장해줘"\n\nAI: "pandas로 엑셀을 읽고, 같은 for+if 로직을 적용한 뒤 합격자만 골라 새 파일로 저장하는 코드입니다.\nimport pandas as pd\ndf = pd.read_excel("성적.xlsx")\npassed = []\nfor s in df["점수"]:\n    if s >= 60:\n        passed.append(s)\npd.DataFrame(passed).to_excel("합격자.xlsx")"
```

> 방금 배운 원리(for로 훑고 if로 판단)는 그대로인데, AI가 실제 파일 구조(엑셀 열 이름 등)에 맞게 코드를 확장해줍니다. 원리는 내가 알고, 세부 연결은 AI와 함께.

### 완성 결과

합격자 리스트와 등급별 분류가 자동으로 출력되는 스크립트. 좋은 결과의 기준: (1) 들여쓰기 에러 없이 한 번에 실행됨 (2) 60점 경계값이 정확히 분류됨 (3) 등급 판정 기준이 높은 값부터 순서대로 놓여 있음.


### 2단계 — for로 리스트 하나씩 훑기 (5분)

점수 리스트를 만들고 for 문으로 한 개씩 꺼내 출력해 봅니다. 콜론(:) 뒤 줄바꿈, 그리고 반드시 스페이스 4칸 들여쓰기가 반복 블록임을 기억하세요. 🙋나

**복사·실행 예시**

```text
scores = [88, 42, 95, 60]\nfor s in scores:\n    print("점수:", s)
```

### 3단계 — if로 조건 분기 넣기 (6분)

for 안에 if/else를 넣어 60점 이상이면 '합격', 아니면 '불합격'을 붙여 출력합니다. == 는 비교, = 는 대입이라는 차이를 꼭 구분하세요. 🙋나

**복사·실행 예시**

```text
for s in scores:\n    if s >= 60:\n        print(s, "합격")\n    else:\n        print(s, "불합격")
```

### 4단계 — elif로 등급 3단 분류 (6분)

조건이 3개 이상이면 elif를 씁니다. 위에서부터 순서대로 검사하다 처음 맞는 곳에서 멈추므로, 높은 기준(90)을 맨 위에 두는 것이 핵심입니다. 🙋나

**복사·실행 예시**

```text
for s in scores:\n    if s >= 90:\n        grade = "A"\n    elif s >= 60:\n        grade = "B"\n    else:\n        grade = "F"\n    print(s, grade)
```

### 5단계 — 조건에 맞는 것만 모으기 (필터, 5분)

빈 리스트를 만들고 for로 돌며 if 조건을 통과한 값만 append로 담습니다. 이게 실무에서 '특정 조건 데이터만 추출'의 원형입니다. 🙋나

**복사·실행 예시**

```text
passed = []\nfor s in scores:\n    if s >= 60:\n        passed.append(s)\nprint("합격자:", passed)  # [88, 95, 60]
```

### 6단계 — while로 끝을 모르는 반복 + AI에게 확장 요청 (7분)

목표 금액을 채울 때까지 도는 while 예제를 실행해 무한루프를 피하는 '멈추는 조건'을 체감합니다. 그다음 만든 코드를 AI에 붙여 실무 상황(내 엑셀 파일)으로 바꿔달라고 요청합니다. 🤝함께

**복사·실행 예시**

```text
total = 0\ncount = 0\nwhile total < 100:\n    total += 30\n    count += 1\nprint(count, "번 만에", total)  # 4 번 만에 120
```

## 흔한 실수와 교정
- **실수:** 들여쓰기를 안 하거나 스페이스와 탭을 섞어 IndentationError가 난다.
  - **교정:** if/for/while 콜론(:) 다음 줄은 반드시 스페이스 4칸으로 들여쓰기하고, 한 파일 안에서 탭과 스페이스를 섞지 마세요. 에디터의 '탭을 스페이스로' 옵션을 켜면 안전합니다.
- **실수:** 조건 비교에 = 하나를 써서(if s = 60) SyntaxError가 난다.
  - **교정:** 값을 넣는 대입은 =, 같은지 비교하는 것은 == 로 두 개입니다. 조건문 안에서는 항상 ==, >=, <=, != 를 쓰세요.
- **실수:** while의 멈추는 조건을 안 바꿔서 무한루프에 빠진다.
  - **교정:** while 블록 안에서 조건에 쓰인 변수(예 total, count)를 매번 증가시켜 언젠가 조건이 거짓이 되게 하세요. 실행이 안 멈추면 Colab은 정지 버튼, 터미널은 Ctrl+C로 중단합니다.
