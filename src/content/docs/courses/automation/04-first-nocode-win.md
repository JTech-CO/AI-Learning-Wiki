_Make/Zapier 같은 노코드로 실제 동작하는 첫 자동화(예: 폼→시트→알림)를 손으로 만들어 성공 경험._

:::note[학습 목표]
- 이 레슨이 끝나면, 노코드 도구(Make 또는 Zapier)로 「폼 제출 → 스프레드시트 자동 기록 → 알림」이 실제로 작동하는 자동화 1개를 손으로 만들어 테스트까지 마칠 수 있습니다.
:::

> 코드 한 줄 없이 30분 만에 「진짜 돌아가는」 자동화를 하나 만들어봅니다. 첫 성공의 짜릿함이 자동화 학습의 연료예요.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 노코드 도구(Make 또는 Zapier)로 「폼 제출 → 스프레드시트 자동 기록 → 알림」이 실제로 작동하는 자동화 1개를 손으로 만들어 테스트까지 마칠 수 있습니다.

## 핵심 개념

노코드 자동화 도구(Zapier, Make)는 트리거→액션을 코딩 없이 블록을 잇듯 연결하게 해준다. 수천 개 앱(구글폼·시트·슬랙·지메일 등)이 미리 연결돼 있어, 우리는 「무엇이 오면(트리거) 무엇을 한다(액션)」만 설정하면 된다. 첫 자동화의 목표는 거창함이 아니라 「끝까지 작동하는 것 하나」를 완성해 흐름 전체를 몸으로 아는 것이다.

### 왜 작동하는가

노코드 도구(Make, Zapier)는 「트리거가 오면 액션을 실행」하는 연결고리를 이미 수천 개 만들어 놨어요. 구글폼, 시트, 지메일, 슬랙 같은 앱들이 서로 대화하는 법을 미리 배워둔 셈이죠. 그래서 당신은 「무엇이 오면(트리거) 무엇을 할지(액션)」만 정해주면, 코드는 도구가 대신 써줍니다.

## 👀 따라하기 예시

「문의 접수 폼」을 만들어서 제출되면 자동으로 스프레드시트에 기록되고 이메일 알림까지 오게 만드는 상황이에요. 제가 먼저 Make.com에서 처음부터 끝까지 해볼게요, 눈으로 따라오세요!

### 1. ① Make에서 새 시나리오 생성 → 첫 모듈로 Google Forms [Watch Responses] 추가

**실제 결과**

```text
모듈 아이콘이 화면에 뜨고, 계정 연결 후 [문의 접수] 폼이 드롭다운에 나타남 → 선택 완료
```

> 이게 바로 「트리거」예요. "폼에 응답이 오면"이라는 감시 카메라를 세워두는 거죠.

### 2. ② 두 번째 모듈로 Google Sheets [Add a Row] 연결

**실제 결과**

```text
시트의 열 목록(이름, 메시지, 제출시각)이 화면에 나오고, 각 열 옆에 폼 데이터를 끌어다 놓는 매핑 슬롯이 생김
```

> 트리거에서 받은 데이터를 어디로 보낼지 "주소"를 정해주는 단계예요. 매핑을 안 하면 빈 행만 생겨요.

### 3. ③ 세 번째 모듈로 Gmail [Send an Email] 추가, 제목에 {{이름}} 변수 삽입

**실제 결과**

```text
제목란에 "새 문의 도착: {{이름}}"이 입력되고, 실행 시 실제로는 "새 문의 도착: 홍길동"으로 자동 치환됨
```

> {{ }} 변수는 앞 단계에서 온 실제 값을 그대로 꽂아주는 자리예요. 이래서 매번 다른 이름이 알림에 찍히는 거죠.

### 4. ④ [Run once] 클릭 후 폼에 테스트 응답 「홍길동 / 견적 문의합니다」 제출

**실제 결과**

```text
몇 초 뒤 시트에 새 행 1개 생성(홍길동, 견적 문의합니다, 타임스탬프) + 메일함에 "새 문의 도착: 홍길동" 알림 도착
```

> 켜기 전에 진짜 데이터 1건으로 눈으로 확인하는 게 핵심이에요. 여기서 안 되면 매핑을 고치면 됩니다.

### 완성 결과

완성물은 「폼 제출 → 시트 자동 기록 → 이메일 알림」까지 실제로 작동하는 시나리오 1개예요. 좋은 결과의 기준: (1) 테스트 제출 시 시트에 빈 칸 없이 행이 생겼는가, (2) 알림 메일이 실제 이름으로 도착했는가, (3) Run once가 아닌 자동 실행(ON)으로 전환해도 그대로 작동하는가.

## 단계별 따라하기

### 1단계 — 도구 계정 만들기 (5분)

make.com 또는 zapier.com에 무료 가입한다(구글 계정으로 바로 가능). 둘 다 무료 플랜으로 이 레슨은 충분하다. Make가 시각적 흐름이 직관적이라 처음엔 Make를 추천.

**복사·실행 예시**

```text
make.com → Sign up → 구글로 가입 → 대시보드에서 [Create a new scenario] 버튼 확인
```

### 2단계 — 재료 준비: 구글폼 + 시트 (5분)

구글폼(forms.google.com)으로 질문 2개짜리 폼(이름·메시지)을 만들고, 응답 탭에서 연결된 구글시트를 생성한다. 이 폼이 트리거, 시트가 액션 대상이 된다.

**복사·실행 예시**

```text
폼 제목 [문의 접수] / 질문: 이름(단답), 메시지(장문) / 응답 → 스프레드시트 만들기
```

### 3단계 — 트리거 연결하기 (7분)

Make에서 새 시나리오를 만들고 첫 모듈로 Google Forms의 [Watch Responses](새 응답 감시)를 고른다. 계정을 연결하고 방금 만든 폼을 선택한다. 이게 「폼 제출되면」 트리거다.

**복사·실행 예시**

```text
모듈 추가 → Google Forms → Watch Responses → 구글 계정 연결 → [문의 접수] 폼 선택
```

### 4단계 — 액션 연결하기 (7분)

두 번째 모듈로 Google Sheets의 [Add a Row](행 추가)를 잇는다. 방금 시트를 고르고, 폼에서 온 이름·메시지·타임스탬프를 각 열에 매핑(끌어다 연결)한다.

**복사·실행 예시**

```text
모듈 추가 → Google Sheets → Add a Row → 시트 선택 → 열1=이름, 열2=메시지, 열3=제출시각 매핑
```

### 5단계 — (선택) 알림 액션 추가 (5분)

세 번째 모듈로 Gmail [Send an Email] 또는 Slack 알림을 붙여 「새 문의 도착: {이름}」을 나에게 보낸다. 자동화가 조용히 도는지 알 수 있는 눈이 된다.

**복사·실행 예시**

```text
Gmail → Send an Email → 받는사람=내 메일 → 제목=새 문의 도착: {{이름}}
```

### 6단계 — 실행·테스트·확인 (6분)

[Run once]를 누른 뒤 폼에 실제로 테스트 응답을 제출한다. 시트에 행이 자동으로 생기고 알림이 오면 성공. 안 되면 각 모듈의 빨간 표시를 눌러 오류 메시지를 읽고 매핑을 고친다.

**복사·실행 예시**

```text
Run once → 폼에 [홍길동/견적 문의합니다] 제출 → 몇 초 뒤 시트에 행 생성 + 메일 도착 확인 → 🎉
```

## 흔한 실수와 교정
- **실수:** 첫 자동화를 너무 복잡하게 잡기
  - **교정:** 트리거 1 + 액션 1의 최소 흐름부터. 작동을 확인한 뒤 모듈을 하나씩 늘려라.
- **실수:** 매핑(필드 연결)을 건너뛰고 실행
  - **교정:** 폼의 어떤 값이 시트의 어느 열로 갈지 끌어다 연결해야 한다. 매핑이 비면 빈 행이 생긴다.
- **실수:** 테스트 없이 켜두기
  - **교정:** 반드시 Run once로 진짜 데이터 한 건을 흘려보고 결과를 눈으로 확인한 뒤 켜라.

## 완료 체크리스트

- Make(또는 Zapier) 무료 계정을 만들었다
- 구글폼과 연결된 구글시트를 준비했다
- 트리거(폼 응답 감시)를 연결했다
- 액션(시트 행 추가)에 필드를 매핑했다
- 실제 테스트 제출로 시트 기록·알림이 작동함을 확인했다

## 도구

- Make (make.com) — 시각적 흐름의 노코드 자동화. 초보 추천
- Zapier (zapier.com) — 가장 많은 앱 연결. 대안으로 사용
- 구글폼·구글시트 — 이 실습의 트리거·저장 대상. 무료
- ChatGPT·Claude — 막힌 단계·오류 메시지를 물어 바로 뚫기
