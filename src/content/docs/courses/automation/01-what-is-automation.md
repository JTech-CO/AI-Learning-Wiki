_반복적이고 규칙적인 일을 사람 대신 프로그램이 자동 실행한다는 개념과, 자동화가 바꾸는 것/못 바꾸는 것._

:::note[학습 목표]
- 이 레슨이 끝나면, 내 일상·업무에서 '반복되고 규칙이 정해진 일' 3가지를 찾아내고, 그중 하나를 자동화 후보로 문서화할 수 있습니다.

> 매주 금요일마다 같은 보고서를 손으로 복사·붙여넣기 하며 30분을 쓰고 있나요? 그 30분은 사실 컴퓨터가 3초에 끝낼 수 있는 일입니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 내 일상·업무에서 '반복되고 규칙이 정해진 일' 3가지를 찾아내고, 그중 하나를 자동화 후보로 문서화할 수 있습니다.

## 핵심 개념

자동화란 '규칙이 정해진 반복 작업'을 사람 대신 프로그램이 알아서 실행하게 만드는 것입니다. 핵심 조건은 두 가지인데, (1) 여러 번 반복되고 (2) 매번 같은 규칙을 따른다는 점입니다. 예를 들어 '입금 문자가 오면 엑셀에 날짜·금액을 적는다'는 규칙이 분명해서 자동화가 잘 되지만, '고객이 화났을 때 어떻게 위로할지 판단한다'는 상황마다 달라서 자동화가 어렵습니다. 그래서 자동화는 사람의 '반복 노동'은 없애주지만 '판단·창의·공감'은 대체하지 못하며, 오히려 사람은 그 판단에 더 집중하게 됩니다.

### 왜 작동하는가

AI는 수많은 사람들이 이미 자동화해 둔 사례(엑셀 매크로, 스마트폰 단축어, 노코드 도구)를 학습해뒀습니다. 그래서 "이 반복 작업을 어떻게 자동화하나요?"라고 물으면, AI가 그 상황에 맞는 도구와 방법을 바로 매칭해줍니다. 즉 당신은 '무엇이 반복되고 규칙이 뭔지'만 정리하면, '어떤 도구로 어떻게'는 AI가 대신 찾아줍니다.

## 👀 따라하기 예시

문자로 들어오는 주문을 매번 손으로 엑셀에 옮겨 적느라 하루 30분씩 쓰는 상황입니다. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요.

### 1. ① 반복 작업 쏟아내기

**실제 결과**

```text
"매일 문자 주문 옮겨적기 / 매주 회의 요약 정리 / 매일 뉴스 3개 사이트 확인" 등 10개를 그냥 나열
```

> 다듬지 않고 먼저 다 꺼내야 진짜 반복 패턴이 보입니다.

### 2. ② 반복 O·규칙 O 채점하기

**실제 결과**

```text
"문자 주문 옮겨적기" → 반복 O(매일), 규칙 O(항상 이름·품목·수량) → 별표 / "SNS 글 감성 판단" → 규칙 X → 탈락
```

> 규칙이 매번 같아야만 자동화가 먹힙니다. 이 필터가 핵심입니다.

### 3. ③ AI에게 검증 프롬프트 던지기

**실제 결과**

```text
"문자로 온 주문(이름/품목/수량)을 자동으로 엑셀에 옮기고 싶어. 어떤 도구를 쓰면 될까?" → AI: "아이폰이면 단축어(Shortcuts) + 문자 자동화, 안드로이드면 Tasker나 Google Sheets 연동 앱을 추천합니다"
```

> 도구를 몰라도 상황만 설명하면 AI가 후보를 좁혀줍니다.

### 4. ④ 기계 몫 vs 사람 몫 나누기

**실제 결과**

```text
기계: 문자에서 이름·품목 추출 후 엑셀 입력 / 사람: 재고 없을 때 대체품 추천 여부 판단, 단골 인사 멘트
```

> 자동화는 반복만 가져가고 판단은 사람에게 남긴다는 걸 눈으로 확인하는 단계입니다.

### 완성 결과

"제목/걸리는시간/주기/자동화 규칙/사람 판단/쓸 도구" 6줄짜리 자동화 후보 문서 1장. 좋은 결과의 기준: (1) 규칙이 항상 같다고 말할 수 있을 것 (2) 사람이 남길 판단이 명확히 분리돼 있을 것 (3) 절약 시간이 숫자로 계산돼 있을 것.

## 단계별 따라하기

### 1단계 — 내 반복 작업 쏟아내기 (7분) 🙋나

종이나 메모장을 열고 '지난 일주일 동안 두 번 이상 한 일'을 떠오르는 대로 10개 이상 적는다. 업무, 공부, 집안일 다 포함한다. 잘 다듬지 말고 그냥 나열한다.

**복사·실행 예시**

```text
매일 출석부 엑셀에 이름 복붙 / 매주 주간회의 요약 정리 / 매일 같은 뉴스 3개 사이트 확인 / 문자로 온 주문을 노트에 옮겨적기 / 사진 파일 이름 날짜로 바꾸기
```

### 2단계 — 자동화 가능 여부 채점하기 (6분) 🙋나

1단계 목록 각 항목 옆에 두 가지를 O/X로 표시한다. ① 자주 반복되나? ② 규칙이 매번 같은가? 둘 다 O인 것에 별표를 친다. 별표가 자동화 1순위 후보다.

**복사·실행 예시**

```text
'문자 주문을 노트에 옮겨적기' → 반복 O, 규칙 O(항상 이름·품목·수량 적음) → 별표. 'SNS에 올릴 글 감성 판단' → 반복 O, 규칙 X → 후보 아님
```

### 3단계 — AI에게 자동화 아이디어 검증받기 (5분) 🤝함께

아래 templates의 첫 번째 프롬프트를 복사해 별표 친 작업 하나를 넣고 ChatGPT나 Claude에 붙여넣는다. AI가 자동화 방법과 필요한 도구를 알려준다.

**복사·실행 예시**

```text
'문자 주문을 엑셀에 옮기기'를 넣으니 AI가 '휴대폰 자동화 앱(iOS 단축어)이나 Google Sheets + 문자 연동으로 가능'이라고 답함 🤖A
```

### 4단계 — 못 바꾸는 부분 구분하기 (5분) 🙋나

고른 작업을 '기계가 대신할 부분'과 '사람이 계속 해야 할 판단'으로 두 칸에 나눠 적는다. 이 구분이 자동화 설계의 뼈대다.

**복사·실행 예시**

```text
기계: 문자에서 이름·품목 추출→엑셀 입력 / 사람: 재고 없을 때 대체품 추천 여부 판단, 단골에게 인사 멘트 넣기
```

### 5단계 — 자동화 후보 1장으로 문서화 (6분) 🙋나

고른 작업 1개를 '제목 / 지금 걸리는 시간 / 반복 주기 / 자동화할 규칙 / 사람이 남길 판단 / 쓸 도구' 6줄로 정리한다. templates 두 번째 프롬프트로 AI에게 초안을 받아 다듬어도 된다.

**복사·실행 예시**

```text
제목: 문자 주문 엑셀화 / 시간: 건당 3분 / 주기: 하루 10건 / 규칙: 이름·품목·수량 추출 / 사람: 재고 판단 / 도구: iOS 단축어 + Google Sheets
```

### 6단계 — 절약 시간 계산하고 공유 (4분) 🤝함께

'건당 시간 × 주간 횟수 × 4주'로 한 달 절약 시간을 계산해 문서 맨 아래 적는다. 동료·가족에게 문서를 보여주고 실제로 자주 하는지 확인받는다.

**복사·실행 예시**

```text
3분 × 하루10건 × 30일 = 900분 ≈ 월 15시간. 동료가 '주문은 하루 10건보다 많다'고 알려줘 효과가 더 큼을 확인
```

## 흔한 실수와 교정
- **실수:** 반복은 하지만 규칙이 매번 다른 일을 자동화하려 한다 (예: 고객 감정 대응).
  - **교정:** 자동화 후보는 '규칙이 항상 같은가?'를 먼저 통과해야 한다. 규칙이 상황마다 바뀌면 그 부분은 사람이 남기고, 앞뒤의 반복 부분만 잘라 자동화한다.
- **실수:** 처음부터 완벽하게 100% 자동화하려다 아무것도 시작하지 못한다.
  - **교정:** 작업을 잘게 쪼개 '가장 지루한 반복 한 조각'만 먼저 자동화한다. 예를 들어 전체 보고서 대신 '데이터 복붙' 단계만 자동화해도 성공이다.
- **실수:** 자동화하면 사람 일이 사라진다고만 생각해 겁먹거나 판단 영역까지 기계에 맡긴다.
  - **교정:** 자동화는 '반복 노동'을 덜어 사람이 판단·창의에 더 쓰게 하는 도구다. 무엇을 사람이 남길지 4단계처럼 명확히 적어두면 오히려 통제력이 커진다.

## 완료 체크리스트

- 지난 일주일의 반복 작업을 10개 이상 적었다
- 각 작업에 반복성·규칙성을 O/X로 채점하고 별표 후보를 골랐다
- AI에게 후보 하나의 자동화 가능성을 검증받았다
- 기계가 할 부분과 사람이 남길 판단을 구분해 적었다
- 자동화 후보 1개를 6줄 문서로 정리하고 월 절약 시간을 계산했다

## 도구

- ChatGPT (chatgpt.com) — 자동화 가능성 진단·후보 문서 초안 작성
- Claude (claude.ai) — 작업 규칙 분해와 사람/기계 역할 구분
- Google Sheets (sheets.google.com) — 반복 데이터 정리·자동화 실습 무료 표 도구
- iOS 단축어 / Google Play '자동화 앱' — 코딩 없이 휴대폰 반복 작업 자동 실행

## 참고 답안

예: "매일 아침 같은 뉴스 3개 사이트 확인" → 반복 O, 규칙 O(항상 같은 3곳 확인) → AI에게 물으니 "RSS 리더나 뉴스레터 자동 요약 서비스"를 추천 → 문서: 제목-아침 뉴스 확인 자동화 / 시간-매일 10분 / 주기-매일 / 규칙-3개 사이트 헤드라인 수집 / 사람 판단-어떤 기사를 실제로 읽을지 선택 / 도구-RSS 리더 앱
