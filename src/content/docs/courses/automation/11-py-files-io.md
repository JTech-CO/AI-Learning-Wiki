_텍스트·CSV 파일을 읽고 쓰며 로컬 데이터를 자동 처리._

:::note[학습 목표]
- 텍스트(.txt)와 표(.csv) 파일을 코드로 읽어서 내용을 처리하고, 결과를 새 파일로 저장할 수 있다.
:::

> 매번 손으로 파일을 열고 복사·붙여넣기 하는 반복 작업, 이제 코드 몇 줄로 자동으로 끝낼 수 있다. 파일 읽고 쓰기는 모든 자동화의 첫걸음이다.

## 이 레슨에서 만드는 것

텍스트(.txt)와 표(.csv) 파일을 코드로 읽어서 내용을 처리하고, 결과를 새 파일로 저장할 수 있다.

## 핵심 개념

파일 읽기·쓰기는 마치 '냉장고에서 재료를 꺼내(읽기) 요리한 뒤 그릇에 담아 다시 넣는(쓰기)' 것과 같다. 컴퓨터에게 '이 파일 열어줘'라고 말하면, 컴퓨터가 파일 속 글자를 그대로 읽어 프로그램 안으로 가져온다. 처리가 끝나면 '이 내용을 이 이름으로 저장해줘'라고 하면 새 파일이 만들어진다. CSV(콤마로 값을 나눈 표 파일)는 엑셀처럼 줄과 칸으로 나뉜 데이터라서, 파이썬이 자동으로 표 모양으로 이해해준다. 이 기본기만 있으면 '수백 개 파일 이름 바꾸기', '데이터 자동 정리' 같은 일이 가능해진다.

### 왜 작동하는가

파이썬은 파일을 "열고(open) → 읽거나 쓰고 → 닫는(close)" 3단계로 이해합니다. 마치 냉장고 문을 열어 재료를 꺼내고, 요리한 뒤 다시 그릇에 담아 넣는 것과 같아요. 그래서 당신은 "무슨 파일을, 어떤 모드(읽기 r / 쓰기 w)로 열지"만 정하면, 파일 속 글자를 통째로 옮기거나 저장하는 반복 작업은 코드가 대신해줍니다.

## 👀 따라하기 예시

엑셀처럼 학생 점수가 담긴 scores.csv 파일을 읽어서, 90점 넘는 학생만 골라 pass.txt로 저장하는 상황. 제가 먼저 처음부터 끝까지 해볼게요, 눈으로 따라오세요!

### 1. ① scores.csv를 읽기('r') 모드로 엽니다

**실제 결과**

```text
f = open('scores.csv', 'r', encoding='utf-8')
```

> encoding='utf-8'을 안 넣으면 한글이 깨져요. 습관처럼 꼭 붙여주는 게 핵심이에요.

### 2. ② csv.reader로 한 줄씩 읽어 리스트로 받습니다

**실제 결과**

```text
import csv\nfor row in csv.reader(f):\n    print(row)\n# 출력: ['이름', '점수'] ['철수', '90'] ['영희', '85']
```

> 한 줄이 통째로 리스트로 쪼개져 나와요. 이름은 row[0], 점수는 row[1]로 꺼내 쓸 수 있어요.

### 3. ③ 점수가 90 이상인 줄만 골라 리스트에 모읍니다

**실제 결과**

```text
if int(row[1]) >= 90:\n    passed.append(row[0])\n# passed = ['철수']
```

> CSV에서 읽은 값은 전부 글자(문자열)라서, 숫자로 비교하려면 int()로 바꿔줘야 해요. 이 실수를 안 하면 절반은 성공이에요.

### 4. ④ with open으로 pass.txt에 안전하게 저장합니다

**실제 결과**

```text
with open('pass.txt', 'w', encoding='utf-8') as f:\n    f.write('\\n'.join(passed))\n# pass.txt 내용: 철수
```

> with를 쓰면 저장이 끝나자마자 파일이 자동으로 닫혀서, close() 깜빡할 일이 없어요.

### 완성 결과

완성물: 90점 이상 학생 이름만 담긴 pass.txt 파일. 좋은 결과의 기준 — (1) 한글이 안 깨져야 함 (2) 원본 scores.csv는 그대로 남아있어야 함('w'는 새 파일에만 써야 함) (3) with 구문으로 파일이 안전하게 닫혔어야 함.

**복사·실행 예시**

무료 편집기 VS Code를 'code.visualstudio.com'에서 설치하거나, 파이썬과 함께 깔리는 IDLE을 시작메뉴에서 실행한다. IDLE에서 File → New File → 코드를 적고 practice 폴더에 read.py로 저장한다.

**복사·실행 예시**

```text
IDLE 상단 메뉴 File > New File 클릭
```

### 텍스트 파일 읽기

아래 코드를 read.py에 입력한다. open() 안에 파일 이름, 'r'은 읽기(read) 모드, encoding='utf-8'은 한글 깨짐 방지다. F5(또는 Run)로 실행하면 화면에 파일 내용이 뜬다.

**복사·실행 예시**

```text
f = open('test.txt', 'r', encoding='utf-8')
print(f.read())
f.close()
```

### 텍스트 파일 쓰기(저장)

'w'는 쓰기(write) 모드로, 파일이 없으면 새로 만들고 있으면 덮어쓴다. write()에 넣은 글자가 새 파일로 저장된다. 실행 후 폴더에 result.txt가 생겼는지 확인한다.

**복사·실행 예시**

```text
f = open('result.txt', 'w', encoding='utf-8')
f.write('자동으로 저장됨!')
f.close()
```

### CSV 파일 읽기

메모장에 이름,점수 / 철수,90 / 영희,85 를 줄바꿈으로 적고 scores.csv로 저장한다. 파이썬 기본 csv 도구를 불러(import) 한 줄씩 읽는다. 각 줄은 리스트(칸 여러 개 묶음)로 나온다.

**복사·실행 예시**

```text
import csv
f = open('scores.csv', 'r', encoding='utf-8')
for row in csv.reader(f):
    print(row)
f.close()
```

### 안전하게 쓰는 방법(with) 익히기

close()를 깜빡하면 파일이 잠길 수 있다. 'with open(...) as f:' 방식을 쓰면 블록이 끝날 때 자동으로 닫힌다. 앞으로는 이 방식을 습관화한다.

**복사·실행 예시**

```text
with open('test.txt', 'r', encoding='utf-8') as f:
    print(f.read())
```

## 흔한 실수와 교정
- **실수:** 한글 내용이 깨져서 이상한 글자로 나온다
  - **교정:** open() 안에 encoding='utf-8'을 반드시 넣는다. 메모장 저장 시에도 인코딩을 UTF-8로 지정한다.
- **실수:** 'w' 모드로 열었더니 원본 파일 내용이 다 사라졌다
  - **교정:** 'w'는 덮어쓰기다. 기존 내용에 이어 붙이려면 'a'(append=추가) 모드를 쓴다. 중요한 파일은 미리 복사본을 둔다.
- **실수:** FileNotFoundError(파일을 못 찾음) 에러가 난다
  - **교정:** 코드 파일과 데이터 파일이 같은 폴더에 있는지 확인한다. 파일 이름 철자와 확장자(.txt/.csv)를 정확히 쓴다.
- **실수:** close()를 안 써서 저장이 안 되거나 파일이 잠긴다
  - **교정:** 'with open(...) as f:' 방식을 쓰면 자동으로 닫혀 안전하다. 이 방식을 기본으로 삼는다.

## 완료 체크리스트

- 파이썬을 설치했고 IDLE이나 VS Code로 코드를 실행할 수 있다
- 코드 파일과 데이터 파일을 같은 폴더에 두었다
- open()에 파일이름, 모드('r'/'w'/'a'), encoding='utf-8'을 넣었다
- read.py를 실행해 파일 내용을 화면에 출력해봤다
- result.txt처럼 새 파일을 만들어 저장하는 데 성공했다
- csv 도구로 표 파일을 한 줄씩 읽어봤다
- with 방식으로 파일을 안전하게 열고 닫는 습관을 들였다
