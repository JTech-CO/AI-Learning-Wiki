_파이썬 설치, 에디터(VS Code) 준비, 첫 스크립트 실행까지 막힘없이._

:::note[학습 목표]
- 이 레슨이 끝나면, 내 컴퓨터에 파이썬을 설치하고 VS Code에서 직접 만든 스크립트를 실행해 결과를 화면에 띄울 수 있습니다.
:::

> "어떻게 시작하죠?"에서 막혀 몇 시간을 버린 경험, 다들 있죠. 파이썬은 딱 세 가지 — 설치, 에디터, 첫 실행 — 만 넘으면 그 뒤로는 술술입니다.

## 이 레슨에서 만드는 것

이 레슨이 끝나면, 내 컴퓨터에 파이썬을 설치하고 VS Code에서 직접 만든 스크립트를 실행해 결과를 화면에 띄울 수 있습니다.

## 핵심 개념

파이썬을 쓰려면 세 가지가 필요합니다. 첫째는 파이썬 자체(코드를 실제로 실행하는 엔진), 둘째는 코드를 편하게 쓰는 에디터(VS Code 같은 글쓰기 프로그램), 셋째는 명령을 입력하는 터미널입니다. 요리에 비유하면 파이썬은 가스레인지, VS Code는 레시피를 적는 노트, 터미널은 "불 켜!"라고 외치는 목소리예요. 초보자가 가장 많이 막히는 지점은 "설치는 됐는데 컴퓨터가 파이썬을 못 찾는" 문제인데, 이건 설치할 때 체크박스 하나(PATH 추가)만 눌러주면 예방됩니다. 이 레슨은 그 함정들을 피해 첫 실행까지 한 번에 도달하는 것이 목표입니다.

### 왜 작동하는가

컴퓨터는 원래 사람 말을 못 알아듣습니다. 파이썬은 "사람이 쓴 코드를 컴퓨터가 알아듣는 신호로 통역해주는 통역사"예요. VS Code는 그 통역사에게 말(코드)을 깔끔하게 적어 건네는 노트이고, 터미널은 "이제 통역 시작해!"라고 스위치를 누르는 버튼입니다. 세 가지가 한 번 맞물리면, 그 다음부터는 저장→실행 버튼 클릭 두 번이면 끝이라 어렵지 않습니다.

## 👀 따라하기 예시

"파이썬 설치는 했는데 터미널에 python --version 쳤더니 아무 반응이 없어요" 상황 — 제가 먼저 처음부터 끝까지 해결하는 과정을 보여드릴게요, 눈으로 따라오세요.

### 1. ① 먼저 증상을 그대로 확인합니다

**실제 결과**

```text
터미널 입력: python --version\n출력: 'python' 은(는) 내부 또는 외부 명령... 이 아닙니다.
```

> 이 에러 메시지 자체가 힌트예요 — "컴퓨터가 python이라는 단어를 모른다"는 뜻이니, 설치가 안 된 게 아니라 '길 안내(PATH)'가 안 된 것을 의심합니다.

### 2. ② 원인을 좁힙니다

**실제 결과**

```text
설치 파일을 다시 열어보니 첫 화면 하단 'Add python.exe to PATH' 체크박스가 비어 있었음을 확인
```

> 아하 포인트 — 설치 자체는 됐는데, '터미널이 파이썬을 찾아가는 길 표지판'을 안 세운 것뿐이라 프로그램을 지울 필요가 없습니다.

### 3. ③ 재설치로 해결

**실제 결과**

```text
프로그램 제거 → python.org 설치파일 재실행 → 이번엔 체크박스 체크 → Install Now → 완료
```

> 체크박스 하나가 'PATH'라는 표지판을 자동으로 세워주기 때문에, 이 한 번의 클릭으로 문제가 근본적으로 사라집니다.

### 4. ④ 검증

**실제 결과**

```text
터미널 재시작 후 python --version 입력 → Python 3.13.1 출력 확인
```

> '재시작' 이 핵심이에요 — 터미널은 열려있는 동안 옛 정보를 기억하기 때문에, 새 표지판을 읽으려면 새 창이 필요합니다.

### 완성 결과

"python --version"을 쳤을 때 버전 숫자가 뜨는 내 컴퓨터. 좋은 결과의 기준: (1) 에러 메시지 없이 버전 숫자가 바로 출력된다 (2) VS Code에서 만든 hello.py가 실행 버튼 클릭 한 번으로 돌아간다 (3) 어디서 막혔는지 스스로 원인을 한 문장으로 설명할 수 있다.

## 단계별 따라하기

### 1단계 — 파이썬 설치 (7분) 🙋나

python.org/downloads 에 접속해 노란색 'Download Python' 버튼을 눌러 최신 버전을 받습니다. 설치 파일을 실행하면 첫 화면 맨 아래에 'Add python.exe to PATH' 체크박스가 있는데 반드시 먼저 체크한 뒤 'Install Now'를 누릅니다. (Mac은 pkg를 열고 계속 눌러 진행)

**복사·실행 예시**

```text
Windows: 다운받은 python-3.x.x.exe 실행 → 하단 'Add python.exe to PATH' 체크 → Install Now → 완료 후 Close
```

### 2단계 — 설치 확인 (3분) 🙋나

제대로 설치됐는지 확인합니다. Windows는 시작 메뉴에서 'cmd' 검색해 명령 프롬프트를, Mac은 '터미널'을 엽니다. 창에 python --version 을 입력하고 Enter를 칩니다. (Mac에서 안 되면 python3 --version)

**복사·실행 예시**

```text
입력: python --version  →  출력: Python 3.13.1  이렇게 버전 숫자가 나오면 성공
```

### 3단계 — VS Code 설치 (5분) 🙋나

code.visualstudio.com 에서 내 운영체제용 설치 파일을 받아 실행합니다. Windows 설치 중 'PATH에 추가' 옵션은 모두 체크하는 것이 편합니다. 설치가 끝나면 VS Code를 실행합니다.

**복사·실행 예시**

```text
code.visualstudio.com → 'Download for Windows' 클릭 → 설치 → 실행하면 파란 배경의 시작 화면이 뜸
```

### 4단계 — Python 확장 설치 (3분) 🙋나

VS Code 왼쪽 세로 막대에서 네모 4개 모양(확장, Extensions) 아이콘을 클릭합니다. 검색창에 'Python'을 입력하고, Microsoft가 만든 파란 체크 표시의 'Python' 확장을 찾아 'Install'을 누릅니다.

**복사·실행 예시**

```text
확장 아이콘 클릭 → 'Python' 검색 → 게시자 'Microsoft' 확인 → Install 버튼 클릭
```

### 5단계 — 첫 스크립트 작성 (4분) 🤝함께

바탕화면에 'python-study' 폴더를 만들고 VS Code에서 '파일 > 폴더 열기'로 엽니다. 새 파일을 만들어 hello.py 라는 이름으로 저장하고, 아래 예시 코드를 그대로 입력합니다. 막히면 6단계 템플릿을 AI에 붙여넣어 물어보세요.

**복사·실행 예시**

```text
hello.py 내용:
name = "에듀버스"
print("안녕하세요, " + name + "!")
print("파이썬 첫 실행 성공")
```

### 6단계 — 실행하고 결과 보기 (3분) 🙋나

hello.py 편집기 오른쪽 위의 삼각형 '실행(Run)' 버튼을 누릅니다. 화면 아래쪽에 터미널이 열리며 결과가 출력됩니다. 버튼이 없으면 터미널에서 python hello.py 를 입력해도 됩니다.

**복사·실행 예시**

```text
실행 버튼 클릭 → 하단 터미널에 출력:
안녕하세요, 에듀버스!
파이썬 첫 실행 성공
```

## 흔한 실수와 교정
- **실수:** 설치할 때 'Add python.exe to PATH' 체크박스를 그냥 지나쳐서, 나중에 터미널이 python을 못 찾는다.
  - **교정:** 파이썬을 다시 설치 파일로 실행하면 'Modify' 화면이 나온다. 여기서 PATH 옵션을 켜거나, 가장 확실한 방법은 프로그램 제거 후 설치 첫 화면에서 체크박스를 먼저 누르고 재설치한다.
- **실수:** 파일 이름을 hello 로만 저장하거나 hello.txt 로 저장해서 파이썬 파일로 인식되지 않는다.
  - **교정:** 파일 이름은 반드시 .py 로 끝나야 한다. VS Code에서 '다른 이름으로 저장' 시 hello.py 처럼 확장자까지 직접 입력하고, 파일 아이콘이 파이썬 로고로 바뀌는지 확인한다.
- **실수:** print 문에서 큰따옴표를 한글 따옴표(“ ”)로 쓰거나 괄호를 빠뜨려 SyntaxError가 난다.
  - **교정:** 따옴표는 반드시 영문 상태에서 " 를 쓰고 괄호 () 를 닫는다. 오류 메시지에 표시된 줄 번호를 보고 해당 줄의 따옴표와 괄호를 점검하거나, 오류 전체를 AI에 붙여넣어 물어본다.

## 완료 체크리스트

- python.org에서 파이썬을 설치하며 'Add to PATH'를 체크했다
- 터미널에서 python --version 으로 버전 숫자를 확인했다
- VS Code를 설치하고 Microsoft의 Python 확장을 추가했다
- hello.py 파일을 .py 확장자로 저장했다
- 실행 버튼(또는 python hello.py)으로 결과가 터미널에 출력되는 것을 봤다

## 도구

- Python (https://www.python.org/downloads) — 파이썬 엔진 설치
- VS Code (https://code.visualstudio.com) — 코드 작성 에디터
- Python 확장 (VS Code 내 Extensions 검색) — 실행·자동완성 지원
- ChatGPT (https://chat.openai.com) — 설치 오류·코드 질문 즉시 해결
