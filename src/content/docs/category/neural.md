---

신경망의 구성 요소와 학습 원리 분야의 검토 완료 백과 문서입니다.

- [가중치](/wiki/weight/) — 신경망에서 입력 신호의 영향력을 조절하며 학습 과정에서 손실을 줄이는 방향으로 갱신되는 수치형 매개변수다.
- [게이트 순환 유닛](/wiki/gated-recurrent-unit/) — 게이트 순환 유닛은 갱신 게이트와 리셋 게이트로 이전 상태와 새 후보 상태를 혼합하는 순환 신경망 구조다.
- [경사하강법](/wiki/gradient-descent/) — 손실 함수의 기울기 반대 방향으로 파라미터를 반복 갱신하는 최적화 방법이다.
- [계산 그래프](/wiki/computational-graph/) — 계산을 값과 연산 노드, 의존 관계의 방향성 그래프로 표현한 구조다.
- [그래디언트 신호](/wiki/gradient-signal/) — 그래디언트 신호는 손실이 각 파라미터 변화에 얼마나 민감한지를 나타내며 역전파로 층을 거슬러 전달된다.
- [다층 퍼셉트론](/wiki/multilayer-perceptron/) — 다층 퍼셉트론은 완전연결 선형 변환과 비선형 활성함수를 여러 층 쌓은 순방향 신경망이다.
- [배치](/wiki/batch/) — 한 번의 순전파와 역전파에서 함께 처리하는 데이터 예시의 묶음이다.
- [변분 오토인코더](/wiki/variational-autoencoder/) — 변분 오토인코더는 잠재 변수의 확률분포를 추론하는 인코더와 데이터를 복원하는 디코더를 함께 학습하는 생성 모델이다.
- [생성적 적대 신경망](/wiki/generative-adversarial-network/) — 생성적 적대 신경망은 실제 데이터와 비슷한 표본을 만드는 생성자와 진위를 구분하는 판별자를 경쟁적으로 학습하는 모델이다.
- [선형층](/wiki/linear-layer/) — 선형층은 입력 벡터에 학습 가능한 행렬과 편향을 적용해 아핀 변환을 수행하는 층이다.
- [손실 함수](/wiki/loss-function/) — 모델의 예측과 목표 사이 차이를 하나의 수치로 측정하는 함수다.
- [수용 영역](/wiki/receptive-field/) — 수용 영역은 신경망의 특정 유닛 출력에 영향을 줄 수 있는 입력 위치의 범위다.
- [순전파](/wiki/forward-pass/) — 신경망 입력을 첫 층부터 마지막 층까지 순서대로 계산해 예측과 중간 활성화를 얻는 과정이다.
- [순환 신경망](/wiki/recurrent-neural-network/) — 순환 신경망은 이전 시점의 은닉 상태를 다음 시점 계산에 사용해 시퀀스 의존성을 표현하는 신경망이다.
- [신경망](/wiki/neural-network/) — 연결된 계산 단위와 가중치를 층으로 쌓아 복잡한 함수를 학습하는 모델이다.
- [신경망 깊이](/wiki/network-depth/) — 신경망 깊이는 입력에서 출력까지 거치는 학습 가능한 층이나 변환 단계의 수를 뜻한다.
- [신경망 너비](/wiki/network-width/) — 신경망 너비는 한 층이 가진 유닛, 채널 또는 은닉 차원의 크기를 뜻한다.
- [신경망 층](/wiki/layer/) — 입력 표현을 정해진 연산과 학습 파라미터로 변환해 다음 표현으로 전달하는 신경망의 구성 단위다.
- [에포크](/wiki/epoch/) — 학습 알고리즘이 전체 학습 데이터셋을 한 번 처리한 주기다.
- [역전파](/wiki/backpropagation/) — 출력의 손실에서 각 파라미터의 기여도를 연쇄 법칙으로 계산하는 알고리즘이다.
- [완전연결층](/wiki/dense-layer/) — 완전연결층은 모든 입력 특성과 모든 출력 유닛 사이에 학습 가능한 가중치를 두는 신경망 층이다.
- [은닉 상태](/wiki/hidden-state/) — 은닉 상태는 순환 모델이나 상태 공간 모델이 이전 입력 정보를 요약해 다음 계산으로 전달하는 내부 표현이다.
- [은닉층](/wiki/hidden-layer/) — 은닉층은 입력과 출력 사이에서 중간 표현을 계산하며 직접 관측되는 목표가 아닌 특징을 학습하는 신경망 층이다.
- [인공 뉴런](/wiki/neuron/) — 입력의 가중합에 활성화 함수를 적용해 출력을 만드는 신경망의 계산 단위다.
- [입력층](/wiki/input-layer/) — 신경망이 외부 특징을 처음 받아 내부 텐서 표현으로 전달하는 입력 경계다.
- [잔차 신경망](/wiki/residual-network/) — 잔차 신경망은 여러 층의 변환 결과에 입력을 지름길 연결로 더해 잔차 함수를 학습하는 심층 신경망이다.
- [장단기 메모리](/wiki/long-short-term-memory/) — 장단기 메모리는 입력·망각·출력 게이트와 셀 상태로 장기 의존성 학습을 돕는 순환 신경망 구조다.
- [출력층](/wiki/output-layer/) — 출력층은 신경망의 마지막 표현을 과제에 필요한 로짓, 확률, 실수값 또는 벡터로 변환하는 층이다.
- [파라미터 초기화](/wiki/parameter-initialization/) — 파라미터 초기화는 학습 시작 전에 가중치와 편향의 초기 값을 정해 신호와 기울기가 안정적으로 흐르게 하는 절차다.
- [편향 항](/wiki/bias/) — 선형 변환의 기준점을 이동시키기 위해 더하는 학습 가능한 값이다.
- [학습률](/wiki/learning-rate/) — 한 번의 최적화 단계에서 파라미터를 얼마나 크게 변경할지 정하는 값이다.
- [합성곱 신경망](/wiki/convolutional-neural-network/) — 합성곱 신경망은 국소 필터의 가중치를 공간 위치에 공유해 격자 데이터의 특징을 학습하는 신경망이다.
- [활성화 함수](/wiki/activation-function/) — 신경망에 비선형성을 부여해 복잡한 관계를 표현하게 하는 함수다.
- [DenseNet](/wiki/densenet/) — DenseNet은 각 층의 특징 맵을 이후 모든 층의 입력에 이어 붙이는 조밀 연결 합성곱 신경망이다.
- [U-Net](/wiki/u-net/) — U-Net은 축소 경로와 확대 경로를 대칭으로 구성하고 같은 해상도의 특징을 건너 연결하는 영상 분할 신경망이다.
