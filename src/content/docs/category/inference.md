title: "추론·서빙·최적화"
description: "학습된 모델이 출력을 생성하고 서비스되는 방식"
---

학습된 모델이 출력을 생성하고 서비스되는 방식 분야의 검토 완료 백과 문서입니다.

- [그리디 디코딩](/wiki/greedy-decoding/) — 매 단계에서 확률이 가장 높은 토큰을 선택하는 결정적 생성 방식이다.
- [길이 페널티](/wiki/length-penalty/) — 길이 페널티는 후보 시퀀스 점수를 길이에 따라 보정해 빔 탐색이 지나치게 짧거나 긴 출력을 선호하지 않게 하는 규칙이다.
- [다양성 빔 탐색](/wiki/diverse-beam-search/) — 다양성 빔 탐색은 빔을 여러 그룹으로 나누고 앞선 그룹과 유사한 후보에 패널티를 주어 서로 다른 시퀀스를 찾는 방법이다.
- [다항 표본추출](/wiki/multinomial-sampling/) — 각 토큰의 확률을 범주형 분포로 보고 그 분포에서 다음 토큰 하나를 무작위로 추출하는 생성 방법이다.
- [대조 탐색](/wiki/contrastive-search/) — 대조 탐색은 높은 언어 모델 확률과 이전 은닉 표현에 대한 낮은 퇴화를 함께 고려해 다음 토큰을 선택하는 디코딩 방법이다.
- [로짓](/wiki/logit/) — 확률로 정규화하기 전 모델이 각 클래스나 토큰 후보에 내놓는 실수 점수이며, 이항 문제에서는 로그 오즈로 해석된다.
- [모델 서빙](/wiki/model-serving/) — 모델 서빙은 학습된 모델을 요청 가능한 서비스로 배치해 입력 전처리, 추론, 출력 후처리와 운영 관측을 제공하는 체계다.
- [반복 페널티](/wiki/repetition-penalty/) — 반복 페널티는 이미 생성된 토큰의 다음 단계 점수를 조정해 동일 표현의 과도한 반복을 줄이는 디코딩 제어다.
- [배칭](/wiki/batching/) — 여러 추론 요청을 묶어 하드웨어 사용률과 처리량을 높이는 기법이다.
- [빈도 페널티](/wiki/frequency-penalty/) — 빈도 페널티는 지금까지 등장한 횟수에 비례해 해당 토큰의 로짓을 낮추는 생성 제어 방식이다.
- [빔 탐색](/wiki/beam-search/) — 여러 후보 시퀀스를 동시에 유지하며 전체 점수가 높은 출력을 찾는 탐색 방법이다.
- [생성 온도](/wiki/temperature/) — 생성 시 로짓을 나누어 토큰 확률분포의 집중도를 조절하고 출력의 반복성과 다양성 사이의 균형을 바꾸는 디코딩 매개변수다.
- [소프트맥스](/wiki/softmax/) — 여러 실수 점수를 지수화하고 합으로 나눠 합이 1인 비율 벡터로 바꾸는 함수다.
- [전형성 샘플링](/wiki/typical-sampling/) — 현재 분포의 엔트로피에 가까운 정보량을 가진 토큰을 우선 남겨 전형적인 확률 영역에서 표본을 추출하는 디코딩 방법이다.
- [제약 디코딩](/wiki/constrained-decoding/) — 제약 디코딩은 문법, 스키마, 어휘 집합이나 필수 구문을 만족하는 토큰만 다음 후보로 허용하는 생성 방법이다.
- [존재 페널티](/wiki/presence-penalty/) — 존재 페널티는 토큰이 한 번이라도 등장했는지를 기준으로 고정된 패널티를 적용하는 생성 제어 방식이다.
- [중지 시퀀스](/wiki/stop-sequence/) — 중지 시퀀스는 생성 결과에서 지정한 토큰 또는 문자열 패턴이 나타나면 디코딩을 종료하도록 하는 조건이다.
- [지연 시간](/wiki/latency/) — 요청을 보낸 뒤 첫 토큰 또는 전체 응답을 받을 때까지 걸리는 시간이다.
- [처리량](/wiki/throughput/) — 단위 시간에 시스템이 처리하거나 생성할 수 있는 요청 또는 토큰 수다.
- [추론](/wiki/inference/) — 학습된 모델이 새 입력을 받아 예측이나 생성을 수행하는 과정이다.
- [토큰 샘플링](/wiki/token-sampling/) — 토큰 샘플링은 다음 토큰 확률분포에서 난수로 토큰을 뽑아 생성 시퀀스를 이어가는 디코딩 방식이다.
- [KV 캐시](/wiki/kv-cache/) — 이전 토큰의 어텐션 키와 값을 저장해 자동회귀 생성의 중복 계산을 줄이는 캐시다.
- [Min-p 샘플링](/wiki/min-p-sampling/) — 최고 확률 토큰의 확률에 비례한 최소 임계값보다 낮은 토큰을 제거한 뒤 남은 분포에서 추출하는 디코딩 방법이다.
- [Top-k 샘플링](/wiki/top-k-sampling/) — 확률이 높은 상위 k개 후보만 남겨 다음 토큰을 선택하는 방법이다.
- [Top-p 샘플링](/wiki/top-p-sampling/) — 누적 확률이 p에 도달하는 최소 후보 집합에서 다음 토큰을 선택하는 방법이다.
