---
title: "학습과 사후학습"
description: "사전학습부터 정렬·경량화까지의 방법"
---

사전학습부터 정렬·경량화까지의 방법 분야의 검토 완료 백과 문서입니다.

- [가치 함수 손실](/wiki/value-function-loss/) — 가치 함수 손실은 상태나 상태-행동의 예상 누적 보상 예측과 목표 반환값 사이의 오차를 측정하는 손실이다.
- [결과 보상 모델](/wiki/outcome-reward-model/) — 결과 보상 모델은 생성 과정 전체보다 최종 산출물의 정확성이나 선호도를 입력으로 평가하는 모델이다.
- [과정 보상 모델](/wiki/process-reward-model/) — 과정 보상 모델은 최종 답뿐 아니라 문제 해결의 각 중간 단계가 올바른지를 평가해 점수를 주는 모델이다.
- [과제 벡터](/wiki/task-vector/) — 과제 벡터는 미세조정 모델과 기반 모델의 가중치 차이로 표현한 과제별 파라미터 업데이트다.
- [과제 적응](/wiki/task-adaptation/) — 과제 적응은 범용 또는 다른 과제로 학습된 모델을 새로운 목표 과제의 입출력과 평가 기준에 맞게 조정하는 과정이다.
- [교사 강요](/wiki/teacher-forcing/) — 교사 강요는 순차 모델 학습에서 이전 시점의 모델 예측 대신 실제 정답 토큰을 다음 입력으로 제공하는 방법이다.
- [구간 손상 복원](/wiki/span-corruption/) — 구간 손상 복원은 연속된 여러 토큰 구간을 특수 표식으로 바꾸고 누락된 구간을 생성하도록 하는 잡음 제거 학습 방식이다.
- [기각 표본추출](/wiki/rejection-sampling/) — 거부 표집은 제안 분포에서 후보를 생성한 뒤 목표 기준에 따른 수용 확률이나 임계값으로 일부만 채택하는 표집 방법이다.
- [다음 문장 예측](/wiki/next-sentence-prediction/) — 다음 문장 예측은 두 텍스트 구간이 원문에서 연속해 나타났는지 분류하도록 하는 사전학습 과제다.
- [다중 과제 목적 함수](/wiki/multi-task-objective/) — 다중 과제 목적 함수는 하나의 모델이 여러 과제의 손실을 함께 최적화하도록 결합한 학습 목표다.
- [다중 과제 지시 튜닝](/wiki/multi-task-instruction-tuning/) — 다중 과제 지시 튜닝은 서로 다른 과제를 자연어 지시 형식으로 통합해 하나의 모델을 동시에 미세조정하는 방법이다.
- [대조 목적 함수](/wiki/contrastive-objective/) — 대조 목적 함수는 관련 있는 표본 표현은 가깝게, 관련 없는 표본 표현은 멀게 배치하도록 학습하는 목적 함수다.
- [데이터 병렬화](/wiki/data-parallelism/) — 데이터 병렬화는 같은 모델 복제본에 서로 다른 미니배치를 처리하게 하고 기울기를 동기화하는 분산 학습 방식이다.
- [데이터 증강](/wiki/data-augmentation/) — 과제의 정답 의미를 보존하는 변환이나 합성으로 학습 표본의 다양성을 늘려 모델의 일반화와 견고성을 높이는 기법이다.
- [데이터 커리큘럼](/wiki/data-curriculum/) — 데이터 커리큘럼은 학습 중 데이터의 난이도, 길이, 품질 또는 영역별 제시 순서를 계획한 전략이다.
- [데이터 혼합](/wiki/data-mixture/) — 데이터 혼합은 여러 출처, 언어와 과제의 학습 데이터를 어떤 비율과 샘플링 규칙으로 결합할지 정한 구성이다.
- [데이터셋 중복 제거](/wiki/dataset-deduplication/) — 데이터셋 중복 제거는 동일하거나 매우 유사한 문서와 구간을 찾아 학습 데이터에서 반복을 줄이는 절차다.
- [도메인 적응](/wiki/domain-adaptation/) — 도메인 적응은 학습 데이터와 운영 데이터의 분포가 다를 때 목표 도메인 성능을 높이도록 표현이나 모델을 조정하는 방법이다.
- [마스크 언어 모델링 목표](/wiki/masked-language-modeling-objective/) — 마스크 언어 모델링 목표는 입력 토큰 일부를 숨기거나 바꾼 뒤 주변 문맥으로 원래 토큰을 예측하도록 학습하는 목적 함수다.
- [모델 가지치기](/wiki/model-pruning/) — 모델 가지치기는 성능에 미치는 영향이 작은 가중치, 채널, 헤드나 층을 제거해 모델 크기와 계산량을 줄이는 기법이다.
- [모델 병렬화](/wiki/model-parallelism/) — 모델 병렬화는 하나의 모델 파라미터와 계산을 여러 장치에 나누어 단일 장치 용량을 넘는 모델을 실행하는 방식이다.
- [모델 병합](/wiki/model-merging/) — 모델 병합은 같은 기반에서 학습된 여러 모델의 가중치나 업데이트를 결합해 하나의 모델을 만드는 방법이다.
- [모델 희소성](/wiki/model-sparsity/) — 모델 희소성은 가중치나 활성값 중 0 또는 사용되지 않는 요소의 비율과 구조를 나타내는 성질이다.
- [문서 패킹](/wiki/document-packing/) — 문서 패킹은 여러 짧은 문서를 하나의 고정 길이 학습 예시에 채워 패딩 낭비를 줄이는 데이터 구성 방식이다.
- [문장 순서 예측](/wiki/sentence-order-prediction/) — 문장 순서 예측은 두 연속 구간의 순서가 원래 순서인지 뒤바뀌었는지 판별하도록 하는 사전학습 과제다.
- [미세조정](/wiki/fine-tuning/) — 사전학습 모델을 특정 데이터와 목적에 맞게 추가 학습하는 과정이다.
- [벤치마크 오염](/wiki/benchmark-contamination/) — 벤치마크 오염은 평가 문제나 그 변형이 학습 데이터에 포함되어 모델이 일반화 대신 기억으로 높은 점수를 얻는 현상이다.
- [보상 모델](/wiki/reward-model/) — 여러 모델 출력 중 사람의 선호에 가까운 출력을 점수화하도록 학습된 모델이다.
- [보상 해킹](/wiki/reward-hacking/) — 보상 해킹은 에이전트가 설계자의 실제 의도 대신 보상 함수의 허점이나 대리 지표를 이용해 높은 점수를 얻는 현상이다.
- [보조 손실](/wiki/auxiliary-loss/) — 보조 손실은 주 과제 학습을 돕기 위해 중간 표현이나 추가 예측에 부과하는 부수적 목적 함수다.
- [복원 손실](/wiki/reconstruction-loss/) — 복원 손실은 인코딩·손상·압축된 입력에서 원본 또는 목표 신호를 얼마나 정확히 재구성했는지 측정하는 손실이다.
- [브래들리-테리 모형](/wiki/bradley-terry-model/) — Bradley–Terry 모형은 두 항목의 양의 능력값 또는 점수 차이로 한 항목이 다른 항목을 이길 확률을 나타내는 쌍대 비교 모형이다.
- [사전학습](/wiki/pretraining/) — 대규모 데이터로 일반적인 표현과 패턴을 먼저 학습하는 단계다.
- [사전학습 파이프라인](/wiki/pretraining-pipeline/) — 사전학습 파이프라인은 데이터 수집·정제·토큰화·혼합부터 분산 학습, 체크포인트와 평가까지 이어지는 생산 체계다.
- [선호 데이터](/wiki/preference-data/) — 선호 데이터는 동일하거나 관련된 입력에 대한 여러 출력의 비교, 순위 또는 점수로 어떤 응답이 더 나은지 기록한 자료다.
- [선호 손실](/wiki/preference-loss/) — 선호 손실은 같은 입력에 대한 선호 출력과 비선호 출력의 상대 점수를 학습하도록 구성한 목적 함수다.
- [시퀀스 분류 미세조정](/wiki/sequence-classification-fine-tuning/) — 시퀀스 분류 미세조정은 사전학습 모델의 문장·문서 표현에 분류기를 연결해 범주 예측 과제에 맞게 매개변수를 갱신하는 과정이다.
- [시퀀스 패킹](/wiki/sequence-packing/) — 시퀀스 패킹은 길이가 다른 토큰 시퀀스를 제한된 컨텍스트 블록에 효율적으로 배치해 연산 활용률을 높이는 기법이다.
- [쌍대 선호 순위화](/wiki/pairwise-preference-ranking/) — 쌍대 선호 순위화는 두 후보 중 선호되는 항목을 관측해 전체 후보의 상대적 품질이나 보상 함수를 학습하는 방식이다.
- [양자화](/wiki/quantization/) — 가중치와 활성값을 낮은 정밀도로 표현해 메모리와 계산 비용을 줄이는 기법이다.
- [양자화 인식 학습](/wiki/quantization-aware-training/) — 양자화 인식 학습은 학습 중 낮은 비트 양자화의 반올림과 범위를 모사해 양자화 후 정확도 저하를 줄이는 방법이다.
- [어댑터 층](/wiki/adapter-layer/) — 어댑터 층은 사전학습 모델의 본체를 대부분 고정한 채 층 사이에 삽입해 과제별로 학습하는 작은 병목 모듈이다.
- [연속 사전학습](/wiki/continued-pretraining/) — 연속 사전학습은 이미 사전학습된 모델을 추가 말뭉치와 자기지도 목표로 더 학습해 도메인·언어·최신 지식을 반영하는 단계다.
- [오프라인 선호 학습](/wiki/offline-preference-learning/) — 오프라인 선호 학습은 미리 수집해 고정한 비교·순위 데이터만으로 정책 또는 보상 모델을 최적화하는 방식이다.
- [온라인 선호 학습](/wiki/online-preference-learning/) — 온라인 선호 학습은 현재 정책이 새 후보를 생성하고 그에 대한 최신 선호 피드백을 받아 반복적으로 정책을 갱신하는 방식이다.
- [웹 규모 학습 데이터](/wiki/web-scale-training-data/) — 웹 규모 학습 데이터는 공개 웹에서 대량 수집한 문서와 미디어를 정제해 구성한 대규모 사전학습 자료다.
- [응답 형식 튜닝](/wiki/response-format-tuning/) — 응답 형식 튜닝은 모델이 지정된 구조, 문체, 길이 또는 스키마에 맞춰 답하도록 예시 데이터로 미세조정하는 과정이다.
- [인간 피드백 기반 강화학습](/wiki/rlhf/) — 사람의 선호 신호를 이용해 모델 응답 정책을 조정하는 사후학습 방법이다.
- [인과 언어 모델링 목표](/wiki/causal-language-modeling-objective/) — 인과 언어 모델링 목표는 이전 토큰들만 조건으로 다음 토큰의 확률을 높이도록 모델을 학습하는 목적 함수다.
- [잡음 제거 목표](/wiki/denoising-objective/) — 잡음 제거 목표는 원본 데이터에 손상을 가한 입력으로부터 손상 전 데이터나 필요한 부분을 복원하도록 학습하는 목적 함수다.
- [전문가 병렬화](/wiki/expert-parallelism/) — 전문가 병렬화는 혼합 전문가 모델의 여러 전문가 네트워크를 장치에 나누어 배치하는 분산 실행 방식이다.
- [전체 파라미터 미세조정](/wiki/full-parameter-fine-tuning/) — 전체 파라미터 미세조정은 사전학습 모델의 모든 학습 가능한 가중치를 목표 데이터에 맞게 갱신하는 적응 방식이다.
- [정책 모델](/wiki/policy-model/) — 정책 모델은 주어진 입력에서 다음 토큰이나 응답을 선택하는 확률분포를 나타내며 선호 신호로 직접 갱신되는 모델이다.
- [정책 목적 함수](/wiki/policy-objective/) — 정책 목적 함수는 상태에서 행동을 선택하는 정책이 기대 누적 보상을 높이도록 최적화하는 목표다.
- [증류 손실](/wiki/distillation-loss/) — 증류 손실은 학생 모델이 교사 모델의 출력 분포나 중간 표현을 모방하도록 차이를 측정하는 학습 목적 함수다.
- [지도 미세조정](/wiki/supervised-fine-tuning/) — 지시와 모범 응답 쌍으로 모델이 원하는 응답 형식을 따르도록 학습하는 단계다.
- [지시 데이터 혼합](/wiki/instruction-mixture/) — 지시 데이터 혼합은 지시 튜닝에 사용할 여러 과제·출처·형식 데이터의 구성과 표본 비율을 정한 집합이다.
- [지시 데이터셋](/wiki/instruction-dataset/) — 지시 데이터셋은 자연어 지시, 선택적 입력과 기대 응답을 짝지어 모델의 과제 수행과 지시 따르기를 학습시키는 데이터 모음이다.
- [지시 튜닝](/wiki/instruction-tuning/) — 다양한 자연어 지시 데이터로 여러 과제를 지시 형식에 맞게 수행하도록 만드는 학습이다.
- [지식 증류](/wiki/knowledge-distillation/) — 큰 교사 모델의 출력이나 표현을 작은 학생 모델이 모방하도록 학습하는 방법이다.
- [직접 선호 최적화](/wiki/dpo/) — 별도 강화학습 루프 없이 선호 응답과 비선호 응답으로 정책을 직접 최적화하는 방법이다.
- [참조 모델](/wiki/reference-model/) — 기준 모델은 선호 최적화 중 새 정책의 변화량을 측정하거나 비교 확률을 계산하기 위해 고정해 두는 이전 모델이다.
- [채팅 템플릿](/wiki/chat-template/) — 채팅 템플릿은 역할이 있는 대화 메시지를 모델이 학습한 특수 토큰과 구분자 순서의 단일 토큰열로 변환하는 규칙이다.
- [체크포인트](/wiki/checkpoint/) — 특정 학습 시점의 모델 가중치와 최적화 상태를 저장한 파일 집합이다.
- [텐서 병렬화](/wiki/tensor-parallelism/) — 텐서 병렬화는 한 층의 큰 가중치 텐서와 행렬 연산을 여러 장치에 분할하는 모델 병렬 방식이다.
- [파라미터 효율적 미세조정](/wiki/peft/) — 전체 가중치 대신 일부 작은 파라미터만 학습해 비용을 줄이는 기법들의 총칭이다.
- [파이프라인 병렬화](/wiki/pipeline-parallelism/) — 파이프라인 병렬화는 모델의 연속된 층 구간을 여러 장치에 배치하고 미니배치를 마이크로배치로 흘려보내는 방식이다.
- [프롬프트 튜닝](/wiki/prompt-tuning/) — 프롬프트 튜닝은 입력 임베딩 앞에 학습 가능한 연속 프롬프트 벡터를 붙이고 기반 모델은 고정하는 미세조정 방법이다.
- [프리픽스 튜닝](/wiki/prefix-tuning/) — 프리픽스 튜닝은 각 트랜스포머 층의 어텐션에 학습 가능한 연속 키·값 접두사를 추가하는 매개변수 효율적 미세조정 방법이다.
- [학습 데이터 출처 추적](/wiki/training-data-provenance/) — 학습 데이터 출처 추적은 각 학습 예시가 어디서 언제 어떤 조건으로 수집·변환됐는지 계보를 기록하는 관리 절차다.
- [학습 데이터 필터링](/wiki/training-data-filtering/) — 학습 데이터 필터링은 품질, 언어, 안전, 개인정보와 라이선스 기준으로 원시 데이터를 선택하거나 제외하는 절차다.
- [학습 데이터 형식화](/wiki/training-data-formatting/) — 학습 데이터 형식화는 원시 사례를 모델이 읽을 입력·목표 토큰, 역할, 마스크와 메타데이터 구조로 변환하는 과정이다.
- [학습 말뭉치](/wiki/training-corpus/) — 학습 말뭉치는 언어 모델이나 다른 학습 시스템의 파라미터를 최적화하는 데 사용하는 문서와 토큰의 조직화된 집합이다.
- [합성 데이터](/wiki/synthetic-data/) — 실제 관측값을 그대로 복제하지 않고 규칙·시뮬레이션·통계 또는 생성 모델로 만든 데이터다.
- [헌법적 AI](/wiki/constitutional-ai/) — 헌법적 AI는 자연어 원칙 집합을 사용해 모델이 자신의 응답을 비평·수정하고 선호 학습 신호를 만드는 정렬 방법이다.
- [확산 학습 목표](/wiki/diffusion-training-objective/) — 확산 학습 목표는 단계별로 노이즈가 추가된 데이터에서 노이즈·원본·점수 중 하나를 예측하도록 모델을 학습하는 목적이다.
- [AI 정렬](/wiki/alignment/) — 모델의 행동이 사람의 의도·가치·안전 제약과 일치하도록 만드는 연구와 과정이다.
- [AI 피드백 기반 강화학습](/wiki/reinforcement-learning-from-ai-feedback/) — AI 피드백 기반 강화학습은 사람 대신 또는 사람과 함께 다른 모델의 비평·선호·규칙 판정을 보상 신호로 사용해 정책을 조정하는 방식이다.
- [Best-of-N 표본추출](/wiki/best-of-n-sampling/) — Best-of-N 표집은 같은 입력에서 N개의 응답을 생성하고 보상 모델이나 평가 기준의 점수가 가장 높은 응답을 선택하는 추론·데이터 생성 방식이다.
- [DoRA](/wiki/dora/) — DoRA는 가중치 행렬을 크기와 방향으로 분해하고 방향 변화는 저계수 어댑터로, 크기는 별도 파라미터로 학습하는 미세조정 방법이다.
- [IA3](/wiki/ia3/) — IA3는 어텐션과 순방향 신경망의 내부 활성값을 학습 가능한 벡터로 곱해 조정하는 매개변수 효율적 미세조정 방법이다.
- [KL 페널티](/wiki/kl-penalty/) — KL 패널티는 새 정책의 출력 분포가 기준 정책에서 지나치게 멀어지는 것을 억제하기 위해 KL 발산을 목적함수에 더하는 항이다.
- [LLM용 근접 정책 최적화](/wiki/proximal-policy-optimization-for-llm/) — LLM용 근접 정책 최적화는 보상 신호를 높이되 새 언어 모델 정책이 기준 정책에서 한 번에 너무 멀어지지 않도록 갱신하는 강화학습 방법이다.
- [LoRA](/wiki/lora/) — 기존 가중치를 고정하고 저랭크 행렬만 학습하는 파라미터 효율적 미세조정 기법이다.
- [QLoRA](/wiki/qlora/) — QLoRA는 사전학습 모델 가중치를 저비트로 양자화해 고정하고 저계수 어댑터만 학습하는 메모리 효율적 미세조정 방법이다.
