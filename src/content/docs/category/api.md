---

모델을 소프트웨어와 연결하는 인터페이스 분야의 검토 완료 백과 문서입니다.

- [경로 매개변수](/wiki/path-parameter/) — 경로 매개변수는 URL 경로의 일부를 변수로 사용해 특정 자원이나 계층을 식별하는 API 입력이다.
- [구조화 출력](/wiki/structured-output/) — 모델 출력을 미리 정의한 JSON 스키마나 데이터 구조에 맞추는 기능이다.
- [도구 호출](/wiki/tool-calling/) — 모델이 정해진 함수 스키마를 선택하고 인수를 생성해 외부 기능 실행을 요청하는 방식이다.
- [도메인 이름 시스템](/wiki/domain-name-system/) — 도메인 이름 시스템(DNS)은 사람이 읽는 도메인 이름을 IP 주소와 여러 자원 레코드에 연결하는 분산 계층형 데이터베이스다.
- [스트리밍 응답](/wiki/streaming-response/) — 전체 결과가 완성되기 전에 생성된 일부 데이터를 순차적으로 전송하는 방식이다.
- [요청 한도](/wiki/rate-limit/) — 일정 시간 동안 허용하는 요청이나 토큰 사용량을 제한하는 정책이다.
- [전송 계층 보안](/wiki/transport-layer-security/) — 전송 계층 보안(TLS)은 통신 상대 인증, 키 합의와 암호화된 레코드 전송을 제공하는 보안 프로토콜이다.
- [질의 매개변수](/wiki/query-parameter/) — 질의 매개변수는 URI의 물음표 뒤에 이름과 값으로 전달되어 필터, 정렬, 페이지 이동이나 선택 옵션을 표현한다.
- [콘텐츠 유형](/wiki/content-type/) — Content-Type은 HTTP 메시지 본문의 매체 유형과 문자 집합 같은 표현 정보를 알리는 헤더 필드다.
- [통합 자원 식별자](/wiki/uri/) — 통합 자원 식별자(URI)는 자원을 식별하기 위한 문자열 문법의 총칭이며 URL과 URN 같은 식별 방식을 포괄한다.
- [통합 자원 위치 지정자](/wiki/url/) — 통합 자원 위치 지정자(URL)는 자원의 위치와 접근 방법을 함께 나타내는 URI의 한 유형이다.
- [API](/wiki/api/) — 소프트웨어 구성 요소가 정해진 규약으로 기능과 데이터를 요청·교환하는 인터페이스다.
- [API 엔드포인트](/wiki/api-endpoint/) — API 엔드포인트는 특정 기능이나 자원에 접근하도록 서버가 공개한 네트워크 주소와 요청 계약의 결합이다.
- [API 키](/wiki/api-key/) — API 요청의 프로젝트나 사용자를 식별하고 권한을 확인하는 비밀 문자열이다.
- [HTTP 메서드](/wiki/http-method/) — HTTP 요청이 대상 자원에 대해 수행하려는 의미를 나타내며 안전성·멱등성·캐시 가능성 같은 프로토콜 속성을 정의하는 토큰이다.
- [HTTP 메시지 본문](/wiki/http-message-body/) — HTTP 메시지에서 헤더 뒤에 전달되는 선택적 콘텐츠로, 요청 데이터나 응답 표현을 운반한다.
- [HTTP 상태 코드](/wiki/http-status-code/) — HTTP 응답의 결과 의미를 세 자리 숫자로 표현하는 표준 코드이며 첫 자리는 정보·성공·리디렉션·클라이언트 오류·서버 오류 계열을 나타낸다.
- [HTTP 요청](/wiki/http-request/) — 클라이언트가 서버에 메서드·주소·헤더·본문을 보내는 메시지다.
- [HTTP 응답](/wiki/http-response/) — 서버가 HTTP 요청의 처리 결과를 상태 코드·필드·선택적 콘텐츠로 전달하는 메시지다.
- [HTTP 헤더](/wiki/http-header/) — HTTP 요청과 응답의 의미, 표현 형식, 인증, 캐시와 연결 처리에 관한 메타데이터를 필드 이름과 값으로 전달하는 부분이다.
- [HTTPS](/wiki/https/) — HTTPS는 HTTP 메시지를 전송 계층 보안(TLS) 연결 위에서 교환해 기밀성, 무결성과 서버 인증을 제공하는 방식이다.
- [JSON](/wiki/json/) — 키-값과 배열 구조로 데이터를 표현하는 경량 텍스트 형식이다.
- [MIME 유형](/wiki/mime-type/) — MIME 유형은 데이터의 매체 형식과 선택적 세부 형식을 type/subtype 형태로 식별하는 표준 표지다.
- [REST API](/wiki/rest-api/) — REST의 제약과 균일한 인터페이스를 적용해 자원의 표현을 주고받도록 설계한 웹 API 방식이다.
- [SDK](/wiki/sdk/) — 특정 플랫폼이나 API를 쉽게 사용하도록 제공하는 라이브러리·도구·문서의 묶음이다.
