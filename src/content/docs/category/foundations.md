---

인공지능의 범위와 기본 학습 방식 분야의 검토 완료 백과 문서입니다.

- [강화학습](/wiki/reinforcement-learning/) — 에이전트가 환경과 상호작용하며 누적 보상을 높이는 행동 정책을 학습하는 방식이다.
- [기호주의 인공지능](/wiki/symbolic-ai/) — 지식을 기호와 명시적 규칙으로 표현하고 탐색·추론 절차를 적용해 결론이나 행동을 도출하는 인공지능 접근법이다.
- [데이터셋](/wiki/dataset/) — 특정 분석이나 학습 목적에 맞춰 구조화하고 관리하는 데이터의 모음이다.
- [딥러닝](/wiki/deep-learning/) — 여러 처리 층을 가진 신경망이 데이터에서 단계적인 표현을 학습하도록 훈련하는 머신러닝 접근이다.
- [머신러닝](/wiki/machine-learning/) — 명시적으로 모든 규칙을 작성하지 않고 데이터에서 패턴을 학습해 예측이나 결정을 수행하는 인공지능의 한 분야다.
- [모델](/wiki/model/) — 입력을 출력으로 변환하도록 데이터에서 학습된 수학적 함수와 파라미터의 집합이다.
- [비지도학습](/wiki/unsupervised-learning/) — 정답 표지 없이 데이터 내부의 구조·군집·표현을 찾는 학습 방식이다.
- [생성형 인공지능](/wiki/generative-ai/) — 학습 데이터의 분포를 바탕으로 텍스트·이미지·음성·코드 같은 새로운 결과물을 생성하는 인공지능이다.
- [알고리즘](/wiki/algorithm/) — 문제를 해결하기 위해 입력을 처리하는 유한하고 명확한 절차다.
- [인공지능](/wiki/artificial-intelligence/) — 컴퓨터 시스템이 지각·추론·학습·행동과 같은 지능적 과제를 수행하도록 만드는 연구와 기술의 총칭이다.
- [자기지도학습](/wiki/self-supervised-learning/) — 데이터 자체에서 학습 목표를 만들어 대규모 비표지 데이터로 표현을 익히는 방식이다.
- [지도학습](/wiki/supervised-learning/) — 입력과 정답이 함께 있는 데이터로 입력에서 정답으로의 관계를 학습하는 방식이다.
- [학습 데이터](/wiki/training-data/) — 모델이 파라미터를 조정하며 패턴을 배우는 데 사용하는 예시와 기록의 집합이다.
