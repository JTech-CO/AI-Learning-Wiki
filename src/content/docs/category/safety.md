---

AI 시스템의 위험을 식별하고 통제하는 방법 분야의 검토 완료 백과 문서입니다.

- [가드레일](/wiki/guardrail/) — AI 시스템의 입력·출력·도구 행동과 운영 상태를 정책에 맞게 제한·검사·기록하는 다층 안전 통제 장치다.
- [간접 프롬프트 인젝션](/wiki/indirect-prompt-injection/) — 모델이 읽는 웹·문서·메일·도구 결과 같은 외부 데이터에 악성 지시를 숨겨 애플리케이션의 행동을 바꾸려는 공격이다.
- [개인정보 보호](/wiki/privacy/) — AI 시스템이 개인 데이터를 수집·처리·저장·공개할 때 권리와 위험을 관리하는 원칙이다.
- [과도한 자율성](/wiki/excessive-agency/) — 과도한 자율성은 AI 시스템에 필요한 범위를 넘는 기능, 권한 또는 독립 실행 능력을 부여해 피해 가능성이 커지는 위험이다.
- [멤버십 추론 공격](/wiki/membership-inference/) — 멤버십 추론 공격은 특정 데이터가 모델 학습에 포함되었는지를 출력 신뢰도나 행동 차이로 추정하는 개인정보 공격이다.
- [모델 백도어](/wiki/model-backdoor/) — 평소에는 정상적으로 동작하지만 특정 트리거나 조건에서 공격자가 원하는 출력을 내도록 숨겨진 행동을 가진 모델이다.
- [모델 서비스 거부 공격](/wiki/model-denial-of-service/) — 모델 서비스 거부 공격은 긴 입력, 반복 요청 또는 계산량이 큰 패턴으로 추론 자원을 고갈시켜 정상 사용을 방해하는 공격이다.
- [모델 역추론 공격](/wiki/model-inversion/) — 모델 역추론 공격은 모델 출력과 접근 가능한 정보를 이용해 입력의 민감한 속성이나 대표적인 학습 특징을 복원하려는 공격이다.
- [모델 오염](/wiki/model-poisoning/) — 공격자가 모델 가중치, 체크포인트 또는 학습·배포 아티팩트를 변조해 의도한 오작동을 심는 공급망 공격이다.
- [모델 추출 공격](/wiki/model-extraction/) — 공격자가 모델 API를 반복 질의해 대상 모델의 기능, 결정 경계 또는 유사한 대체 모델을 복제하는 공격이다.
- [민감정보 노출](/wiki/sensitive-information-disclosure/) — 민감정보 노출은 모델이나 애플리케이션이 개인정보, 비밀 키, 내부 지침 또는 보호된 문서를 허가되지 않은 사용자에게 드러내는 문제다.
- [안전하지 않은 출력 처리](/wiki/insecure-output-handling/) — 안전하지 않은 출력 처리는 언어 모델의 출력을 검증 없이 코드, 쿼리, HTML 또는 외부 명령으로 실행해 취약점이 생기는 문제다.
- [적대적 예시](/wiki/adversarial-example/) — 사람이 보기에는 같거나 의미가 유지되지만 모델의 예측을 바꾸도록 의도적으로 조작된 입력이다.
- [콘텐츠 조정](/wiki/content-moderation/) — 유해하거나 정책을 위반하는 콘텐츠를 탐지·분류·처리하는 과정이다.
- [탈옥 공격](/wiki/jailbreak/) — 모델의 안전 정책과 행동 제한을 우회하도록 입력을 구성하는 공격 기법이다.
- [편향과 공정성](/wiki/bias-fairness/) — 모델의 결과가 집단이나 특성에 따라 체계적으로 불리하게 달라지는지를 다루는 개념이다.
- [프롬프트 유출](/wiki/prompt-leakage/) — 프롬프트 유출은 시스템 지침, 내부 예시나 숨겨진 컨텍스트가 모델 응답을 통해 노출되는 현상이다.
- [프롬프트 인젝션](/wiki/prompt-injection/) — 악의적 입력이 기존 지시를 무시하거나 비밀을 노출하도록 모델 행동을 조작하는 공격이다.
- [학습 데이터 오염](/wiki/training-data-poisoning/) — 공격자가 학습 데이터에 조작된 사례나 레이블을 섞어 모델의 일반 성능 또는 특정 행동을 훼손하는 공격이다.
- [환각](/wiki/hallucination/) — 모델이 근거가 없거나 사실과 다른 내용을 그럴듯하게 생성하는 현상이다.
- [회피 공격](/wiki/evasion-attack/) — 운영 중인 모델의 입력을 조작해 탐지나 올바른 분류를 피하게 만드는 추론 시점 공격이다.
- [AI 거버넌스](/wiki/ai-governance/) — AI의 개발과 사용을 조직의 정책·책임·통제·감사 체계로 관리하는 활동이다.
- [AI 공급망 취약점](/wiki/ai-supply-chain-vulnerability/) — AI 공급망 취약점은 모델, 데이터, 라이브러리, 저장소와 배포 구성 요소 중 하나가 변조되거나 신뢰되지 않아 전체 시스템이 손상되는 위험이다.
- [AI 안전](/wiki/ai-safety/) — AI 안전은 AI 시스템이 의도한 목표를 신뢰할 수 있게 수행하고 오용, 사고와 예측하지 못한 피해를 줄이기 위한 연구와 실무 영역이다.
- [RAG 오염](/wiki/rag-poisoning/) — RAG 오염은 검색 증강 생성 시스템의 문서나 인덱스에 악성 또는 거짓 콘텐츠를 넣어 검색 결과와 모델 출력을 조작하는 공격이다.
