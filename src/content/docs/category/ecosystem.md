description: "모델 공개와 배포 생태계의 기본 개념"
---

모델 공개와 배포 생태계의 기본 개념 분야의 검토 완료 백과 문서입니다.

- [모델 가중치 파일](/wiki/model-weights/) — 학습 과정에서 갱신된 신경망 파라미터 텐서를 저장한 파일 또는 파일 집합이다.
- [모델 계보](/wiki/model-lineage/) — 모델이 어떤 데이터, 코드, 구성, 학습 실행, 평가와 상위 아티팩트에서 만들어졌는지를 연결한 계보 정보다.
- [모델 라이선스](/wiki/model-license/) — 모델 가중치·코드 등 배포물의 사용·수정·재배포 조건을 정한 법적 약정이다. 일부 약정은 출력과 파생 모델의 이용 조건도 별도로 규정한다.
- [모델 레지스트리](/wiki/model-registry/) — 학습된 모델 버전과 메타데이터·검증 상태·배포 참조를 중앙에서 추적하고 관리하는 수명주기 시스템이다.
- [모델 롤백](/wiki/model-rollback/) — 문제가 있는 모델 변경을 중단하고 이전에 검증된 모델·구성·데이터 처리 상태로 되돌리는 복구 절차다.
- [모델 버전](/wiki/model-version/) — 가중치·구조·전처리·토크나이저·설정과 평가 기록의 특정 조합을 식별하고 재현·비교·롤백하기 위한 불변 참조 단위다.
- [모델 아티팩트 형식](/wiki/model-artifact-format/) — 모델 구조와 파라미터 또는 관련 메타데이터를 파일로 표현하기 위한 직렬화 규약과 컨테이너 형식이다.
- [모델 업데이트](/wiki/model-update/) — 운영 중인 모델이나 그 구성 요소를 새로운 버전으로 교체해 성능, 안전성, 비용 또는 호환성을 개선하는 변경이다.
- [모델 출시](/wiki/model-release/) — 검증된 모델 버전과 관련 아티팩트를 정해진 사용자 또는 환경에서 사용할 수 있도록 승인하고 배포 가능한 상태로 발표하는 과정이다.
- [모델 카탈로그](/wiki/model-catalog/) — 조직이나 플랫폼이 보유한 모델을 검색하고 소유권, 상태, 용도와 관련 아티팩트를 확인할 수 있게 정리한 관리 목록이다.
- [모델 패키지](/wiki/model-package/) — 모델을 로드하고 재현하거나 배포하는 데 필요한 가중치, 구성, 전처리 자산과 메타데이터를 묶은 배포 단위다.
- [모델 평가 보고서](/wiki/model-evaluation-report/) — 모델을 어떤 데이터와 절차, 지표로 평가했고 어떤 한계와 승인 결론을 얻었는지 기록한 검토 산출물이다.
- [모델 폐기](/wiki/model-retirement/) — 모델의 사용과 지원을 계획적으로 종료하고 대체 경로, 기록 보존과 접근 차단을 수행하는 수명주기 단계다.
- [모델 허브](/wiki/model-hub/) — 모델·데이터셋·데모·평가 정보를 검색하고 배포하는 공유 플랫폼이다.
- [오픈소스 모델](/wiki/open-source-model/) — 사용·연구·수정·공유의 자유를 보장하고, 모델을 수정하는 데 필요한 코드·파라미터·데이터 정보를 제공하는 AI 모델 또는 시스템이다.
