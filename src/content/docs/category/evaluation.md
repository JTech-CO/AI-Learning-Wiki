title: "평가·관측성·벤치마크"
description: "모델과 시스템의 품질을 측정하는 방법"
---

모델과 시스템의 품질을 측정하는 방법 분야의 검토 완료 백과 문서입니다.

- [곡선 아래 면적](/wiki/area-under-curve/) — 성능 곡선 아래의 면적을 하나의 수로 요약한 값이며 어떤 곡선과 적분 규칙을 사용했는지 함께 명시해야 한다.
- [관측성](/wiki/observability/) — 로그·메트릭·추적 정보로 시스템 내부 상태와 실패 원인을 이해할 수 있는 정도다.
- [로그 손실](/wiki/log-loss/) — 모델이 실제 클래스에 부여한 확률의 음의 로그를 평균한 확률적 분류 손실이다.
- [모델 평가](/wiki/evaluation/) — 정해진 데이터·기준·절차로 모델이나 시스템의 품질과 위험을 측정하는 과정이다.
- [벤치마크](/wiki/benchmark/) — 여러 모델이나 시스템을 비교하기 위해 고정한 과제·데이터·평가 지표의 묶음이다.
- [정밀도-재현율 곡선](/wiki/precision-recall-curve/) — 분류 임계값을 변화시키며 재현율에 대한 정밀도를 그려 양성 탐지와 오탐의 교환 관계를 보여 주는 곡선이다.
- [정밀도와 재현율](/wiki/precision-recall/) — 정밀도는 양성으로 예측한 항목의 적중 비율이고 재현율은 실제 양성 가운데 찾아낸 비율이다.
- [정확도](/wiki/accuracy/) — 전체 평가 예시 중 모델이 정답을 맞힌 비율이다.
- [추적](/wiki/tracing/) — 한 요청이 여러 모델·도구·단계를 거치는 실행 흐름과 시간을 기록하는 방법이다.
- [특이도](/wiki/specificity/) — 실제 음성 사례 가운데 모델이 음성으로 올바르게 판정한 비율이며 TN을 TN과 FP의 합으로 나눈다.
- [평가 지표](/wiki/metric/) — 성능이나 품질의 특정 측면을 수치로 요약하는 측정 기준이다.
- [혼동 행렬](/wiki/confusion-matrix/) — 분류 모델의 실제 클래스와 예측 클래스를 교차표로 집계해 어떤 종류의 정답과 오류가 발생했는지 보여 주는 행렬이다.
- [F1 점수](/wiki/f1-score/) — 정밀도와 재현율의 조화평균으로 두 지표가 모두 높을 때만 큰 값을 갖는 분류·검색 성능 지표다.
- [LLM 심사자](/wiki/llm-as-a-judge/) — 언어 모델을 사용해 다른 모델 출력의 품질을 판정하거나 비교하는 평가 방식이다.
- [ROC 곡선](/wiki/roc-curve/) — 분류 임계값을 변화시키며 거짓양성률에 대한 참양성률을 그린 곡선이다.
