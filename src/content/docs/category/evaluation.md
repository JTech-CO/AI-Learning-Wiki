---
title: "평가·관측성·벤치마크"
description: "모델과 시스템의 품질을 측정하는 방법"
---

모델과 시스템의 품질을 측정하는 방법 분야의 검토 완료 백과 문서입니다.

- [곡선 아래 면적](/wiki/area-under-curve/) — 성능 곡선 아래의 면적을 하나의 수로 요약한 값이며 어떤 곡선과 적분 규칙을 사용했는지 함께 명시해야 한다.
- [과제 벤치마크](/wiki/task-benchmark/) — 과제 벤치마크는 번역·분류·코드 생성처럼 명시된 한 과제의 성능을 비교하기 위한 데이터와 채점 규칙이다.
- [관측성](/wiki/observability/) — 로그·메트릭·추적 정보로 시스템 내부 상태와 실패 원인을 이해할 수 있는 정도다.
- [기대 보정 오차](/wiki/expected-calibration-error/) — 기대 보정 오차(ECE)는 비슷한 신뢰도의 예측을 구간으로 묶고 각 구간의 평균 신뢰도와 실제 정확도 차이를 가중 평균한 값이다.
- [능력 벤치마크](/wiki/capability-benchmark/) — 능력 벤치마크는 지식, 추론, 계획처럼 여러 과제에 걸친 상위 능력을 조작적으로 정의해 측정하는 평가다.
- [데이터 주석](/wiki/data-annotation/) — 데이터 주석은 원시 데이터에 범주, 경계, 관계, 선호나 설명을 부여해 학습·평가에 사용할 참조 정보를 만드는 과정이다.
- [동적 벤치마크](/wiki/dynamic-benchmark/) — 동적 벤치마크는 모델 성능과 실패 양상에 맞추어 평가 사례를 지속적으로 수집·갱신하는 벤치마크다.
- [로그 손실](/wiki/log-loss/) — 모델이 실제 클래스에 부여한 확률의 음의 로그를 평균한 확률적 분류 손실이다.
- [리더보드](/wiki/leaderboard/) — 리더보드는 동일한 평가 규칙으로 측정한 모델이나 시스템의 성능을 순위와 함께 공개하는 표다.
- [리커트 척도](/wiki/likert-scale/) — 리커트 척도는 응답자가 진술에 대한 동의나 평가 정도를 순서가 있는 여러 범주 중 하나로 표시하는 척도다.
- [맹검 평가](/wiki/blind-evaluation/) — 맹검 평가는 평가자가 후보의 제작자·모델명·실험 조건 중 판단에 불필요한 정보를 모른 채 결과를 판정하는 절차다.
- [모델 평가](/wiki/evaluation/) — 정해진 데이터·기준·절차로 모델이나 시스템의 품질과 위험을 측정하는 과정이다.
- [벤치마크](/wiki/benchmark/) — 여러 모델이나 시스템을 비교하기 위해 고정한 과제·데이터·평가 지표의 묶음이다.
- [벤치마크 데이터셋](/wiki/benchmark-dataset/) — 벤치마크 데이터셋은 모델이나 방법을 같은 입력과 정답 기준에서 비교하도록 고정한 평가용 데이터 모음이다.
- [벤치마크 모음](/wiki/benchmark-suite/) — 벤치마크 모음은 여러 과제·데이터셋·지표를 하나의 평가 프로토콜로 묶어 시스템의 다양한 능력을 측정하는 구성이다.
- [벤치마크 타당도](/wiki/benchmark-validity/) — 벤치마크 타당도는 평가 점수가 측정하려는 실제 능력이나 사용 목표를 얼마나 제대로 대표하는지를 뜻한다.
- [벤치마크 포화](/wiki/benchmark-saturation/) — 벤치마크 포화는 많은 시스템이 평가 상한에 가까워져 점수 차이가 실제 능력 차이를 충분히 구분하지 못하는 상태다.
- [브라이어 점수](/wiki/brier-score/) — 브라이어 점수는 확률 예측과 실제 이진 결과 사이의 제곱 오차 평균으로 확률 예측의 정확성을 평가한다.
- [승률](/wiki/win-rate/) — 승률은 두 모델이나 방법을 쌍대 비교했을 때 한쪽이 더 낫다고 판정된 비율이다.
- [쌍대 비교](/wiki/pairwise-comparison/) — 쌍대 비교는 두 후보를 동시에 제시하고 어느 쪽이 기준에 더 부합하는지 선택하게 하는 평가 방식이다.
- [안전 벤치마크](/wiki/safety-benchmark/) — 안전 벤치마크는 유해 출력, 편향, 보안 취약성이나 거부 행동 등 모델의 위험 관련 특성을 측정하는 평가다.
- [완전 일치](/wiki/exact-match/) — 완전 일치는 예측 문자열이나 구조가 정답과 사전에 정한 정규화 뒤 정확히 같은지를 세는 평가 지표다.
- [인간 평가](/wiki/human-evaluation/) — 인간 평가는 사람이 정의된 기준에 따라 모델 출력의 품질·선호·안전성 등을 직접 판단하는 평가 방식이다.
- [전문가 평가](/wiki/expert-evaluation/) — 전문가 평가는 해당 분야의 지식과 실무 경험을 가진 평가자가 전문 기준으로 결과의 정확성·유용성·위험을 판정하는 방식이다.
- [정밀도-재현율 곡선](/wiki/precision-recall-curve/) — 분류 임계값을 변화시키며 재현율에 대한 정밀도를 그려 양성 탐지와 오탐의 교환 관계를 보여 주는 곡선이다.
- [정밀도와 재현율](/wiki/precision-recall/) — 정밀도는 양성으로 예측한 항목의 적중 비율이고 재현율은 실제 양성 가운데 찾아낸 비율이다.
- [정확도](/wiki/accuracy/) — 전체 평가 예시 중 모델이 정답을 맞힌 비율이다.
- [주석 판정](/wiki/annotation-adjudication/) — 주석 판정은 주석자 사이의 불일치를 지침과 증거에 따라 검토해 최종 참조 레이블을 결정하는 절차다.
- [주석자 합의도](/wiki/annotator-agreement/) — 주석자 합의도는 같은 사례를 독립적으로 판정한 주석자들이 얼마나 일치하는지 나타내는 품질 정보다.
- [추적](/wiki/tracing/) — 한 요청이 여러 모델·도구·단계를 거치는 실행 흐름과 시간을 기록하는 방법이다.
- [크라우드소싱 평가](/wiki/crowdsourced-evaluation/) — 크라우드소싱 평가는 온라인 참여자 집단에 작은 평가 과제를 분배해 대규모 판단 데이터를 수집하는 방식이다.
- [특이도](/wiki/specificity/) — 실제 음성 사례 가운데 모델이 음성으로 올바르게 판정한 비율이며 TN을 TN과 FP의 합으로 나눈다.
- [평가 루브릭](/wiki/evaluation-rubric/) — 평가 루브릭은 결과를 판단할 기준과 수준별 설명, 배점 규칙을 명시한 채점 도구다.
- [평가 지표](/wiki/metric/) — 성능이나 품질의 특정 측면을 수치로 요약하는 측정 기준이다.
- [평가 표본추출](/wiki/evaluation-sampling/) — 평가 표본추출은 전체 가능한 입력 중 평가에 사용할 사례를 규칙에 따라 선택하는 과정이다.
- [평가자 간 신뢰도](/wiki/inter-rater-reliability/) — 평가자 간 신뢰도는 여러 평가자의 점수가 평가 대상의 차이를 일관되게 반영하는 정도를 통계적으로 측정한 값이다.
- [혼동 행렬](/wiki/confusion-matrix/) — 분류 모델의 실제 클래스와 예측 클래스를 교차표로 집계해 어떤 종류의 정답과 오류가 발생했는지 보여 주는 행렬이다.
- [BEIR 벤치마크](/wiki/beir-benchmark/) — BEIR 벤치마크는 여러 도메인의 정보 검색 데이터셋에서 검색 모델의 제로샷 일반화 성능을 비교하는 평가 모음이다.
- [BERTScore](/wiki/bertscore/) — BERTScore는 문맥 임베딩 사이의 코사인 유사도로 후보와 참조 토큰을 대응시켜 정밀도, 재현율과 F1을 계산한다.
- [BIG-bench](/wiki/big-bench/) — BIG-bench는 다양한 연구자가 제안한 광범위한 과제로 대규모 언어 모델의 능력과 한계를 탐색하는 협업 벤치마크다.
- [BLEU 점수](/wiki/bleu-score/) — BLEU 점수는 기계 번역 후보와 하나 이상의 참조 문장 사이의 수정된 n-그램 정밀도와 길이 패널티를 결합한 말뭉치 수준 지표다.
- [F1 점수](/wiki/f1-score/) — 정밀도와 재현율의 조화평균으로 두 지표가 모두 높을 때만 큰 값을 갖는 분류·검색 성능 지표다.
- [GPQA](/wiki/gpqa/) — GPQA는 전문 지식이 없는 검색만으로 풀기 어려운 대학원 수준 과학 객관식 문제로 추론 능력을 평가하는 벤치마크다.
- [HELM 벤치마크](/wiki/helm-benchmark/) — HELM은 시나리오, 적응 방식과 여러 지표를 명시해 언어 모델을 투명하고 다면적으로 비교하는 평가 체계다.
- [HumanEval](/wiki/humaneval/) — HumanEval은 함수 설명과 테스트를 이용해 코드 생성 모델이 올바른 프로그램을 작성하는지 평가하는 벤치마크다.
- [ImageNet](/wiki/imagenet/) — ImageNet은 대규모 계층형 이미지 범주와 주석으로 구성되어 이미지 분류와 시각 표현 학습 연구에 널리 쓰인 데이터셋이다.
- [LLM 심사자](/wiki/llm-as-a-judge/) — 언어 모델을 사용해 다른 모델 출력의 품질을 판정하거나 비교하는 평가 방식이다.
- [METEOR 점수](/wiki/meteor-score/) — METEOR는 후보와 참조의 단어 정렬을 바탕으로 정밀도·재현율 조화평균과 어순 단절 패널티를 계산하는 생성 평가 지표다.
- [MLPerf](/wiki/mlperf/) — MLPerf는 합의된 모델·데이터·품질 목표와 실행 규칙으로 AI 학습 및 추론 시스템의 성능을 비교하는 벤치마크 제품군이다.
- [MMLU](/wiki/mmlu/) — MMLU는 초등 수준부터 전문 영역까지 여러 선택형 과목을 이용해 언어 모델의 지식과 문제 해결 능력을 평가하는 벤치마크다.
- [MTEB](/wiki/mteb/) — MTEB는 분류·검색·군집·유사도 등 다양한 과제에서 텍스트 임베딩 모델을 공통 절차로 비교하는 평가 묶음이다.
- [Pass@K](/wiki/pass-at-k/) — Pass@K는 코드 생성처럼 여러 후보를 만들 때 k개 후보 중 적어도 하나가 테스트를 통과할 확률을 추정하는 지표다.
- [ROC 곡선](/wiki/roc-curve/) — 분류 임계값을 변화시키며 거짓양성률에 대한 참양성률을 그린 곡선이다.
- [ROUGE 점수](/wiki/rouge-score/) — ROUGE는 생성 요약과 참조 요약이 공유하는 n-그램, 최장 공통 부분수열 등의 재현율 중심 중복을 측정하는 지표군이다.
- [SWE-bench](/wiki/swe-bench/) — SWE-bench는 실제 오픈소스 저장소의 이슈와 코드 상태를 사용해 시스템이 결함을 수정하고 테스트를 통과시키는 능력을 평가하는 벤치마크다.
