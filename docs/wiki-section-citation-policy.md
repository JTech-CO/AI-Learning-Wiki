# W3 구획별 인용 정책

## 목적

백과 본문의 각 사실 구획이 참고문헌 중 어느 자료에 기대는지 독자가 바로 추적할 수 있게 한다. W3은 출처의 문서 범위와 구획 주제의 대응을 확정하는 단계이며, 모든 문장을 원문 구절과 대조한 최종 출판 승인은 아니다.

## 표시 규칙

- 사실을 설명하는 `overview`부터 `practice`까지의 9개 구획에 `sourceRefs`를 둔다.
- `sourceRefs`의 정수는 해당 문서 `sources` 배열의 1부터 시작하는 참고문헌 번호다.
- 독자 확인 문제인 `check` 구획에는 출처 번호를 붙이지 않는다.
- 본문에는 `근거 [n]` 링크를 표시하고, 링크는 같은 문서 하단의 참고문헌 항목으로 이동한다.
- 하나의 출처를 문서 전체의 만능 근거처럼 사용하지 않는다. 구획의 역할에 맞춰 논문·공식 문서·표준·백과를 선택한다.

## 상태 구분

- `document-scope-reviewed`: 출처의 제목·초록·공식 설명 범위가 해당 구획의 주제와 맞는지 검토했다.
- `pending-line-review`: 구획 안의 개별 수치·고유명사·강한 인과 주장까지 원문 위치와 대조하는 작업이 남아 있다.
- W3 매핑만으로 문서를 `publicationReady`로 바꾸지 않는다. 문장 단위 대조와 편집자 승인을 별도 관문으로 유지한다.

## 저작권 원칙

외부 문장의 복사본이나 긴 인용문은 저장하지 않는다. 백과 자료는 범위와 용어 관계 대조에 쓰고, 본문은 1차 자료 및 공식 문서와 함께 독자적으로 재서술한다.
