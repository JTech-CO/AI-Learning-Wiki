# W8 분야별 두 번째 제작 배치

W8은 W7 제작 대기열에서 아직 발행되지 않은 문서 가운데 분야별 최상위 문서 1개씩, 총 14개를 선정했다. 기존 백과 문서 6개를 전면 보강하고 후보 표제어 8개를 새 백과 문서로 제작했다.

## 배치 구성

- 기존 문서 보강 6개: 가중치, 쿼리·키·값, 다음 토큰 예측, 데이터 증강, 생성 온도, AI 가드레일
- 신규 문서 8개: 상징적 인공지능, 행렬 곱셈, 밀집 임베딩, HTTP 메서드, ReAct 에이전트, 이미지 분류, F1 점수, 모델 버전
- 각 문서는 논문·표준 또는 공식 문서와 외부 백과를 포함한 세 독립 출처 계열로 교차 검토했다.
- 정의, 작동 원리, 구성 요소, 적용 기준, 한계, 관련 개념 구분, 예시와 운영 검증 절차를 문장 단위 근거 장부에 고정한다.

## 완료 후 상태

- 전체 백과 문서 163개
- 문장 단위 근거 검토 완료 70개
- 기존 문서 보강 대기 93개
- 신규 조사·작성 대기 1,237개

다음 배치는 W8 제작 큐에서 각 분야의 다음 미발행 문서를 같은 기준으로 선정한다.
