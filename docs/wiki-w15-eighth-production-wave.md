- LLM: 시범 예시, 문맥 길이·설계·대화·절단, 슬라이딩 창, 메모리 토큰, 외부·순환 메모리와 문맥 캐싱

- 안전: 편향 완화, 설명 가능성·해석 가능성, 모델 투명성, 모델 카드·데이터시트·시스템 카드, AI 고지, 의사결정 출처와 불확실성 소통

## 파이프라인 변경

- W15 전용 140개 사실 프로필과 주제별 학술·표준·공식 출처 매핑을 추가했다.
- W15 준비, 문장 주장 원장, 생산 큐, 검증과 렌더 검사 단계를 전체 빌드에 연결했다.
- 주장 원장과 생산 큐 스키마가 W15 버전을 허용하도록 확장했다.
- Wiki 페이지 생성기가 W15 원장을 출판 준비 상태에 포함하도록 갱신했다.
- W14 생산 큐 검증은 최신 분류 상태가 아니라 W14 원장의 910/490 스냅샷을 계속 검증하도록 전방 호환 처리했다.
- 신규 출처 중 접근이 막힌 3개 주소는 공개 접근 가능한 KServe 공식 문서, MIT 강의 자료와 Stanford 정보이론 자료로 교체했다.
