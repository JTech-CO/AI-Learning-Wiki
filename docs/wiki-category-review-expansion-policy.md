# W5 분야별 검토 완료 문서 확장 정책

W5는 W4에서 분야당 1개로 검증한 문장 단위 근거 검토를 14개 분야의 다음 핵심 문서 1개씩에 적용한다. 이 배치가 끝나면 14개 분야마다 최소 2개의 게시 준비 문서를 확보하며, 누적 게시 준비 문서는 28개가 된다.

## 선정 기준

- W0 분류에서 `core` 등급인 기존 문서를 우선한다.
- W4 문서와 중복하지 않으며 14개 주 분류에서 정확히 1개씩 선택한다.
- 독립 출처 계열 3개 이상, 논문·표준·공식 문서 1개 이상, 백과 계열 1개 이상을 요구한다.
- 안전 문서는 직접·간접 공격과 완화 한계를 전수 검토하고, 라이선스 문서는 공개 접근과 실제 사용 권리를 분리한다.

## 승인과 변경 관리

각 사실 구획은 출처 번호와 원문 위치를 표시한다. 본문은 한국어 문장 단위로 분리하고 SHA-256 해시만 승인 원장에 저장한다. 모든 문장이 `accepted`이고 본문 해시가 일치하는 문서만 `publicationReady`가 된다.

일반 빌드는 승인 원장을 자동 갱신하지 않는다. 본문, 출처 순서 또는 근거 위치가 바뀌면 검증이 실패하며, 편집자가 출처를 다시 대조한 뒤 `wiki:w5:refresh`를 명시적으로 실행해야 한다.
