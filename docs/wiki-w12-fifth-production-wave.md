# W12 5차 백과 문서 생산 웨이브

## 목표

W12는 14개 분야에서 다음 우선순위 문서를 10개씩 새로 제작해 검토 완료 백과 문서를 분야별 45개, 누적 630개로 확장하는 단계다. W11의 문서 생산, 출처 검증, 문장 단위 근거 잠금, 렌더링 검사를 그대로 유지하면서 에이전트 도구 사용, API 상호작용, 모델 생태계와 가속기, 평가 벤치마크, 학습 이론, 추론 서빙, 언어 모델 스케일링, 최적화 수학, 오디오·비디오, 신경망 구조, 검색 인덱스 운영, AI 통제와 개인정보 보호, 학습 목적 함수, 트랜스포머 구성 요소를 확장했다.

## 완료 범위

- 14개 분야에서 신규 문서 140개를 제작했다.
- 검토 완료 백과 문서는 누적 630개이며 모든 분야에 45개씩 균등하게 배치했다.
- 각 문서는 개요, 배경, 작동 원리, 구성 요소, 활용, 한계, 관련 개념, 적용 예시, 실무 검증, 참고 자료를 포함한다.
- W12 신규 문서 140개를 10개의 재개 가능한 작업 묶음으로 관리한다.
- 미작성 후보 770개는 분야·우선순위·출처 조사 상태와 함께 다음 웨이브 대기열에 유지한다.

신규 문서는 주제별 정의와 작동 원리를 별도로 작성하고 논문·표준·공식 문서·학술서와 백과 자료를 교차 연결했다. 문서별 최소 길이, 구획별 최소 설명량, 중복 문단, 한국어·영문 표제, 출처 유형 다양성, 문장 단위 근거와 내부 링크를 자동 검증한다.

W0부터 W12까지의 전체 회귀 빌드에서 630개 백과 문서의 렌더링 상태와 근거 앵커를 검사했고, 661개 정적 페이지에 걸친 내부 링크 22,591건이 모두 유효함을 확인했다. 기존 실습 자료는 독립 레슨 경로 없이 1,173개 프롬프트로 통합되어 있으며 릴리스 검사에서도 과거 에듀버스 종속 경로가 검출되지 않았다.

## W13 제안

W13에서는 같은 기준으로 분야별 다음 우선순위 신규 문서 10개씩, 총 140개를 추가한다. 완료 시 누적 770개, 분야별 55개가 되며 1,400개 목표 중 630개가 다음 생산 후보로 남는다.
