# W7 첫 제작 배치

W7은 W6에서 고정한 1,400개 제작 큐를 실제 백과 확장으로 전환한 첫 운영 배치다. 각 분야에서 아직 발행되지 않은 항목 가운데 순위가 가장 높은 문서 1개를 선택해 총 14개를 문장 단위로 검토했다.

## 배치 구성

- 기존 문서 출처·본문 보강 9개: 워크플로 오케스트레이션, 정밀도와 재현율, 딥러닝, 소프트맥스, 소규모 언어 모델, 신경망 층, 임베딩 모델, 합성 데이터, 크로스 어텐션
- 신규 백과 문서 5개: HTTP 응답, 스칼라, 컴퓨터 비전, 간접 프롬프트 인젝션, 모델 레지스트리
- 각 문서는 논문·표준·공식 문서 가운데 하나 이상과 외부 백과를 포함해 세 계열 이상의 독립 출처를 사용한다.
- 핵심 정의와 작동 원리는 백과 자료만으로 승인하지 않으며 1차·공식 자료에 연결한다.

## 완료 뒤 상태

- 전체 백과 문서 155개
- 문장 단위 근거 검토 완료 56개
- 기존 문서 보강 대기 99개
- 신규 조사·작성 대기 1,245개

다음 배치도 W7 제작 큐에서 분야별 미발행 항목의 순위를 기준으로 선택하고 같은 본문 해시·문장 근거 게이트를 통과시킨다.
