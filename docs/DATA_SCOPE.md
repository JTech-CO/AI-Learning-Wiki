# 데이터 수집·이용 범위

기준일: 2026-07-12

프로젝트 소유자는 EduVerse 운영 측과 사이트 데이터 파싱에 관해 협의가 완료되었다고 2026-07-12 Codex 이관 대화에서 확인했다.

이 문서는 법률 문서나 운영 측 원문 합의서를 대체하지 않는다. 실제 배포 전에는 합의 원문 또는 담당자 확인 기록을 별도 보관해야 한다.

## 현재 적용 원칙

- 허용된 EduVerse 학습 콘텐츠만 수집한다.
- 인증정보, 세션 토큰, API 키, 개인 학습 기록은 수집·커밋하지 않는다.
- 화면에 정상 렌더된 콘텐츠 또는 운영자가 제공한 export를 원본으로 사용한다.
- 수집 원문은 `content-model/raw`에 두며 기본적으로 Git에서 제외한다.
- 운영 측 콘텐츠와 자체 제작·보강 콘텐츠의 출처를 구분한다.
- 외부 공개 범위가 확인되기 전에는 내부용으로 취급한다.

## 배포 전 확정 항목

- [ ] 운영 측 담당자 또는 합의 문서 식별 정보
- [ ] 허용된 코스와 데이터 필드
- [ ] 원문 보관 허용 여부와 보관 기간
- [ ] 내부 공개 / 제한 공개 / 전체 공개 범위
- [ ] 상업 이용 및 2차 저작물 허용 범위
- [ ] 출처 표기 문구와 링크 방식
- [ ] 삭제·정정 요청 접수 및 반영 절차
