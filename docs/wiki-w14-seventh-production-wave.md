각 분야에서 W13 생산 큐의 다음 우선순위 10개를 선택했다.

- 에이전트: 계층적 작업 네트워크, 생각의 나무·그래프, 탐색·모델 기반 계획, 재계획과 계획 검증
- API: 도구 오류, 출력 파싱·검증, 동기·비동기 클라이언트, 재시도와 미들웨어
- 생태계: PyTorch, TensorFlow, JAX, Keras, Transformers, Datasets, 실험 추적과 피처 스토어
- 평가: 주석자 피로·편향, 정성 평가, 자동 평가기와 LLM 판정 방식
- 기초: 그래디언트 부스팅, SVM, 나이브 베이즈, KNN, PCA·ICA, 이상 탐지와 앙상블
- 추론: 프롬프트 조회 디코딩, 캐시 적중률, 학습 후·가중치·활성값 양자화, INT8·INT4·FP8, GGUF와 ONNX Runtime
- LLM: 프롬프트 템플릿·설계·압축·체이닝, 출력 제약, 민감도와 자동 최적화
- 수학: 추정량, 편향, 신뢰구간, 가설 검정, p값, 가능도, 베이즈 사전·사후확률과 부트스트랩
- 멀티모달: 모달리티, 초기·후기 융합, 교차 모달 어텐션·정렬, 공동 임베딩과 지시 미세조정
- 신경망: Adam·AdamW, 학습률 스케줄·워밍업, 그래디언트 클리핑·소실·폭주, 2차 최적화와 누적
- 검색: 연합·패싯·적응형·재귀 검색, 청크 크기·중첩, 문장 분할, 문서 파싱과 수집 파이프라인
- 안전: 측정·선택·역사적 편향, 인구통계적 동등성, 균등 오즈, 기회균등과 교차 공정성
- 학습: 선호 데이터, Bradley–Terry 모형, KL 패널티, 기준·정책 모델, Best-of-N과 온·오프라인 선호 학습

## 파이프라인 변경

- W14 전용 사실 프로필과 주제별 1차·공식 출처 매핑을 추가했다.
- W14 준비, 문장 주장 원장, 생산 큐, 검증과 렌더 검사 단계를 전체 빌드에 연결했다.
- 주장 원장과 생산 큐 스키마가 W14 버전을 허용하도록 확장했다.
- Wiki 페이지 생성기가 W14 원장을 출판 준비 상태에 포함하도록 갱신했다.
- W13과 W14 생산 큐는 최신 분류 상태가 아니라 각 마일스톤의 출판 원장으로 당시 상태를 재구성한다. 따라서 W13의 770/630 스냅샷과 W14의 910/490 스냅샷을 동시에 재현할 수 있다.
- W13 문서 수·렌더 검사는 이후 마일스톤 문서가 추가되어도 기존 보증을 계속 검증하도록 전방 호환 처리했다.
