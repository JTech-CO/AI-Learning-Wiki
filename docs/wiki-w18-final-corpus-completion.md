## 구축 범위

W18에서는 각 분야의 우선순위 96~100위 문서를 추가했다. 주제별로 고유한 한국어 정의와 작동 원리를 작성하고, 논문·표준·공식 문서와 백과 자료를 결합해 최소 세 개의 독립 출처 계열을 유지했다.

- AI·머신러닝 기초: 무공짜 점심 정리, 협의·범용 인공지능, 튜링 테스트, AI 생애주기
- 수학: 커널 함수와 커널 트릭, 고차원 기하학, 차원의 저주, 측도 집중
- 트랜스포머·LLM: 희소·상태공간 하이브리드·확산·멀티모달 트랜스포머, 깊이 혼합, 모델 붕괴, 잠재 추론
- 학습·추론: 차등 개인정보보호 학습, 기계 언러닝, 재현성·감사 로그, 결정적 추론과 운영 모니터링
- 검색·API·에이전트: 온톨로지·SPARQL·하이브리드 RAG, API 감사와 버전 계약, 에이전트 추적·가드레일·보안
- 멀티모달·평가·안전: 시각 환각과 딥페이크, 통계적 불확실성, AI 사건 대응과 심층 방어

## W19 권장 범위

문서 수 확장 목표는 W18에서 종료한다. W19부터는 수량 증가보다 기존 1,400개 문서의 유지보수와 깊이 향상에 집중한다.

1. 짧거나 일반론적인 문서를 분야별로 선별해 사례·비교·수식·실패 조건을 심화한다.
2. 변동성이 높은 API·정책·모델·표준 문서에 갱신 주기와 기준 날짜를 적용한다.
3. 출처의 주제 관련성, 독립성, 철회·폐기 여부를 정기 감사한다.
4. 중복 설명과 번역투를 교정하고 한국어 표제·영문 표제·별칭을 재검토한다.
5. 문서 간 선행·관련 링크와 8개 학습 코스의 다음 문서 연결을 학습 난이도에 맞게 개선한다.
