# AI Learning Wiki 근거 감사 정책 — W2

W2는 기존 150개 문서가 가진 출처를 주장 단위 인용으로 전환하기 전의 감사 단계다. HTTP 응답 성공은 URL이 접근 가능하다는 뜻일 뿐, 문서의 주장과 출처가 관련 있거나 주장이 사실임을 보증하지 않는다. 따라서 자동화 결과는 `publicationReady`가 될 수 없으며 모든 문서는 수동 주장 검토를 거쳐야 한다.

## 출처 접근성

기존 문서에 연결된 출처와 W1 권위 출처 앵커의 URL을 점검한다. 저장하는 값은 최종 URL, HTTP 상태, 콘텐츠 유형, ETag, Last-Modified, 확인 시각뿐이다. 외부 본문은 저장하지 않는다. 인증이나 봇 제한으로 401·403·429를 반환하면 `restricted`, 그 밖의 실패는 `unavailable`로 분리한다.

W1에서 MediaWiki API로 페이지 ID와 리비전 ID를 확인한 Wikipedia 항목은 `wikimedia-api` 상태로 기록한다. 이 역시 관련성 검토를 대신하지 않는다.

## 문서별 근거 팩

각 문서에는 현재 편집자가 연결한 출처, W1에서 발견한 Wikimedia 메타데이터, 분야별 조사 앵커가 연결된다. 기존 출처는 `editor-linked`, Wikimedia 자동 발견 항목은 `metadata-only`로 구분한다.

구획별 연결은 확정 인용이 아니라 수동 검토 후보이다. 개요·범위·개념 구분에는 백과·책·논문·표준을 우선 배치하고, 작동 원리·구조·활용·한계·실무 구획에는 논문·책·표준·공식 문서를 우선 배치한다. 적절한 후보가 없으면 누락 상태를 유지한다.

## 통과 조건

수동 주장 검토를 시작할 수 있으려면 독립 출처 계열 3개, 1차 자료 후보 1개, 백과 계열 1개가 필요하고 모든 사실 구획에 하나 이상의 검토 후보가 있어야 한다. 이는 작성 완료 조건이 아니다. 실제 발행 전에는 사람이 각 주장과 원문을 대조하고 문장·구획 단위 인용을 확정해야 한다.

재검토 기한은 W0 정책에 따라 evergreen 730일, periodic 180일, fast-changing 60일로 계산한다.
