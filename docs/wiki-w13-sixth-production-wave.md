# W13 6차 백과 문서 생산 웨이브

## 목표

W13은 14개 분야에서 다음 우선순위 문서를 10개씩 새로 제작해 검토 완료 백과 문서를 분야별 55개, 누적 770개로 확장하는 단계다. W12까지 구축한 분류·출처·문장 단위 근거·렌더링 검증 체계를 유지하면서 에이전트, API, 생태계, 평가, 기초, 추론, LLM, 수학, 멀티모달, 신경망, 검색, 안전, 학습, 트랜스포머 분야를 균등하게 확장했다.

## 완료 범위

- 14개 분야에 신규 문서 140개를 제작했다.
- 검토 완료 백과 문서는 누적 770개이며, 모든 분야에 55개씩 균등하게 배치했다.
- 신규 문서마다 정의, 배경, 작동 원리, 구성 요소, 활용, 한계, 관련 개념, 적용 예시, 실무 검증, 참고 자료를 구성했다.
- W13 신규 문서는 10개의 재개 가능한 작업 묶음으로 관리한다.
- 미작성 후보 630개는 분야·우선순위·출처 조사 상태와 함께 다음 생산 대기열에 유지한다.

신규 문서의 정의와 작동 원리는 주제별로 별도 작성하고 논문, 표준, 공식 문서와 공개 백과 자료를 교차 연결했다. 문서 최소 길이, 구획별 설명량, 중복 문단, 한글·영문 표제, 출처 유형, 문장 단위 근거와 내부 링크를 자동 검증했다.

W0부터 W13까지의 전체 회귀 빌드에서 770개 백과 문서의 검토 완료 상태와 근거 앵커를 확인했다. 801개 정적 페이지에 포함된 내부 링크 참조 27,491건이 모두 유효했고, 기존 실습 자료는 별도 레슨 경로 없이 프롬프트 자료실의 1,173개 프롬프트로 통합된 상태를 유지했다.

## W14 제안

W14에서는 같은 기준으로 분야별 다음 우선순위 신규 문서 10개씩, 총 140개를 추가한다. 완료 시 누적 910개, 분야별 65개가 되며 1,400개 목표 가운데 490개가 다음 생산 후보로 남는다.
