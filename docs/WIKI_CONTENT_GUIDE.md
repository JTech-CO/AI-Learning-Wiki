# 백과 문서 작성·검토 기준

## 문서의 역할

백과 문서는 코스의 한 단계를 설명하기 위한 부속 자료가 아니라 독립적으로 읽을 수 있는 지식 단위다. 문서 하나만 열어도 용어의 정의, 원리, 관계, 적용 범위와 출처를 파악할 수 있어야 한다.

실습 절차, 미션, 복사 가능한 프롬프트는 백과 본문에 길게 반복하지 않는다. 필요한 경우 기존 실습 자료실이나 프롬프트 자료실로 연결한다.

## 필수 필드

- 한국어 표준 문서명
- 영문명과 약어·별칭
- 독립적으로 이해 가능한 한 문단 정의
- 개요, 핵심 원리, 관련 개념과 활용, 주의점
- 대분류
- 선행 개념과 관련 문서
- 최소 하나의 공식·1차 출처
- 문서 상태와 최근 검토일

## 링크 원칙

- 핵심 용어의 첫 등장은 `/wiki/{slug}/` 문서에 연결한다.
- 선행 개념은 이 문서를 읽기 전에 알아야 하는 지식만 지정한다.
- 관련 문서는 단순히 같은 태그가 아니라 의미 관계가 있는 문서를 지정한다.
- 코스는 `/wiki/` 문서만 참조하며 `/courses/`의 기존 Guide를 참조하지 않는다.
- 기존 Guide에서 핵심 백과 문서가 존재하는 개념은 자동으로 `/wiki/` 링크로 바뀐다.

## 출처와 최신성

- 논문, 표준, 공식 문서, 원저자의 공개 자료를 우선한다.
- 특정 제품의 가격·모델 순위·성능처럼 빠르게 변하는 값은 기준일을 기록한다.
- 안정적인 원리와 특정 구현의 동작을 구분한다.
- 출처가 없는 문서는 `reviewed`로 표시하지 않는다.

## 검증 명령

```bash
npm run wiki:validate
npm run wiki:test
npm run build
```

`wiki:validate`는 스키마, 별칭 충돌, 참조 대상과 코스 참조를 확인한다. `wiki:test`는 고립 문서, 그래프 단절, 대표 검색어 순위, 기존 Guide가 Wiki 코스에 들어갔는지를 검사한다.
