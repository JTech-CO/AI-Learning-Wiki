# W4 문장 단위 주장 검토 정책

## 목적

W3의 구획별 참고문헌 연결을 문장 단위 검토 원장으로 확장한다. 각 문장은 원문을 복사해 보관하지 않고 정규화된 SHA-256 해시로 잠근다. 본문이 바뀌면 해시 검증이 실패하므로 출처 대조 없이 기존 승인을 재사용할 수 없다.

## 문장 분류

- `source-supported`: 정의·작동 원리·한계처럼 외부 근거로 확인해야 하는 주장
- `provenance-note`: 외부 백과의 사용 범위와 문서 편집 원칙을 설명하는 문장
- `editorial-synthesis`: 여러 출처와 내부 개념 관계를 종합한 설명
- `editorial-guidance`: 예제·검증 절차·운영 체크리스트처럼 편집자가 구성한 실무 안내

모든 분류는 참고문헌 번호와 장·절 또는 문서 구획 위치를 가진다. `source-supported` 문장은 백과 자료만을 단독 근거로 사용할 수 없다.

## 승인 관문

1. W2의 출처 다양성·도달성 관문을 통과한다.
2. W3의 9개 사실 구획에 참고문헌 번호가 연결되어 있다.
3. 현재 본문의 모든 문장이 W4 원장에 존재하고 해시가 일치한다.
4. 모든 문장의 결정이 `accepted`이며 근거 위치가 유효하다.
5. 위 조건을 모두 만족한 문서만 W4의 `publicationReady`로 집계한다.

W4 원장은 일반 빌드 중 자동 갱신하지 않는다. 본문을 고친 뒤에는 출처를 다시 대조하고 명시적으로 원장을 새로 만들어야 한다.
